# SA1127: 泛型类型约束应各占一行

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

C# 代码文件中，类型或方法声明的泛型约束与声明位于同一行。

## 规则说明

包含泛型类型约束的一个或多个 `where` 子句与类型或方法声明本身位于同一行时，会违反此规则。

例如，以下代码会产生两处违规：

```csharp
private void Method<T, R>() where T : class where R : class, new()
{
}
```

以下代码不会产生任何违规：

```csharp
private void Method<T, R>()
    where T : class
    where R : class, new()
{
}
```

## 如何修复违规

将每个 `where` 子句移到独立的一行即可修复违规。

## 如何抑制违规

```csharp
#pragma warning disable SA1127 // Generic type constraints should be on their own line
private void Method<T>() where T : class
#pragma warning restore SA1127 // Generic type constraints should be on their own line
{
    // method body...
}
```
