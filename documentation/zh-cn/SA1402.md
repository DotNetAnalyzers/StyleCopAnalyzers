# SA1402: 文件只能包含一个类型

## 原因

C# 代码文件包含多个不同的类型。

## 规则说明

当 C# 文件包含多个类型时，会违反此规则。
为了提高代码库的长期可维护性，每个类型都应放在自己的文件中，文件名也应体现文件内的类型名称。

可以配置此规则影响哪些种类的类型。
默认情况下，允许将委托、枚举、结构和接口与类放在一起。

同一个分部类型的多个部分也可以放在同一个文件中。

使用 `file` 修饰符声明的文件本地类型不受此规则约束。

## 如何修复违规

要修复此违规情况，请将每个类型移到各自的文件中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1402:FileMayOnlyContainASingleType", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1402 // FileMayOnlyContainASingleType
#pragma warning restore SA1402 // FileMayOnlyContainASingleType
```
