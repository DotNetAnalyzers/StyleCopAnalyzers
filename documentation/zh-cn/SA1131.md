# SA1131: 使用易读的条件表达式

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

变量与字面量或常量值进行比较时，变量位于表达式右侧。

## 规则说明

代码将字面量或常量值与变量值进行比较，且变量位于表达式右侧时，会违反此规则。

例如，以下代码展示了一种常见情况：

```csharp
public void Method(string value)
{
    if (null == value) // SA1131
    {
        throw new ArgumentNullException(nameof(value));
    }
}
```

对此规则而言，*字面量或常量值*指以下任一项：

* 数值字面量，例如 `1`、`0.0f` 或 `5.0m`。
* 字符串字面量。
* `null`。
* `default(T)`（`T` 为任意类型）。
* 在编译时求值为常量的任何表达式。
* 对 `static readonly` 字段的引用，例如 `IntPtr.Zero`。
* 模式。

*变量值*指不被视为字面量或常量值的任何表达式。

*比较*指使用以下任一运算符的二元表达式。

* `==`
* `!=`
* `<`
* `>`
* `<=`
* `>=`

## 如何修复违规

交换比较运算中操作数的顺序即可修复违规。

## 如何抑制违规

```csharp
public void Method(string value)
{
#pragma warning disable SA1131 // Use readable conditions
    if (null == value)
#pragma warning restore SA1131 // Use readable conditions
    {
        throw new ArgumentNullException(nameof(value));
    }
}
```
