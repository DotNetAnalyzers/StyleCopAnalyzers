# SA1409: 删除不必要的代码

:warning: StyleCop Analyzers 有意未包含此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

C# 文件包含不必要的代码，删除这些代码不会改变代码的整体逻辑。

## 规则说明

当文件包含可以删除而不改变代码整体逻辑的代码时，会违反此规则。

例如，以下 try-catch 语句可以完全删除，因为 try 块和 catch 块都是空的。

```csharp
try
{
}
catch (Exception ex)
{
}
```

以下 try-finally 语句的 try 块中确实包含代码，但它没有任何 catch 块，且 finally 块为空。
因此，这个 try-finally 没有起到任何有用的作用，可以删除。

```csharp
try
{
    this.Method();
}
finally
{
}
```

最后一个示例是以下空的 unsafe 语句，它同样没有任何作用。

```csharp
unsafe
{
}
```

## 如何修复违规

要修复此规则的违规情况，请删除不必要的代码，或通过添加语句补全代码。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1409:RemoveUnnecessaryCode", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1409 // RemoveUnnecessaryCode
#pragma warning restore SA1409 // RemoveUnnecessaryCode
```
