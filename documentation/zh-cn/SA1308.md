# SA1308: 变量名称不应带有前缀

## 原因

C# 字段名称带有 *m_*、*s_* 或 *t_* 前缀。

## 规则说明

当字段名称带有 *m_*、*s_* 或 *t_* 前缀时，会违反此规则。

默认情况下，StyleCop 不允许使用下划线、*m_* 等标记类的本地字段，而倾向于使用 'this.' 前缀。
使用 'this.' 的优点在于，它同样适用于方法、属性等所有元素类型，而不仅仅是字段；无论使用哪种编辑器查看代码，都能立即识别对类成员的所有调用。
另一个优点是，它能快速、清楚地区分实例成员和不带此前缀的静态成员。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以前缀开头，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

## 如何修复违规

要修复此规则的违规情况，请删除字段名称开头的前缀，或者在合适时将该项放在 NativeMethods 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1308:VariableNamesMustNotBePrefixed", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1308 // VariableNamesMustNotBePrefixed
#pragma warning restore SA1308 // VariableNamesMustNotBePrefixed
```
