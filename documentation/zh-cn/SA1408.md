# SA1408: 条件表达式应明确运算优先级

## 原因

C# 语句中的复杂条件表达式省略了运算符周围的圆括号。

## 规则说明

C# 为条件运算符规定了优先级层次。
在 C# 中，可以将多个条件运算串联在一个语句中，而不为任何运算添加圆括号；此时，编译器会根据这些预先规定的规则自动确定运算顺序和优先级。
例如：

```csharp
if (x || y && z && a || b)
{
}
```

虽然这段代码是合法的，但其可读性和可维护性并不高。
要完全理解这段代码，开发者必须了解并理解 C# 的基本运算符优先级规则。

此规则要求开发者插入圆括号，显式说明运算符优先级，旨在提高这类代码的可读性和可维护性，并降低以后引入错误的风险。
例如，开发者可以将代码写成：

```csharp
if ((x || y) && z && (a || b))
{
}
```

或者：

```csharp
if (x || (y && z && a) || b)
{
}
```

此规则也将空合并运算符 (`??`) 视为条件运算符。由于它的优先级低于 `&&` 和 `||`，将它们混用而不加圆括号会产生诊断：

```csharp
if (myObject?.SomeValue ?? false && otherCondition)
{
}
```

添加圆括号以明确分组：

```csharp
if (myObject?.SomeValue ?? (false && otherCondition))
{
}
```

从 C# 9 引入模式组合符开始，`and` 和 `or` 模式按与 `&&` 和 `||` 相同的方式处理。
混用它们而不加圆括号会产生诊断，例如：

```csharp
if (value is > 0 and < 5 or 10)
{
}

if (value is (> 0 and < 5) or 10)
{
}
```

插入圆括号使代码的含义更明确、更容易理解，读者也无需对代码作出假设。

## 如何修复违规

在条件表达式中插入圆括号，明确运算的优先级。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1408:ConditionalExpressionsMustDeclarePrecedence", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1408 // ConditionalExpressionsMustDeclarePrecedence
#pragma warning restore SA1408 // ConditionalExpressionsMustDeclarePrecedence
```
