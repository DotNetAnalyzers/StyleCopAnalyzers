# SA1604: 元素的文档注释应有摘要

## 原因

C# 元素的 XML 文档注释缺少 `<summary>` 标记。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果元素的文档注释缺少 `<summary>` 标记，就会违反此规则。

对于此规则，具有顶层 `<exclude/>` 标记的元素即使可公开访问，也会被视为私有元素。
启用 `documentPrivateElements` 时（对于字段则是 `documentPrivateFields`），仍然需要摘要。
该标记可以直接出现在文档注释中，也可以出现在引入的文档中。
它不会禁用其他文档规则。

## 如何修复违规

为元素添加 `<summary>` 标记，并在其中填写元素的说明，即可修复此规则的违规。

以下示例展示了文档注释中没有摘要的类。

```csharp
/// <remarks>A remark.</remarks>
public class Customer
{
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1604:ElementDocumentationMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1604 // ElementDocumentationMustHaveSummary
#pragma warning restore SA1604 // ElementDocumentationMustHaveSummary
```
