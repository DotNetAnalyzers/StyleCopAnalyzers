# SA1317: 标识符应仅使用拉丁字母命名

## 原因

声明的标识符包含基本拉丁字母 `A`–`Z` 和 `a`–`z` 以外的字母。

## 规则说明

不同字母表中的字母可能看起来相同，因此很难发现意外的替换。
此规则检查命名空间的各个组成部分、类型和成员名称、参数和类型参数、局部变量、查询变量、标签以及显式指定的元组元素名称。
它检查声明，而不检查对标识符的引用。

限制仅适用于字母：数字、下划线以及 C# 允许的其他非字母字符不受影响。
带重音符号的拉丁字母（例如 `é`）不是基本拉丁字母，也会触发诊断。
检查名称之前，会移除 `@` 前缀并解码 Unicode 转义序列。
每个不允许的字母都会在标识符上产生一条诊断；消息中的位置是解码后名称中从零开始的 UTF-16 索引，不包括 `@` 前缀。

例如，名称 `ЕxаmplеClаss` 包含西里尔字母，因此以下声明违反此规则：

```csharp
public class ЕxаmplеClаss {}
```

以下声明不违反此规则：

```csharp
public class ExampleClass {}
```

## 如何修复违规

将不允许的字母替换为合适的基本拉丁字母。
由于无法可靠地确定预期的替换字母，因此不提供自动代码修复。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1317:IdentifierShouldBeNamedOnlyWithLatinLetters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1317 // Identifier should be named only with Latin letters
#pragma warning restore SA1317 // Identifier should be named only with Latin letters
```
