# SA1643: 析构函数的摘要文档应以标准文本开头

## 原因

C# 析构函数的 XML 文档注释没有包含正确的摘要文本。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果析构函数的文档注释中的 summary 标记没有以正确的文本开头，就会违反此规则。

此规则旨在统一析构函数的摘要文本。
析构函数的摘要应以“终结 {class name} 类的实例.”开头。
例如，以下示例展示了 Customer 类的析构函数。

```csharp
/// <summary>
/// Finalizes an instance of the Customer class.
/// </summary>
~Customer()
{
}
```

可以在摘要文本中嵌入其他标记。
例如：

```csharp
/// <summary>
/// Finalizes an instance of the <see cref="Customer"/> class.
/// </summary>
~Customer()
{
}
```

## 如何修复违规

按照上述说明编辑析构函数的摘要文本，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1643:DestructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
```
