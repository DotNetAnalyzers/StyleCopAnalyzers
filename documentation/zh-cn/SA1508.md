# SA1508: 右大括号之前不应有空行

## 原因

C# 元素、语句或表达式中的右大括号之前有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

当右大括号之前有空行时，会违反此规则。
例如：

```csharp
public bool Enabled
{
    get 
    { 
        return this.enabled; 

    }

}
```

上述代码会产生两处违规，因为有两处右大括号之前存在空行。

从 C# 8.0 开始，此规则也适用于 switch 表达式和属性模式中的右大括号。
如果大括号属于多行 switch 表达式分支列表或多行属性模式，其前面仍不得有空行。

## 如何修复违规

要修复此规则的违规情况，请删除右大括号之前的空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1508:ClosingBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1508 // ClosingBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1508 // ClosingBracesMustNotBePrecededByBlankLine
```
