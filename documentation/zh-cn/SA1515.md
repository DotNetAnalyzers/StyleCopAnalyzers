# SA1515: 单行注释之前应有空行

## 原因

C# 代码中的单行注释之前没有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

当单行注释之前没有空行时，会违反此规则。
例如：

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

上述代码会产生一处违规，因为单行注释之前没有空行。

此规则的一个例外是单行注释位于其作用域中的第一项的情况。
此时，注释之前不应有空行。
例如：

```csharp
public bool Enabled
{
    get 
    {
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

在上述代码中，注释是其作用域中的第一项，因此其前面不应有空行。

如果注释用于注释掉一行代码，请在注释开头使用四个正斜杠，而不是两个。
这样 StyleCop 就会忽略此违规。
例如：

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        ////return false;
        return this.enabled;  
    }
}
```

## 如何修复违规

要修复此规则的违规情况，请在注释上方添加空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1515:SingleLineCommentMustBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1515 // SingleLineCommentMustBePrecededByBlankLine
#pragma warning restore SA1515 // SingleLineCommentMustBePrecededByBlankLine
```
