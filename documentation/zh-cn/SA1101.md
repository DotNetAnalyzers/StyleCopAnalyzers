# SA1101: 当前类的成员调用应使用 this 前缀

## 原因

C# 代码文件中对当前类或基类实例成员的调用没有使用 'this.' 前缀。

## 规则说明

代码中对当前类或基类实例成员的调用没有使用 'this.' 前缀时，会违反此规则。
如果当前类重写了基类成员，并且代码有意绕过当前类的重写直接调用基类成员，则属于例外。
此时可以使用 'base.' 前缀而不是 'this.'。

默认情况下，StyleCop 不允许使用下划线或 *m_* 标记当前类的字段，而要求使用 'this.' 前缀。
使用 'this.' 的优点是它适用于方法、属性等所有元素类型，而不仅仅是字段；无论使用哪种编辑器查看代码，都能立即识别对类成员的调用。
另一个优点是能够快速区分实例成员和没有此前缀的静态成员。

使用 'this.' 前缀的最后一个优点是，输入 *this.* 会使 Visual Studio 显示 IntelliSense 弹出列表，方便开发者快速选择要调用的类成员。

使用属性模式时，包括 C# 10 引入的扩展属性模式语法，此规则不要求（也不允许）使用 `this.` 限定模式中引用的属性。
这些表达式引用的是被匹配值的成员，而不是包含它们的类型的成员。
例如，以下代码不会报告 SA1101 诊断：

```csharp
if (item is { Outer.Inner: value })
{
}
```

## 如何修复违规

在类成员调用前添加 'this.' 前缀即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1101:PrefixLocalCallsWithThis", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1101 // PrefixLocalCallsWithThis
#pragma warning restore SA1101 // PrefixLocalCallsWithThis
```
