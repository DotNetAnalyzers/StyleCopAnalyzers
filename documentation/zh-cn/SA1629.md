# SA1629: 文档文本应以句点结尾

## 原因

C# 元素的 XML 文档注释中的某个部分没有以句点（即英文句号）、感叹号或问号结尾。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果文档的某个部分没有以句点、感叹号或问号结尾，就会违反此规则。
例如，以下文档中的摘要文本没有以有效的标点符号结尾：

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

句点、感叹号或问号后面可以有结束引号（`"`、`'`、`”` 或 `’`），然后还可以有右圆括号，因此以 `."`、`!”` 或 `?)` 结尾的文本符合此规则。

## 如何修复违规

确保文档的所有部分都以句点、感叹号或问号结尾，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1629:DocumentationTextMustEndWithAPeriod", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1629 // DocumentationTextMustEndWithAPeriod
#pragma warning restore SA1629 // DocumentationTextMustEndWithAPeriod
```
