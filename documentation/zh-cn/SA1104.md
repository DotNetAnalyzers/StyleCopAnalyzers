# SA1104: 前一个查询子句跨多行时，下一个子句应另起一行

## 原因

C# 查询表达式中，前一个子句跨越多行，而下一个子句在前一个子句的结束行开始。

## 规则说明

查询子句跨越多行，而下一个子句在前一个子句的结束行开始时，会违反此规则。
例如：

```c#
    var elementNames =
        from element in GetElements
        (
            12,
			45
        ) select element.Name;
```

查询子句的正确写法如下：

```c#
    var elementNames =
        from element in GetElements
        (
            12,
			45
        )
		select element.Name;
```

## 如何修复违规

将子句下移，使其在下一行开始即可修复违规。

## 如何抑制违规

```c#
#pragma warning disable SA1104 // Query clause should begin on new line when previous clause spans multiple lines
    var elementNames =
        from element in GetElements
        (
            12,
			45
        ) select element.Name;
#pragma warning restore SA1104 // Query clause should begin on new line when previous clause spans multiple lines
```
