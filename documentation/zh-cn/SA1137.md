# SA1137: 元素应具有相同的缩进

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

两个各自另起一行的同级元素具有不同的缩进级别。

## 规则说明

两个或更多同级元素各自另起一行，但缩进量不同时，会违反此规则。

例如，以下代码会产生违规：

```csharp
public void MethodName()
{
    A();
   B(); // SA1137: Expected the indentation to match the previous line
}
```

以下代码不会产生任何违规：

```csharp
public void MethodName()
{
    A();
    B();
}
```

请注意，此规则不检查相对缩进，也不检查相互独立的同级元素组之间的缩进。
以下代码展示了不会产生任何违规的较复杂示例：

```csharp
public void Method1()
{
    A();
    B();
}

public void Method2()
{
        A();
        B();
}

public void Method3()
{
A();
B();
}

public void Method4()
    {
    A();
    B();
    }
```

### 特性

此规则将特性列表视为与其所应用元素处于同一级别的独立元素。
确定同级元素的预期缩进时，特性列表的优先级低于其他元素。
对于类型成员，由非特性列表元素中数量最多的缩进级别决定预期缩进。
如果多个缩进级别出现次数相同，则由第一个另起一行的非特性列表元素决定预期缩进。
对于其他分组，由第一个另起一行的非特性列表元素决定预期缩进。
如果不存在这样的元素，则使用第一个特性列表的缩进。
例如，以下代码展示了特性列表附近报告 SA1137 的位置。

```csharp
  [Obsolete]                // SA1137 (expected no indentation)
public void Method()        // OK (this line establishes indentation for the group)
{
}

  public Task MethodAsync() // SA1137 (expected no indentation)
    {                       // OK (not part of the analysis group)
    }
```

以下示例展示了*使用*特性列表的缩进来确定整组缩进的情况。

```csharp
public void Method(int x,   // Ignored (parameter does not start on its own line)
    [In] int y,             // OK (this line establishes indentation for the group)
      [In] int z)           // SA1137
{
}
```

### 标签

块语句内部的标签采用特殊的检查方式。
块中的每个标签都应具有相同的缩进，即使该缩进与块中语句的缩进不同。
此规则不检查标签相对于其他语句的具体缩进量。

以下示例展示了同时包含语句和标签的块。

```csharp
public int MethodName()
{
    int x;

  beginning:    // OK (label indentation may differ from other statements)
     x = 3;     // SA1137 (should be indented four spaces to match 'int x;' above)

end:            // SA1137 (should be indented two spaces to match 'beginning:' above)
    return x;
}
```

在 `switch` 语句内部，`case` 和 `default` 标签构成一个额外的类别。
此时的具体规则如下：

1. `switch` 语句中的 `case` 和 `default` 标签必须使用相同的缩进。
2. `switch` 语句中的其他标签必须使用相同的缩进（但可以与 `case` 标签的缩进不同）。
3. `switch` 语句中的语句必须使用相同的缩进（但可以与上述两类标签的缩进都不同）。

## 如何修复违规

调整同级元素的缩进，使其一致即可修复违规。

如果数组初始值设定项中缩进不一致的大括号各自另起一行，且左大括号没有缩进而包含该初始值设定项的表达式有缩进，则代码修复会将两个大括号与表达式对齐，并将元素再缩进一级，同时保留注释。
此代码修复行为不会改变规则所报告的违规。

## 如何抑制违规

```csharp
class TypeName { }

#pragma warning disable SA1137 // Elements should have the same indentation
  class Indented { }
#pragma warning restore SA1137 // Elements should have the same indentation
```
