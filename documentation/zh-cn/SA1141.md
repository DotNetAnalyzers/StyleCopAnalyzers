# SA1141: 使用元组语法

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

:memo: 此规则仅在 C# 7.0 及更高版本中启用。

## 原因

使用了 ValueTuple 类型声明，而不是推荐的元组语言构造。

## 规则说明

使用了 ValueTuple 类型声明，而不是推荐的元组语言构造。
有关如何在 C# 7 中使用元组的信息，请参阅[元组类型](https://docs.microsoft.com/en-us/dotnet/csharp/tuples)文档。

例如，以下代码会产生违规：

```csharp
ValueTuple<int, int> x; // SA1141
```

以下代码不会产生任何违规：

```csharp
(int, int) x;
```

## 如何修复违规

在代码中使用适当的元组类型而不是 ValueTuple 类型即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1141:UseTupleSyntax", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1141 // Use tuple syntax
#pragma warning restore SA1141 // Use tuple syntax
```
