# SA1209: using 别名指令应位于其他 using 指令之后

## 原因

using 别名指令位于普通 using 指令之前。

## 规则说明

当 using 别名指令位于普通 using 指令之前时，会违反此规则。
using 别名指令具有特殊行为，可能改变文件或命名空间中其余代码的含义。
将 using 别名指令集中放在所有其他 using 指令之后，可以使代码更整洁、更易读，也更容易识别代码中使用的类型。

全局 using 指令（C# 10）与本地 using 指令分开分析。
诊断和修复只比较都使用或都省略 `global` 修饰符的指令。

## 如何修复违规

要修复此违规情况，请将所有 using 别名指令放在所有普通 using 指令之后。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1209:UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1209 // UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives
#pragma warning restore SA1209 // UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives
```
