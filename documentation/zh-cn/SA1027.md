# SA1027: 正确使用制表符

## 原因

代码中包含不符合当前项目设置的制表符或空格字符。

## 规则说明

代码中包含不符合当前项目设置的制表符或空格字符时，会违反此规则。
默认情况下，StyleCop Analyzers 不允许代码中包含任何制表符。
有关如何通过 **stylecop.json** 更改此行为的信息，请参阅 [Configuration.md](Configuration.md)。

无论采用何种配置，一行中第一个非空白字符之后出现的制表符始终会触发此违规。
在这些位置使用制表符时，无法确保不同的制表符宽度不会改变代码布局。
有关详细信息，请参阅[问题 #2035](https://github.com/DotNetAnalyzers/StyleCopAnalyzers/issues/2035)。

### 默认行为

默认行为与 StyleCop Classic 一致，其依据如下。

> C# 代码中不应使用制表符，因为制表符的长度可能随查看代码所用的编辑器而变化。
> 这可能使代码的间距和缩进偏离开发者的原意，有时还会降低代码的可读性。
>
> 因此，不应使用制表符，每级缩进应由四个空格组成。
> 这样可以确保无论使用哪种编辑器查看，代码的外观都保持一致。

### 排除情况

为避免意外改变代码的行为，以下情况不会报告此违规。

* 字符串字面量，包括 C# 6 的内插字符串字面量。
* 字符字面量。
* 被注释掉的代码（以 `////` 开头的行注释），以确保其中的字面量不会被更改。
* 禁用的文本。

    ```csharp
    #if DEBUG
    This is ignored in release configurations
    #else
    This is ignored in debug configurations
    #endif
    ```

## 如何修复违规

按照项目设置使用空格或制表符缩进行，并避免在缩进之外使用制表符即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1027:TabsMustNotBeUsed", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1027 // TabsMustNotBeUsed
#pragma warning restore SA1027 // TabsMustNotBeUsed
```
