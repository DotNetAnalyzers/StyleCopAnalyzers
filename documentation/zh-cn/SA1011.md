# SA1011: 右方括号周围的空格应正确

## 原因

C# 语句中右方括号周围的空格不正确。

## 规则说明

右方括号周围的空格不正确时，会违反此规则。

右方括号前不得有空白字符，除非它是一行中的第一个字符。

右方括号后应有空白字符，但以下情况除外：

* 它是一行中的最后一个字符。
* 它后面是右括号或左圆括号。
* 它后面是逗号或分号。
* 它后面是字符串内插的对齐部分，例如：`$"{x[i]:C}"`。
* 它后面是字符串内插的格式部分，例如：`$"{x[i],3}"`。
* 它后面是特定类型的运算符。
* 它后面是数组的可为 null 引用类型批注，例如 `string[]? items`。
* 它后面是应用于数组或元素访问的 null 包容运算符，例如 `values[0]!`。
* 它位于函数指针的非托管调用约定列表中，后面紧接 `<`，例如 `delegate* unmanaged[Cdecl]<void>`。

## 如何修复违规

确保右方括号周围的空格符合上述规则即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1011:ClosingSquareBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1011 // ClosingSquareBracketsMustBeSpacedCorrectly
#pragma warning restore SA1011 // ClosingSquareBracketsMustBeSpacedCorrectly
```
