# SA1024: 冒号周围的空格应正确

## 原因

C# 元素中冒号周围的空格不正确。

## 规则说明

冒号周围的空格不正确时，会违反此规则。

冒号周围的间距取决于冒号的类型及其在代码中的用途。
元素声明中的冒号两侧应始终各有一个空格，除非它是一行中的第一个或最后一个字符。
例如，以下所有冒号都遵循此规则：

```csharp
public class Class2<T> : Class1 where T : MyType
{
    public Class2(int x) : base(x)
    {
    }
}
```

冒号位于标签或 case 语句末尾时，后面应始终有空白字符，或者它应是一行中的最后一个字符，但前面不得有空白字符。
例如：

```csharp
_label:
switch (x)
{
    case 2: 
        return x;
}
```

作为字符串内插格式部分使用的冒号前不应有空白字符。
例如：

```csharp
var s = $"{x:N}";
```

冒号出现在属性模式中时（包括通过扩展属性模式语法引用的嵌套成员），应将其视为命名元素分隔符。
冒号前不应有空白字符，后面通常应有一个空格。

```csharp
if (item is { Outer.Inner: value })
{
}
```

最后，冒号用于条件语句中时，两侧应始终各有一个空格，除非它是一行中的第一个或最后一个字符。
例如：

```csharp
int x = y ? 2 : 3;
```

## 如何修复违规

确保冒号周围的空格符合上述规则即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1024:ColonsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1024 // ColonsMustBeSpacedCorrectly
#pragma warning restore SA1024 // ColonsMustBeSpacedCorrectly
```
