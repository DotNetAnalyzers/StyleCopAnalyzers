# SA1212: 属性访问器应按顺序排列

## 原因

属性或索引器中的 get 访问器位于 set 或 init 访问器之后。

## 规则说明

当属性或索引器中的 get 访问器位于 set 或 init 访问器之后时，会违反此规则。
要遵循此规则，get 访问器应位于最前面。

例如，以下代码会触发此违规：

```csharp
public string Name
{ 
    set { this.name = value; }
    get { return this.name; }
}
```

以下代码不会触发此违规：

```csharp
public string Name
{ 
    get { return this.name; }
    set { this.name = value; }
}
```

### C# 8 只读访问器

结构中的只读成员不会改变排序要求。
`readonly` get 访问器仍需位于任何 `set` 或 `init` 访问器之前，才能满足此规则。

```csharp
public struct S
{
    public int Value
    {
        set => this.value = value;
        readonly get => this.value;
    }
}
```

上述属性违反 SA1212，因为只读 get 访问器位于 set 访问器之后。
将只读 get 访问器移到 set 访问器之前即可消除警告。

## 如何修复违规

要修复此违规情况，请将 get 访问器放在 set 访问器之前。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1212:PropertyAccessorsMustFollowOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1212 // PropertyAccessorsMustFollowOrder
#pragma warning restore SA1212 // PropertyAccessorsMustFollowOrder
```
