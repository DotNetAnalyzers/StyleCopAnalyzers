# SA1608: 元素的文档注释不应使用默认摘要

## 原因

元素的 XML 文档注释中的 `<summary>` 标记包含 Visual Studio 在创建元素时生成的默认文本。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

Visual Studio 提供辅助功能，可以向项目添加类等新元素。
Visual Studio 会为新类创建默认的文档注释，并填入默认的文档文本。

如果代码元素的 `<summary>` 标记仍然包含 Visual Studio 生成的默认文档文本，就会违反此规则。

## 如何修复违规

将默认文档文本替换为描述代码元素内容的新文本，即可修复此规则的违规。

以下示例展示了包含 Visual Studio 生成的默认摘要文本的类。

```csharp
/// <summary>
/// Summary description for the Example class.
/// </summary>
public class Example
{
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1608:ElementDocumentationMustNotHaveDefaultSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1608 // ElementDocumentationMustNotHaveDefaultSummary
#pragma warning restore SA1608 // ElementDocumentationMustNotHaveDefaultSummary
```
