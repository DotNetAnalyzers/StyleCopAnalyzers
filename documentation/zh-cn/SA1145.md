# SA1145：不要将赋值用作条件

## 原因

赋值表达式被用作条件，或用作逻辑运算符的操作数。
此规则默认启用，并在赋值表达式处报告警告。

## 规则说明

在条件中使用 `=` 代替 `==` 通常无法在 C# 中编译，但当被赋的值为 `bool` 时可以编译。
跳过所有括号后，如果赋值（简单赋值、复合赋值或 `??=`）的父级是以下之一，则此规则会报告它：

* 条件与（`&&`）、条件或（`||`）或逻辑非（`!`）运算符
* 条件（`?:`）表达式的条件
* `if`、`while`、`do`...`while` 或 `for` 语句的条件
* 异常筛选器（`when` 子句）

以下代码违反该规则：

```csharp
bool flag = false;
if (flag = Compute())
{
}

while (!(done = Step()))
{
}
```

与其他值比较的赋值不会被报告：

```csharp
string line;
while ((line = reader.ReadLine()) != null)
{
}
```

## 如何修复违规

将赋值替换为比较，或将赋值移到单独的语句中。

```csharp
bool flag = Compute();
if (flag)
{
}
```

## 如何抑制违规

```csharp
#pragma warning disable SA1145 // Do not use assignment as condition
// Code containing the violation.
#pragma warning restore SA1145 // Do not use assignment as condition
```
