# SA1618: 泛型类型参数应有文档注释

## 原因

C# 泛型元素缺少一个或多个泛型类型参数的文档注释。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果带有泛型类型参数的元素缺少一个或多个泛型类型参数的文档注释，就会违反此规则。

## 如何修复违规

为元素的每个泛型类型参数添加 <typeparam> 标记，或补全标记中的文档文本，即可修复此规则的违规。

以下示例展示了具有有效文档注释的方法：

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1618:GenericTypeParametersMustBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1618 // GenericTypeParametersMustBeDocumented
#pragma warning restore SA1618 // GenericTypeParametersMustBeDocumented
```
