# SA1125: 使用可为 null 类型的简写形式

## 原因

Nullable 类型没有使用 C# 简写形式定义。
例如，使用了 `Nullable<DateTime>`，而不是推荐的 `DateTime?`。

## 规则说明

Nullable 类型没有使用 C# 简写形式定义时，会违反此规则。

此规则仅适用于可为 null 值类型的语法。
在 `#nullable enable` 上下文中，`Nullable<int>` 或 `System.Nullable<DateTime>` 等长形式的值类型用法仍会报告 SA1125，应写为 `int?` 或 `DateTime?`。
`string?` 或 `T?` 等可为 null 引用类型批注不受此规则影响。

在 C# 12 及更高版本中，此规则也适用于 using 别名指令的目标：`using MyNullableInt = System.Nullable<int>;` 应写为 `using MyNullableInt = int?;`。
较早的语言版本不允许在该位置使用简写形式，因此此规则在这些版本中不报告 using 指令。

### 示例

```csharp
#nullable enable

// The following fields will report SA1125 and should use the shorthand form
private Nullable<int> count;
private System.Nullable<DateTime> timestamp;

// These nullable reference type annotations are valid and do not require changes for SA1125
private string? name;
private T? value;
```

## 如何修复违规

使用可为 null 类型的简写形式（例如 int?、DateTime? 等）即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1125:UseShorthandForNullableTypes", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1125 // UseShorthandForNullableTypes
#pragma warning restore SA1125 // UseShorthandForNullableTypes
```
