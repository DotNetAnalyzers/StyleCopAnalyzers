# SA1500: 多行语句的大括号不应与其他内容共用一行

## 原因

C# 语句、元素或表达式中的左大括号或右大括号未独占一行。

> :memo: 此规则的行为可能随 **stylecop.json** 中 `allowDoWhileOnClosingBrace` 属性的配置而变化。
> 有关详细信息，请参阅 [Configuration.md](Configuration.md#layout-rules)。

## 规则说明

当语句、元素或表达式中的左大括号或右大括号未独占一行时，会违反此规则。
例如：

```csharp
public object Method()
{
    lock (this) {
        return this.value;
    }
}
```

StyleCop 检查这段代码时，会报告此规则的违规，因为 lock 语句的左大括号与 lock 关键字位于同一行，而没有像下面这样独占一行：

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value;
    }
}
```

如果右大括号与其他代码共用一行，也会产生违规。
例如：

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value; }
}
```

从 C# 8.0 开始，此规则也适用于 switch 表达式和属性模式引入的大括号。
当分支或模式内容跨多行书写时，switch 表达式或属性模式的 `{` 和 `}` 必须分别独占一行。

## 如何修复违规

要修复此规则的违规情况，请确保左大括号和右大括号分别独占一行，除注释外，不与任何其他代码共用一行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1500:BracesForMultiLineStatementsMustNotShareLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1500 // BracesForMultiLineStatementsMustNotShareLine
#pragma warning restore SA1500 // BracesForMultiLineStatementsMustNotShareLine
```
