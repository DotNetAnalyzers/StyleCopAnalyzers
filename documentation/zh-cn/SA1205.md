# SA1205: 分部元素应声明访问级别

## 原因

分部元素未定义访问修饰符。

## 规则说明

当分部元素未定义访问修饰符时，会违反此规则。

### C# 9 中的分部方法

C# 9 允许分部方法具有访问修饰符和非 `void` 返回类型。
为保持跨版本兼容，SA1205 不要求包含这些访问修饰符。
此外，使用这些新功能时，编译器会强制要求访问修饰符，因此在省略必需的修饰符时，SA1205 不会报告重复的诊断。

### C# 11 中的文件本地类型

`file` 类型仅在其所在文件内部可见，不能同时声明 `public`、`internal`、`protected` 或 `private`。
SA1205 将 `file` 视为分部类型的访问修饰符，因此不会对 `file partial class` 报告诊断。

## 如何修复违规

要修复此违规情况，请为分部元素指定访问修饰符。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1205:PartialElementsMustDeclareAccess", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1205 // PartialElementsMustDeclareAccess
#pragma warning restore SA1205 // PartialElementsMustDeclareAccess
```
