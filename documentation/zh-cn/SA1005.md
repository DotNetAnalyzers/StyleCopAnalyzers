# SA1005: 单行注释应以一个空格开头

## 原因

C# 代码文件中的单行注释没有以一个空格开头。

## 规则说明

单行注释没有以一个空格开头时，会违反此规则。
例如：

```csharp
private void Method1()
{
    //A single-line comment.
    //   A single-line comment.
}
```

注释应在开头的正斜杠后添加一个空格：

```csharp
private void Method1()
{
    // A single-line comment.
    // A single-line comment.
}
```

使用注释来注释掉一行代码时属于例外。
此时，如果注释以四个正斜杠开头以表明这是被注释掉的代码，则可以省略空格。
例如：

```csharp
private void Method1()
{
    ////int x = 2;
    ////return x;
}
```

以两个或更多短划线（`//--`）、反斜杠（`//\`）或 .NET 模板引擎处理指令（`//-:cnd` 或 `//+:cnd`，例如 `//-:cnd:noEmit`）开头的注释也不会触发此规则。

## 如何修复违规

确保注释以一个空格开头即可修复违规。
如果注释用于注释掉一行代码，请确保它以四个正斜杠开头，此时可以省略开头的空格。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1005:SingleLineCommentsMustBeginWithSingleSpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1005 // SingleLineCommentsMustBeginWithSingleSpace
#pragma warning restore SA1005 // SingleLineCommentsMustBeginWithSingleSpace
```
