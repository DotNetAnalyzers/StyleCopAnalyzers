# SA1208: System 的 using 指令应位于其他 using 指令之前

## 原因

在 C# 代码文件中，声明 *System* 命名空间成员的 using 指令位于声明其他命名空间成员的 using 指令之后。

## 规则说明

当 *System* 命名空间的 using 指令位于非 *System* 的 using 指令之后时，会违反此规则。
将所有 *System* 的 using 指令放在 using 指令列表的顶部，可以使代码更整洁、更易读，也更容易识别代码所使用的命名空间。

此规则仅在 `systemUsingDirectivesFirst` 为 `true` 时适用，这是默认值（参阅 [Configuration.md](Configuration.md#using-directives)）。

全局 using 指令（C# 10）与本地 using 指令分开分析。
诊断和修复只比较都使用或都省略 `global` 修饰符的指令。

## 如何修复违规

要修复此违规情况，请将 *System* 的 using 指令放在所有其他命名空间的 using 指令之前。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1208:SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
#pragma warning restore SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
```
