# SA1516: 元素之间应用空行分隔

## 原因

相邻的 C# 元素之间没有用空行分隔。

> :memo: 此规则的行为可能随 **stylecop.json** 中 `blankLinesBetweenUsingGroups` 属性的配置而变化。
> 有关详细信息，请参阅 [Configuration.md](Configuration.md)。

> :memo: 全局 using 指令（C# 10）被视为单独的一组 using 指令组。
> 当 `blankLinesBetweenUsingGroups` 要求分隔时，除了每组 using 指令内部通常要求的间距之外，此规则还要求在全局 using 块与后续的命名空间级 using 指令或顶级语句之间保留空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

当两个相邻元素之间没有用空行分隔时，会违反此规则。
例如：

```csharp
public void Method1()
{
}
public bool Property
{
    get { return true; }
}
```

在上述示例中，方法与属性之间没有用空行分隔，因此会违反此规则。

```csharp
public event EventHandler SomeEvent
{
    add
    {
        // add event subscriber here
    }
    remove
    {
        // remove event subscriber here
    }
}
```

在上述示例中，事件的 add 和 remove 访问器之间需要用空行分隔，因为 add 访问器跨多行书写。

使用 C# 10 文件范围命名空间时，`namespace` 声明之后、任何 `using`、`extern alias` 或类型声明之前应有空行。

## 如何修复违规

要修复此规则的违规情况，请在相邻元素之间添加空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1516:ElementsMustBeSeparatedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1516 // ElementsMustBeSeparatedByBlankLine
#pragma warning restore SA1516 // ElementsMustBeSeparatedByBlankLine
```
