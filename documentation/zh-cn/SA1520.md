# SA1520: 一致地使用大括号

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

相互链接的 `if`/`else if`/`else` 结构中，有些分支包含左大括号和右大括号，而其他分支省略了大括号。

## 规则说明

当相互链接的语句中有些分支包含左大括号和右大括号，而其他分支省略大括号时，会违反此规则。
在 C# 中，某些类型的语句可以选择是否包含大括号。
例如，`if` 语句可以采用不一致的大括号用法：

```csharp
if (true)
    return this.value;
else
{
    return that.value.
}
```

虽然这在 C# 中是合法的，但为了提高代码的可读性和可维护性，StyleCop 要求：只要相互链接的 `if`/`else if`/`else` 结构中任意一个分支包含大括号，所有分支就都必须包含大括号。

## 如何修复违规

修复此规则的违规情况时，会将违规语句转换为块语句。

## 如何抑制违规

```csharp
if (true)
#pragma warning disable SA1520 // Use braces consistently
    return this.value;
#pragma warning restore SA1520 // Use braces consistently
else
{
    return that.value.
}
```
