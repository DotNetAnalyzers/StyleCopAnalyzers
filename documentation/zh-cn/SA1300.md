# SA1300: 元素应以大写字母开头

## 原因

C# 元素的名称未以大写字母开头。

## 规则说明

当某些类型的元素名称未以大写字母开头时，会违反此规则。
以下类型的元素名称应以大写字母作为首字母：

* 命名空间
* 类
* 枚举
* 枚举成员
* 结构
* 委托
* 事件
* 方法
* 属性
* 本地函数（包括静态本地函数）

此外，任何公共字段、内部字段或使用 const 修饰符的字段都应以大写字母开头。
非私有只读字段的名称也应以大写字母开头。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以小写字母开头，请将该字段或变量放在特殊的 `NativeMethods` 类中。
`NativeMethods` 类是名称以 `NativeMethods` 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 `NativeMethods` 类中，StyleCop 会忽略此违规。

对于因品牌命名或其他原因而以小写字母开头的命名空间组成部分，请将相应的名称添加到 `allowedNamespaceComponents` 列表中。

## 如何修复违规

要修复此规则的违规情况，请将元素名称改为以大写字母开头；如果合适，也可以将该项放在 `NativeMethods` 类中；如果它是命名空间的组成部分，则可以将它添加到 `allowedNamespaceComponents` 列表中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1300:ElementMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1300 // ElementMustBeginWithUpperCaseLetter
#pragma warning restore SA1300 // ElementMustBeginWithUpperCaseLetter
```
