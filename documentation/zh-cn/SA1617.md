# SA1617: 不应为 void 返回值编写文档注释

## 原因

C# 代码元素没有返回值，或者返回 void，但其文档注释包含 `<returns>` 标记。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果返回 void 的元素在文档注释中包含 `<returns>` 标记，就会违反此规则。

## 如何修复违规

从元素的文档注释中删除 `<returns>` 标记，即可修复此规则的违规。

以下示例展示了具有有效文档注释的方法：

```csharp
/// <summary>
/// Prints the given name.
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
public void PrintNames(string firstName, string lastName)
{
    Console.WriteLine(firstName + " " + lastName);
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1617:VoidReturnValueMustNotBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1617 // VoidReturnValueMustNotBeDocumented
#pragma warning restore SA1617 // VoidReturnValueMustNotBeDocumented
```
