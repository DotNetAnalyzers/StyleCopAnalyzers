# SA1122: 使用 string.Empty 表示空字符串

## 原因

C# 代码中使用 `""` 表示空字符串。

## 规则说明

代码中包含空字符串时，会违反此规则。
例如：

```csharp
string s = "";
```

这会使编译器将空字符串嵌入编译后的代码中。
应使用静态的 string.Empty 属性，而不是硬编码空字符串：

```csharp
string s = string.Empty;
```

各种形式的空字符串字面量都会被报告，包括逐字字符串、内插字符串和原始字符串：

```csharp
string s1 = @"";
string s2 = $"";
string s3 = @$"";
string s4 = """

    """;
string s5 = $"""

    """;
```

仅当内插字符串完全没有内容时才会报告，因此不会报告 `$"{value}"` 和 `$"text"`。
空内插字符串转换为 `FormattableString`、`IFormattable` 或内插字符串处理程序类型时也不会报告，因为 `string.Empty` 不能转换为这些类型。

不会报告 `""u8` 等 UTF-8 字符串字面量，因为它们是 `ReadOnlySpan<byte>` 而不是字符串。

语言要求使用常量的位置不会报告违规，无论字符串采用何种形式，因为 `string.Empty` 是静态只读字段，而不是常量，不能用于替代。
这些位置包括特性实参、`case` 标签、常量模式、默认参数值以及 `const` 字段和局部变量。

## 如何修复违规

将硬编码的空字符串替换为 string.Empty 即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1122:UseStringEmptyForEmptyStrings", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1122 // UseStringEmptyForEmptyStrings
#pragma warning restore SA1122 // UseStringEmptyForEmptyStrings
```
