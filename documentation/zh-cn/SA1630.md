# SA1630: 文档文本应包含空白字符

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

C# 元素的 XML 文档注释中的某个部分在词与词之间没有任何空白字符。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果文档的某个部分在词与词之间没有任何空白字符，就会违反此规则。
这可能意味着文档内容或格式不佳。
例如：

```csharp
/// <summary>
/// Joinsnames
/// </summary>
/// <param name="firstName">First</param>
/// <param name="lastName">Last</param>
/// <returns>Name</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

## 如何修复违规

确保文档的每个部分在词与词之间至少有一处空白字符，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1630:DocumentationTextMustContainWhitespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1630 // DocumentationTextMustContainWhitespace
#pragma warning restore SA1630 // DocumentationTextMustContainWhitespace
```
