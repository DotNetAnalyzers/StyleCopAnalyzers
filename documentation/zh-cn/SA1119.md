# SA1119: 语句不应使用不必要的圆括号

## 原因

C# 语句包含不必要的圆括号，应将其删除。

## 规则说明

C# 允许在几乎任何类型的表达式、语句或子句周围添加圆括号，而且在许多情况下，圆括号能显著提高代码的可读性。
但是，过度使用圆括号会适得其反，使代码更难阅读和维护。

在没有实际价值的情况下使用圆括号时，会违反此规则。
通常，这指的是不严格需要圆括号的表达式被圆括号包围，并且该带括号表达式位于语句的根部。
例如，以下各行代码都包含不必要的圆括号，会违反此规则：

```csharp
int x = (5 + b);
string y = (this.Method()).ToString();
return (x.Value);
```

这些语句中的多余圆括号都可以删除，而不会降低代码的可读性：

```csharp
int x = 5 + b;
string y = this.Method().ToString();
return x.Value;
```

从 C# 8.0 开始，switch 表达式或模式匹配表达式参与其他运算时，可能需要使用圆括号，例如强制转换、`await`、条件访问、元素访问、成员访问或逻辑求反。
SA1119 不会报告保证正确性所必需的圆括号，但仍会标记纯粹冗余的圆括号，例如 `return (value switch { ... });` 或 `var flag = (input is { Length: 1 });`。

## 如何修复违规

删除不必要的圆括号即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1119:StatementMustNotUseUnnecessaryParenthesis", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1119 // StatementMustNotUseUnnecessaryParenthesis
#pragma warning restore SA1119 // StatementMustNotUseUnnecessaryParenthesis
```
