# SA1210: using 指令应按命名空间的字母顺序排列

## 原因

C# 代码文件中的 using 指令未按命名空间的字母顺序排列。

## 规则说明

当 using 指令未按命名空间的字母顺序排列时，会违反此规则。
按字母顺序排列 using 指令，可以使代码更整洁、更易读，也更容易识别代码所使用的命名空间。
默认情况下，System 命名空间是此规则的例外，应位于所有其他命名空间之前。
有关详细信息，请参阅 SA1208。
可以将 `systemUsingDirectivesFirst` 设置为 `false` 来关闭此例外（参阅 [Configuration.md](Configuration.md#using-directives)），此时 System 命名空间会与所有其他命名空间一起按字母顺序排列。

全局 using 指令（C# 10）与本地 using 指令分开分析。
诊断和修复只比较都使用或都省略 `global` 修饰符的指令。

## 如何修复违规

要修复此违规情况，请按命名空间的字母顺序排列 using 指令；除非 `systemUsingDirectivesFirst` 为 `false`，否则应将所有 System 命名空间条目放在最前面。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1210:UsingDirectivesMustBeOrderedAlphabeticallyByNamespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
#pragma warning restore SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
```
