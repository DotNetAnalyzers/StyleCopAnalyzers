# SA1636: 文件头的版权文本应与配置匹配

## 原因

C# 代码文件顶部的文件头没有包含正确的版权文本。

## 规则说明

如果 C# 文件顶部的文件头没有包含为项目指定的版权文本，就会违反此规则。

要启用此规则，必须指定 `copyrightText` 属性。
有关设置方法的详细信息，请参阅[配置](Configuration.md)部分。

`xmlHeader` 属性的值会影响此规则的行为。
当 `xmlHeader` 属性为 **true** 时（默认值），StyleCop Analyzers 要求文件头符合以下标准 StyleCop 格式。

```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

当 `xmlHeader` 属性显式设为 **false** 时，StyleCop Analyzers 要求文件头符合以下可自定义的格式。

```csharp
// {copyrightText}
```

配置这些设置后，项目中的每个文件都应按上述格式包含所需的版权文本。

### 注释样式

此规则接受多种注释样式。
以下示例概述了支持的样式。

`xmlHeader` 属性设为 **true** 时的示例：

```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

```csharp
// ----------------------------------------------------------------------
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
// ----------------------------------------------------------------------
```

```csharp
/* <copyright file="{fileName}" company="{companyName}">
 * {copyrightText}
 * </copyright>
 */
```

```csharp
/*
  <copyright file="{fileName}" company="{companyName}">
  {copyrightText}
  </copyright>
*/
```

`xmlHeader` 属性设为 **false** 时的示例：

```csharp
// {copyrightText}
```

```csharp
/* {copyrightText} */
```

```csharp
/*
 * {copyrightText}
 */
```

```csharp
/*
  {copyrightText}
*/
```

## 如何修复违规

在文件头的 copyright 标记中添加公司的标准版权文本，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1636:FileHeaderCopyrightTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1636 // FileHeaderCopyrightTextMustMatch
#pragma warning restore SA1636 // FileHeaderCopyrightTextMustMatch
```
