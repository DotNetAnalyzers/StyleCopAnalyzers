# SA1647: include 节点未包含有效的 file 和 path 属性

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

XML 文档注释中的 include 标记没有有效的 file 和 path 属性。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments.](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

除了直接在代码文件中编写文档，还可以将多个元素的文档放在单独的 XML 文件中，然后在元素的文档注释中引用该文件的某个部分。
编译器会从引入的文档中导入该元素的文档。
例如：

```csharp
/// <include file="IncludedDocumentation.xml" path="root/EnabledMethodDocs" />
public bool Enabled(bool true)
{
}
```

如果 include 标记缺少 file 或 path 属性，或者这些属性的格式不正确，就会违反此规则。

## 如何修复违规

添加或修正 file 和 path 属性，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1647:IncludeNodeDoesNotContainValidFileAndPath", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1647 // IncludeNodeDoesNotContainValidFileAndPath
#pragma warning restore SA1647 // IncludeNodeDoesNotContainValidFileAndPath
```
