# SA0002: 设置文件无效

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

由于反序列化错误，无法加载 **stylecop.json** 设置文件，或者配置的成员种类顺序包含无效值。

## 规则说明

此规则报告无法加载 StyleCop Analyzers 设置文件的情况。
发生这种情况时，各分析器会自动回退到默认设置，而这些默认设置可能不符合用户的预期。

此规则还会报告通过 **.editorconfig** 或 **.globalconfig** 提供的 `stylecop.ordering.memberKindOrder` 中无法识别的值或重复值。

## 如何修复违规

要修复此规则的违规，请先检查以下事项：

* 确保 <em>stylecop.json</em> 包含有效的 JSON 语法。
  可在 Visual Studio 2015 中打开此文件，检查常见错误（IDE 会在“错误”窗口中报告这些错误）。
* 查看[配置](Configuration.md)文档，确保 <em>stylecop.json</em> 的内容包含有效设置。
* 检查配置的[成员种类顺序](Configuration.md#member-kind-order)是否仅包含受支持且唯一的种类。

## 如何抑制违规

只能通过在项目的 **ruleset** 文件中禁用此警告来抑制它。
