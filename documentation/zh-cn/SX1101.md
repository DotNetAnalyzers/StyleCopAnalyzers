# SX1101: 当前类的成员调用不应使用 'this.' 前缀

## 原因

对当前类或基类实例成员的调用使用了 `this.` 前缀。

## 规则说明

代码中对当前类或基类实例成员的调用使用了 `this.` 前缀时，会违反此规则。
如果方法参数的名称与 `this.` 前缀后的标识符冲突，则属于例外，不会报告违规。
此规则默认禁用。
启用此规则时，应禁用 [SA1101](SA1101.md) 规则。

## 如何修复违规

删除类成员调用前的 'this.' 前缀即可修复违规。

## 如何抑制违规

```csharp
#pragma warning disable SX1101 // DoNotPrefixLocalMembersWithThis
#pragma warning restore SX1101 // DoNotPrefixLocalMembersWithThis
```
