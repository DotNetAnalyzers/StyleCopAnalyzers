# SA1316: 元组元素名称应使用正确的大小写

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

:memo: 此规则仅在 C# 7.0 及更高版本中生效。

## 原因

元组类型中的元素名称应使用正确的大小写。

## 规则说明

具有元素名称的元组类型应采用配置指定的元素名称大小写形式（有关详细信息，请参阅 [Configuration.md](Configuration.md)）。
有关如何在 C# 7 中使用元组的信息，请参阅[元组类型](https://docs.microsoft.com/en-us/dotnet/csharp/tuples)文档。

例如，在默认设置下，以下代码会违反此规则：

```csharp
public class ExampleClass
{
  public (int valueA, int valueB) ExampleMethod() // SA1316
  {
  }
}
```

以下代码不会产生任何违规：

```csharp
public class ExampleClass
{
  public (int ValueA, int ValueB) ExampleMethod()
  {
  }
}
```

元组表达式中显式指定的元素名称（如 `(valueA: 1, valueB: 2)`）也按相同方式检查。
从表达式推断出的元素名称（如 `(valueA, valueB)`）仅在启用 `includeInferredTupleElementNames` 时检查（参阅 [Configuration.md](Configuration.md)）。

## 如何修复违规

要修复此规则的违规情况，请修正元组元素名称的大小写。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1316:TupleElementNamesShouldUseCorrectCasing", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1316 // Tuple element names should use correct casing
#pragma warning restore SA1316 // Tuple element names should use correct casing
```
