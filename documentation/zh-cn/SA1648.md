# SA1648: inheritdoc 应用于具有继承关系的类

## 原因

在既不继承基类也不实现接口的元素上使用了 `<inheritdoc>`。

## 规则说明

此规则检查未继承基类或接口的类或接口是否使用了 `<inheritdoc>` 元素。
如果包含 `<inheritdoc>` 元素的代码元素既不继承基类也不实现接口，就会违反此规则。

只要 `<inheritdoc/>` 元素包含 `cref` 属性，指定要从哪个目标元素继承文档，就始终允许使用它。

## 如何修复违规

删除 `<inheritdoc>` 元素，并为代码元素编写适当的文档，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1648:InheritDocMustBeUsedWithInheritingClass", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1648 // InheritDocMustBeUsedWithInheritingClass
#pragma warning restore SA1648 // InheritDocMustBeUsedWithInheritingClass
```
