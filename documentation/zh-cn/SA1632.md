# SA1632: 文档文本应满足最少字符数要求

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

从 StyleCop 4.5 开始，此规则默认禁用。

C# 元素的 XML 文档注释中的某个部分过短。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果文档的某个部分过短，就会违反此规则。
这通常意味着文档没有充分描述相关内容。
例如：

```csharp
/// <summary>
/// A name
/// </summary>
public class Name
{
    ...
}
```

## 如何修复违规

使用符合语法且具有描述性的语言重写文档文本，即可修复此规则的违规。
在大多数情况下，这样做会使文档文本的长度超过触发此规则的最小长度。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1632:DocumentationTextMustMeetMinimumCharacterLength", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1632 // DocumentationTextMustMeetMinimumCharacterLength
#pragma warning restore SA1632 // DocumentationTextMustMeetMinimumCharacterLength
```
