# SA1625: 元素文档不应包含重复条目

## 原因

C# 元素的 XML 文档包含两个或更多相同的条目。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果元素包含两个或更多相同的文档文本，就会违反此规则。
例如：

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">Part of the name.</param>
/// <param name="lastName">Part of the name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

在某些情况下，方法可能有一个或多个参数未在方法体内使用。
此时可以将参数文档设为 `此参数未使用.`。
只要文档字符串是 `此参数未使用.`，StyleCop 就允许多个参数包含相同的文档。

## 如何修复违规

编辑元素的文档，确保各个文档文本都不相同，即可修复此规则的违规。
例如：

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1625:ElementDocumentationMustNotBeDuplicated", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1625 // ElementDocumentationMustNotBeDuplicated
#pragma warning restore SA1625 // ElementDocumentationMustNotBeDuplicated
```
