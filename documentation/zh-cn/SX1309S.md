# SX1309S: 静态字段名称应以下划线开头

## 替代规则

此规则是对 StyleCop 默认行为的非标准扩展，代表某些项目采用的另一种风格。
替代规则已知会与标准 StyleCop 规则直接冲突。

## 原因

静态字段名称未以下划线开头。

## 规则说明

当静态字段名称未以下划线开头时，会违反此规则。

### 详细行为

此规则仅检查既不是 `const` 也不是 `readonly` 的私有静态字段名称。
静态 `readonly` 字段被视为常量，因而会被忽略。
此规则不分析 C# 8 的 `readonly` 结构成员（方法、属性、索引器）。

## 如何修复违规

要修复此违规情况，请为字段名称添加下划线（`_`）前缀。

## 如何抑制违规

```csharp
#pragma warning disable SX1309S // Static field names should begin with underscore
static int bar;
#pragma warning restore SX1309S // Static field names should begin with underscore
```
