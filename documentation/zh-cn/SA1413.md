# SA1413: 在多行初始值设定项和列表中使用尾随逗号

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

多行 C# 初始值设定项、枚举声明、switch 表达式、属性模式或集合表达式的最后一项缺少尾随逗号。

### 设计理由

此规则专门设计为与最常用的源代码管理系统良好配合，从而有助于长期的代码审查。
在多行序列的最后一行添加逗号后，开发者将来向列表追加条目或重新排序时，就无需修改超出该变更绝对必要范围的行。
因此，后续代码审查的范围更小、重点更明确，**git blame** 等工具也能继续为原先位于列表末尾的条目显示最初的作者和提交。

## 规则说明

当 C# 初始值设定项或列表中的最后一条语句缺少尾随逗号时，会违反此规则。

例如，以下代码会产生一处违规：

```csharp
var x = new Barnacle
{
    Age = 100,
    Height = 0.2M,
    Weight = 0.88M
};
```

以下代码不会产生任何违规：

```csharp
var x = new Barnacle
{
    Age = 100,
    Height = 0.2M,
    Weight = 0.88M,
};
```

此规则涵盖对象、集合、数组和 `with` 初始值设定项、匿名对象创建表达式以及枚举成员。
从 C# 8.0 开始，它也适用于 switch 表达式分支和多行属性模式中的子模式。
从 C# 12 开始，它还适用于多行集合表达式中的元素。
当这些内容跨多行书写时，请在最后一个分支、子模式或元素之后添加尾随逗号。

## 如何修复违规

要修复此规则的违规情况，请在初始值设定项的最后一条语句之后添加尾随逗号。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1413:UseTrailingCommasInMultiLineInitializers", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1413 // UseTrailingCommasInMultiLineInitializers
#pragma warning restore SA1413 // UseTrailingCommasInMultiLineInitializers
```
