# SA1118: 参数不应跨越多行

## 原因

C# 方法或索引器中除第一个参数以外的某个参数跨越多行。

## 规则说明

为了避免方法调用过于复杂而难以阅读，单个参数和实参应放在一行中。
第一个参数以外的参数跨越多行时，可能难以判断传给方法的参数数量。
总体而言，这会使代码难以阅读。
参数或实参跨越多行时，会报告此违规，但以下特定情况除外：

* 第一个参数可以跨越多行。
* 匿名方法（包括 lambda 表达式）可以跨越多行。
* 调用表达式可以跨越多行。
* 对象和数组创建表达式可以跨越多行。
* `with` 表达式（C# 9）可以跨越多行。

这些例外既适用于特性实参，也适用于方法和索引器实参。

例如，以下代码的第二个参数跨越多行，因此会违反此规则：

```csharp
return JoinStrings(
    "John",
    "Smith" + 
    " Doe");
```

要修复上述示例，请确保第一个参数之后的参数不跨越多行。
如果这会导致某个参数过长，请将其值存储在临时变量中。
例如：

```csharp
string last = "Smith" + 
    " Doe";

return JoinStrings(
    "John",
    last);
```

有时，这还能使方法调用更加简洁，例如：

```csharp
return JoinStrings("John", last);
```

## 如何修复违规

确保参数和实参不跨越多行（上述特定例外除外）即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1118:ParameterMustNotSpanMultipleLines", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1118 // ParameterMustNotSpanMultipleLines
#pragma warning restore SA1118 // ParameterMustNotSpanMultipleLines
```
