# SA1313: 参数名称应以小写字母开头

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

C# 参数的名称未以小写字母开头。

## 规则说明

当参数名称未以小写字母开头时，会违反此规则。

### 弃元

名为 `_` 和 `__` 的 lambda 参数是此规则的例外。
这些参数常用于表示占位参数，实际上并未在 lambda 表达式体中使用。

### 记录和主构造函数

位置记录参数会成为公共属性，因此即使这些参数出现在主构造函数签名中，也允许使用 PascalCase 名称。

### 互操作代码

如果参数名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以大写字母开头，请将该参数放在特殊的 `NativeMethods` 类中。
`NativeMethods` 类是名称以 `NativeMethods` 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 `NativeMethods` 类中，StyleCop 会忽略此违规。

## 如何修复违规

要修复此规则的违规情况，请将参数名称改为以小写字母开头，或者在合适时将该项放在 `NativeMethods` 类中。

## 如何抑制违规

```csharp
#pragma warning disable SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
void Method(int Parameter)
#pragma warning restore SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
{
}
```
