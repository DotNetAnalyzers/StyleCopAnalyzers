# SA1509: 左大括号之前不应有空行

## 原因

C# 元素、语句或表达式中的左大括号之前有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

通常，当左大括号之前有空行时，会违反此规则。
例如，以下代码会产生两处违规，因为有两处左大括号之前存在空行。

```csharp
public bool Enabled

{
    get

    {
        return this.enabled;
    }
}
```

此规则的一个例外是左大括号之前为右大括号的情况。
此时，[SA1513](SA1513.md) 要求使用空行。
以下示例展示了空行的正确用法：

```csharp
public bool Enabled
{
    get
    {
        {
        }

        {
            return this.enabled;
        }
    }
}
```

此规则也适用于 C# 8.0 switch 表达式和属性模式引入的左大括号。
即使在这些结构中，也不得在左大括号的紧前方放置空行。

## 如何修复违规

要修复此规则的违规情况，请删除左大括号之前的空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1509:OpeningBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1509 // OpeningBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1509 // OpeningBracesMustNotBePrecededByBlankLine
```
