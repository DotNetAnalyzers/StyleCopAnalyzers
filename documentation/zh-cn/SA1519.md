# SA1519: 多行子语句不应省略大括号

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

多行 C# 语句省略了左大括号和右大括号。

## 规则说明

当多行语句省略了左大括号和右大括号时，会违反此规则。
在 C# 中，某些类型的语句可以选择是否包含大括号，例如 `if`、`while` 和 `for` 语句。
例如，`if` 语句可以不使用大括号：

```csharp
if (true)
    return
        this.value;
```

虽然这在 C# 中是合法的，但当语句跨多行书写时，StyleCop 要求使用大括号，以提高代码的可读性和可维护性。

## 如何修复违规

修复此规则的违规情况时，会将违规语句转换为块语句。

## 如何抑制违规

```csharp
if (true)
#pragma warning disable SA1519 // Braces should not be omitted from multi-line child statement
    return
        this.value;
#pragma warning restore SA1519 // Braces should not be omitted from multi-line child statement
```
