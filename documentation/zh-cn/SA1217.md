# SA1217: using static 指令应按字母顺序排列

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

C# 代码文件中的 `using static` 指令未按完整类型名称的字母顺序排列。

## 规则说明

当 `using static` 指令未按完整类型名称的字母顺序排列时，会违反此规则。
按字母顺序排列 `using static` 指令，可以使代码更整洁、更易读。

默认情况下，System 命名空间中类型的 `using static` 指令应位于所有其他 `using static` 指令之前，这与 SA1210 优先排列 System 命名空间的方式相同。
例如，`using static System.Math;` 应位于 `using static Absolutes.Constants;` 之前。
如果要将所有 `using static` 指令统一按字母顺序排列，请将 `systemUsingDirectivesFirst` 设置为 `false`（参阅 [Configuration.md](Configuration.md#using-directives)）。

全局 using 指令（C# 10）与本地 using 指令分开分析。
诊断和修复只比较都使用或都省略 `global` 修饰符的指令。

## 如何修复违规

要修复此违规情况，请按完整类型名称的字母顺序排列 `using static` 指令。

## 如何抑制违规

```csharp
#pragma warning disable SA1217 // Using static directives should be ordered alphabetically
using static System.Math;
#pragma warning restore SA1217 // Using static directives should be ordered alphabetically
```
