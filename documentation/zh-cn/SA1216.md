# SA1216: using static 指令应放置在正确的位置

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

`using static` 指令的位置不正确（位于普通 using 指令之前或 using 别名指令之后）。

## 规则说明

当 using static 指令位于普通 using 指令之前或 using 别名指令之后时，会违反此规则。
将 using static 指令集中放在普通 using 指令之后、using 别名指令之前，可以使代码更整洁、更易读，也更容易识别代码中使用的静态成员。

全局 using 指令（C# 10）与本地 using 指令分开分析。
诊断和修复只比较都使用或都省略 `global` 修饰符的指令。

## 如何修复违规

要修复此违规情况，请将 `using static` 指令放在普通 using 指令之后、using 别名指令之前。

## 如何抑制违规

```csharp
#pragma warning disable SA1216 // Using static directives should be placed at the correct location
using static System.Math;
#pragma warning restore SA1216 // Using static directives should be placed at the correct location
```
