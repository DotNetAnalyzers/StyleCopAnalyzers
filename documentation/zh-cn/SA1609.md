# SA1609: 属性的文档注释应有值说明

## 原因

C# 属性的 XML 文档注释不包含 `<value>` 标记。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

属性的文档注释可以包含 `<value>` 标记，用来描述属性保存的值。

如果属性缺少 `<value>` 标记，就会违反此规则。

## 如何修复违规

在属性的文档注释中添加 `<value>` 标记并填写其内容，即可修复此规则的违规。

以下示例展示了文档注释中包含 `<value>` 标记的属性。

```csharp
/// <summary>
/// Gets the name of the customer. 
/// </summary>
/// <value>The name of the customer.</value>
public bool Name
{
    get { return this.name; }
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1609:PropertyDocumentationMustHaveValue", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1609 // PropertyDocumentationMustHaveValue
#pragma warning restore SA1609 // PropertyDocumentationMustHaveValue
```
