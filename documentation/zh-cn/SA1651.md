# SA1651: 不要使用占位符元素

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

元素的文档注释包含一个或多个 `<placeholder>` 元素。

## 规则说明

如果元素的文档注释包含 `<placeholder>` 元素，就会违反此规则：

```csharp
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
{
}
```

应审阅占位符元素，并将其从文档中移除。

## 如何修复违规

审阅占位符文档，确认其准确性，然后删除 `<placeholder>` 标记，即可修复此规则的违规。

## 如何抑制违规

```csharp
#pragma warning disable SA1651 // Do not use placeholder elements
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
#pragma warning restore SA1651 // Do not use placeholder elements
{
}
```
