# SA1309: 字段名称不应以下划线开头

## 原因

C# 字段名称以下划线开头。

## 规则说明

当字段名称以下划线开头时，会违反此规则。

默认情况下，StyleCop 不允许使用下划线、*m_* 等标记类的本地字段，而倾向于使用 'this.' 前缀。
使用 'this.' 的优点在于，它同样适用于方法、属性等所有元素类型，而不仅仅是字段；无论使用哪种编辑器查看代码，都能立即识别对类成员的所有调用。
另一个优点是，它能快速、清楚地区分实例成员和不带此前缀的静态成员。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以下划线开头，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

模式匹配引入的弃元指定（例如 C# 8 属性模式或位置模式中的 `_`）不受此规则约束。

## 如何修复违规

要修复此规则的违规情况，请删除字段名称开头的下划线，或者在合适时将该项放在 NativeMethods 类中。

如果新的字段名称与局部变量或参数冲突，代码修复会为受影响的引用添加限定：实例字段使用 `this.`，静态字段使用包含该字段的类型。
这也包括在 `out` 实参中内联声明的变量。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1309:FieldNamesMustNotBeginWithUnderscore", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1309 // FieldNamesMustNotBeginWithUnderscore
#pragma warning restore SA1309 // FieldNamesMustNotBeginWithUnderscore
```
