# SA1505: 左大括号之后不应有空行

## 原因

C# 元素、语句或表达式中的左大括号之后有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

当左大括号之后有空行时，会违反此规则。
例如：

```csharp
public bool Enabled
{

    get 
    { 

        return this.enabled; 
    }
}
```

上述代码会产生两处违规，因为有两处左大括号之后跟有空行。

## 如何修复违规

要修复此规则的违规情况，请删除左大括号之后的空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1505:OpeningBracesMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
#pragma warning restore SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
```
