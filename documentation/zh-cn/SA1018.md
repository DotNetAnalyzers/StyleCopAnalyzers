# SA1018: 可为 null 类型符号周围的空格应正确

## 原因

C# 元素中可为 null 类型符号周围的空格不正确。

## 规则说明

可为 null 类型符号周围的空格不正确时，会违反此规则。

可为 null 类型符号前不得有空白字符，除非它是一行中的第一个字符。

此规则适用于可为 null 值类型以及 C# 8 引入的可为 null 引用类型。
在 `#nullable enable` 上下文中，`string ? value` 或 `System.Collections.Generic.List<string?> ? list` 等代码会触发此规则。
正确的间距应省略 `?` 前的空白字符，例如 `string? value` 或 `System.Collections.Generic.List<string?>? list`。

## 如何修复违规

确保可为 null 类型符号前没有任何空白字符即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1018:NullableTypeSymbolsMustNotBePrecededBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
#pragma warning restore SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
```
