# SA1502: 元素不应写在一行中

## 原因

包含左大括号和右大括号的 C# 元素完全写在一行中。

## 规则说明

当用左大括号和右大括号包围的元素写在一行中时，会违反此规则。
例如：

```csharp
public object Method() { return null; }
```

StyleCop 检查这段代码时，会报告此规则的违规，因为整个方法写在一行中。
此方法应跨多行书写，左大括号和右大括号分别独占一行，如下所示：

```csharp
public object Method()
{
    return null; 
}
```

此规则有一个例外：属性、事件或索引器中的访问器，只要足够简短，就允许完整写在一行中。

## 如何修复违规

要修复此规则的违规情况，请重写元素，将其展开到多行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1502:ElementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1502 // ElementMustNotBeOnSingleLine
#pragma warning restore SA1502 // ElementMustNotBeOnSingleLine
```
