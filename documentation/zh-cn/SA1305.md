# SA1305: 字段名称不应使用匈牙利命名法

:bulb: 此规则默认禁用。

## 原因

C# 字段或变量的名称使用了匈牙利命名法。

## 规则说明

当字段和变量的命名使用匈牙利命名法时，会违反此规则。
匈牙利命名法在 C++ 代码中已广泛使用，但 C# 的趋势是使用更长、更具描述性的变量名称；这些名称不基于变量的类型，而是说明变量的用途。

此外，Visual Studio 等现代代码编辑器使变量或字段的类型信息很容易识别，通常只需将鼠标指针悬停在变量名称上即可。
这降低了使用匈牙利命名法的必要性。

StyleCop 会假定任何以一个或两个小写字母后接一个大写字母开头的变量名称使用了匈牙利命名法，并逐一报告此规则的违规。
可以将某些前缀声明为合法前缀，这样就会忽略它们。
例如，名为 *onExecute* 的变量在 StyleCop 看来使用了匈牙利命名法，但实际上并非如此。
因此，应将 *on* 前缀标记为允许的前缀。

要配置允许的前缀列表，请按以下方式使用 **stylecop.json**：

```json
{
  "settings": {
    "namingRules": {
      "allowedHungarianPrefixes": [ "aa", "bb" ],
    },
  }
}
```

将一个或两个字母组成的前缀添加到此列表后，StyleCop 就会忽略以该前缀开头的变量或字段。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须使用匈牙利命名法，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

## 如何修复违规

要修复此规则的违规情况，请移除字段或变量名称中的匈牙利命名法，或者在合适时将该项放在 NativeMethods 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1305:FieldNamesMustNotUseHungarianNotation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1305 // FieldNamesMustNotUseHungarianNotation
#pragma warning restore SA1305 // FieldNamesMustNotUseHungarianNotation
```
