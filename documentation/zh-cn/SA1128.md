# SA1128: 构造函数初始值设定项应独占一行

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

C# 代码文件中，构造函数初始值设定项与构造函数声明位于同一行。

## 规则说明

构造函数初始值设定项的一部分或全部与构造函数声明位于同一行时，会违反此规则。

例如，以下代码会产生违规：

```csharp
public class TypeName
{
    public TypeName() : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

`:`（冒号）被视为初始值设定项的一部分，应与 `base` 或 `this` 关键字位于同一行。

以下代码也会产生违规：

```csharp
public class TypeName
{
	public TypeName() :
		base()
	{
	}
}
```

以下代码不会产生任何违规：

```csharp
public class TypeName
{
    public TypeName()
        : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

## 如何修复违规

将构造函数初始值设定项（包括 `:` 字符）移到独立的一行即可修复违规。

## 如何抑制违规

```csharp
public class TypeName
{
#pragma warning disable SA1128 // Constructor initializers should be on their own line
    public TypeName() : this(0)
#pragma warning restore SA1128 // Constructor initializers should be on their own line
    {
    }

    public TypeName(int value)
    {
    }
}
```
