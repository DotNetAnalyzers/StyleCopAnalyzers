# SA1315: 参数名称应与继承的名称一致

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

重写基类方法或实现接口成员的方法，其参数名称与继承的参数名称不一致。

## 规则说明

重写基类方法时，参数名称应与被重写方法中声明的名称一致。实现接口成员时，参数名称应与该接口成员中声明
的名称一致。保持参数名称一致，可以确保调用方根据抽象契约使用命名实参时名称保持一致。

对于重写方法，直接基类中的方法决定预期的参数名称。对于接口实现，分析器接受与任何已实现且签名相同的接口
成员相匹配的名称。

## 如何修复违规

将参数重命名为对应的继承参数名称。如果实现对应多个继承名称，代码修复会提供可用的名称选项。

## 如何抑制违规

```csharp
#pragma warning disable SA1315 // ParametersShouldMatchInheritedNames
public override void Method(int differentName)
#pragma warning restore SA1315 // ParametersShouldMatchInheritedNames
{
}
```
