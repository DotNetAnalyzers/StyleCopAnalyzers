# SA1641: 文件头的公司名称文本应与配置匹配

## 原因

C# 代码文件顶部的文件头没有包含正确的公司名称文本。

## 规则说明

如果 C# 文件顶部的文件头没有包含为项目指定的公司名称文本，就会违反此规则。

要启用此规则，必须指定 `companyName` 属性。
此外，必须省略 `xmlHeader` 属性，或将其值设为 **true**。
有关设置方法的详细信息，请参阅[配置](Configuration.md)部分。

配置这些设置后，项目中的每个文件都应在文件头的 copyright 标记中包含所需的公司名称文本，如以下示例所示：

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## 如何修复违规

在文件头的 copyright 标记中添加公司的标准名称文本，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1641:FileHeaderCompanyNameTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1641 // FileHeaderCompanyNameTextMustMatch
#pragma warning restore SA1641 // FileHeaderCompanyNameTextMustMatch
```
