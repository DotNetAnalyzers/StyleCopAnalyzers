# SA1310: 字段名称不应包含下划线

## 原因

C# 字段名称包含下划线。

## 规则说明

当字段名称包含下划线时，会违反此规则。
字段和变量应采用具有描述性、易读的名称，说明字段或变量的用途。
这些名称通常采用驼峰式大小写，不应使用下划线。
例如，应使用 *customerPostCode*，而不是 *customer_post_code*。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须包含下划线，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

## 如何修复违规

要修复此规则的违规情况，请删除字段名称中的下划线，或者在合适时将该项放在 NativeMethods 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1310:FieldNamesMustNotContainUnderscore", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1310 // FieldNamesMustNotContainUnderscore
#pragma warning restore SA1310 // FieldNamesMustNotContainUnderscore
```
