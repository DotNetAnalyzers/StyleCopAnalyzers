# SA1207: protected 应位于 internal 之前

## 原因

在 protected internal C# 元素的声明中，关键字 *protected* 位于关键字 *internal* 之后，或者关键字 *private* 位于关键字 *protected* 之后。

## 规则说明

当 protected internal 元素的访问修饰符写成 *internal protected*，或者 private protected 元素的访问修饰符写成 *protected private* 时，会违反此规则。
实际上，使用关键字 *protected internal* 的元素与使用关键字 *internal protected* 的元素具有相同的访问级别。
为了使代码更易读且更一致，StyleCop 规范了这些关键字的顺序，使 protected internal 元素始终按这个顺序声明，而不写成 internal protected。
这有助于减少对这些访问级别是否相同的疑惑。

## 如何修复违规

要修复此违规情况，请将 *protected* 关键字放在 *internal* 关键字之前，或将 *private* 关键字放在 *protected* 关键字之前。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1207:ProtectedMustComeBeforeInternal", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1207 // ProtectedMustComeBeforeInternal
#pragma warning restore SA1207 // ProtectedMustComeBeforeInternal
```
