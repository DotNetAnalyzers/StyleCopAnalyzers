# SA1307: 可访问字段应以大写字母开头

## 原因

C# 公共字段或内部字段的名称未以大写字母开头。

## 规则说明

当公共字段或内部字段的名称以小写字母开头时，会违反此规则。
公共字段或内部字段应以大写字母开头。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以小写字母开头，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

C# 8 只读成员不会改变此规则的适用范围。
此规则仍仅适用于字段声明（包括结构中的只读字段），而忽略只读方法、属性、索引器或事件。
公共和内部只读字段仍在此处分析，静态只读字段还可能触发 SA1311。
启用 SA1307 时，SA1304 不会对 public、internal 和 protected internal 只读字段报告诊断，因此这两个规则只会产生一个诊断。
protected 和 private protected 只读字段由 SA1304 而非 SA1307 检查。

## 如何修复违规

要修复此规则的违规情况，请将字段名称改为以大写字母开头，或者在合适时将该项放在 NativeMethods 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1307:AccessibleFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1307 // AccessibleFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1307 // AccessibleFieldsMustBeginWithUpperCaseLetter
```
