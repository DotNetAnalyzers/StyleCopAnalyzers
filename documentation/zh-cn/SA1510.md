# SA1510: 链接的语句块之前不应有空行

## 原因

相互链接的 C# 语句之间有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

某些类型的 C# 语句只有链接在另一条语句下方才能使用。
例如，catch 和 finally 语句必须始终链接在 try 语句下方。
另一个例子是 else 语句，它必须始终链接在 if 语句或另一条 else 语句下方。
这类相互链接的语句之间不应用空行分隔。
例如：

```csharp
try
{
    this.SomeMethod();
}

catch (Exception ex)
{
    Console.WriteLine(ex.ToString());
}
```

## 如何修复违规

要修复此规则的违规情况，请删除链接语句之间的所有空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1510:ChainedStatementBlocksMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
#pragma warning restore SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
```
