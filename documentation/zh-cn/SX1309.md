# SX1309: 字段名称应以下划线开头

## 替代规则

此规则是对 StyleCop 默认行为的非标准扩展，代表某些项目采用的另一种风格。
替代规则已知会与标准 StyleCop 规则直接冲突。

## 原因

字段名称未以下划线开头。

## 规则说明

当字段名称未以下划线开头时，会违反此规则。

### 详细行为

此规则仅检查私有实例字段的名称。
它会忽略 `static`、`const` 字段，以及具有 public、internal 或 protected 访问级别的字段。
在 C# 8 及更高版本中，此规则不考虑结构中的 `readonly` 实例成员（如 `readonly` 方法或访问器）；只有私有字段（包括私有 `readonly` 字段）需要下划线前缀。
此规则会忽略静态 `readonly` 字段（将其视为常量）。

## 如何修复违规

要修复此违规情况，请为字段名称添加下划线（`_`）前缀。

模式匹配引入的弃元指定（例如 C# 8 属性模式或位置模式中的 `_`）不被视为字段，此规则会将其忽略。

## 如何抑制违规

```csharp
#pragma warning disable SX1309 // Field names should begin with underscore
int bar;
#pragma warning restore SX1309 // Field names should begin with underscore
```
