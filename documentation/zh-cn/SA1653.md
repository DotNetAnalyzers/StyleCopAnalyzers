# SA1653: 只有一个分部声明应包含摘要文档注释

## 原因

分部类型的多个声明包含顶级 `<summary>` 元素。

## 规则说明

分部类型各声明中的 XML 文档注释会合并为该类型的一份文档。
在多个声明中提供 `<summary>` 文档注释可能导致摘要重复或相互冲突。

应将类型的正式文档（包括 `<summary>` 和所有 `<typeparam>` 元素）保留在一个声明中。
为方便源代码的读者理解其他部分，应使用 `<content>` 而不是 `<summary>` 来编写这些部分的文档。
这与 [SA1619](SA1619.md) 的要求一致。

此规则会报告所有包含冲突摘要的声明，而不会自行选择应保留摘要的声明。
无论类型的可访问性是否要求提供文档注释，此规则都适用于已有的文档注释。
生成的声明中的摘要也会计入冲突，但只会对非生成的声明报告诊断。

此规则仅统计显式编写的顶级 `<summary>` 元素。
嵌套的摘要不计入统计，通过 `<include>` 或 `<inheritdoc>` 提供的文档也不会由此规则展开。

## 如何修复冲突

选择一个声明保留 `<summary>` 文档注释，并将其他声明改为使用 `<content>`：

```csharp
/// <summary>
/// 表示请求处理器。
/// </summary>
public partial class RequestProcessor
{
}

/// <content>
/// 包含请求验证逻辑。
/// </content>
public partial class RequestProcessor
{
}
```

由于需要由用户决定哪个声明是主要声明，因此不提供自动代码修复。

## 如何抑制冲突

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1653:OnlyOnePartialDeclarationShouldContainSummaryDocumentation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1653 // 只有一个分部声明应包含摘要文档注释
#pragma warning restore SA1653 // 只有一个分部声明应包含摘要文档注释
```
