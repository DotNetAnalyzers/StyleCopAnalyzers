# SA1139: 使用字面量后缀表示法而不是强制转换

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

使用了强制转换，而不是相应类型的数值字面量。

## 规则说明

使用了强制转换，而不是相应类型的数值字面量。
使用后缀 "U" 创建 32 位无符号整数，"L" 创建 64 位整数，"UL" 创建 64 位无符号整数，"F" 创建 32 位浮点数，"D" 创建 64 位浮点数，"M" 创建十进制数。
后缀不区分大小写。

例如，以下代码会产生违规：

```csharp
var x = (long)1;
```

以下代码不会产生任何违规：

```csharp
var x = 1L;
```

## 如何修复违规

使用适当的字面量后缀，而不是在代码中对值进行强制转换，即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1139:UseLiteralsSuffixNotationInsteadOfCasting", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1139 // Use literal suffix notation instead of casting
#pragma warning restore SA1139 // Use literal suffix notation instead of casting
```
