# SA1602: 枚举项应有文档注释

## 原因

C# 枚举中的某个枚举项缺少 XML 文档注释。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果枚举中的某个枚举项缺少文档注释，就会违反此规则。
例如：

```csharp
/// <summary>
/// Types of animals.
/// </summary>
public enum Animals
{
    Dog,
    Cat,
    Horse
}
```

## 如何修复违规

为枚举中的每个枚举项添加文档注释，即可修复此规则的违规。
例如：

```csharp
/// <summary>
/// Types of animals.
/// </summary>
public enum Animals
{
    /// <summary>
    /// Represents a dog.
    /// </summary>
    Dog,

    /// <summary>
    /// Represents a cat.
    /// </summary>
    Cat,

    /// <summary>
    /// Represents a horse.
    /// </summary>
    Horse
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1602:EnumerationItemsMustBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1602 // EnumerationItemsMustBeDocumented
#pragma warning restore SA1602 // EnumerationItemsMustBeDocumented
```
