# SA1204: 静态元素应位于实例元素之前

## 原因

静态元素位于同类型的实例元素之后。

## 规则说明

当静态元素位于同类型的实例元素之后时，会违反此规则。
所有静态元素都应位于同类型的所有实例元素之前，以便更容易看出类的实例部分和静态部分所公开的接口。

此规则适用于类、结构和接口。
静态接口成员（随 C# 8 默认接口成员引入）必须位于实例成员之前，包括提供默认实现的实例成员。

例如，以下接口声明违反了此规则，因为静态成员位于带默认实现的实例成员之后：

```csharp
public interface IExample
{
    void Instance() { }
    static void Helper() { } // SA1204
}
```

符合要求的顺序是将静态接口成员放在实例成员之前：

```csharp
public interface IExample
{
    static void Helper() { }
    void Instance() { }
}
```

## 如何修复违规

要修复此违规情况，请将所有静态元素放在同类型的所有实例元素之前。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1204:StaticElementsMustAppearBeforeInstanceElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1204 // StaticElementsMustAppearBeforeInstanceElements
#pragma warning restore SA1204 // StaticElementsMustAppearBeforeInstanceElements
```
