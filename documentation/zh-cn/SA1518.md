# SA1518: 在文件末尾正确使用换行符

## 原因

文件末尾的换行符不符合项目设置。

## 规则说明

为了改善代码布局，StyleCop 要求文件末尾的换行符保持一致。
可以使用 **stylecop.json** 配置项目的具体要求。
有关详细信息，请参阅 [Configuration.md](Configuration.md)。

具体设置为以下选项之一：

* Allow（默认）：允许文件以一个换行符结尾，但不强制要求。
* Require：文件必须以一个换行符结尾。
* Omit：文件不得以换行符结尾。

## 如何修复违规

要修复此规则的违规情况，请更新文件末尾的换行符，使其符合当前项目的设置。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1518:CodeMustNotContainBlankLinesAtEndOfFile", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
#pragma warning restore SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
```
