# SA1504: 所有访问器应统一使用单行或多行样式

## 原因

C# 属性、索引器或事件中至少有一个子访问器写在一行中，同时至少有一个子访问器跨多行书写。

## 规则说明

当属性、索引器或事件中具有实现的访问器未统一采用单行或多行样式时，会违反此规则。
块体访问器和表达式体访问器都会被检查。
没有主体的访问器（如自动属性访问器）不在检查范围内。
此规则要求同一元素中所有具有实现的访问器采用相同的格式，旨在提高代码的可读性。

例如，以下属性会违反此规则，因为一个访问器写在一行中，而另一个访问器跨多行书写。

```csharp
public bool Enabled
{
    get { return this.enabled; }

    set
    {
        this.enabled = value;
    }
}
```

可以将两个访问器分别写在一行中，或者都展开到多行，以避免此违规：

```csharp
public bool Enabled
{
    get { return this.enabled; }
    set { this.enabled = value; }
}


public bool Enabled
{
    get 
    { 
        return this.enabled; 
    }

    set 
    { 
        this.enabled = value;
    }
}
```

## 如何修复违规

要修复此规则的违规情况，如果访问器较短，请将每个访问器写在一行中；如果访问器较长，请将两个访问器都展开到多行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1504:AllAccessorsMustBeSingleLineOrMultiLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
#pragma warning restore SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
```
