# SA1412: 使用带字节顺序标记的 UTF-8 保存文件

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

文件的编码不是带字节顺序标记的 UTF-8。

## 规则说明

使用此编码保存文件，可以确保即使在默认系统编码不同的系统上编译，编译器也始终以相同的方式处理文件。
此外，对于 GitHub 上的可视化差异比较以及其他工具中的类似功能，此编码也是得到最广泛支持的编码。
在 Visual Studio 中创建新的 C# 源文件时，默认也使用此编码。

## 如何修复违规

要修复此规则的违规情况，请将文件编码转换为带字节顺序标记的 UTF-8。

## 替代规则

如果项目要求使用不带字节顺序标记的 UTF-8 文件，请改用 [SX1412](SX1412.md)。
