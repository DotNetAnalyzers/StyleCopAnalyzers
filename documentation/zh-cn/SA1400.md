# SA1400: 应声明访问修饰符

## 原因

C# 元素未显式定义访问修饰符。

## 规则说明

C# 允许在不指定访问修饰符的情况下定义元素。
在这种情况下，C# 会根据元素的类型自动为其分配访问级别。

此规则要求为每个元素显式定义访问修饰符。
这样读者无需对代码作出假设，从而提高代码的可读性。

在 `interface` 中声明的成员隐式为 `public`，不需要显式访问修饰符。
这包括 C# 8 引入的默认接口成员（带默认实现的实例成员、静态接口成员，以及委托等嵌套接口成员）。
SA1400 不会对这些接口成员报告诊断。

## 如何修复违规

要修复此规则的违规情况，请在元素声明中添加访问修饰符。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1400:AccessModifierMustBeDeclared", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1400 // AccessModifierMustBeDeclared
#pragma warning restore SA1400 // AccessModifierMustBeDeclared
```
