# SA1142: 通过名称引用元组字段

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

:memo: 此规则仅在 C# 7.0 及更高版本中启用。

## 原因

元组元素具有可用的元素名称，但引用时使用了其元数据名称。

## 规则说明

元组元素具有可用的元素名称，但引用时使用了其元数据名称。
有关如何在 C# 7 中使用元组的信息，请参阅[元组类型](https://docs.microsoft.com/en-us/dotnet/csharp/tuples)文档。

例如，以下代码会产生违规：

```csharp
(int valueA, int valueB) x;

var y = x.Item1; // SA1142
```

以下代码不会产生任何违规：

```csharp
(int valueA, int valueB) x;

var y = x.valueA;
```

## 如何修复违规

在代码中使用适当的元组元素名称而不是元数据名称即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1142:ReferToTupleElementsByName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1142 // Refer to tuple elements by name
#pragma warning restore SA1142 // Refer to tuple elements by name
```
