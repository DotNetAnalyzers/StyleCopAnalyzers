# SA1306: 字段名称应以小写字母开头

## 原因

C# 字段的名称未以小写字母开头。

## 规则说明

当字段名称以大写字母开头时，会违反此规则。
常量、非私有只读字段和静态只读字段应始终以大写字母开头，而私有只读字段应以小写字母开头。
此外，公共字段或内部字段也应始终以大写字母开头。

可变的 `protected` 和 `private protected` 字段名称应以小写字母开头。具有这些访问修饰符的 `readonly` 字段名称应以
大写字母开头（SA1304）。`protected internal` 字段名称应以大写字母开头，与其他 `internal` 字段相同。

如果字段名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以大写字母开头，请将该字段放在特殊的 `NativeMethods` 类中。
`NativeMethods` 类是名称以 `NativeMethods` 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 `NativeMethods` 类中，StyleCop 会忽略此违规。

> :warning: 此规则与 StyleCop “classic” 中的对应规则有以下区别：
>
> 此规则仅检查字段名称。
> StyleCop “classic” 中的 SA1306 检查字段、参数和局部变量。

## 如何修复违规

要修复此规则的违规情况，请将字段名称改为以小写字母开头，或者在合适时将该项放在 `NativeMethods` 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1306:FieldNamesMustBeginWithLowerCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1306 // FieldNamesMustBeginWithLowerCaseLetter
private int Field = 3;
#pragma warning restore SA1306 // FieldNamesMustBeginWithLowerCaseLetter
```
