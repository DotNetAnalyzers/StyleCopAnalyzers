# SA1015: 泛型右尖括号周围的空格应正确

## 原因

C# 元素中泛型右尖括号周围的空格不正确。

## 规则说明

泛型右尖括号周围的空格不正确时，会违反此规则。

泛型右尖括号前不得有空白字符，除非它是一行中的第一个字符。
泛型右尖括号后应为左圆括号、右圆括号、泛型右尖括号、可为 null 类型符号、行尾或一个空白字符（但不能是空白字符后再接左圆括号）。
在支持可为 null 类型的上下文中，可为 null 引用类型批注（例如 `List<string?>?`）与可为 null 值类型遵循相同的规则。

C# 9 函数指针参数列表末尾的 `>` 标记也遵循相同的间距规则，例如 `delegate*<int, void>`。

## 如何修复违规

确保泛型右尖括号周围的空白字符正确即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1015:ClosingGenericBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
#pragma warning restore SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
```
