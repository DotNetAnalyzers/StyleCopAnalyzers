# SA1008: 左圆括号周围的空格应正确

## 原因

C# 语句中左圆括号周围的空格不正确。

## 规则说明

语句中左圆括号周围的空格不正确时，会违反此规则。
左圆括号前不应有任何空白字符，除非它是一行中的第一个字符，或前面是 if、while、for 等特定的 C# 关键字。
此外，左圆括号位于表达式中的运算符之后时，允许在它前面使用空白字符。

左圆括号后不应有空白字符，除非它是一行中的最后一个字符，或空白字符后是注释。

## 如何修复违规

确保左圆括号周围的空格符合上述规则即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1008:OpeningParenthesisMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1008 // OpeningParenthesisMustBeSpacedCorrectly
#pragma warning restore SA1008 // OpeningParenthesisMustBeSpacedCorrectly
```
