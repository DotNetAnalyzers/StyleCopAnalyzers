# SA1603: 文档注释应包含有效的 XML

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

C# 元素的文档注释中的 XML 格式不正确。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果文档注释中的 XML 格式不正确，无法解析，就会违反此规则。
例如，XML 包含无效字符，或者 XML 节点缺少结束标记时，都可能出现这种情况。

## 如何修复违规

将格式不正确的 XML 替换为标准 XML 解析器能够解析的有效 XML，即可修复此规则的违规。

以下示例展示了文档注释中包含无效 XML 的类。
`<summary>` 节点的结束标记无效。

```csharp
/// <summary>
/// An example of badly formed Xml.
/// </summa3ry>
public class Example
{
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1603:DocumentationMustContainValidXml", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1603 // DocumentationMustContainValidXml
#pragma warning restore SA1603 // DocumentationMustContainValidXml
```
