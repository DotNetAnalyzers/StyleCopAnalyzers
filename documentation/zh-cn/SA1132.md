# SA1132: 不要合并字段声明

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

在同一个字段声明中声明了两个或更多字段。

## 规则说明

在同一个字段定义中声明两个字段时，会违反此规则。

例如，以下代码会产生违规：

```csharp
public class TypeName
{
    private int field1,
        field2; // SA1132
}
```

以下代码不会产生任何违规：

```csharp
public class TypeName
{
    private int field1;
    private int field2;
}
```

## 如何修复违规

为每个字段使用独立的字段定义即可修复违规。

## 如何抑制违规

```csharp
public class TypeName
{
    private int field1,
#pragma warning disable SA1132 // Do not combine fields
        field2;
#pragma warning restore SA1132 // Do not combine fields
}
```
