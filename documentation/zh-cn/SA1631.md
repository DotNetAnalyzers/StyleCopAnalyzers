# SA1631: 文档注释应满足字母字符占比要求

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

C# 元素的 XML 文档注释中的某个部分没有包含足够的字母字符。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果文档的某个部分没有包含足够的字母字符，就会违反此规则。
此规则统计文档文本中字母和数字的数量，并将其与符号和其他非字母字符的数量进行比较。
如果非字母字符占比过高，通常意味着文档格式不佳，难以阅读。
例如，考虑以下摘要文档：

```csharp
/// <summary>
/// @)$(*A name--------
/// </summary>
public class Name
{
    ...
}
```

## 如何修复违规

使用符合语法的语言重写文档文本，并确保文本中的符号相对于字母字符的比例不过高，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1631:DocumentationMustMeetCharacterPercentage", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1631 // DocumentationMustMeetCharacterPercentage
#pragma warning restore SA1631 // DocumentationMustMeetCharacterPercentage
```
