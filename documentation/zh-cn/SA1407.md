# SA1407: 算术表达式应明确运算优先级

## 原因

C# 语句中的复杂算术表达式省略了运算符周围的圆括号。

## 规则说明

C# 为算术运算符规定了优先级层次。
在 C# 中，可以将多个算术运算串联在一个语句中，而不为任何运算添加圆括号；此时，编译器会根据这些预先规定的规则自动确定运算顺序和优先级。
例如：

```csharp
int x = 5 + y * b / 6 % z - 2;
```

虽然这段代码是合法的，但其可读性和可维护性并不高。
要完全理解这段代码，开发者必须了解并理解 C# 的基本运算符优先级规则。

此规则要求开发者插入圆括号，显式说明运算符优先级，旨在提高这类代码的可读性和可维护性，并降低以后引入错误的风险。
以下示例展示了用圆括号包围多个算术运算的方式：

```csharp
int x = 5 + (y * ((b / 6) % z)) - 2;
```

插入圆括号使代码的含义更明确、更容易理解，读者也无需对代码作出假设。

## 如何修复违规

要修复此规则的违规情况，请在算术表达式中插入圆括号，明确运算的优先级。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1407:ArithmeticExpressionsMustDeclarePrecedence", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1407 // ArithmeticExpressionsMustDeclarePrecedence
#pragma warning restore SA1407 // ArithmeticExpressionsMustDeclarePrecedence
```
