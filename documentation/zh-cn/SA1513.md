# SA1513: 右大括号之后应有空行

## 原因

C# 元素、语句或表达式中的右大括号之后没有空行。

## 规则说明

为了提高代码的可读性，StyleCop 在某些情况下要求空行，在其他情况下禁止空行。
这样会在代码中形成一致的视觉模式，使不熟悉的代码也更容易识别和阅读。

当右大括号之后没有空行时，会违反此规则。
例如，以下代码会产生一处违规，因为有一处右大括号之后没有空行。

```csharp
if (condition)
{
    DoSomething();
}
return value;
```

switch 表达式的右大括号之后不要求空行，无论后续是什么延续标记。
例如，空合并运算符（`??`）可以跟在同一行或下一行。

对于其他属于表达式或模式的大括号（例如 C# 8.0 引入的属性模式），如果大括号后紧接 `=>`、`,` 或 `;` 等延续标记，则不要求空行。
如果大括号后直接跟有逻辑运算符（如 `&&` 或 `||`），或者跟有延续同一表达式的模式指定（如 `} patternVar`），同样不要求空行。

## 如何修复违规

要修复此规则的违规情况，请确保右大括号之后有空行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1513:ClosingBraceMustBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1513 // ClosingBraceMustBeFollowedByBlankLine
#pragma warning restore SA1513 // ClosingBraceMustBeFollowedByBlankLine
```
