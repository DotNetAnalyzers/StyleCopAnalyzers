# SA1135: using 指令应使用完全限定名称

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

using 指令没有使用完全限定名称。

## 规则说明

using 指令位于命名空间内部，且没有使用完全限定名称时，会违反此规则。
请注意，同一命名空间中类的别名定义不需要使用完全限定名称。

以外部别名开头的 `using` 指令（例如 `using SomeClass = externalAssembly::SomeNamespace.SomeOtherClass;`）已使用完全限定名称。

例如，以下代码会产生违规：

```csharp
namespace System.Threading
{
    using IO;
    using Tasks;
}
```

以下代码不会产生任何违规：

```csharp
namespace System.Threading
{
    using System.IO;
    using System.Threading.Tasks;

    using T = Thread;
}
```

## 如何修复违规

使用完全限定的命名空间名称即可修复违规。

## 如何抑制违规

```csharp
namespace N1.N2
{
#pragma warning disable SA1135 // Using directives must be qualified
    using N3;
#pragma warning restore SA1135 // Using directives must be qualified
}
```
