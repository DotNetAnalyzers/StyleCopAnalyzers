# SA1028: 代码中不应有尾随空白字符

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

代码行在换行字符之前以空格、制表符或其他空白字符结尾。

## 规则说明

代码行以换行字符之外的任何空白字符结尾时，会违反此规则。
多余的空白字符可能会在显示空白字符的编辑器中显现，或在开发者以后格式化文档、删除尾随空白字符时产生不必要的代码改动。
某些差异比较工具甚至会突出显示尾随空白字符，以鼓励开发者将其删除。

### 详细行为

C# 语言中有多种跨越多行代码的构造。
下表说明了此规则针对这些构造的行为。

| 构造 | 启用分析 |
| --- | --- |
| “普通”代码 | ✔ |
| 行注释（以 `// ...` 开头） | ✔ |
| 块注释内部（`/* ... */`） | ✔ |
| 单行文档注释（`/// ...`） | ✔ |
| 多行文档注释（`/** ... */`） | ✔ |
| 预处理器指令（`#if`、`#pragma`、`#region` 等） | ✔ |
| 逐字字符串字面量（`@""`） | |
| 禁用的代码（位于未激活的 `#if`、`#elif` 或 `#else` 块中的文本） | |

## 如何修复违规

删除行尾所有多余的空白字符即可修复违规。

## 如何抑制违规

```csharp
#pragma warning disable SA1028 // Code should not contain trailing whitespace
SomeMethodWithSpaceAfterTheSemicolon();    
#pragma warning restore SA1028 // Code should not contain trailing whitespace
```
