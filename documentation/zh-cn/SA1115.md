# SA1115: 参数应紧接逗号

## 原因

C# 方法或索引器的调用或声明中的参数，没有在前一个参数所在行或其下一行开始。

## 规则说明

参数与前一个参数之间有一个或多个空行时，会违反此规则。
例如：

```csharp
public string JoinName(
    string first, 

    string last)
{
}
```

参数应在前一个逗号所在行或其下一行开始。
例如：

```csharp
public string JoinName(string first, string last)
{
}

public string JoinName(
    string first, 
    string last)
{
}
```

## 如何修复违规

确保参数在前一个逗号所在行或其下一行开始即可修复违规。

代码修复会删除参数之间的空行，并保留注释、预处理器指令和缩进。也支持全部修复（Fix All）。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1115:ParameterMustFollowComma", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1115 // ParameterMustFollowComma
#pragma warning restore SA1115 // ParameterMustFollowComma
```
