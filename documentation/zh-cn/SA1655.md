# SA1655: 文档元素标记的位置必须一致

## 原因

XML 文档元素的开始标记单独占一行，而结束标记没有（或者相反）。

## 规则说明

对于 XML 文档注释中的每个元素，要么开始标记和结束标记都单独占一行（前面只有 `///` 注释前缀，后面没有任何内容），
要么两者都不单独占一行。

以下写法是允许的：

```csharp
/// <summary>摘要文本。</summary>
///
/// <summary>
/// 摘要文本。
/// </summary>
///
/// <remarks>跨越
/// 多行的文本。</remarks>
```

元素的标记*可以*位于不同的行，而不必单独占一行：

```csharp
/// <para>段落文本
/// 后续文本。</para>
```

以下代码违反该规则：

```csharp
/// <summary>
/// 摘要文本。</summary>
///
/// <summary>摘要文本
/// </summary>
///
/// <para>
/// 段落文本。</para>
```

该规则适用于所有元素（包括 `<para>`），也适用于嵌套在其他元素内的元素。

## 如何修复违规

将两个标记都放在单独的行上，或者让文本与两个标记处于相同的行：

```csharp
/// <summary>
/// 摘要文本。
/// </summary>
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1655:DocumentationElementTagsMustBeConsistentlyPlaced", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1655 // Documentation element tags must be consistently placed
#pragma warning restore SA1655 // Documentation element tags must be consistently placed
```
