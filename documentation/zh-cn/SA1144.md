# SA1144: 字面量中的零宽字符必须转义

## 原因

字符串或字符字面量直接在源文本中包含零宽字符。

## 规则说明

零宽字符在大多数编辑器中不可见，因此很容易被意外引入（例如从网页粘贴文本），之后也很难发现。此规则会报告包含下列任一字符的字符串、字符、UTF-8 字符串和内插字符串字面量：

* U+200B ZERO WIDTH SPACE
* U+2060 WORD JOINER
* U+FEFF ZERO WIDTH NO-BREAK SPACE

每个字面量标记只报告一个诊断。零宽连接符和非连接符（U+200D 和 U+200C）在某些文字和表情符号序列中具有意义，因此不会被报告。

```csharp
string value = "a​b"; // 'a' 和 'b' 之间包含不可见的 U+200B
```

## 如何修复违规

将每个零宽字符替换为其转义序列。代码修复会对常规字符串、字符和（非逐字）内插字符串字面量执行此操作：

```csharp
string value = "a\u200Bb";
```

第二个代码修复会改为删除零宽字符，适用于所有种类的字符串字面量，但不适用于字符字面量。逐字字符串和原始字符串字面量不支持转义序列，因此对它们只提供删除；若要保留该字符，请使用转义序列构建字符串，例如拼接 `"\u200B"`。

## 如何禁止显示违规

```csharp
#pragma warning disable SA1144 // Zero-width characters in literals must be escaped
// Code containing the violation.
#pragma warning restore SA1144 // Zero-width characters in literals must be escaped
```
