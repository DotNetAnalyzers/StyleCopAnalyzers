# SA1304: 非私有只读字段应以大写字母开头

## 原因

C# 非私有只读字段的名称应以大写字母开头。

## 规则说明

当非私有只读字段的名称未以大写字母开头时，会违反此规则。
非私有只读字段应始终以大写字母开头。

如果字段或变量的名称需要与 Win32 或 COM 相关项的名称匹配，因此必须以小写字母开头，请将该字段或变量放在特殊的 *NativeMethods* 类中。
NativeMethods 类是名称以 NativeMethods 结尾的类，用于容纳 Win32 或 COM 包装器。
如果该项位于 NativeMethods 类中，StyleCop 会忽略此违规。

C# 8 允许结构具有只读成员。
此规则仍仅分析只读字段，而忽略只读方法、属性、索引器或事件。
即使启用了 SA1307，SA1304 仍检查 protected 和 private protected 只读字段。
对于 public、internal 和 protected internal 只读字段，启用 SA1307 时，由 SA1307 而非 SA1304 报告命名违规；禁用 SA1307 时，SA1304 也会检查这些字段。
静态只读字段还可能触发 SA1311。

## 如何修复违规

要修复此规则的违规情况，请将只读字段名称改为以大写字母开头，将字段改为私有字段，或者在合适时将该项放在 NativeMethods 类中。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1304:NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1304 // NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1304 // NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter
```
