# SA1642: 构造函数的摘要文档应以标准文本开头

## 原因

C# 构造函数的 XML 文档注释没有包含正确的摘要文本。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果构造函数的文档注释中的 summary 标记没有以正确的文本开头，就会违反此规则。

此规则旨在根据构造函数的访问级别统一其摘要文本。
实例构造函数的摘要应以“初始化 {class name} 类的新实例.”开头。
例如，以下示例展示了 `Customer` 类的构造函数。

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </summary>
public Customer()
{
}
```

为结构编写文档时，摘要应使用“结构”而不是“类”。
例如，以下示例展示了 `MyStruct` 结构的构造函数。

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="MyStruct"/> struct.
/// </summary>
public MyStruct()
{
}
```

记录类型的构造函数遵循相同的模式：记录类的摘要文本使用“类”，记录结构则使用“结构”。
例如：

```csharp
public record struct Customer
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Customer"/> struct.
    /// </summary>
    public Customer()
    {
    }
}
```

对于 C# 15 的联合类型，摘要应使用“联合”。
例如，以下示例展示了 `Result<T>` 联合的构造函数。

```csharp
public union Result<T>(T, string)
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Result{T}"/> union.
    /// </summary>
    /// <param name="value">The value.</param>
    /// <param name="message">The message.</param>
    public Result(T value, string message)
    {
    }
}
```

如果类包含泛型参数，可以使用以下两种格式之一，在 `cref` 链接中注明这些参数：

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer`1"/> class.
/// </summary>
public Customer()
{
}

/// <summary>
/// Initializes a new instance of the <see cref="Customer{T}"/> class.
/// </summary>
public Customer()
{
}
```

如果构造函数是静态的，摘要文本应以“初始化 {class name} 类的静态成员.”开头。
例如：

```csharp
/// <summary>
/// Initializes static members of the <see cref="Customer"/> class.
/// </summary>
static Customer()
{
}
```

标准文本也可以使用 `<see langword="static"/>`、`<see langword="class"/>` 或 `<see langword="struct"/>` 表示相应的关键字。
记录声明可以用 `<see langword="record"/>` 代替标准的 `class` 或 `struct` 类型类别。
例如：

```csharp
/// <summary>
/// Initializes <see langword="static"/> members of the <see cref="Customer"/> class.
/// </summary>
static Customer()
{
}
```

此许可不适用于作为普通文本使用的词，例如实例构造函数标准文本中的 `new`。

为了兼容 StyleCop Classic，允许私有实例构造函数使用“防止创建 {class name} 类的默认实例.”作为摘要文本。
对于新代码，建议所有实例构造函数都使用前述形式。

```csharp
/// <summary>
/// Prevents a default instance of the <see cref="Customer"/> class from being created.
/// </summary>
private Customer()
{
}
```

可以在 `<summary>` 标记内使用 `<para>` 标记来组织文本。
例如：

```csharp
/// <summary>
/// <para>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </para>
/// <para>
/// Additional information can be included in subsequent paragraphs.
/// </para>
/// </summary>
public Customer()
{
}
```

## 如何修复违规

按照上述说明编辑构造函数的摘要文本，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1642:ConstructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
```
