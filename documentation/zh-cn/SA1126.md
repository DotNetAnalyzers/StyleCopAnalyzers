# SA1126: 正确使用调用前缀

:warning: StyleCop Analyzers 有意未包含此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

C# 代码文件中的成员调用没有使用 'this.'、'base.'、'object.' 或 'typename.' 前缀来明确要执行的方法调用。

## 规则说明

代码中的成员调用没有使用正确的前缀时，会违反此规则。

有些情况下，仅通过源代码分析无法确定应使用哪种前缀。
它可能是 'this'、'base'、'object'、当前类的类型名称或某个基类的类型名称。

## 如何修复违规

在类成员调用前添加正确的前缀即可修复违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1126:PrefixCallsCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1126 // PrefixCallsCorrectly
#pragma warning restore SA1126 // PrefixCallsCorrectly
```
