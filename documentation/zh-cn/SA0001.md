# SA0001: XML 注释分析已禁用

:memo: 此规则是 StyleCop Analyzers 新增的规则，StyleCop Classic 中没有此规则。

## 原因

文档注释的诊断可能缺失或不正确，且所有诊断的代码修复在包含文档注释的源文件中都可能表现异常。

## 规则说明

当一个编译（项目）包含一个或多个在解析时将 `DocumentationMode` 设置为 `None` 的文件时，就会违反此规则。
最常见的情况是项目被配置为在生成时不输出 XML 文档文件。

SA0001 并不表示所有文档诊断均已禁用；SA1600 和 SA1604 等规则仍可能报告诊断。

每个项目都应配置为将 XML 文档文件包含在编译输出中。
否则，所有文档注释的语义都不会得到检查，注释中的错误可能会随着时间推移而不断增多。

## 如何修复违规

要修复此规则的违规，请在项目文件中添加 `<GenerateDocumentationFile>true</GenerateDocumentationFile>`，启用作为项目输出一部分的 XML 文档文件。

**注意：** 在某些情况下，启用 XML 文档输出会产生大量 CS1573、CS1591 和/或 CS1712 警告。
为了便于团队先解决 SA0001，再解决 CS1573、CS1591 和 CS1712，可考虑使用以下方法之一禁用这些警告。

### 通过规则集文件抑制

编辑规则集文件是抑制 CS1573、CS1591 和 CS1712 最简单的方法。
可将这些规则的严重级别设置为 **Hidden** 或 **None**，使其不显示在生成输出中。
设置为 **Hidden** 时，这些诊断的代码修复仍可作为编写文档的辅助工具正常使用，但警告本身不会显示。

### 通过项目文件抑制

对于有时使用不支持规则集文件的较旧 C# 版本生成项目的用户，可通过配置项目文件中的 `<NoWarn>` 元素抑制这些警告。
在项目文件中添加以下属性组，即可同时配置文档输出（修正 SA0001）并抑制 CS1573、CS1591 和 CS1712。

```xml
<PropertyGroup>
  <!--
    Make sure any documentation comments which are included in code get checked for syntax during the build, but do
    not report warnings for missing comments.

    CS1573: Parameter 'parameter' has no matching param tag in the XML comment for 'parameter' (but other parameters do)
    CS1591: Missing XML comment for publicly visible type or member 'Type_or_Member'
  -->
  <DocumentationFile>$(OutputPath)$(AssemblyName).xml</DocumentationFile>
  <NoWarn>$(NoWarn),1573,1591,1712</NoWarn>
</PropertyGroup>
```

## 如何抑制违规

只能通过在项目的 **ruleset** 文件中禁用此警告来抑制它。
