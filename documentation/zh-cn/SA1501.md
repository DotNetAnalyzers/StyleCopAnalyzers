# SA1501: 语句不应写在一行中

## 原因

包含左大括号和右大括号的 C# 语句完全写在一行中。

## 规则说明

当用左大括号和右大括号包围的语句写在一行中时，会违反此规则。
例如：

```csharp
public object Method()
{
    lock (this) { return this.value; }
}
```

StyleCop 检查这段代码时，会报告此规则的违规，因为整个 lock 语句写在一行中。
此语句应跨多行书写，左大括号和右大括号分别独占一行，如下所示：

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value; 
    }
}
```

空的 `catch` 和 `finally` 块可以写在同一行。此例外也适用于仅包含注释的块；包含语句的块仍受此规则约束。

## 如何修复违规

要修复此规则的违规情况，请重写语句，将其展开到多行。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1501:StatementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1501 // StatementMustNotBeOnSingleLine
#pragma warning restore SA1501 // StatementMustNotBeOnSingleLine
```
