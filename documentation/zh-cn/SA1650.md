# SA1650: 元素的文档注释应拼写正确

:warning: StyleCop Analyzers 有意未实现此规则。
有关详细信息，请参阅 [KnownChanges.md](KnownChanges.md)。

## 原因

元素的文档注释包含一个或多个拼写错误或无法识别的词。

## 规则说明

如果元素的文档注释包含拼写错误，就会违反此规则：

```csharp
/// <summary>
/// Joinsnames
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>Name</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

拼写检查使用 Settings.StyleCop 文件中指定的区域性，默认使用 en-US。

在此示例中，summary 元素中的 Joinsnames 一词拼写错误。
可以修正拼写、将 C# 名称放在 `<c> </c>` 元素中、抑制违规，或者将 Joinsnames 添加到 CustomDictionary.xml 文件中。

CustomDictionary.xml 文件可以包含拼写检查器通常无法识别的词。

CustomDictionary.xml 文件应与 StyleCop.dll 和规则文件放在同一文件夹中。
检查器会在该文件夹及其所有子文件夹中查找词典文件。

StyleCop 依次加载 CustomDictionary.xml、CustomDictionary.en-GB.xml 和 CustomDictionary.en.xml（其中 en-GB 是 Settings.StyleCop 文件中指定的区域性）。

StyleCop 也依次加载 custom.dic、custom.en-GB.dic 和 custom.en.dic（其中 en-GB 是 Settings.StyleCop 文件中指定的区域性）。

还可以使用设置编辑器的拼写选项卡，将可识别的词添加到 Settings.StyleCop 文件中。

不会检查元素的 XML 文档注释中的属性值的拼写。

也会忽略 `<c> </c>` 或 `<code> </code>` 元素中的所有文本。

以 '$' 开头和结尾，或以 '$$' 开头和结尾的文本也会被忽略，例如 $$(thtp kthpo kthpk)$$。

## 如何修复违规

修正元素的文档注释中的所有拼写错误，即可修复此规则的违规。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1650:ElementDocumentationMustBeSpelledCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1650 // ElementDocumentationMustBeSpelledCorrectly
#pragma warning restore SA1650 // ElementDocumentationMustBeSpelledCorrectly
```
