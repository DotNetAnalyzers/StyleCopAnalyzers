# SA1017: 特性右方括号周围的空格应正确

## 原因

C# 元素中特性右方括号周围的空格不正确。

## 规则说明

特性右方括号周围的空格不正确时，会违反此规则。

特性右方括号前不得有空白字符，除非它是一行中的第一个字符。

参数或类型参数的最后一个特性右方括号与其后的参数类型、修饰符或名称之间应有一个空格，除非声明在下一行继续。相邻特性列表之间不要求空格。

例如，应使用 `[NotNullWhen(true)] out string? foo`，而不是 `[NotNullWhen(true)]out string? foo`。多个连续空格由 [SA1025](SA1025.md) 单独报告。

## 如何修复违规

确保特性右方括号前没有任何空白字符即可修复违规。
对于参数和类型参数的特性，还应确保最后一个特性右方括号后在同一行上有一个空格。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1017:ClosingAttributeBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1017 // ClosingAttributeBracketsMustBeSpacedCorrectly
#pragma warning restore SA1017 // ClosingAttributeBracketsMustBeSpacedCorrectly
```
