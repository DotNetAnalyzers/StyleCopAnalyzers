# SA1401: 字段应为私有字段

## 原因

C# 类中的字段使用了 private 以外的访问修饰符。

## 规则说明

只要类中的字段具有非私有访问级别，就会违反此规则。
出于可维护性的考虑，应始终通过属性向类外部公开字段，并始终将字段声明为私有字段。
这样就可以在以后更改属性的内部实现，而无需改变类的接口。

C# 结构中的字段可以具有任意访问级别。

同时为静态和只读的字段不会触发违规。
在无法使用 `const` 关键字时，通常使用这类字段表示常量值，因此它们不受此规则约束。
实例字段不会仅因是只读字段而获得豁免；要满足此规则，它们仍需为私有字段。

C# 8 用于结构成员（方法、属性、索引器和事件）的 `readonly` 修饰符不会影响此规则，因为此规则仅考虑字段。

## 如何修复违规

要修复此规则的违规情况，请将字段设为私有字段，并添加属性以向类外部公开该字段。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1401:FieldsMustBePrivate", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1401 // FieldsMustBePrivate
#pragma warning restore SA1401 // FieldsMustBePrivate
```
