# SA1503: 不应省略大括号

## 原因

C# 语句省略了左大括号和右大括号。

## 规则说明

当语句省略了左大括号和右大括号时，会违反此规则。
在 C# 中，某些类型的语句可以选择是否包含大括号，例如 if、while 和 for 语句。
例如，if 语句可以不使用大括号：

```csharp
if (true) 
    return this.value;
```

虽然这在 C# 中是合法的，但 StyleCop 始终要求使用大括号，以提高代码的可读性和可维护性。

省略大括号后，在 if 语句下方插入额外语句可能导致代码错误。
例如：

```csharp
if (true) 
    this.value = 2;       
    return this.value;
```

粗略看这段代码，似乎赋值语句和 return 语句都是 if 语句的子语句。
实际上并非如此。
只有赋值语句是 if 语句的子语句，而无论 if 语句的结果如何，return 语句都会执行。

StyleCop 始终要求使用左大括号和右大括号，以防止这类错误：

```csharp
if (true) 
{
    this.value = 2;
    return this.value;
}
```

C# 8 的 using 声明有意省略了带大括号的块。
`using var stream = new MemoryStream();` 这样的语句（或用于 `IAsyncDisposable` 的 `await using`）是合法的，此规则不会报告它们，因为用大括号包围会改变所声明资源的生存期。

## 如何修复违规

要修复此规则的违规情况，请用大括号包围语句体。

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1503:BracesMustNotBeOmitted", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1503 // BracesMustNotBeOmitted
#pragma warning restore SA1503 // BracesMustNotBeOmitted
```
