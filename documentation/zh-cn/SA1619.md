# SA1619: 分部类的泛型类型参数应有文档注释

## 原因

C# 泛型分部元素缺少一个或多个泛型类型参数的文档注释，且元素的文档注释包含 `<summary>` 标记。

## 规则说明

C# 语法允许使用 XML 文档注释，直接在代码中为类和其他元素编写文档。
有关这些注释及其语法的介绍，请参阅：[https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)。

如果泛型分部元素缺少一个或多个泛型类型参数的文档注释，且元素的文档注释包含 `<summary>` 标记而不是 `<content>` 标记，就会违反此规则。

如果在分部类的多个部分中提供文档，这些部分的文档可能会合并为一份文档。
例如，考虑以下分部类的两个部分：

```csharp
/// <summary>
/// Documentation for the first part of Class1.
/// </summary>
public partial class Class1
{
}

/// <summary>
/// Documentation for the second part of Class1.
/// </summary>
public partial class Class1
{
}
```

同一分部类的这两个部分分别为类提供了不同的文档。
将该类的文档生成到 SDK 中时，文档生成工具可能只选择其中一部分而忽略其他部分；在某些情况下，也可能合并两份文档，形成类似这样的文本：“Class1 第一部分的文档。Class1 第二部分的文档。”

因此，在分部类的多个部分中提供 SDK 文档可能会引发问题。
不过，为了提高代码的可读性和可维护性，仍然建议为类的每个部分编写文档，StyleCop 也要求每个部分都包含文档注释。

使用 `<content>` 标记可以解决此问题，它可以替代分部类中的 `<summary>` 标记。
推荐的做法是在分部类的主要部分提供该类的正式 SDK 文档。
这份文档应使用标准的 `<summary>` 标记。
分部类的所有其他部分都应完全省略 `<summary>` 标记，改用 `<content>` 标记。
这样，开发人员既能为分部类的所有部分编写文档，又能将该类的所有正式 SDK 文档集中在一个部分中。
SDK 文档工具会忽略 `<content>` 标记。

如果泛型元素的文档注释包含 `<summary>` 标记，StyleCop 会认为这是类的主要部分，并要求为类的每个泛型类型参数提供 `<typeparam>` 标记。
但是，如果类的文档注释包含 `<content>` 标记而不是 `<summary>` 标记，StyleCop 会认为泛型类型参数已在类的其他部分说明，因此不会要求此部分包含 `<typeparam>` 标记。

## 如何修复违规

为元素的每个泛型类型参数添加 `<typeparam>` 标记，或补全标记中的文档文本，即可修复此规则的违规；如果这不是分部类的主要部分，也可以将 `<summary>` 标记改为 `<content>` 标记。

以下示例展示了具有有效文档注释的方法：

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## 如何抑制违规

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1619:GenericTypeParametersMustBeDocumentedPartialClass", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1619 // GenericTypeParametersMustBeDocumentedPartialClass
#pragma warning restore SA1619 // GenericTypeParametersMustBeDocumentedPartialClass
```
