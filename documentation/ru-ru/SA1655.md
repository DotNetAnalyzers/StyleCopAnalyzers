# SA1655: Теги элементов документации должны размещаться согласованно

## Причина

Открывающий тег элемента XML-документации находится на отдельной строке, а закрывающий — нет (или наоборот).

## Описание правила

Для каждого элемента в комментарии XML-документации либо оба тега (открывающий и закрывающий) находятся на
отдельных строках (перед ними только префикс комментария `///`, после них ничего нет), либо ни один из них.

Допустимо:

```csharp
/// <summary>Summary text.</summary>
///
/// <summary>
/// Summary text.
/// </summary>
///
/// <remarks>Text that spans
/// multiple lines.</remarks>
```

Теги элемента *могут* находиться на разных строках, не будучи на отдельных строках:

```csharp
/// <para>Paragraph text
/// more text.</para>
```

Следующий код нарушает правило:

```csharp
/// <summary>
/// Summary text.</summary>
///
/// <summary>Summary text
/// </summary>
///
/// <para>
/// Paragraph text.</para>
```

Правило применяется ко всем элементам, включая `<para>`, и к элементам, вложенным в другие элементы.

## Как исправить нарушение

Расположите оба тега на отдельных строках либо оставьте текст на тех же строках, что и оба тега:

```csharp
/// <summary>
/// Summary text.
/// </summary>
```

## Как отключить предупреждение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1655:DocumentationElementTagsMustBeConsistentlyPlaced", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1655 // Documentation element tags must be consistently placed
#pragma warning restore SA1655 // Documentation element tags must be consistently placed
```
