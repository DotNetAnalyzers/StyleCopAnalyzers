## Причина

Соседние элементы C# не разделены пустой строкой.

> :memo: Поведение этого правила может изменяться в зависимости от значения свойства `blankLinesBetweenUsingGroups` в **stylecop.json**. Дополнительные сведения см. в [Configuration.md](Configuration.md).

> :memo: Глобальные директивы using (C# 10) рассматриваются как отдельный набор групп using. Если `blankLinesBetweenUsingGroups` требует разделения, правило обеспечивает пустые строки между блоком глобальных using и последующими директивами using уровня пространства имён или инструкциями верхнего уровня, в дополнение к обычным промежуткам внутри каждого набора директив using.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда два соседних элемента не разделены пустой строкой. Например:

```csharp
public void Method1()
{
}
public bool Property
{
    get { return true; }
}
```

В приведённом выше примере метод и свойство не разделены пустой строкой, что вызывает нарушение.

```csharp
public event EventHandler SomeEvent
{
    add
    {
        // add event subscriber here
    }
    remove
    {
        // remove event subscriber here
    }
}
```

В приведённом выше примере методы доступа add и remove события должны разделяться пустой строкой, поскольку add занимает несколько строк.

При использовании пространств имён с областью видимости файла C# 10 после объявления `namespace` должна находиться пустая строка перед любыми директивами `using`, `extern alias` или объявлениями типов.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте пустую строку между соседними элементами.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1516:ElementsMustBeSeparatedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1516 // ElementsMustBeSeparatedByBlankLine
#pragma warning restore SA1516 // ElementsMustBeSeparatedByBlankLine
```
