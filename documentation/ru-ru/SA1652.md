# SA1652: Включите создание XML-документации

:memo: Это новое правило StyleCop Analyzers, которого не было в StyleCop Classic.

:warning: Начиная со StyleCop Analyzers 1.1 это правило перенесено в [SA0001](SA0001.md). Однако документация
нового правила по-прежнему применима к пользователям, получающим SA1652 в StyleCop Analyzers 1.0.
