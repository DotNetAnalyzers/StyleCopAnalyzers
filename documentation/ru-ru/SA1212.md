## Причина

Метод доступа get расположен после метода доступа set или init внутри свойства или индексатора.

## Описание правила

Нарушение этого правила возникает, когда метод доступа get размещён после метода доступа set или init внутри свойства или индексатора. Чтобы соблюдать правило, метод доступа get должен располагаться первым.

Например, следующий код вызывает нарушение:

```csharp
public string Name
{ 
    set { this.name = value; }
    get { return this.name; }
}
```

Следующий код не вызывает этого нарушения:

```csharp
public string Name
{ 
    get { return this.name; }
    set { this.name = value; }
}
```

### Методы доступа readonly в C# 8

Члены readonly в структурах не изменяют требования к порядку. Метод доступа `readonly get` по-прежнему должен предшествовать любому методу доступа `set` или `init`.

```csharp
public struct S
{
    public int Value
    {
        set => this.value = value;
        readonly get => this.value;
    }
}
```

Приведённое выше свойство нарушает SA1212, поскольку метод доступа readonly get расположен после set. Чтобы устранить предупреждение, переместите readonly get перед set.

## Как исправить нарушения

Чтобы исправить нарушение, разместите метод доступа get перед set.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1212:PropertyAccessorsMustFollowOrder", Justification = "Reviewed.")]
```
