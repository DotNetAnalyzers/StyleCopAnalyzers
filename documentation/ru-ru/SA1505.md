## Причина

После открывающей фигурной скобки в элементе, инструкции или выражении C# находится пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда после открывающей фигурной скобки находится пустая строка. Например:

```csharp
public bool Enabled
{

    get 
    { 

        return this.enabled; 
    }
}
```

Приведённый выше код вызывает два нарушения, поскольку в двух местах после открывающих скобок идут пустые строки.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустую строку после открывающей фигурной скобки.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1505:OpeningBracesMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
#pragma warning restore SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
```
