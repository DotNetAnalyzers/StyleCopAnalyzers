## Причина

Документация параметров метода, конструктора, делегата или индексатора C# не соответствует фактическим параметрам элемента.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если документация параметров элемента не соответствует его фактическим параметрам или описания параметров перечислены не в том порядке, в котором параметры объявлены в элементе.

## Как исправить нарушение

Исправьте документацию параметров так, чтобы теги `<param>` следовали в том же порядке, что и параметры элемента, и каждому параметру соответствовал один тег `<param>`.

В следующем примере показан метод с корректным комментарием документации:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1612:ElementParameterDocumentationMustMatchElementParameters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1612 // ElementParameterDocumentationMustMatchElementParameters
#pragma warning restore SA1612 // ElementParameterDocumentationMustMatchElementParameters
```
