## Причина

Раздел XML-комментария документации элемента C# не содержит пробельных символов между словами.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если часть документации не содержит пробельных символов между словами. Это может указывать на некачественно написанную или оформленную документацию. Например:

```csharp
/// <summary>
/// Joinsnames
/// </summary>
/// <param name="firstName">First</param>
/// <param name="lastName">Last</param>
/// <returns>Name</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

## Как исправить нарушение

Убедитесь, что все разделы документации содержат хотя бы один пробельный символ между словами.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1630:DocumentationTextMustContainWhitespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1630 // DocumentationTextMustContainWhitespace
#pragma warning restore SA1630 // DocumentationTextMustContainWhitespace
```
