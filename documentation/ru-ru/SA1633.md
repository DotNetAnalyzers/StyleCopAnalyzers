## Причина

В файле кода C# отсутствует стандартный заголовок файла.

## Описание правила

Нарушение возникает, если в исходном файле C# отсутствует заголовок файла.

Заголовок должен располагаться в начале файла; перед ним допускаются только пробельные символы.

Заголовок файла должен быть оформлен как блок комментариев, содержащий XML или заранее настроенный текст, например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="NameOfFile.cs" company="CompanyName">
//     Company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

или

```csharp
// Copyright (c) Tunnel Vision Laboratories, LLC. All Rights Reserved.
// Licensed under the MIT License. See LICENSE in the project root for license information.
```

Тип заголовка зависит от значения свойства `xmlHeader`. Подробности настройки приведены в разделе [Настройка](Configuration.md).

### Примеры

Например, файл Widget.cs вымышленной компании Sprocket Enterprises должен содержать заголовок, подобный следующему:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
//-----------------------------------------------------------------------
```

Строки из дефисов в начале и конце заголовка не обязательны, поэтому заголовок можно записать так:

```csharp
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
```

Можно добавлять дополнительные теги, однако StyleCop не проверяет их и не требует их наличия:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
// <author>John Doe</author>
//-----------------------------------------------------------------------
```

Файл, полностью автоматически сгенерированный инструментом и не подлежащий проверке StyleCop, может содержать заголовок «auto-generated» вместо стандартного заголовка. В этом случае StyleCop игнорирует файл. Такой заголовок никогда не следует помещать в начало файла с кодом, написанным вручную.

```csharp
// <auto-generated />
namespace Sample.Something
{
    // The contents of this file are completely auto-generated by a tool.
}
```

## Как исправить нарушение

Добавьте стандартный заголовок в начало файла.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1633:FileMustHaveHeader", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1633 // FileMustHaveHeader
#pragma warning restore SA1633 // FileMustHaveHeader
```
