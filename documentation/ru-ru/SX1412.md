# SX1412: Сохраняйте файлы в кодировке UTF-8 без метки порядка байтов

:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Файл сохранён не в кодировке UTF-8 без метки порядка байтов.

## Описание правила

Хранение файлов в этой кодировке обеспечивает их одинаковую обработку компилятором даже при компиляции в системах с разными кодировками по умолчанию. Некоторые средства и библиотеки также требуют исходные файлы UTF-8 без метки порядка байтов.

Это правило противоречит правилу [SA1412](SA1412.md), которое требует метку порядка байтов UTF-8. Включите только правило, соответствующее требованиям проекта.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, преобразуйте кодировку файла в UTF-8 без метки порядка байтов.
