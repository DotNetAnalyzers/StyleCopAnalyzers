## Причина

В заголовке файла в начале файла кода C# отсутствует имя файла.

## Описание правила

Нарушение возникает, если заголовок файла C# не содержит корректного указания имени файла. Например:

```csharp
//-----------------------------------------------------------------------
// <copyright company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Заголовок должен включать атрибут file с именем файла, например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Как исправить нарушение

Добавьте атрибут file с именем файла.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1637:FileHeaderMustContainFileName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1637 // FileHeaderMustContainFileName
#pragma warning restore SA1637 // FileHeaderMustContainFileName
```
