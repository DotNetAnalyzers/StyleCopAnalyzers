## Причина

В файле кода C# директива using для пространства имён *System* расположена после директивы using для другого пространства имён.

## Описание правила

Нарушение этого правила возникает, когда директива using для пространства имён *System* размещена после директивы using, не относящейся к *System*. Размещение всех директив using для *System* в начале списка делает код аккуратнее и понятнее, а также помогает быстрее определить используемые пространства имён.

Это правило применяется только при значении `true` параметра `systemUsingDirectivesFirst`, установленном по умолчанию (см. [Configuration.md](Configuration.md#using-directives)).

Глобальные директивы using (C# 10) анализируются независимо от локальных. Диагностика и исправления сравнивают только директивы, в которых либо у обеих есть модификатор `global`, либо у обеих его нет.

## Как исправить нарушения

Чтобы исправить нарушение, разместите директиву using для *System* выше всех директив using для других пространств имён.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1208:SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
#pragma warning restore SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
```
