## Причина

Тег `<typeparam>` в XML-комментарии документации обобщённого элемента C# пуст.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если XML-комментарий документации элемента содержит пустой тег `<typeparam>`.

## Как исправить нарушение

Заполните каждый тег `<typeparam>` описанием параметра типа.

В следующем примере показан метод с корректным комментарием документации:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1622:GenericTypeParameterDocumentationMustHaveText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1622 // GenericTypeParameterDocumentationMustHaveText
#pragma warning restore SA1622 // GenericTypeParameterDocumentationMustHaveText
```
