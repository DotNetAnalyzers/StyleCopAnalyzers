## Причина

Имя поля public или internal языка C# не начинается с прописной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя поля public или internal начинается со строчной буквы. Имена полей public и internal должны начинаться с прописной буквы.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому начинаться со строчной буквы, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

Члены readonly в C# 8 не изменяют область действия этого правила. Оно по-прежнему применяется только к объявлениям полей (включая поля readonly в структурах) и игнорирует методы, свойства, индексаторы и события readonly. Поля readonly с доступом public и internal по-прежнему анализируются этим правилом, а статические поля readonly также могут вызывать SA1311. Когда SA1307 включено, SA1304 не срабатывает для полей readonly с доступом public, internal и protected internal, поэтому выдаётся только одно из этих двух диагностических сообщений. Поля readonly с доступом protected и private protected проверяются SA1304, а не SA1307.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя поля так, чтобы оно начиналось с прописной буквы, либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1307:AccessibleFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1307 // AccessibleFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1307 // AccessibleFieldsMustBeginWithUpperCaseLetter
```
