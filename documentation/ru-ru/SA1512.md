## Причина

После однострочного комментария в коде C# находится пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда после однострочного комментария находится пустая строка. Например:

```csharp
public bool Enabled
{
    get 
    {
        // Return the value of the 'enabled' field.

        return this.enabled;
    }
}
```

Приведённый выше код вызывает нарушение, поскольку после однострочного комментария идёт пустая строка.

Между двумя блоками однострочных комментариев допускается пустая строка. Например:

```csharp
public bool Enabled
{
    get 
    {
        // This is a sample comment which doesn't really say anything.
        // This is another part of the comment.

        // There is a blank line above this comment but that is ok.
        return this.enabled;  
    }
}
```

Если комментарий используется для отключения строки кода, начните его с четырёх символов косой черты, а не с двух. В этом случае StyleCop игнорирует нарушение. Например:

```csharp
public bool Enabled
{
    get 
    {
        ////return false;

        return this.enabled;  
    }
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустую строку после однострочного комментария.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1512:SingleLineCommentsMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1512 // SingleLineCommentsMustNotBeFollowedByBlankLine
#pragma warning restore SA1512 // SingleLineCommentsMustNotBeFollowedByBlankLine
```
