:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Имя переменной C# не начинается со строчной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя переменной не начинается со строчной буквы.

Если имя переменной должно совпадать с именем элемента Win32 или COM и поэтому начинаться с прописной буквы, поместите переменную в специальный класс `NativeMethods`. Классом `NativeMethods` считается любой класс, имя которого заканчивается на `NativeMethods` и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе `NativeMethods`.

Имена, состоящие только из подчёркиваний (например, `_` или `__`), допускаются для переменных итерации `foreach` и объявлений `using` C# 8, поскольку в этих местах нельзя использовать отбрасывание. В остальных случаях вместо переменной с именем `_` следует использовать отбрасывание. Например, пишите `_ = GetValue();`, а не `var _ = GetValue();`.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя переменной так, чтобы оно начиналось со строчной буквы, либо при необходимости поместите элемент в класс `NativeMethods`.

Если переменная, имя которой состоит только из подчёркиваний, нигде не используется, исправление кода может заменить её отбрасыванием (C# 7 и новее). Например:

| До | После |
| --- | --- |
| `var _ = GetValue();` | `_ = GetValue();` |
| `string __ = GetValue();` | `_ = GetValue();` |
| `int.TryParse(text, out var __);` | `int.TryParse(text, out _);` |
| `int.TryParse(text, out int __);` | `int.TryParse(text, out int _);` |
| `var (__, value) = GetPair();` | `var (_, value) = GetPair();` |
| `if (obj is int __)` | `if (obj is int _)` |

Это исправление не предлагается, если переменная читается или изменяется в другом месте, если объявление содержит несколько переменных или не имеет инициализатора, если замена на отбрасывание изменила бы преобразование, применяемое к значению (например, `long __ = 1;`, `string __ = null;` или пользовательское неявное преобразование), либо если в области видимости есть другой символ с именем `_` и отбрасывание вместо этого связывалось бы с ним. Если другой символ с именем `_` находится в области видимости, `out var __` превращается в `out var _`, а не в `out _`.

## Как подавить нарушения

```csharp
#pragma warning disable SA1312 // VariableNamesMustBeginWithLowerCaseLetter
int Variable = 3;
#pragma warning restore SA1312 // VariableNamesMustBeginWithLowerCaseLetter
```
