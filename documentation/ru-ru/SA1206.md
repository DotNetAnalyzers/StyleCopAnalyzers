# SA1206: Ключевые слова объявления должны следовать установленному порядку

## Причина

Ключевые слова в объявлении элемента не следуют стандартному порядку.

## Описание правила

Нарушение этого правила возникает, когда ключевые слова в объявлении элемента не следуют стандартному порядку.

В объявлении элемента ключевые слова должны располагаться в следующем порядке:

*Модификаторы доступа*

*static*

*Все остальные ключевые слова*

Использование стандартного порядка ключевых слов в объявлениях делает код более читаемым, выделяя уровень доступа каждого элемента. Это помогает избежать предоставления элементам более высокого уровня доступа, чем необходимо.

## Как исправить нарушения

Чтобы исправить нарушение, расположите ключевые слова в объявлении элемента в описанном выше порядке.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1206:DeclarationKeywordsMustFollowOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1206 // DeclarationKeywordsMustFollowOrder
#pragma warning restore SA1206 // DeclarationKeywordsMustFollowOrder
```
