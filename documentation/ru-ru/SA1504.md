## Причина

В свойстве, индексаторе или событии C# как минимум один метод доступа записан на одной строке и как минимум один — на нескольких строках.

## Описание правила

Нарушение этого правила возникает, когда методы доступа внутри свойства, индексатора или события оформлены неодинаково: часть занимает одну строку, а часть — несколько. Правило повышает читаемость кода, требуя одинакового оформления всех методов доступа одного элемента.

Например, следующее свойство вызывает нарушение, поскольку один метод доступа занимает одну строку, а другой — несколько.

```csharp
public bool Enabled
{
    get { return this.enabled; }

    set
    {
        this.enabled = value;
    }
}
```

Нарушения можно избежать, записав каждый метод доступа на одной строке либо развернув оба на несколько строк:

```csharp
public bool Enabled
{
    get { return this.enabled; }
    set { this.enabled = value; }
}


public bool Enabled
{
    get 
    { 
        return this.enabled; 
    }

    set 
    { 
        this.enabled = value;
    }
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, запишите каждый метод доступа на одной строке, если они короткие, либо разверните оба на несколько строк, если они длиннее.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1504:AllAccessorsMustBeSingleLineOrMultiLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
#pragma warning restore SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
```
