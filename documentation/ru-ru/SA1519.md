:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

В многострочной инструкции C# отсутствуют открывающая и закрывающая фигурные скобки.

## Описание правила

Нарушение этого правила возникает, когда у многострочной инструкции отсутствуют открывающая и закрывающая фигурные скобки. В C# для некоторых видов инструкций скобки необязательны, например для `if`, `while` и `for`. Так, инструкцию `if` можно записать без скобок:

```csharp
if (true)
    return
        this.value;
```

Хотя в C# это допустимо, StyleCop требует наличия скобок, если инструкция занимает несколько строк, для повышения читаемости и удобства сопровождения кода.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, инструкция, вызывающая нарушение, преобразуется в блок инструкций.

## Как подавить нарушения

```csharp
if (true)
#pragma warning disable SA1519 // Braces should not be omitted from multi-line child statement
    return
        this.value;
#pragma warning restore SA1519 // Braces should not be omitted from multi-line child statement
```
