## Причина

Статический элемент размещён ниже элемента экземпляра того же вида.

## Описание правила

Нарушение этого правила возникает, когда статический элемент размещён ниже элемента экземпляра того же вида. Все статические элементы должны располагаться выше элементов экземпляра того же вида, чтобы было проще различать интерфейсы статической части класса и его экземпляров.

Это правило применяется к классам, структурам и интерфейсам. Статические члены интерфейсов (появившиеся вместе с членами интерфейсов по умолчанию в C# 8) должны предшествовать членам экземпляра, включая члены с реализацией по умолчанию.

Например, следующее объявление интерфейса нарушает это правило, поскольку статический член расположен после члена экземпляра с реализацией по умолчанию:

```csharp
public interface IExample
{
    void Instance() { }
    static void Helper() { } // SA1204
}
```

При правильном упорядочивании статические члены интерфейса располагаются перед членами экземпляра:

```csharp
public interface IExample
{
    static void Helper() { }
    void Instance() { }
}
```

## Как исправить нарушения

Чтобы исправить нарушение, разместите все статические элементы выше элементов экземпляра того же вида.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1204:StaticElementsMustAppearBeforeInstanceElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1204 // StaticElementsMustAppearBeforeInstanceElements
#pragma warning restore SA1204 // StaticElementsMustAppearBeforeInstanceElements
```
