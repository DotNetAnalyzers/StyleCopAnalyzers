## Причина

Элемент C#, содержащий открывающую и закрывающую фигурные скобки, целиком записан на одной строке.

## Описание правила

Нарушение этого правила возникает, когда элемент, заключённый в фигурные скобки, записан на одной строке. Например:

```csharp
public object Method() { return null; }
```

При проверке этого кода StyleCop сообщает о нарушении, поскольку весь метод записан на одной строке. Метод следует разместить на нескольких строках, причём открывающая и закрывающая скобки должны находиться на отдельных строках, как в следующем примере:

```csharp
public object Method()
{
    return null; 
}
```

В качестве исключения короткие методы доступа свойств, событий и индексаторов допускается целиком записывать на одной строке.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, перепишите элемент так, чтобы он занимал несколько строк.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1502:ElementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1502 // ElementMustNotBeOnSingleLine
#pragma warning restore SA1502 // ElementMustNotBeOnSingleLine
```
