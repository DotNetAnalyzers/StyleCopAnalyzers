:memo: Это новое правило StyleCop Analyzers, которого не было в StyleCop Classic.

## Причина

Документация элемента содержит один или несколько элементов `<placeholder>`.

## Описание правила

Нарушение возникает, если документация элемента содержит элементы `<placeholder>`:

```csharp
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
{
}
```

Элементы-заполнители следует проверять и удалять из документации.

## Как исправить нарушение

Проверьте точность текста документации внутри заполнителей и удалите теги `<placeholder>`.

## Как подавить нарушение

```csharp
#pragma warning disable SA1651 // Do not use placeholder elements
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
#pragma warning restore SA1651 // Do not use placeholder elements
{
}
```
