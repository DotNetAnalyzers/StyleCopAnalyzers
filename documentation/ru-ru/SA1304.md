## Причина

Имя поля readonly языка C#, не являющегося private, должно начинаться с прописной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя поля readonly, не являющегося private, не начинается с прописной буквы. Имена таких полей всегда должны начинаться с прописной буквы.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому начинаться со строчной буквы, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

C# 8 позволяет объявлять члены readonly в структурах. Это правило по-прежнему анализирует только поля readonly; методы, свойства, индексаторы и события readonly игнорируются. SA1304 проверяет поля readonly с доступом protected и private protected, даже если SA1307 включено. Для полей readonly с доступом public, internal и protected internal нарушение именования сообщает SA1307, а не SA1304, если SA1307 включено; если SA1307 отключено, SA1304 проверяет и эти поля. Статические поля readonly также могут вызывать SA1311.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя поля readonly так, чтобы оно начиналось с прописной буквы, сделайте поле private либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1304:NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1304 // NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1304 // NonPrivateReadonlyFieldsMustBeginWithUpperCaseLetter
```
