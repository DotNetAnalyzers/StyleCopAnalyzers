## Причина

Имя статического поля readonly не начинается с прописной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя статического поля readonly начинается со строчной буквы.

В C# 8 появились члены readonly для структур; это правило по-прежнему проверяет только статические поля readonly и игнорирует методы, свойства, индексаторы и события readonly. Доступные извне статические поля readonly также могут вызывать SA1307, тогда как SA1304 не сообщает о нарушениях для статических полей readonly. Это предотвращает срабатывание всех трёх правил именования на одном поле, сохраняя проверку статических полей readonly.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя поля так, чтобы оно начиналось с прописной буквы.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1311:StaticReadonlyFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1311 // StaticReadonlyFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1311 // StaticReadonlyFieldsMustBeginWithUpperCaseLetter
```
