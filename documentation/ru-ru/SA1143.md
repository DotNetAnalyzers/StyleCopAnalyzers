# SA1143: Условные выражения должны быть единообразно оформлены

## Причина

Условное выражение (`?:`) занимает несколько строк, но не использует ни один из поддерживаемых форматов.
Правило включено по умолчанию и выдаёт предупреждение на токене `?` внешнего условного выражения.

## Описание правила

Используйте один из трёх форматов:

* Всё выражение в одной строке.
* Условие может занимать несколько строк, затем следуют отдельные строки с одинаковым отступом,
  начинающиеся с `?` и `:`. Каждая ветвь начинается в строке своего оператора и может продолжаться на
  дополнительных строках. Отступ строк с операторами должен быть больше отступа последней строки условия.
* Для цепочки по ложным ветвям — одно условие, `?`, истинная ветвь и `:` в каждой строке.
  Последующие условия и последняя ложная ветвь начинаются в отдельных строках и выравниваются по первому условию.

Например, следующее выражение с частичным переносом строк нарушает правило:

```csharp
var x = condition ? first :
    second;
```

Все следующие форматы допустимы:

```csharp
var x = condition ? first : second;

var x = condition
    ? first
    : second;

var x = p == "Cat" ? "Animals" :
        p == "Bat" ? "Equipment" :
        p == "Fat" ? "Nutrition" :
        "None";
```

Развёрнутый формат также позволяет продолжать ветвь на дополнительных строках. Каждая строка продолжения должна иметь
отступ больше, чем у её оператора `?` или `:`; исключение — строка, начинающаяся с `{` или `}`, которая может быть выровнена по оператору:

```csharp
var x = condition &&
        otherCondition
            ? first * second +
                third * fourth +
                fifth * sixth
            : 0;
```

Развёрнутый формат также поддерживает вложенные ложные ветви с дополнительным отступом:

```csharp
var x = firstCondition
    ? first
    : secondCondition
        ? second
        : third;
```

Символы табуляции учитываются согласно настроенной ширине табуляции. Правило не ограничивает длину строк.
Правило не добавляет и не удаляет скобки; выражения в скобках также проверяются.

## Исправление нарушений

Исправление кода предлагает однострочный и развёрнутый многострочный форматы. Для цепочек по ложным ветвям
также предлагается формат с выравниванием. Каждый вариант поддерживает массовое исправление (Fix All).

Блочные комментарии, занимающие одну строку, сохраняются. Автоматическое исправление не предлагается,
если выражение содержит строчные комментарии, многострочные комментарии, директивы или многострочные токены
литералов, которые нельзя безопасно разместить в одной строке. В таких случаях измените формат вручную,
не меняя содержимое комментариев и литералов.

## Подавление нарушений

```csharp
#pragma warning disable SA1143 // Conditional expressions must be formatted consistently
// Code containing the violation.
#pragma warning restore SA1143 // Conditional expressions must be formatted consistently
```
