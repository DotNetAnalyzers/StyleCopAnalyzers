:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.
:memo: Это правило действует только для C# 7.0 и новее.

## Причина

Имена элементов типа-кортежа должны использовать правильный регистр.

## Описание правила

В типах-кортежах с именованными элементами регистр имён элементов должен соответствовать настройкам (подробности см. в [Configuration.md](Configuration.md)). Сведения о работе с кортежами в C# 7 см. в документации по [типам-кортежам](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Например, следующий код вызывает нарушение этого правила при настройках по умолчанию:

```csharp
public class ExampleClass
{
  public (int valueA, int valueB) ExampleMethod() // SA1316
  {
  }
}
```

Следующий код не вызывает нарушений:

```csharp
public class ExampleClass
{
  public (int ValueA, int ValueB) ExampleMethod()
  {
  }
}
```

Явные имена элементов в выражениях кортежей, например `(valueA: 1, valueB: 2)`, проверяются аналогично. Имена элементов, выведенные из выражения, например `(valueA, valueB)`, проверяются только при включённом параметре `includeInferredTupleElementNames` (см. [Configuration.md](Configuration.md)).

## Как исправить нарушения

Чтобы исправить нарушение этого правила, исправьте регистр имени элемента кортежа.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1316:TupleElementNamesShouldUseCorrectCasing", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1316 // Tuple element names should use correct casing
#pragma warning restore SA1316 // Tuple element names should use correct casing
```
