## Причина

В XML-комментарии документации элемента C# отсутствует тег `<summary>`.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, когда в документации элемента отсутствует тег `<summary>`.

## Как исправить нарушение

Добавьте тег `<summary>` для элемента и заполните его описанием элемента.

В следующем примере показан класс с комментарием документации без краткого описания.

```csharp
/// <remarks>A remark.</remarks>
public class Customer
{
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1604:ElementDocumentationMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1604 // ElementDocumentationMustHaveSummary
#pragma warning restore SA1604 // ElementDocumentationMustHaveSummary
```
