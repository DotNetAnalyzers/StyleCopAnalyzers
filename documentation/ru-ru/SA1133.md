## SA1133

<table>

  <td>TypeName</td>
  <td>SA1133DoNotCombineAttributes</td>
</tr>
<tr>
  <td>CheckId</td>
  <td>SA1133</td>
</tr>
<tr>
  <td>Категория</td>
  <td>Правила удобочитаемости</td>
</tr>
</table>

:memo: Это правило является новым для **StyleCop Analyzers**, и его не было в **StyleCop Classic**.

## Причина

Два или более атрибута находятся в одном блоке квадратных скобок.

## Описание правила

Нарушение этого правила происходит, когда два или более атрибута помещаются в один и тот же блок квадратных скобок.

Например, следующий код приведет к нарушению этого правила:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider)), Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

Следующий код не приведет ни к каким нарушениям:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))]
[Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

### Исключения

Нарушение этого правила не произойдет для атрибутов, размещенных у параметров или параметров типа.

Например, следующий код не приведет к нарушению:

```csharp
public class MyClass<[Foo, Bar] T>
{
	public T MyMethod([In, MarshalAs(UnmanagedType.LPWStr)] string value)
	{
	    ...
	}
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, поместите каждый атрибут в свой собственный набор квадратных скобок.

## Как подавить нарушения

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider)),
#pragma warning disable SA1133 // Do not combine attributes
    Shared]
#pragma warning restore SA1133 // Do not combine attributes
public class MyCodeFixProvider : CodeFixProvider
{
}
```
