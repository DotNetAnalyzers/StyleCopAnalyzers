# SA1654: Правильно оформляйте угловые скобки обобщенных типов

## Причина

В атрибуте `cref` для аргументов обобщенного типа используются экранированные угловые скобки, например `GenericClass&lt;T&gt;`.

## Описание правила

В атрибутах `cref` XML-документации для аргументов обобщенных типов следует использовать фигурные скобки.
Это более читаемый вариант, чем экранированные угловые скобки, и рекомендуемый синтаксис ссылок в документации C#.

## Как исправить нарушение

Используйте автоматическое исправление кода или замените экранированные угловые скобки фигурными:

```csharp
/// <summary>
/// Uses <see cref="GenericClass{T}"/>.
/// </summary>
public class GenericClass<T>
{
}
```

## Как отключить предупреждение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1654:ProperlyEncodeGenericBrackets", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1654 // Properly encode generic brackets
#pragma warning restore SA1654 // Properly encode generic brackets
```
