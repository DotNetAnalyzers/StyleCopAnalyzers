## Причина

В инструкции C# отсутствуют открывающая и закрывающая фигурные скобки.

## Описание правила

Нарушение этого правила возникает, когда у инструкции отсутствуют открывающая и закрывающая фигурные скобки. В C# для некоторых видов инструкций скобки необязательны, например для if, while и for. Так, инструкцию if можно записать без скобок:

```csharp
if (true) 
    return this.value;
```

Хотя в C# это допустимо, StyleCop всегда требует наличия скобок для повышения читаемости и удобства сопровождения кода.

При отсутствии скобок можно внести ошибку, добавив ещё одну инструкцию ниже if. Например:

```csharp
if (true) 
    this.value = 2;       
    return this.value;
```

При беглом взгляде на этот код кажется, что и присваивание, и return принадлежат инструкции if. В действительности это не так. Только присваивание относится к if, а return будет выполняться всегда, независимо от результата проверки условия if.

Чтобы предотвратить подобные ошибки, StyleCop всегда требует наличия открывающей и закрывающей фигурных скобок:

```csharp
if (true) 
{
    this.value = 2;
    return this.value;
}
```

Объявления using в C# 8 намеренно не содержат блока в фигурных скобках. Такие инструкции, как `using var stream = new MemoryStream();` (или `await using` для `IAsyncDisposable`), допустимы и не отмечаются этим правилом, поскольку заключение их в скобки изменило бы время жизни объявленного ресурса.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, заключите тело инструкции в фигурные скобки.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1503:BracesMustNotBeOmitted", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1503 // BracesMustNotBeOmitted
#pragma warning restore SA1503 // BracesMustNotBeOmitted
```
