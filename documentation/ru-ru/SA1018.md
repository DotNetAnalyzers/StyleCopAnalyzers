## Причина

Пробелы вокруг символа типа, допускающего значение null, в элементе C# расставлены неправильно.

## Описание правила

Нарушение этого правила происходит при неправильной расстановке пробелов вокруг символа типа, допускающего значение null.

Перед символом типа, допускающего значение null, не должно быть пробельных символов, если только он не является первым символом в строке.

Это относится как к типам значений, допускающим null, так и к ссылочным типам, допускающим null, введённым в C# 8.
В контексте `#nullable enable` код вида `string ? value` или `System.Collections.Generic.List<string?> ? list`
вызывает срабатывание этого правила. При правильной расстановке пробелов перед `?` пробела нет:
например, `string? value` или `System.Collections.Generic.List<string?>? list`.

## Как исправить нарушение

Чтобы исправить нарушение этого правила, убедитесь, что перед символом типа, допускающего значение null, нет пробельных символов.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1018:NullableTypeSymbolsMustNotBePrecededBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
#pragma warning restore SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
```
