# SA1317: В именах идентификаторов должны использоваться только латинские буквы

## Причина

Объявленный идентификатор содержит букву, не входящую в базовую латиницу `A`–`Z` и `a`–`z`.

## Описание правила

Буквы разных алфавитов могут выглядеть одинаково, поэтому случайную подмену легко не заметить.
Правило проверяет компоненты пространств имен, имена типов и членов, параметры и параметры типов, локальные переменные, переменные запросов, метки и явно заданные имена элементов кортежей.
Проверяются объявления, а не ссылки на идентификаторы.

Ограничение относится только к буквам: цифры, символы подчеркивания и другие небуквенные символы, разрешенные в C#, не затрагиваются.
Латинские буквы с диакритическими знаками, например `é`, не входят в базовую латиницу и вызывают диагностику.
Перед проверкой имени префикс `@` удаляется, а escape-последовательности Юникода декодируются.
Для каждой недопустимой буквы выдается диагностика на идентификаторе; позиция в сообщении — это индекс с отсчетом от нуля в кодовых единицах UTF-16 в декодированном имени без префикса `@`.

Например, имя `ЕxаmplеClаss` содержит кириллические буквы и нарушает правило:

```csharp
public class ЕxаmplеClаss {}
```

Следующее объявление не нарушает правило:

```csharp
public class ExampleClass {}
```

## Исправление нарушений

Замените недопустимые буквы подходящими буквами базовой латиницы.
Автоматическое исправление не предоставляется, поскольку нельзя надежно определить предполагаемую замену.

## Подавление нарушений

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1317:IdentifierShouldBeNamedOnlyWithLatinLetters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1317 // Identifier should be named only with Latin letters
#pragma warning restore SA1317 // Identifier should be named only with Latin letters
```
