# SA1412: Сохраняйте файлы в кодировке UTF-8 с меткой порядка байтов

:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Файл сохранён не в кодировке UTF-8 с маркером порядка байтов.

## Описание правила

Хранение файлов в этой кодировке обеспечивает их одинаковую обработку компилятором даже при компиляции в системах с разными кодировками по умолчанию. Кроме того, эта кодировка наиболее широко поддерживается такими средствами, как визуальное сравнение изменений на GitHub, и другими инструментами. Она также используется по умолчанию при создании новых файлов исходного кода C# в Visual Studio.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, преобразуйте кодировку файла в UTF-8 с маркером порядка байтов.

## Альтернативные правила

Если проект требует файлы UTF-8 без маркера порядка байтов, используйте вместо этого [SX1412](SX1412.md).
