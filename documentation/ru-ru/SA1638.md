# SA1638: Имя файла в документации заголовка должно соответствовать имени файла

## Причина

Атрибут file в заголовке файла в начале файла кода C# не содержит имя этого файла.

## Описание правила

Нарушение возникает, если атрибут file в заголовке файла C# не содержит имя файла. Например, рассмотрим исходный файл C# с именем File1.cs и следующим заголовком:

```csharp
//-----------------------------------------------------------------------
// <copyright file="File2.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Здесь возникает нарушение, поскольку атрибут file не содержит правильного имени файла. Заголовок следует записать так:

```csharp
//-----------------------------------------------------------------------
// <copyright file="File1.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Как исправить нарушение

Укажите имя файла в атрибуте file.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1638:FileHeaderFileNameDocumentationMustMatchFileName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1638 // FileHeaderFileNameDocumentationMustMatchFileName
#pragma warning restore SA1638 // FileHeaderFileNameDocumentationMustMatchFileName
```
