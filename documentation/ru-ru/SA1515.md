## Причина

Перед однострочным комментарием в коде C# отсутствует пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда перед однострочным комментарием нет пустой строки. Например:

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

Приведённый выше код вызывает нарушение, поскольку перед однострочным комментарием отсутствует пустая строка.

Исключение возникает, когда однострочный комментарий является первым элементом в своей области видимости. В этом случае перед ним не должно быть пустой строки. Например:

```csharp
public bool Enabled
{
    get 
    {
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

В приведённом выше коде комментарий является первым элементом в своей области видимости, поэтому перед ним не должно быть пустой строки.

Если комментарий используется для отключения строки кода, начните его с четырёх символов косой черты, а не с двух. В этом случае StyleCop игнорирует нарушение. Например:

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        ////return false;
        return this.enabled;  
    }
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте пустую строку перед комментарием.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1515:SingleLineCommentMustBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1515 // SingleLineCommentMustBePrecededByBlankLine
#pragma warning restore SA1515 // SingleLineCommentMustBePrecededByBlankLine
```
