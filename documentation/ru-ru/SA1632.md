## Причина

Начиная со StyleCop 4.5 это правило отключено по умолчанию.

Раздел XML-комментария документации элемента C# слишком короткий.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если часть документации слишком короткая. Часто это указывает на недостаточную содержательность документации. Например:

```csharp
/// <summary>
/// A name
/// </summary>
public class Name
{
    ...
}
```

## Как исправить нарушение

Перепишите текст документации грамматически правильно и содержательно. В большинстве случаев после этого длина текста превысит минимальную длину, при которой срабатывает правило.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1632:DocumentationTextMustMeetMinimumCharacterLength", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1632 // DocumentationTextMustMeetMinimumCharacterLength
#pragma warning restore SA1632 // DocumentationTextMustMeetMinimumCharacterLength
```
