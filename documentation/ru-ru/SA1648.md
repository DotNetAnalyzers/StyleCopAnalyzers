# SA1648: Тег inheritdoc должен использоваться с наследующим классом

## Причина

Тег `<inheritdoc>` использован у элемента, который не наследует базовый класс и не реализует интерфейс.

## Описание правила

Правило проверяет, что элемент `<inheritdoc>` не используется, если класс или интерфейс не наследует базовый класс или
интерфейс. Нарушение возникает, если элемент, содержащий `<inheritdoc>`, не наследует
базовый класс и не реализует интерфейс.

Элементы `<inheritdoc/>` всегда разрешены, если у них есть атрибут `cref`, указывающий целевой элемент,
от которого наследуется документация.

## Как исправить нарушение

Удалите элемент `<inheritdoc>` и надлежащим образом документируйте элемент кода.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1648:InheritDocMustBeUsedWithInheritingClass", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1648 // InheritDocMustBeUsedWithInheritingClass
#pragma warning restore SA1648 // InheritDocMustBeUsedWithInheritingClass
```
