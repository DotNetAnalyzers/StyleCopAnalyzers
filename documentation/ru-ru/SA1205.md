## Причина

У частичного элемента не указан модификатор доступа.

## Описание правила

Нарушение этого правила возникает, когда у частичного элемента не указан модификатор доступа.

### Частичные методы в C# 9

C# 9 позволяет частичным методам иметь модификаторы доступа и возвращаемые типы, отличные от `void`. Для совместимости между версиями SA1205 не требует указывать эти модификаторы доступа. Кроме того, при использовании новых возможностей их наличие проверяет компилятор, поэтому SA1205 не выдаёт дублирующие диагностические сообщения при отсутствии обязательных модификаторов.

### Типы с областью видимости файла в C# 11

Тип `file` виден только в своём файле и не может одновременно объявляться как `public`, `internal`, `protected` или `private`. SA1205 рассматривает `file` как модификатор доступа частичного типа, поэтому объявление `file partial class` не вызывает диагностику.

## Как исправить нарушения

Чтобы исправить нарушение, укажите модификатор доступа для частичного элемента.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1205:PartialElementsMustDeclareAccess", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1205 // PartialElementsMustDeclareAccess
#pragma warning restore SA1205 // PartialElementsMustDeclareAccess
```
