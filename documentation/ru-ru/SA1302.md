## Причина

Имя интерфейса C# не начинается с прописной буквы I.

## Описание правила

Нарушение этого правила возникает, когда имя интерфейса не начинается с прописной буквы I. Имена интерфейсов всегда должны начинаться с I, например *ICustomer*.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому не может начинаться с буквы I, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте прописную букву I в начало имени интерфейса либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1302:InterfaceNamesMustBeginWithI", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1302 // InterfaceNamesMustBeginWithI
#pragma warning restore SA1302 // InterfaceNamesMustBeginWithI
```
