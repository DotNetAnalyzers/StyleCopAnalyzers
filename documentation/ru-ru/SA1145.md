# SA1145: Не используйте присваивание в качестве условия

## Причина

Выражение присваивания используется как условие или как операнд логического оператора.
Это правило включено по умолчанию и выдаёт предупреждение на выражении присваивания.

## Описание правила

Использование `=` вместо `==` в условии обычно не компилируется в C#, но компилируется, если присваиваемое значение имеет тип `bool`.
Правило сообщает о присваивании (простом, составном или `??=`), если после пропуска скобок его родителем является:

* оператор условного И (`&&`), условного ИЛИ (`||`) или логического НЕ (`!`)
* условие условного выражения (`?:`)
* условие инструкции `if`, `while`, `do`...`while` или `for`
* фильтр исключений (предложение `when`)

Следующий код нарушает правило:

```csharp
bool flag = false;
if (flag = Compute())
{
}

while (!(done = Step()))
{
}
```

О присваиваниях, результат которых сравнивается с другим значением, сообщения нет:

```csharp
string line;
while ((line = reader.ReadLine()) != null)
{
}
```

## Как исправить нарушения

Замените присваивание сравнением или вынесите присваивание в отдельную инструкцию.

```csharp
bool flag = Compute();
if (flag)
{
}
```

## Как подавить нарушения

```csharp
#pragma warning disable SA1145 // Do not use assignment as condition
// Code containing the violation.
#pragma warning restore SA1145 // Do not use assignment as condition
```
