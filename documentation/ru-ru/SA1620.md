## Причина

Теги `<typeparam>` в XML-комментарии документации обобщённого элемента C# не соответствуют параметрам типа элемента.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если теги `<typeparam>` в комментарии документации элемента не соответствуют его параметрам типа или следуют не в том порядке, в котором параметры типа объявлены в элементе.

## Как исправить нарушение

Добавьте и заполните по одному тегу `<typeparam>` для каждого параметра типа элемента и убедитесь, что эти теги следуют в том же порядке, что и параметры типа.

В следующем примере показан метод с корректным комментарием документации:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1620:GenericTypeParameterDocumentationMustMatchTypeParameters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1620 // GenericTypeParameterDocumentationMustMatchTypeParameters
#pragma warning restore SA1620 // GenericTypeParameterDocumentationMustMatchTypeParameters
```
