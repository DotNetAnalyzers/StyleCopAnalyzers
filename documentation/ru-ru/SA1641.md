## Причина

Заголовок файла в начале файла кода C# не содержит требуемого названия компании.

## Описание правила

Нарушение возникает, если заголовок файла C# не содержит названия компании, заданного для проекта.

Для работы этого правила необходимо задать свойство `companyName`. Кроме того, свойство `xmlHeader` должно либо отсутствовать, либо иметь значение **true**.
Подробности приведены в разделе [Настройка](Configuration.md).

При этих настройках каждый файл проекта должен содержать требуемое название компании в теге copyright заголовка файла, как показано в следующем примере:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Как исправить нарушение

Добавьте стандартное название вашей компании в тег copyright заголовка файла.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1641:FileHeaderCompanyNameTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1641 // FileHeaderCompanyNameTextMustMatch
#pragma warning restore SA1641 // FileHeaderCompanyNameTextMustMatch
```
