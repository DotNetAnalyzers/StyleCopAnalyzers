## Причина

XML в комментарии документации элемента C# имеет некорректную структуру.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, когда XML документации имеет некорректную структуру и не может быть разобран. Например, это возможно, если XML содержит недопустимые символы или у XML-узла отсутствует закрывающий тег.

## Как исправить нарушение

Замените некорректный XML корректным XML, который может быть разобран стандартным XML-парсером.

В следующем примере показан класс с некорректным XML в комментарии документации. Закрывающий тег узла `<summary>` неверен.

```csharp
/// <summary>
/// An example of badly formed Xml.
/// </summa3ry>
public class Example
{
}
```
