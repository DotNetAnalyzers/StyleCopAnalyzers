## Причина

При использовании анонимного метода C# без параметров в записи по-прежнему присутствуют круглые скобки.

## Описание правила

Если анонимный метод не содержит параметров, круглые скобки вокруг списка параметров необязательны.

Нарушение этого правила возникает, когда при использовании анонимного метода без параметров присутствуют круглые скобки. Например:

```csharp
this.Method(delegate() { return 2; });
this.Method(static delegate() { return 2; });
```

Эти скобки не нужны, и их следует удалить:

```csharp
this.Method(delegate { return 2; });
this.Method(static delegate { return 2; });
```

## Как исправить нарушения

Удалите ненужные круглые скобки после ключевого слова delegate.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1410:RemoveDelegateParenthesisWhenPossible", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1410 // RemoveDelegateParenthesisWhenPossible
#pragma warning restore SA1410 // RemoveDelegateParenthesisWhenPossible
```
