## Причина

Имя поля C# не начинается со строчной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя поля начинается с прописной буквы. Имена констант, полей readonly, не являющихся private, и статических полей readonly всегда должны начинаться с прописной буквы, а имена полей private readonly — со строчной. Кроме того, имена полей public или internal всегда должны начинаться с прописной буквы.

Если имя поля должно совпадать с именем элемента Win32 или COM и поэтому начинаться с прописной буквы, поместите поле в специальный класс `NativeMethods`. Классом `NativeMethods` считается любой класс, имя которого заканчивается на `NativeMethods` и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе `NativeMethods`.

> :warning: Это правило отличается от соответствующего правила в StyleCop «classic» следующим образом:
>
> Это правило проверяет только имена полей. SA1306 в StyleCop «classic» проверяет поля, параметры и локальные переменные.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя поля так, чтобы оно начиналось со строчной буквы, либо при необходимости поместите элемент в класс `NativeMethods`.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1306:FieldNamesMustBeginWithLowerCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1306 // FieldNamesMustBeginWithLowerCaseLetter
private int Field = 3;
#pragma warning restore SA1306 // FieldNamesMustBeginWithLowerCaseLetter
```
