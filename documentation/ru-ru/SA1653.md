# SA1653: Только одно частичное объявление должно содержать краткое описание

## Причина

Несколько объявлений частичного типа содержат тег `<summary>` на верхнем уровне.

## Описание правила

XML-документация из объявлений частичного типа объединяется в документацию одного типа.
Наличие документации `<summary>` в нескольких объявлениях может привести к повторяющимся или противоречащим друг другу кратким описаниям.

Оставьте официальную документацию типа, включая `<summary>` и все теги `<typeparam>`, в одном объявлении.
Для описания остальных частей в исходном коде используйте `<content>` вместо `<summary>`.
Это соответствует правилу [SA1619](SA1619.md).

Правило сообщает о каждом объявлении с конфликтующим кратким описанием, а не выбирает объявление, в котором его следует оставить.
Оно применяется к существующей документации независимо от того, требуется ли документация для типа с данным уровнем доступности.
Краткие описания в сгенерированных объявлениях также учитываются при выявлении конфликтов, но диагностика выдаётся только для объявлений, которые не являются сгенерированными.

Учитываются только явно заданные теги `<summary>` на верхнем уровне.
Вложенные краткие описания не учитываются, а документация, предоставляемая через `<include>` или `<inheritdoc>`, не разворачивается этим правилом.

## Как исправить нарушение

Выберите одно объявление, в котором останется документация `<summary>`, а в остальных объявлениях используйте `<content>`:

```csharp
/// <summary>
/// Представляет обработчик запросов.
/// </summary>
public partial class RequestProcessor
{
}

/// <content>
/// Содержит логику проверки запросов.
/// </content>
public partial class RequestProcessor
{
}
```

Автоматическое исправление кода не предоставляется, поскольку выбор основного объявления требует решения пользователя.

## Как отключить предупреждение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1653:OnlyOnePartialDeclarationShouldContainSummaryDocumentation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1653 // Только одно частичное объявление должно содержать краткое описание
#pragma warning restore SA1653 // Только одно частичное объявление должно содержать краткое описание
```
