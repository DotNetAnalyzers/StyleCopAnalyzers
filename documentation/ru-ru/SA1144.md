# SA1144: Символы нулевой ширины в литералах должны быть экранированы

## Причина

Строковый или символьный литерал содержит символ нулевой ширины, записанный непосредственно в исходном тексте.

## Описание правила

Символы нулевой ширины невидимы в большинстве редакторов, поэтому их легко добавить случайно (например, при вставке текста с веб-страницы) и трудно найти позже. Правило сообщает о строковых, символьных, UTF-8 строковых и интерполированных строковых литералах, содержащих любой из этих символов:

* U+200B ZERO WIDTH SPACE
* U+2060 WORD JOINER
* U+FEFF ZERO WIDTH NO-BREAK SPACE

Для каждого токена литерала выдаётся одна диагностика. Соединитель и разделитель нулевой ширины (U+200D и U+200C) не обнаруживаются, поскольку они значимы в некоторых письменностях и последовательностях эмодзи.

```csharp
string value = "a​b"; // между 'a' и 'b' находится невидимый U+200B
```

## Как исправить нарушения

Замените каждый символ нулевой ширины его escape-последовательностью. Исправление кода делает это для обычных строковых, символьных и (не дословных) интерполированных строковых литералов:

```csharp
string value = "a\u200Bb";
```

Второе исправление кода вместо этого удаляет символы нулевой ширины в строковых литералах любого вида. Для символьных литералов оно не предлагается. Дословные и необработанные строковые литералы не поддерживают escape-последовательности, поэтому для них предлагается только удаление; чтобы сохранить символ, постройте строку с escape-последовательностью, например с помощью конкатенации `"\u200B"`.

## Как подавить нарушения

```csharp
#pragma warning disable SA1144 // Zero-width characters in literals must be escaped
// Code containing the violation.
#pragma warning restore SA1144 // Zero-width characters in literals must be escaped
```
