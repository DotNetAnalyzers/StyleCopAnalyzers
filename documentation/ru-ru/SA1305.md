## Причина

В имени поля или переменной C# используется венгерская нотация.

## Описание правила

Нарушение этого правила возникает, когда для именования полей и переменных используется венгерская нотация. Она получила широкое распространение в коде C++, однако в C# принято использовать более длинные и содержательные имена переменных, описывающие их назначение, а не тип.

Кроме того, современные редакторы кода, такие как Visual Studio, позволяют легко узнать тип переменной или поля — обычно достаточно навести указатель мыши на имя переменной. Это снижает потребность в венгерской нотации.

StyleCop считает, что любое имя переменной, начинающееся с одной или двух строчных букв, за которыми следует прописная буква, использует венгерскую нотацию, и сообщает о нарушении в каждом таком случае. Некоторые префиксы можно объявить допустимыми, после чего они будут игнорироваться. Например, имя переменной *onExecute* кажется StyleCop венгерской нотацией, хотя на самом деле это не так. Поэтому префикс *on* следует отметить как разрешённый.

Чтобы настроить список разрешённых префиксов, используйте **stylecop.json**, например:

```json
{
  "settings": {
    "namingRules": {
      "allowedHungarianPrefixes": [ "aa", "bb" ],
    },
  }
}
```

Добавление префикса из одной или двух букв в этот список заставит StyleCop игнорировать переменные и поля, имена которых начинаются с такого префикса.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому использовать венгерскую нотацию, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, откажитесь от венгерской нотации в имени поля или переменной либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1305:FieldNamesMustNotUseHungarianNotation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1305 // FieldNamesMustNotUseHungarianNotation
#pragma warning restore SA1305 // FieldNamesMustNotUseHungarianNotation
```
