## Причина

Атрибут SuppressMessage для анализа кода не содержит обоснования.

## Описание правила

Нарушение этого правила возникает, когда код содержит атрибут SuppressMessage для анализа кода, но в нём не указано обоснование подавления. При каждом подавлении правила анализа кода следует указывать причину. Это повышает удобство долгосрочного сопровождения кода.

```csharp
[SuppressMessage("Microsoft.Performance", "CA1804:RemoveUnusedLocals", Justification = "Used during unit testing")]
public bool Enable()
{
}
```

## Как исправить нарушения

Чтобы исправить нарушение, добавьте в атрибут SuppressMessage свойство Justification с текстом, объясняющим причину подавления.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1404:CodeAnalysisSuppressionMustHaveJustification", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1404 // CodeAnalysisSuppressionMustHaveJustification
#pragma warning restore SA1404 // CodeAnalysisSuppressionMustHaveJustification
```
