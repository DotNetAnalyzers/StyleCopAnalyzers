# SA1501: Оператор не должен располагаться в одной строке

## Причина

Инструкция C#, содержащая открывающую и закрывающую фигурные скобки, целиком записана на одной строке.

## Описание правила

Нарушение этого правила возникает, когда инструкция, заключённая в фигурные скобки, записана на одной строке. Например:

```csharp
public object Method()
{
    lock (this) { return this.value; }
}
```

При проверке этого кода StyleCop сообщает о нарушении, поскольку вся инструкция lock записана на одной строке. Инструкцию следует разместить на нескольких строках, причём открывающая и закрывающая скобки должны находиться на отдельных строках, как в следующем примере:

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value; 
    }
}
```

Пустые блоки `catch` и `finally` можно записывать в одну строку. Это исключение также распространяется на блоки, содержащие только комментарии; к блокам с инструкциями по-прежнему применяется это правило.

## Как исправить нарушения

The optional `layoutRules.allowBracelessIfStatements` setting defaults to `"off"`. With `"sameLine"`, a
standalone `if` may have a single-line jump statement without braces on the same line as its closing `)`.
With `"nextLine"`, the jump must be on the immediately following line. This does not apply to any branch
of an `if`/`else if`/`else` chain, or to other statement bodies. Existing braced statements are unaffected.
The entire `if` header must fit on one line for either option; `"sameLine"` requires the whole `if`
statement to fit on one line. Multiline conditions require braces.
See [Configuration.md](Configuration.md#braceless-if-statements) for supported jumps and examples.

Чтобы исправить нарушение этого правила, перепишите инструкцию так, чтобы она занимала несколько строк.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1501:StatementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1501 // StatementMustNotBeOnSingleLine
#pragma warning restore SA1501 // StatementMustNotBeOnSingleLine
```
