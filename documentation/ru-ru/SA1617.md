## Причина

Элемент кода C# не возвращает значения или возвращает void, но его комментарий документации содержит тег `<returns>`.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если комментарий документации элемента, возвращающего void, содержит тег `<returns>`.

## Как исправить нарушение

Удалите тег `<returns>` из документации элемента.

В следующем примере показан метод с корректным комментарием документации:

```csharp
/// <summary>
/// Prints the given name.
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
public void PrintNames(string firstName, string lastName)
{
    Console.WriteLine(firstName + " " + lastName);
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1617:VoidReturnValueMustNotBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1617 // VoidReturnValueMustNotBeDocumented
#pragma warning restore SA1617 // VoidReturnValueMustNotBeDocumented
```
