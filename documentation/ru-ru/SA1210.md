# SA1210: Директивы using должны упорядочиваться по пространствам имен в алфавитном порядке

## Причина

Директивы using в файле кода C# не отсортированы по алфавиту по пространствам имён.

## Описание правила

Нарушение этого правила возникает, когда директивы using не отсортированы по алфавиту по пространствам имён. Алфавитная сортировка делает код аккуратнее и понятнее, а также помогает быстрее определить используемые пространства имён. По умолчанию пространства имён System являются исключением и предшествуют всем остальным. Подробности см. в SA1208. Это исключение можно отключить, задав параметру `systemUsingDirectivesFirst` значение `false` (см. [Configuration.md](Configuration.md#using-directives)); тогда пространства имён System сортируются по алфавиту вместе со всеми остальными.

Глобальные директивы using (C# 10) анализируются независимо от локальных. Диагностика и исправления сравнивают только директивы, в которых либо у обеих есть модификатор `global`, либо у обеих его нет.

## Как исправить нарушения

Чтобы исправить нарушение, отсортируйте директивы using по алфавиту по пространствам имён, разместив все пространства имён System первыми, если только `systemUsingDirectivesFirst` не имеет значение `false`.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1210:UsingDirectivesMustBeOrderedAlphabeticallyByNamespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
#pragma warning restore SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
```
