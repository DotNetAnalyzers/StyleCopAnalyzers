## Причина

Раздел XML-комментария документации элемента C# содержит недостаточно букв.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если часть документации содержит недостаточно буквенных символов. Проверка подсчитывает количество букв и цифр в тексте документации и сравнивает его с количеством знаков и других небуквенных символов. Слишком высокая доля небуквенных символов обычно указывает на плохо оформленную документацию, которую будет трудно читать. Например, рассмотрим следующее краткое описание:

```csharp
/// <summary>
/// @)$(*A name--------
/// </summary>
public class Name
{
    ...
}
```

## Как исправить нарушение

Перепишите текст документации грамматически правильно и убедитесь, что доля знаков по отношению к буквам в тексте не слишком велика.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1631:DocumentationMustMeetCharacterPercentage", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1631 // DocumentationMustMeetCharacterPercentage
#pragma warning restore SA1631 // DocumentationMustMeetCharacterPercentage
```
