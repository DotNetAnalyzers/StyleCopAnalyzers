## Причина

Файл C# содержит ненужный код, который можно удалить, не меняя общую логику программы.

## Описание правила

Нарушение этого правила возникает, когда файл содержит код, который можно удалить, не меняя общую логику программы.

Например, следующую инструкцию try-catch можно удалить целиком, поскольку оба блока, try и catch, пусты.

```csharp
try
{
}
catch (Exception ex)
{
}
```

В следующей инструкции try-finally блок try содержит код, но блоков catch нет, а блок finally пуст. Таким образом, try-finally не выполняет никакой полезной функции и может быть удалён.

```csharp
try
{
    this.Method();
}
finally
{
}
```

В последнем примере инструкция unsafe пуста и потому не приносит пользы.

```csharp
unsafe
{
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите ненужный код либо дополните его необходимыми инструкциями.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1409:RemoveUnnecessaryCode", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1409 // RemoveUnnecessaryCode
#pragma warning restore SA1409 // RemoveUnnecessaryCode
```
