## Причина

Перед закрывающей фигурной скобкой в элементе, инструкции или выражении C# находится пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда перед закрывающей фигурной скобкой находится пустая строка. Например:

```csharp
public bool Enabled
{
    get 
    { 
        return this.enabled; 

    }

}
```

Приведённый выше код вызывает два нарушения, поскольку в двух местах перед закрывающими скобками находятся пустые строки.

Начиная с C# 8.0 это правило также применяется к закрывающим скобкам в выражениях switch и образцах свойств. Если скобка относится к многострочному списку ветвей выражения switch или многострочному образцу свойств, перед ней также не должно быть пустой строки.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустую строку перед закрывающей фигурной скобкой.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1508:ClosingBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1508 // ClosingBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1508 // ClosingBracesMustNotBePrecededByBlankLine
```
