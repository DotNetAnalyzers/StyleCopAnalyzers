# Подключение **stylecop.json**

В настоящее время исправление кода не может полностью настроить только что созданный файл **stylecop.json** для использования.
Эта проблема отслеживается в [dotnet/roslyn#4655](https://github.com/dotnet/roslyn/issues/4655). Пока она не устранена,
после создания файла **stylecop.json** пользователям необходимо вручную выполнить следующие дополнительные действия.

В Visual Studio 2017, 2019 и 2022:

1. Выберите файл в **Обозревателе решений (Solution Explorer)**.
2. В окне **Свойства (Properties)** задайте для **Действия при сборке (Build Action)** значение:
    * Для большинства проектов: **AdditionalFiles**
    * Для проектов с новой системой проектов, включая проекты .NET Core и .NET Standard: **C# analyzer
      additional file** (дополнительный файл анализатора C#).

В Visual Studio 2015 Update 3 и более новых версиях:

1. Выберите файл в **Обозревателе решений (Solution Explorer)**.
2. В окне «Свойства» задайте для **Действия при сборке (Build Action)** значение **AdditionalFiles**.

В более ранних версиях Visual Studio 2015:

1. Щёлкните проект правой кнопкой мыши в **Обозревателе решений (Solution Explorer)** и выберите **Выгрузить проект (Unload Project)**.
   Если будет предложено сохранить изменения, нажмите **Да (Yes)**.
2. Щёлкните выгруженный проект правой кнопкой мыши в **Обозревателе решений (Solution Explorer)** и выберите **Изменить (Edit) *ProjectName*.csproj**.
3. Найдите в файле проекта следующий элемент.

    ```csharp
    <None Include="stylecop.json" />
    ```

4. Замените его определение следующим.

    ```csharp
    <AdditionalFiles Include="stylecop.json" />
    ```

5. Сохраните и закройте файл проекта.
6. Щёлкните выгруженный проект правой кнопкой мыши в **Обозревателе решений (Solution Explorer)** и выберите **Перезагрузить проект (Reload Project)**.
