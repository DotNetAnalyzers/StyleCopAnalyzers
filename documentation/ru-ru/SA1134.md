## SA1134

<table>
<tr>
  <td>TypeName</td>
  <td>SA1134AttributesMustNotShareLine</td>
</tr>
<tr>
  <td>CheckId</td>
  <td>SA1134</td>
</tr>
<tr>
  <td>Категория</td>
  <td>Правила удобочитаемости</td>
</tr>
</table>

:memo: Это правило является новым для **StyleCop Analyzers**, и его не было в **StyleCop Classic**.

## Причина

Атрибут помещен в ту же строку кода, что и другой атрибут или элемент.

## Описание правила

Нарушение этого правила происходит, когда в одной строке кода размещаются два атрибута, или атрибут размещается в одной строке кода с другим элементом.

Например, следующий код приведет к нарушению этого правила:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

Следующий код не приведет к каким-либо нарушениям:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))]
[Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

### Исключения

Нарушение этого правила не возникает для атрибутов, применённых к параметрам, параметрам типа или лямбда-выражениям.

Например, следующий код не приведет к нарушению:

```csharp
public class MyClass<[Foo][Bar] T>
{
	public T MyMethod([In][MarshalAs(UnmanagedType.LPWStr)] string value)
	{
	    ...
	}
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, поместите каждый атрибут в свою собственную строку.

## Как подавить нарушения

```csharp
#pragma warning disable SA1134 // Attributes should not share line
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
#pragma warning restore SA1134 // Attributes should not share line
public class MyCodeFixProvider : CodeFixProvider
{
}
```
