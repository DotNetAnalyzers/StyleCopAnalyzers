## Причина

Перед открывающей фигурной скобкой в элементе, инструкции или выражении C# находится пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Как правило, нарушение возникает, когда перед открывающей фигурной скобкой находится пустая строка. Например, следующий код вызывает два нарушения, поскольку в двух местах перед открывающими скобками находятся пустые строки.

```csharp
public bool Enabled

{
    get

    {
        return this.enabled;
    }
}
```

Исключение возникает, когда открывающей скобке предшествует закрывающая скобка. В этом случае правило [SA1513](SA1513.md) требует пустую строку. Следующий пример показывает правильное использование пустых строк:

```csharp
public bool Enabled
{
    get
    {
        {
        }

        {
            return this.enabled;
        }
    }
}
```

Это правило также применяется к открывающим скобкам в выражениях switch и образцах свойств C# 8.0. Даже в таких конструкциях непосредственно перед открывающей скобкой не может находиться пустая строка.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустую строку перед открывающей фигурной скобкой.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1509:OpeningBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1509 // OpeningBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1509 // OpeningBracesMustNotBePrecededByBlankLine
```
