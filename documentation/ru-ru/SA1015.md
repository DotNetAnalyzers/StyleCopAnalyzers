## Причина

Пробелы вокруг закрывающей угловой скобки обобщённого типа в элементе C# расставлены неправильно.

## Описание правила

Нарушение этого правила происходит при неправильной расстановке пробелов вокруг закрывающей угловой скобки обобщённого типа.

Перед закрывающей угловой скобкой обобщённого типа не должно быть пробельных символов, если только она не является первым символом в строке.
За ней должна следовать открывающая круглая скобка, закрывающая круглая скобка, закрывающая угловая скобка обобщённого типа,
символ типа, допускающего значение null, конец строки или один пробел (но не пробел перед открывающей круглой скобкой).
В контекстах с поддержкой nullable аннотации ссылочных типов, допускающих значение null (например, `List<string?>?`),
подчиняются тем же правилам, что и типы значений, допускающие null.

Лексема `>`, завершающая список параметров указателя на функцию в C# 9, подчиняется тем же правилам расстановки пробелов, например `delegate*<int, void>`.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, убедитесь, что пробельные символы вокруг закрывающейся скобки обобщенного типа расставлены правильно.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1015:ClosingGenericBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
#pragma warning restore SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
```
