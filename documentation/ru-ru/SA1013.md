## Причина

Пробелы вокруг закрывающей фигурной скобки в элементе C# расставлены неправильно.

## Описание правила

Нарушение этого правила происходит при неправильной расстановке пробелов вокруг закрывающей фигурной скобки.

После закрывающей фигурной скобки всегда должен стоять один пробел, если только она не является последним символом в строке или за ней не следует закрывающая круглая скобка, запятая или точка с запятой. Оператор подавления предупреждений о null (`!`) также может следовать непосредственно за закрывающей фигурной скобкой без пробела (например, `new Foo { Value = null }!`).

Перед закрывающей фигурной скобкой всегда должен стоять один пробел, если только она не является первым символом в строке.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, убедитесь, что пробелы вокруг закрывающей фигурной скобки расставлены согласно описанному выше правилу.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1013:ClosingBracesMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1013 // ClosingBracesMustBeSpacedCorrectly
#pragma warning restore SA1013 // ClosingBracesMustBeSpacedCorrectly
```
