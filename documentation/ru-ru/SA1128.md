:memo: Это правило является новым для **StyleCop Analyzers**, и его не было в **StyleCop Classic**.

## Причина

Инициализатор конструктора находится в той же строке, что и объявление конструктора, в файле кода C#.

## Описание правила

Нарушение этого правила происходит, когда код содержит инициализатор конструктора, который частично или полностью находится в той же строке, что и объявление конструктора.

Например, следующий код приведет к нарушению этого правила:

```csharp
public class TypeName
{
    public TypeName() : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

Символ `:` (двоеточие) рассматривается как часть инициализатора и должен находиться в той же строке, что и ключевое слово `base` или `this`.

Следующий код также будет нарушать это правило:

```csharp
public class TypeName
{
	public TypeName() :
		base()
	{
	}
}
```

Следующий код не приведет к каким-либо нарушениям:

```csharp
public class TypeName
{
    public TypeName()
        : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, перенесите инициализатор конструктора, включая символ `:`, в отдельную строку.

## Как подавить нарушения

```csharp
public class TypeName
{
#pragma warning disable SA1128 // Constructor initializers should be on their own line
    public TypeName() : this(0)
#pragma warning restore SA1128 // Constructor initializers should be on their own line
    {
    }

    public TypeName(int value)
    {
    }
}
```
