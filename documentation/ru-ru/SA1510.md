# SA1510: Перед связанными блоками операторов не должна располагаться пустая строка

## Причина

Связанные инструкции C# разделены пустой строкой.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Некоторые виды инструкций C# можно использовать только непосредственно после другой инструкции. Например, catch и finally всегда должны следовать за try. Другой пример — else, который всегда должен следовать за if или другим else. Такие связанные инструкции не должны разделяться пустой строкой. Например:

```csharp
try
{
    this.SomeMethod();
}

catch (Exception ex)
{
    Console.WriteLine(ex.ToString());
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите все пустые строки между связанными инструкциями.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1510:ChainedStatementBlocksMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
#pragma warning restore SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
```
