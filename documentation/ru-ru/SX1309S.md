## Альтернативное правило

Это правило является нестандартным расширением поведения StyleCop по умолчанию и представляет альтернативный стиль, принятый в некоторых проектах. Альтернативные правила могут напрямую конфликтовать со стандартными правилами StyleCop.

## Причина

Имя статического поля не начинается с подчёркивания.

## Описание правила

Нарушение этого правила возникает, когда имя статического поля не начинается с подчёркивания.

### Подробное описание поведения

Это правило проверяет только имена закрытых статических полей, не имеющих модификаторов `const` и `readonly`. Статические поля `readonly` рассматриваются как константы и игнорируются. Члены readonly структур C# 8 (методы, свойства, индексаторы) этим правилом не анализируются.

## Как исправить нарушения

Чтобы исправить нарушение, добавьте префикс подчёркивания (`_`) к имени поля.

## Как подавить нарушения

```csharp
#pragma warning disable SX1309S // Static field names should begin with underscore
static int bar;
#pragma warning restore SX1309S // Static field names should begin with underscore
```
