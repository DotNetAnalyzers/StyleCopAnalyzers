## Причина

После блока документации, расположенного над элементом C#, находится пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда после блока документации над элементом находится пустая строка. Например:

```csharp
/// <summary>
/// Gets a value indicating whether the control is enabled.
/// </summary>

public bool Enabled
{
    get { return this.enabled; }
}
```

Приведённый выше код вызывает нарушение, поскольку после блока документации идёт пустая строка.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустую строку после блока документации.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1506:ElementDocumentationHeadersMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1506 // ElementDocumentationHeadersMustNotBeFollowedByBlankLine
#pragma warning restore SA1506 // ElementDocumentationHeadersMustNotBeFollowedByBlankLine
```
