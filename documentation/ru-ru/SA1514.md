## Причина

Перед блоком документации, расположенным над элементом C#, отсутствует пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда перед блоком документации над элементом отсутствует пустая строка. Например:

```csharp
public bool Visible
{
    get { return this.visible; }
}
/// <summary>
/// Gets a value indicating whether the control is enabled.
/// </summary>
public bool Enabled
{
    get { return this.enabled; }
}
```

Приведённый выше код вызывает нарушение, поскольку перед блоком документации нет пустой строки.

Исключение возникает, когда блок документации является первым элементом в своей области видимости. В этом случае перед ним не должно быть пустой строки. Например:

```csharp
public class Class1
{
    /// <summary>
    /// Gets a value indicating whether the control is enabled.
    /// </summary>
    public bool Enabled
    {
        get { return this.enabled; }
    }
}
```

В приведённом выше коде блок документации является первым элементом в своей области видимости, поэтому перед ним не должно быть пустой строки.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте пустую строку перед блоком документации.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1514:ElementDocumentationHeaderMustBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1514 // ElementDocumentationHeaderMustBePrecededByBlankLine
#pragma warning restore SA1514 // ElementDocumentationHeaderMustBePrecededByBlankLine
```
