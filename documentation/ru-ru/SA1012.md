## Причина

Пробелы вокруг открывающей фигурной скобки в элементе C# расставлены неправильно.

## Описание правила

Нарушение этого правила происходит при неправильной расстановке пробелов вокруг открывающей фигурной скобки.

Перед открывающей фигурной скобкой всегда должен стоять один пробел, если только она не является первым символом в строке или перед ней не стоит открывающая круглая скобка. В последнем случае между круглой и фигурной скобками не должно быть пробела.

После открывающей фигурной скобки всегда должен стоять один пробел, если только она не является последним символом в строке.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, убедитесь, что пробелы вокруг открывающей фигурной скобки расставлены согласно описанному выше правилу.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1012:OpeningBracesMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1012 // OpeningBracesMustBeSpacedCorrectly
#pragma warning restore SA1012 // OpeningBracesMustBeSpacedCorrectly
```
