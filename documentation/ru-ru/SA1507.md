## Причина

Код C# содержит несколько пустых строк подряд.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда код содержит более одной пустой строки подряд. Например:

```csharp
public bool Enabled
{
    get 
    { 
        Console.WriteLine("Getting the enabled flag.");


        return this.enabled; 
    }
}
```

Приведённый выше код вызывает нарушение, поскольку содержит несколько пустых строк подряд.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите лишние пустые строки.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1507:CodeMustNotContainMultipleBlankLinesInARow", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1507 // CodeMustNotContainMultipleBlankLinesInARow
#pragma warning restore SA1507 // CodeMustNotContainMultipleBlankLinesInARow
```
