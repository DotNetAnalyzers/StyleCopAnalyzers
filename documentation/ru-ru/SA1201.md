## Причина

Элемент в файле кода C# расположен в неправильном порядке относительно других элементов.

## Описание правила

Нарушение этого правила возникает, когда элементы кода в файле не следуют стандартному порядку.

Чтобы соблюдать это правило, элементы на верхнем уровне файла или внутри пространства имён должны располагаться в следующем порядке:

* Директивы extern alias
* Директивы using
* Пространства имён
* Делегаты
* Перечисления
* Интерфейсы
* Структуры
* Классы

Внутри класса, структуры или интерфейса элементы должны располагаться в следующем порядке:

* Поля
* Конструкторы
* Финализаторы (деструкторы)
* Делегаты
* События
* Перечисления
* Интерфейсы
* Блоки расширений
* Свойства
* Индексаторы
* Операторы преобразования
* Операторы
* Методы
* Структуры
* Классы

> 📝 При упорядочивании записи C# 9 рассматриваются как классы, а структуры-записи C# 10 — как структуры.

> 📝 Блоки расширений C# 14 (`extension(...) { }`) рассматриваются как отдельный вид элементов и располагаются после интерфейсов, но перед свойствами.

Соблюдение стандартного порядка, основанного на виде элемента, повышает читаемость и удобство сопровождения файла, а также способствует повторному использованию кода.

При реализации интерфейса иногда желательно сгруппировать все его члены рядом друг с другом. Если интерфейс содержит элементы разных видов, это может потребовать нарушения данного правила. Эту проблему можно решить с помощью частичных классов.

1. Добавьте к классу модификатор partial, если класс ещё не является частичным.

2. Добавьте второй частичный класс с тем же именем. Его можно разместить в том же файле непосредственно под исходным классом или в отдельном файле.

3. Перенесите указание реализуемого интерфейса и все члены его реализации во вторую часть класса.

Например:

```csharp
/// <summary>
/// Represents a customer of the system.
/// </summary>
public partial class Customer
{
    // Contains the main functionality of the class.
}

/// <content>
/// Implements the ICollection class.
/// </content>
public partial class Customer : ICollection
{
    public int Count 
    { 
        get { return this.count; }
    }

    public bool IsSynchronized 
    { 
        get { return false; }
    }

    public object SyncRoot 
    { 
        get { return null; }
    }

    public void CopyTo(Array array, int index)
    {
        throw new NotImplementedException();
    }
}
```

## Как исправить нарушения

Чтобы исправить нарушение, расположите элементы файла в описанном выше порядке.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1201:ElementsMustAppearInTheCorrectOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1201 // ElementsMustAppearInTheCorrectOrder
#pragma warning restore SA1201 // ElementsMustAppearInTheCorrectOrder
```
