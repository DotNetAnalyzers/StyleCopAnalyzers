:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Имя параметра типа C# не начинается с прописной буквы T.

## Описание правила

Нарушение этого правила возникает, когда имя параметра типа C# не начинается с прописной буквы T. Имена параметров типов всегда должны начинаться с T, например *T* или *TKey*.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте прописную букву T в начало имени параметра типа.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1314:TypeParameterNamesMustBeginWithT", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1314 // Type parameter names should begin with T
#pragma warning restore SA1314 // Type parameter names should begin with T
```
