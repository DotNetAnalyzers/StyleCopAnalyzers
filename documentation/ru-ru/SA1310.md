## Причина

Имя поля C# содержит подчёркивание.

## Описание правила

Нарушение этого правила возникает, когда имя поля содержит подчёркивание. Полям и переменным следует давать содержательные и понятные имена, описывающие их назначение. Обычно такие имена записываются в стиле camelCase и не должны содержать подчёркиваний. Например, используйте *customerPostCode*, а не *customer_post_code*.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому содержать подчёркивания, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите подчёркивание из имени поля либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1310:FieldNamesMustNotContainUnderscore", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1310 // FieldNamesMustNotContainUnderscore
#pragma warning restore SA1310 // FieldNamesMustNotContainUnderscore
```
