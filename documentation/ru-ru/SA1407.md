# SA1407: Арифметические выражения должны явно указывать приоритет операций

## Причина

Инструкция C# содержит сложное выражение с арифметическими, побитовыми операторами или операторами сдвига без скобок, явно задающих приоритет операций.

## Описание правила

В C# определена иерархия приоритетов арифметических, побитовых операторов и операторов сдвига. Можно объединить несколько операций в одной инструкции, не заключая ни одну из них в скобки. В таком случае компилятор автоматически определяет порядок и приоритет операций по установленным правилам. Например:

```csharp
int x = 5 + y * b / 6 % z - 2;
```

Хотя этот код допустим, его трудно читать и сопровождать. Чтобы полностью понять его, разработчик должен знать и понимать основные правила приоритета операторов C#.

Это правило предназначено для повышения читаемости и удобства сопровождения такого кода, а также для снижения риска последующих ошибок. Оно требует от разработчика вставлять скобки, явно задающие приоритет операций. В следующем примере несколько арифметических операций заключены в скобки:

```csharp
int x = 5 + (y * ((b / 6) % z)) - 2;
```

Скобки делают код более наглядным и понятным, избавляя читателя от необходимости делать предположения о нём. Правило также применяется к побитовым операторам `&`, `|` и `^`, а также к операторам сдвига `<<`, `>>` и `>>>`.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте скобки в выражение, явно задав приоритет операций.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1407:ArithmeticExpressionsMustDeclarePrecedence", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1407 // ArithmeticExpressionsMustDeclarePrecedence
#pragma warning restore SA1407 // ArithmeticExpressionsMustDeclarePrecedence
```
