## Причина

Файл кода C# содержит более одного отдельного типа.

## Описание правила

Нарушение этого правила возникает, когда файл C# содержит более одного типа. Для удобства долгосрочного сопровождения кодовой базы каждый тип следует размещать в отдельном файле, имя которого отражает имя содержащегося в нём типа.

Можно настроить, на какие виды типов распространяется правило. По умолчанию оно позволяет размещать делегаты, перечисления, структуры и интерфейсы вместе с классом.

Также допускается размещение нескольких частей одного частичного типа в одном файле.

Типы с областью видимости файла, объявленные с модификатором `file`, освобождены от этого правила.

## Как исправить нарушения

Чтобы исправить нарушение, переместите каждый тип в отдельный файл.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1402:FileMayOnlyContainASingleType", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1402 // FileMayOnlyContainASingleType
#pragma warning restore SA1402 // FileMayOnlyContainASingleType
```
