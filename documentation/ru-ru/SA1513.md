## Причина

После закрывающей фигурной скобки в элементе, инструкции или выражении C# отсутствует пустая строка.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда после закрывающей фигурной скобки нет пустой строки. Например, следующий код вызывает одно нарушение, поскольку в одном месте после закрывающей скобки отсутствует пустая строка.

```csharp
if (condition)
{
    DoSomething();
}
return value;
```

Для скобок, являющихся частью выражения или образца (например, выражений switch или образцов свойств C# 8.0), пустая строка не требуется, если сразу после скобки следует продолжение конструкции, например `=>`, `,` или `;`. То же относится к случаям, когда сразу после скобки идёт логический оператор (такой как `&&` или `||`) либо обозначение переменной образца (например, `} patternVar`), продолжающее то же выражение.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте пустую строку после закрывающих фигурных скобок.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1513:ClosingBraceMustBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1513 // ClosingBraceMustBeFollowedByBlankLine
#pragma warning restore SA1513 // ClosingBraceMustBeFollowedByBlankLine
```
