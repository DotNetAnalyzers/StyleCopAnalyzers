# SA1517: Код не должен содержать пустые строки в начале файла

## Причина

В начале файла кода находятся пустые строки.

## Описание правила

Для улучшения оформления кода StyleCop требует, чтобы в начале файлов не было пустых строк.

Нарушение этого правила возникает, когда файл начинается с одной или нескольких пустых строк.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите пустые строки из начала файла.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1517:CodeMustNotContainBlankLinesAtStartOfFile", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1517 // CodeMustNotContainBlankLinesAtStartOfFile
#pragma warning restore SA1517 // CodeMustNotContainBlankLinesAtStartOfFile
```
