# SA1639: Заголовок файла должен содержать краткое описание

:bulb: Это правило отключено по умолчанию.

## Причина

Заголовок файла в начале файла кода C# не содержит заполненного тега summary.

## Описание правила

Нарушение возникает, если заголовок файла C# не содержит корректного тега summary.

Например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Если правило включено, заголовок файла должен содержать тег summary. Например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
// <summary>This is the Widget class.</summary>
//-----------------------------------------------------------------------
```

## Как исправить нарушение

Добавьте тег summary и заполните его описанием содержимого файла.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1639:FileHeaderMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1639 // FileHeaderMustHaveSummary
#pragma warning restore SA1639 // FileHeaderMustHaveSummary
```
