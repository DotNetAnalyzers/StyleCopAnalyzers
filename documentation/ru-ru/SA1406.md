## Причина

Вызов Debug.Fail в коде C# не содержит поясняющего сообщения.

## Описание правила

Нарушение этого правила возникает, когда код содержит вызов Debug.Fail без пояснения для конечного пользователя. Например, следующий вызов содержит поясняющее сообщение:

```csharp
Debug.Fail("The code should never reach this point.");
```

## Как исправить нарушения

Чтобы исправить нарушение, добавьте в вызов Debug.Fail поясняющее сообщение, которое увидит конечный пользователь при срабатывании проверки.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1406:DebugFailMustProvideMessageText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1406 // DebugFailMustProvideMessageText
#pragma warning restore SA1406 // DebugFailMustProvideMessageText
```
