:warning: Это правило намеренно не включено в StyleCop Analyzers. Дополнительные сведения см. в [KnownChanges.md](KnownChanges.md).

## Причина

Элемент экземпляра readonly размещён ниже элемента экземпляра того же вида без модификатора readonly.

## Описание правила

Нарушение этого правила возникает, когда элемент экземпляра readonly размещён ниже элемента экземпляра того же вида без модификатора readonly.

## Как исправить нарушения

Чтобы исправить нарушение, разместите все элементы экземпляра readonly выше элементов экземпляра того же вида без модификатора readonly.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1215:InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1215 // InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements
#pragma warning restore SA1215 // InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements
```
