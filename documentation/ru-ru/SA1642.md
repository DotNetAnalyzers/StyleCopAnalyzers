## Причина

XML-комментарий документации конструктора C# не содержит требуемого текста краткого описания.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью
XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в
статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если тег summary в комментарии документации конструктора не начинается
с требуемого текста.

Правило стандартизирует краткое описание конструктора с учётом его уровня доступности.
Описание конструктора экземпляра должно начинаться с «Initializes a new instance of the {class name} class.»
(«Инициализирует новый экземпляр класса {имя класса}.»). Например, ниже показан конструктор класса `Customer`.

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </summary>
public Customer()
{
}
```

При документировании структуры описание должно содержать слово «struct» вместо «class». Например, ниже показан конструктор структуры `MyStruct`.

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="MyStruct"/> struct.
/// </summary>
public MyStruct()
{
}
```

Для типов-записей конструкторы следуют той же схеме: в описании классов-записей используется слово «class», а структур-записей — «struct». Например:

```csharp
public record struct Customer
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Customer"/> struct.
    /// </summary>
    public Customer()
    {
    }
}
```

Для типов-объединений C# 15 описание должно содержать слово «union». Например, ниже показан конструктор
объединения `Result<T>`.

```csharp
public union Result<T>(T, string)
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Result{T}"/> union.
    /// </summary>
    /// <param name="value">The value.</param>
    /// <param name="message">The message.</param>
    public Result(T value, string message)
    {
    }
}
```

Если у класса есть параметры типа, их можно указать в ссылке `cref` в любом из следующих
двух форматов:

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer`1"/> class.
/// </summary>
public Customer()
{
}

/// <summary>
/// Initializes a new instance of the <see cref="Customer{T}"/> class.
/// </summary>
public Customer()
{
}
```

Если конструктор статический, краткое описание должно начинаться с «Initializes static members of the {class name} class.»
(«Инициализирует статические члены класса {имя класса}.»). Например:

```csharp
/// <summary>
/// Initializes static members of the <see cref="Customer"/> class.
/// </summary>
public static Customer()
{
}
```

Для совместимости со StyleCop Classic закрытым конструкторам экземпляра разрешено использовать описание
«Prevents a default instance of the {class name} class from being created.» («Предотвращает создание экземпляра класса {имя класса} по умолчанию.»).
В новом коде для всех конструкторов экземпляра рекомендуется использовать приведённую выше форму.

```csharp
/// <summary>
/// Prevents a default instance of the <see cref="Customer"/> class from being created.
/// </summary>
private Customer()
{
}
```

Для структурирования текста внутри тега `<summary>` можно использовать тег `<para>`.
Например:

```csharp
/// <summary>
/// <para>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </para>
/// <para>
/// Additional information can be included in subsequent paragraphs.
/// </para>
/// </summary>
public Customer()
{
}
```

## Как исправить нарушение

Измените краткое описание конструктора в соответствии с приведёнными выше требованиями.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1642:ConstructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
```
