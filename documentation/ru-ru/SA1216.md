:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Директива `using static` размещена в неправильном месте: перед обычной директивой using или после директивы using с псевдонимом.

## Описание правила

Нарушение этого правила возникает, когда директива using static размещена перед обычной директивой using или после директивы using с псевдонимом. Группировка директив using static ниже обычных директив и выше директив с псевдонимами делает код аккуратнее и понятнее, а также помогает быстрее определить используемые статические члены.

Глобальные директивы using (C# 10) анализируются независимо от локальных. Диагностика и исправления сравнивают только директивы, в которых либо у обеих есть модификатор `global`, либо у обеих его нет.

## Как исправить нарушения

Чтобы исправить нарушение, разместите директиву `using static` после обычных директив using и перед директивами using с псевдонимами.

## Как подавить нарушения

```csharp
#pragma warning disable SA1216 // Using static directives should be placed at the correct location
using static System.Math;
#pragma warning restore SA1216 // Using static directives should be placed at the correct location
```
