## Причина

XML-комментарий документации финализатора C# не содержит требуемого текста краткого описания.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если тег summary в комментарии документации финализатора не начинается с требуемого текста.

Правило стандартизирует краткое описание финализатора. Оно должно начинаться с «Finalizes an instance of the {class name} class.» («Выполняет финализацию экземпляра класса {имя класса}.»). Например, ниже показан финализатор класса Customer.

```csharp
/// <summary>
/// Finalizes an instance of the Customer class.
/// </summary>
~Customer()
{
}
```

В текст краткого описания можно включать другие теги. Например:

```csharp
/// <summary>
/// Finalizes an instance of the <see cref="Customer"/> class.
/// </summary>
~Customer()
{
}
```

## Как исправить нарушение

Измените краткое описание финализатора в соответствии с приведёнными выше требованиями.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1643:DestructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
```
