:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.
:memo: Это правило действует только для C# 7.0 и новее.

## Причина

В объявлении члена присутствует тип-кортеж без имён элементов.

## Описание правила

Типы-кортежи в объявлениях членов должны иметь явно именованные элементы. Сведения о работе с кортежами в C# 7 см. в документации по [типам-кортежам](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Например, следующий код вызывает нарушение этого правила:

```csharp
public class ExampleClass
{
  public (int, int) ExampleMethod() // SA1414
  {
  }
}
```

Следующий код не вызывает нарушений:

```csharp
public class ExampleClass
{
  public (int valueA, int valueB) ExampleMethod()
  {
  }
}
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, укажите имя для каждого элемента кортежа.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainAbilityRules", "SA1414:TupleTypesInSignaturesShouldHaveElementNames", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1414 // Tuple types appearing in member declarations should have explicitly named tuple elements
#pragma warning restore SA1414 // Tuple types appearing in member declarations should have explicitly named tuple elements
```
