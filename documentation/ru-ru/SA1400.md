## Причина

Модификатор доступа элемента C# не указан явно.

## Описание правила

C# позволяет объявлять элементы без модификатора доступа. В этом случае C# автоматически назначает уровень доступа в зависимости от вида элемента.

Это правило требует явно указывать модификатор доступа для каждого элемента. Читателю не приходится делать предположения о коде, что повышает его читаемость.

Члены, объявленные в `interface`, неявно являются `public` и не требуют явного модификатора доступа. Это относится и к членам интерфейсов по умолчанию, появившимся в C# 8: членам экземпляра с реализацией по умолчанию, статическим членам интерфейса и вложенным членам, таким как делегаты. SA1400 не выдаёт диагностических сообщений для этих членов интерфейса.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте модификатор доступа в объявление элемента.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1400:AccessModifierMustBeDeclared", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1400 // AccessModifierMustBeDeclared
#pragma warning restore SA1400 // AccessModifierMustBeDeclared
```
