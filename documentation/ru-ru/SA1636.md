## Причина

Заголовок файла в начале файла кода C# не содержит требуемого текста об авторских правах.

## Описание правила

Нарушение возникает, если заголовок файла C# не содержит текста об авторских правах, заданного для проекта.

Для работы этого правила необходимо задать свойство `copyrightText`. Подробности приведены в разделе [Настройка](Configuration.md).

Значение свойства `xmlHeader` влияет на поведение этого правила. Когда `xmlHeader` равно **true** (по умолчанию), StyleCop Analyzers ожидает заголовки файлов в следующем стандартном формате StyleCop.

```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

Когда свойство `xmlHeader` явно установлено в **false**, StyleCop Analyzers ожидает заголовки файлов в следующем настраиваемом формате.

```csharp
// {copyrightText}
```

При этих настройках каждый файл проекта должен содержать требуемый текст об авторских правах в описанном выше формате.

### Стили комментариев

Это правило допускает несколько стилей комментариев. Следующие примеры показывают допустимые варианты.

Примеры при значении **true** свойства `xmlHeader`

```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

```csharp
// ----------------------------------------------------------------------
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
// ----------------------------------------------------------------------
```

```csharp
/* <copyright file="{fileName}" company="{companyName}">
 * {copyrightText}
 * </copyright>
 */
```

```csharp
/*
  <copyright file="{fileName}" company="{companyName}">
  {copyrightText}
  </copyright>
*/
```

Примеры при значении **false** свойства `xmlHeader`

```csharp
// {copyrightText}
```

```csharp
/* {copyrightText} */
```

```csharp
/*
 * {copyrightText}
 */
```

```csharp
/*
  {copyrightText}
*/
```

## Как исправить нарушение

Добавьте стандартный текст об авторских правах вашей компании в тег copyright заголовка файла.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1636:FileHeaderCopyrightTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1636 // FileHeaderCopyrightTextMustMatch
#pragma warning restore SA1636 // FileHeaderCopyrightTextMustMatch
```
