## Причина

У тега `<typeparam>` в XML-комментарии документации обобщённого элемента C# отсутствует атрибут name или этот атрибут пуст.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если XML-комментарий документации элемента содержит тег `<typeparam>`, в котором не указано имя параметра типа.

## Как исправить нарушение

Добавьте или заполните атрибут name каждого тега `<typeparam>`, указав имя параметра типа, к которому относится документация.

В следующем примере показан метод с корректным комментарием документации:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1621:GenericTypeParameterDocumentationMustDeclareParameterName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1621 // GenericTypeParameterDocumentationMustDeclareParameterName
#pragma warning restore SA1621 // GenericTypeParameterDocumentationMustDeclareParameterName
```
