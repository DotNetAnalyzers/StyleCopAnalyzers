# SA1511: Перед завершающей частью while оператора do-while не должна располагаться пустая строка

## Причина

Завершающая часть while в инструкции do-while отделена от основной части пустой строкой.

## Описание правила

Для повышения читаемости кода StyleCop требует пустых строк в одних случаях и запрещает их в других. Это создаёт единообразное визуальное оформление, которое помогает распознавать структуру и читать незнакомый код.

Нарушение этого правила возникает, когда ключевое слово while в конце инструкции do-while отделено от её основной части одной или несколькими пустыми строками. Например:

```csharp
do
{
    Console.WriteLine("Loop forever");
}

while (true);
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, удалите все пустые строки перед ключевым словом while.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1511:WhileDoFooterMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1511 // WhileDoFooterMustNotBePrecededByBlankLine
#pragma warning restore SA1511 // WhileDoFooterMustNotBePrecededByBlankLine
```
