## Причина

Поле-константа размещено ниже поля, не являющегося константой.

## Описание правила

Нарушение этого правила возникает, когда поле-константа размещено ниже поля, не являющегося константой. Константы должны располагаться выше полей, чтобы подчеркнуть принципиальные различия этих видов элементов: компилятор обрабатывает их по-разному, к их именам предъявляются разные требования и т. д.

## Как исправить нарушения

Чтобы исправить нарушение, разместите все константы выше всех полей.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1203:ConstantsMustAppearBeforeFields", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1203 // ConstantsMustAppearBeforeFields
#pragma warning restore SA1203 // ConstantsMustAppearBeforeFields
```
