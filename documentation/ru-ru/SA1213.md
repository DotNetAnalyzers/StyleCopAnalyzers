## Причина

Метод доступа add расположен после метода доступа remove внутри события.

## Описание правила

Нарушение этого правила возникает, когда метод доступа add размещён после remove внутри события. Чтобы соблюдать правило, метод доступа add должен предшествовать remove.

Например, следующий код вызывает нарушение:

```csharp
public event EventHandler NameChanged
{ 
    remove { this.nameChanged -= value; }
    add { this.nameChanged += value; }
}
```

Следующий код не вызывает этого нарушения:

```csharp
public event EventHandler NameChanged
{ 
    add { this.nameChanged += value; }
    remove { this.nameChanged -= value; }
}
```

## Как исправить нарушения

Чтобы исправить нарушение, разместите метод доступа add перед remove.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1213:EventAccessorsMustFollowOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1213 // EventAccessorsMustFollowOrder
#pragma warning restore SA1213 // EventAccessorsMustFollowOrder
```
