# SA1315: Имена параметров должны совпадать с унаследованными именами

:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Имя параметра метода, переопределяющего метод базового класса или реализующего член интерфейса, не совпадает с именем
унаследованного параметра.

## Описание правила

Метод, переопределяющий метод базового класса, должен использовать те же имена параметров, что и переопределяемый
метод. Метод, реализующий член интерфейса, должен использовать имена параметров, объявленные этим членом интерфейса.
Совпадение имен сохраняет единообразие именованных аргументов при вызове методов в соответствии с их абстрактным
контрактом.

Для переопределенного метода ожидаемые имена параметров определяются непосредственным методом базового класса. Для
реализации интерфейса анализатор допускает имя, совпадающее с именем любого реализуемого члена интерфейса с такой же
сигнатурой.

## Как исправить нарушения

Переименуйте параметр так, чтобы его имя совпадало с именем соответствующего унаследованного параметра. Если
реализация соответствует нескольким унаследованным именам, исправление кода предложит доступные варианты.

## Как подавить нарушения

```csharp
#pragma warning disable SA1315 // ParametersShouldMatchInheritedNames
public override void Method(int differentName)
#pragma warning restore SA1315 // ParametersShouldMatchInheritedNames
{
}
```
