## Причина

В файле кода на языке C# неверно расставлены пробелы вокруг символа оператора.

## Описание правила

Нарушение этого правила происходит, когда интервал вокруг символа оператора неверен.

Следующие типы символов операторов должны быть окружены одинарным пробелом с обеих сторон: двоеточия, арифметические
операторы, операторы присваивания, условные операторы, логические операторы, реляционные операторы, операторы сдвига и
лямбда-операторы. Например:

```csharp
int x = 4 + y;
```

Начиная с C# 8.0, лямбда-оператор `=>` также используется в ветвях выражения switch. К нему применяются те же
правила: с обеих сторон стрелки должен быть один пробел.

```csharp
var description = value switch { 0 => "zero", _ => "nonzero" };
```

Операторы сравнения в выражениях сопоставления с образцом подчиняются тем же правилам, когда они следуют за
ключевыми словами, такими как `is`. Например, оператор `>` в образце сравнения `value is > 5` должен быть окружён
пробелами: `value is > 5`. Если образец сравнения заключён в круглые скобки, сразу после `(` и перед `)` не должно
быть пробелов, в соответствии с правилами для круглых скобок, описанными в SA1008.

В отличие от них, унарные операторы должны предваряться одним пробелом, но никогда не должны сопровождаться пробелами. Например:

```csharp
bool x = !value;
```

Исключение составляют случаи, когда символу предшествует или за ним следует круглая или квадратная скобка.
В этом случае между символом и скобкой не должно быть пробела. Например:

```csharp
if (!value)
{
}
```

Оператор *индекса от конца* (`^`), введённый в C# 8, подчиняется тем же правилам для унарных операторов.
Он записывается вплотную к операнду, без пробела после оператора. Если он следует непосредственно за `[` или `(`,
между ним и скобкой также не добавляется пробел. Примеры:

```csharp
var last = values[^1];
Index start = ^5;
```

Оператор *диапазона* (`..`), введённый в C# 8, рассматривается как бинарный оператор, который не должен быть
окружён пробелами. В индексаторах это правило применяется между операндами; после `[` и перед `]` пробелы
также не ставятся. Например:

```csharp
Range middle = 1..4;
var slice = values[1..^2];
```

## Как исправить нарушения

Чтобы исправить нарушение этого правила, убедитесь, что интервал вокруг символа соответствует правилу, описанному выше.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1003:SymbolsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1003 // SymbolsMustBeSpacedCorrectly
#pragma warning restore SA1003 // SymbolsMustBeSpacedCorrectly
```
