## Причина

Тип **Nullable** был определен без использования сокращения C#. Например, `Nullable<DateTime>` был использован вместо предпочтительного `DateTime?`.

## Описание правила

Нарушение этого правила происходит всякий раз, когда тип **Nullable** был определен без использования сокращенного стиля C#.

Правило относится только к синтаксису типов значений, допускающих null. В контексте `#nullable enable` развёрнутые
записи таких типов, например `Nullable<int>` или `System.Nullable<DateTime>`, по-прежнему вызывают диагностику SA1125;
вместо них следует использовать `int?` или `DateTime?`. Аннотации ссылочных типов, допускающих null,
такие как `string?` или `T?`, этим правилом не затрагиваются.

В C# 12 и более поздних версиях это также относится к целевому типу директивы псевдонима using:
`using MyNullableInt = System.Nullable<int>;` следует записывать как `using MyNullableInt = int?;`.
В более ранних версиях языка сокращённая запись здесь недопустима, поэтому правило не сообщает о директивах using в этих версиях.

### Примеры

```csharp
#nullable enable

// The following fields will report SA1125 and should use the shorthand form
private Nullable<int> count;
private System.Nullable<DateTime> timestamp;

// These nullable reference type annotations are valid and do not require changes for SA1125
private string? name;
private T? value;
```

## Как исправить нарушение

Чтобы исправить нарушение этого правила, используйте сокращенную версию типа **Nullable**, т. е. **int?**, **DateTime?** и т. д.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1125:UseShorthandForNullableTypes", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1125 // UseShorthandForNullableTypes
#pragma warning restore SA1125 // UseShorthandForNullableTypes
```
