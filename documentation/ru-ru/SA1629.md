## Причина

Раздел XML-комментария документации элемента C# не заканчивается точкой.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если часть документации не заканчивается точкой. Например, текст краткого описания в документации ниже не заканчивается точкой:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

После точки могут следовать закрывающие кавычки (`"`, `'`, `”` или `’`), а затем закрывающая круглая скобка, поэтому текст,
заканчивающийся на `."`, `.”`, `.’”` или `.)`, соответствует этому правилу.

## Как исправить нарушение

Убедитесь, что все разделы документации заканчиваются точкой.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1629:DocumentationTextMustEndWithAPeriod", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1629 // DocumentationTextMustEndWithAPeriod
#pragma warning restore SA1629 // DocumentationTextMustEndWithAPeriod
```
