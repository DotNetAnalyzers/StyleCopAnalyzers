## Причина

Тег `<summary>` в комментарии документации элемента кода C# пуст.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если комментарий документации элемента содержит пустой тег `<summary>`, в котором нет описания элемента.

## Как исправить нарушение

Заполните тег `<summary>` описанием элемента кода.

Пример:

В следующем примере показан метод с пустым тегом `<summary>`.

```csharp
/// <summary>  </summary>
/// <param name="customerId">The ID of the customer to find.</param>
/// <returns>The customer, or null if the customer could not be
/// found.</returns>
public Customer FindCustomer(int customerId)
{
    // ... finds the customer ...
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1606:ElementDocumentationMustHaveSummaryText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1606 // ElementDocumentationMustHaveSummaryText
#pragma warning restore SA1606 // ElementDocumentationMustHaveSummaryText
```
