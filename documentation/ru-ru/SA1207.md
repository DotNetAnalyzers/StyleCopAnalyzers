## Причина

Ключевое слово *protected* размещено после *internal* в объявлении элемента C# с доступом protected internal либо ключевое слово *private* размещено после *protected*.

## Описание правила

Нарушение этого правила возникает, когда модификаторы доступа элемента protected internal записаны как *internal protected* либо модификаторы доступа элемента private protected записаны как *protected private*. В действительности элемент с ключевыми словами *protected internal* имеет тот же уровень доступа, что и элемент с ключевыми словами *internal protected*. Для повышения читаемости и единообразия кода StyleCop стандартизирует порядок этих ключевых слов: элемент protected internal всегда описывается именно так, а не как internal protected. Это помогает устранить сомнения в том, действительно ли эти уровни доступа совпадают.

## Как исправить нарушения

Чтобы исправить нарушение, разместите ключевое слово *protected* перед *internal* либо *private* перед *protected*.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1207:ProtectedMustComeBeforeInternal", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1207 // ProtectedMustComeBeforeInternal
#pragma warning restore SA1207 // ProtectedMustComeBeforeInternal
```
