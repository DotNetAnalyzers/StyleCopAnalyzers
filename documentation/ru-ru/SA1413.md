:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

После последнего элемента многострочного инициализатора C#, объявления перечисления, выражения switch, образца свойств или выражения коллекции отсутствует завершающая запятая.

### Обоснование

Это правило специально разработано для удобной работы с наиболее распространёнными системами управления версиями и облегчения долгосрочной проверки изменений кода. Если в последней строке многострочной последовательности есть запятая, разработчикам, которые впоследствии добавляют элемент в список или меняют его порядок, не приходится изменять больше строк, чем необходимо. В результате последующая проверка кода охватывает меньше изменений и сосредоточена на их сути, а такие инструменты, как **git blame**, продолжают показывать исходного автора и коммит для элемента, который раньше был последним в списке.

## Описание правила

Нарушение этого правила возникает, когда после последнего элемента инициализатора или списка C# отсутствует завершающая запятая.

Например, следующий код вызывает одно нарушение:

```csharp
var x = new Barnacle
{
    Age = 100,
    Height = 0.2M,
    Weight = 0.88M
};
```

Следующий код не вызывает нарушений:

```csharp
var x = new Barnacle
{
    Age = 100,
    Height = 0.2M,
    Weight = 0.88M,
};
```

Правило охватывает инициализаторы объектов, коллекций, массивов и `with`, выражения создания анонимных объектов, а также члены перечислений. Начиная с C# 8.0 оно также применяется к ветвям выражений switch и вложенным образцам внутри многострочных образцов свойств. Начиная с C# 12 оно применяется и к элементам многострочных выражений коллекций. Если такая конструкция занимает несколько строк, добавьте завершающую запятую после последней ветви, вложенного образца или элемента.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, добавьте завершающую запятую после последнего элемента инициализатора.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1413:UseTrailingCommasInMultiLineInitializers", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1413 // UseTrailingCommasInMultiLineInitializers
#pragma warning restore SA1413 // UseTrailingCommasInMultiLineInitializers
```
