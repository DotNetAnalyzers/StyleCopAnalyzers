## Причина

У элемента перечисления C# отсутствует XML-комментарий документации.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, когда у элемента перечисления отсутствует комментарий документации. Например:

```csharp
/// <summary>
/// Types of animals.
/// </summary>
public enum Animals
{
    Dog,
    Cat,
    Horse
}
```

## Как исправить нарушение

Добавьте комментарий документации для каждого элемента перечисления. Например:

```csharp
/// <summary>
/// Types of animals.
/// </summary>
public enum Animals
{
    /// <summary>
    /// Represents a dog.
    /// </summary>
    Dog,

    /// <summary>
    /// Represents a cat.
    /// </summary>
    Cat,

    /// <summary>
    /// Represents a horse.
    /// </summary>
    Horse
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1602:EnumerationItemsMustBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1602 // EnumerationItemsMustBeDocumented
#pragma warning restore SA1602 // EnumerationItemsMustBeDocumented
```
