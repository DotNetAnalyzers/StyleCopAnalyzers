## Причина

Переводы строк в конце файла не соответствуют настройкам проекта.

## Описание правила

Для улучшения оформления кода StyleCop требует единообразного использования переводов строк в конце файлов. Конкретные требования проекта можно настроить с помощью **stylecop.json**. Дополнительные сведения см. в [Configuration.md](Configuration.md).

Используется одна из следующих настроек:

* Allow (по умолчанию): файлы могут заканчиваться одним переводом строки, но это не обязательно.
* Require: файлы должны заканчиваться одним переводом строки.
* Omit: файлы не должны заканчиваться переводом строки.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените переводы строк в конце файла в соответствии с настройками текущего проекта.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1518:CodeMustNotContainBlankLinesAtEndOfFile", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
#pragma warning restore SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
```
