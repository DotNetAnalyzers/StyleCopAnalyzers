## Причина

Имя элемента C# не начинается с прописной буквы.

## Описание правила

Нарушение этого правила возникает, когда имена элементов определённых видов не начинаются с прописной буквы. Следующие виды элементов должны использовать прописную букву в начале имени:

* Пространства имён
* Классы
* Перечисления
* Члены перечислений
* Структуры
* Делегаты
* События
* Методы
* Свойства
* Локальные функции (включая статические локальные функции)

Кроме того, имя любого поля с доступом public или internal либо с модификатором const должно начинаться с прописной буквы. Имена полей readonly, не являющихся private, также должны начинаться с прописной буквы.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому начинаться со строчной буквы, поместите поле или переменную в специальный класс `NativeMethods`. Классом `NativeMethods` считается любой класс, имя которого заканчивается на `NativeMethods` и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе `NativeMethods`.

Для компонентов пространств имён, начинающихся со строчной буквы из-за особенностей фирменного написания или по другим причинам, добавьте соответствующее имя в список `allowedNamespaceComponents`.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя элемента так, чтобы оно начиналось с прописной буквы, при необходимости поместите элемент в класс `NativeMethods` либо добавьте его в список `allowedNamespaceComponents`, если это компонент пространства имён.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1300:ElementMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1300 // ElementMustBeginWithUpperCaseLetter
#pragma warning restore SA1300 // ElementMustBeginWithUpperCaseLetter
```
