:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

В цепочке `if`/`else if`/`else` для некоторых ветвей указаны открывающая и закрывающая фигурные скобки, а для других они опущены.

## Описание правила

Нарушение этого правила возникает, когда в цепочке связанных инструкций для одних ветвей указаны открывающая и закрывающая фигурные скобки, а для других они опущены. В C# для некоторых видов инструкций скобки необязательны. Например, инструкцию `if` можно записать с неодинаковым использованием скобок:

```csharp
if (true)
    return this.value;
else
{
    return that.value.
}
```

Хотя в C# это допустимо, StyleCop требует наличия скобок во всех ветвях цепочки `if`/`else if`/`else`, если они присутствуют хотя бы в одной ветви, для повышения читаемости и удобства сопровождения кода.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, инструкция, вызывающая нарушение, преобразуется в блок инструкций.

## Как подавить нарушения

```csharp
if (true)
#pragma warning disable SA1520 // Use braces consistently
    return this.value;
#pragma warning restore SA1520 // Use braces consistently
else
{
    return that.value.
}
```
