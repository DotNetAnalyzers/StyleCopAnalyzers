## Причина

Имя поля-константы C# должно начинаться с прописной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя поля с модификатором *const* не начинается с прописной буквы.

Если имя поля или переменной должно совпадать с именем элемента Win32 или COM и поэтому начинаться со строчной буквы, поместите поле или переменную в специальный класс *NativeMethods*. Классом NativeMethods считается любой класс, имя которого заканчивается на NativeMethods и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе NativeMethods.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя поля-константы так, чтобы оно начиналось с прописной буквы, либо при необходимости поместите элемент в класс NativeMethods.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1303:ConstFieldNamesMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1303 // ConstFieldNamesMustBeginWithUpperCaseLetter
#pragma warning restore SA1303 // ConstFieldNamesMustBeginWithUpperCaseLetter
```
