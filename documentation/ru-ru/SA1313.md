:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Имя параметра C# не начинается со строчной буквы.

## Описание правила

Нарушение этого правила возникает, когда имя параметра не начинается со строчной буквы.

### Отбрасывания

Исключение из этого правила сделано для параметров лямбда-выражений с именами `_` и `__`. Такие имена часто обозначают параметры-заполнители, которые фактически не используются в теле лямбда-выражения.

### Записи и первичные конструкторы

Параметры позиционных записей становятся открытыми свойствами, поэтому для них допускаются имена в стиле PascalCase, хотя они указаны в сигнатуре первичного конструктора.

### Код взаимодействия

Если имя параметра должно совпадать с именем элемента Win32 или COM и поэтому начинаться с прописной буквы, поместите параметр в специальный класс `NativeMethods`. Классом `NativeMethods` считается любой класс, имя которого заканчивается на `NativeMethods` и который предназначен для размещения оболочек Win32 или COM. StyleCop игнорирует это нарушение, если элемент находится в классе `NativeMethods`.

## Как исправить нарушения

Чтобы исправить нарушение этого правила, измените имя параметра так, чтобы оно начиналось со строчной буквы, либо при необходимости поместите элемент в класс `NativeMethods`.

## Как подавить нарушения

```csharp
#pragma warning disable SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
void Method(int Parameter)
#pragma warning restore SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
{
}
```
