## Причина

Директивы using с псевдонимами в файле кода C# не отсортированы по алфавиту по именам псевдонимов.

## Описание правила

Нарушение этого правила возникает, когда директивы using с псевдонимами не отсортированы по алфавиту по именам псевдонимов. Алфавитная сортировка делает код аккуратнее и понятнее, а также помогает быстрее определить используемые пространства имён.

Глобальные директивы using (C# 10) анализируются независимо от локальных. Диагностика и исправления сравнивают только директивы, в которых либо у обеих есть модификатор `global`, либо у обеих его нет.

## Как исправить нарушения

Чтобы исправить нарушение, отсортируйте директивы using с псевдонимами по алфавиту по именам псевдонимов.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1211:UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1211 // UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName
#pragma warning restore SA1211 // UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName
```
