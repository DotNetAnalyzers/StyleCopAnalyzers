# SA1415: Не объявляйте члены внутренних типов как public

:bulb: Это правило по умолчанию отключено.

## Причина

Член типа, который фактически является внутренним или закрытым, объявлен как `public`.

## Описание правила

Нарушение этого правила возникает, когда член объявлен как `public`, но содержащий его тип не виден за пределами сборки. Член `public` у типа `internal` или `private` не входит в общедоступный API сборки; его видимость ограничена видимостью самого типа. Рецензентам, которые следят за изменениями общедоступного API, приходится отсеивать такие члены.

Это правило сообщает о явном модификаторе `public` у члена типа, чья фактическая доступность — `internal`, `private` или `private protected`. Сюда относятся члены:

* типов верхнего уровня со спецификатором `internal`
* вложенных типов `private` или `internal`
* типов `public` или `protected`, вложенных во внутренний тип и поэтому фактически внутренних
* вложенных типов `private protected` (в том числе вложенных в открытый тип), которые не видны за пределами сборки
* типов с модификатором `file`

Не сообщается о следующих случаях:

* Члены типов, которые фактически являются `public`, `protected` или `protected internal` (они могут быть видны за пределами сборки)
* Члены, реализующие интерфейс или переопределяющие член базового типа; они должны оставаться `public`
* Пользовательские операторы и преобразования, которые язык требует объявлять как `public`
* Члены интерфейсов (включая внутренние интерфейсы) и члены перечислений
* Члены, не объявленные как `public`, включая неявно общие позиционные свойства записей, например `internal record R(int Value)`
* Члены `protected` или `protected internal` внутренних типов

Правило по умолчанию отключено, потому что не каждая команда считает `public` у внутренних типов проблемой. Некоторые команды используют `public` у внутренних типов, чтобы пометить члены, которые позже планируют сделать общедоступными.

Чтобы включить правило, добавьте в файл `.editorconfig` следующее:

```ini
dotnet_diagnostic.SA1415.severity = warning
```

## Как исправить нарушения

Измените доступность члена с `public` на `internal`. Для членов типов, не видимых за пределами сборки, эти модификаторы эквивалентны, и `internal` не выглядит как часть общедоступного API.

```csharp
internal class Example
{
    public void Method() // SA1415
    {
    }
}
```

```csharp
internal class Example
{
    internal void Method()
    {
    }
}
```

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1415:DoNotUsePublicOnMembersOfInternalTypes", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1415 // Do not use public on members of internal types
#pragma warning restore SA1415 // Do not use public on members of internal types
```
