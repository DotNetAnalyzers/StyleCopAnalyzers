# SA1610: Документация свойства должна содержать текст описания значения

## Причина

XML-комментарий документации свойства C# содержит пустой тег `<value>`.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Документация свойств может включать тег `<value>`, описывающий значение свойства.

Нарушение возникает, если тег `<value>` свойства пуст.

## Как исправить нарушение

Заполните тег `<value>` описанием значения свойства.

Пример:

В следующем примере показано свойство с тегом `<value>` в комментарии документации.

```csharp
/// <summary>
/// Gets the name of the customer. 
/// </summary>
/// <value>The name of the customer.</value>
public bool Name
{
    get { return this.name; }
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1610:PropertyDocumentationMustHaveValueText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1610 // PropertyDocumentationMustHaveValueText
#pragma warning restore SA1610 // PropertyDocumentationMustHaveValueText
```
