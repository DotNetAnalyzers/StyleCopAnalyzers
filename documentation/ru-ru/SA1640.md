## Причина

Заголовок файла в начале файла кода C# не содержит названия компании.

## Описание правила

Нарушение возникает, если заголовок файла C# не содержит атрибута company с названием компании. Например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Атрибут company должен содержать текст. Например:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Как исправить нарушение

Добавьте и заполните атрибут company названием компании.

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1640:FileHeaderMustHaveValidCompanyText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1640 // FileHeaderMustHaveValidCompanyText
#pragma warning restore SA1640 // FileHeaderMustHaveValidCompanyText
```
