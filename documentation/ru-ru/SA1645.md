## Причина

Включаемый файл XML-документации не существует.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments.](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)

Вместо написания документации непосредственно в файле кода можно поместить документацию нескольких элементов в отдельный XML-файл, а затем сослаться на раздел этого файла в комментарии документации элемента. В результате компилятор импортирует документацию этого элемента из включаемого документа. Например:

```csharp
/// <include file="IncludedDocumentation.xml" path="root/EnabledMethodDocs" />
public bool Enabled(bool true)
{
}
```

Нарушение возникает, если включаемый файл не существует по указанному пути или не может быть загружен.

## Как исправить нарушение

Исправьте путь к включаемому файлу документации, указав существующий файл.

## Как подавить нарушение

[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1645:IncludedDocumentationFileDoesNotExist", Justification = "Reviewed.")]
