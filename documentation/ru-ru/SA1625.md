## Причина

XML-документация элемента C# содержит две или более одинаковые записи, что указывает на копирование и вставку документации. Иногда это признак некорректной или некачественно написанной документации.

## Описание правила

Синтаксис C# позволяет включать документацию для классов и других элементов непосредственно в код с помощью XML-комментариев документации. Введение в эти комментарии и описание их синтаксиса приведены в статье: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Нарушение возникает, если элемент содержит два или более одинаковых текста документации. Например:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">Part of the name.</param>
/// <param name="lastName">Part of the name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

В некоторых случаях метод может иметь один или несколько параметров, не используемых в его теле. Тогда для параметра можно указать документацию «The parameter is not used.» («Параметр не используется.»). StyleCop допускает одинаковую документацию нескольких параметров, если строка документации в точности равна «The parameter is not used.».

## Как исправить нарушение

Отредактируйте документацию элемента так, чтобы каждый отдельный текст документации был уникальным. Например:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Как подавить нарушение

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1625:ElementDocumentationMustNotBeCopiedAndPasted", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1625 // ElementDocumentationMustNotBeCopiedAndPasted
#pragma warning restore SA1625 // ElementDocumentationMustNotBeCopiedAndPasted
```
