### Правила удобства сопровождения (SA1400-)
Правила, повышающие удобство сопровождения кода.

Идентификатор | Имя | Описание
-----------|------|------------
[SA1119](SA1119.md) | StatementMustNotUseUnnecessaryParenthesis | Инструкция C# содержит ненужные круглые скобки, которые следует удалить.
[SA1400](SA1400.md) | AccessModifierMustBeDeclared | Модификатор доступа элемента C# не указан явно.
[SA1401](SA1401.md) | FieldsMustBePrivate | Поле в классе C# имеет модификатор доступа, отличный от private.
[SA1402](SA1402.md) | FileMayOnlyContainASingleType | Файл кода C# содержит более одного отдельного типа.
[SA1403](SA1403.md) | FileMayOnlyContainASingleNamespace | Файл кода C# содержит более одного пространства имён.
[SA1404](SA1404.md) | CodeAnalysisSuppressionMustHaveJustification | Атрибут SuppressMessage для анализа кода не содержит обоснования.
[SA1405](SA1405.md) | DebugAssertMustProvideMessageText | Вызов Debug.Assert в коде C# не содержит поясняющего сообщения.
[SA1406](SA1406.md) | DebugFailMustProvideMessageText | Вызов Debug.Fail в коде C# не содержит поясняющего сообщения.
[SA1407](SA1407.md) | ArithmeticExpressionsMustDeclarePrecedence | Инструкция C# содержит сложное арифметическое выражение, в котором операции не выделены скобками.
[SA1408](SA1408.md) | ConditionalExpressionsMustDeclarePrecedence | Инструкция C# содержит сложное условное выражение, в котором операции не выделены скобками.
[SA1409](SA1409.md) | RemoveUnnecessaryCode | Файл C# содержит ненужный код, который можно удалить, не меняя общую логику программы.
[SA1410](SA1410.md) | RemoveDelegateParenthesisWhenPossible | При использовании анонимного метода C# без параметров в записи по-прежнему присутствуют круглые скобки.
[SA1411](SA1411.md) | AttributeConstructorMustNotUseUnnecessaryParenthesis | Объявление атрибута не содержит параметров, но в нём по-прежнему присутствуют круглые скобки.
[SA1412](SA1412.md) | StoreFilesAsUtf8 | Файл сохранён не в кодировке UTF-8 с маркером порядка байтов.
[SA1413](SA1413.md) | UseTrailingCommasInMultiLineInitializers | В многострочном инициализаторе, перечислении, выражении switch или образце свойств после последнего элемента должна стоять запятая.
[SA1414](SA1414.md) | TupleTypesInSignaturesShouldHaveElementNames | Типы-кортежи в объявлениях членов должны иметь явно именованные элементы.
