:memo: Это новое правило StyleCop Analyzers, отсутствовавшее в StyleCop Classic.

## Причина

Директивы `using static` в файле кода C# не отсортированы по алфавиту по полным именам типов.

## Описание правила

Нарушение этого правила возникает, когда директивы `using static` не отсортированы по алфавиту по полным именам типов. Алфавитная сортировка делает код аккуратнее и понятнее.

По умолчанию директивы `using static` для типов из пространства имён System предшествуют всем остальным директивам `using static`, подобно тому как SA1210 располагает пространства имён System первыми. Например, `using static System.Math;` должна предшествовать `using static Absolutes.Constants;`. Чтобы вместо этого сортировать все директивы `using static` вместе по алфавиту, задайте параметру `systemUsingDirectivesFirst` значение `false` (см. [Configuration.md](Configuration.md#using-directives)).

Глобальные директивы using (C# 10) анализируются независимо от локальных. Диагностика и исправления сравнивают только директивы, в которых либо у обеих есть модификатор `global`, либо у обеих его нет.

## Как исправить нарушения

Чтобы исправить нарушение, отсортируйте директивы `using static` по алфавиту по полным именам типов.

## Как подавить нарушения

```csharp
#pragma warning disable SA1217 // Using static directives should be ordered alphabetically
using static System.Math;
#pragma warning restore SA1217 // Using static directives should be ordered alphabetically
```
