# SA1006: Ключевым словам препроцессора не должен предшествовать пробел

## Причина

Ключевому слову препроцессора C# предшествует пробел.

## Описание правила

Нарушение этого правила происходит, когда перед ключевым словом, определяющим тип директивы препроцессора, стоит пробел. Например:

```csharp
# if Debug
```

Между начальным знаком решётки и ключевым словом директивы препроцессора не должно быть пробельных символов:

```csharp
#if Debug
```

## Как исправить нарушение

Чтобы исправить нарушение этого правила, убедитесь, что между начальным знаком решётки и ключевым словом директивы препроцессора нет пробельных символов.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1006:PreprocessorKeywordsMustNotBePrecededBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1006 // PreprocessorKeywordsMustNotBePrecededBySpace
#pragma warning restore SA1006 // PreprocessorKeywordsMustNotBePrecededBySpace
```
