## Причина

Инструкция C# содержит сложное условное выражение, в котором операции не выделены скобками.

## Описание правила

В C# определена иерархия приоритетов условных операторов. Можно объединить несколько условных операций в одной инструкции, не заключая ни одну из них в скобки. В таком случае компилятор автоматически определяет порядок и приоритет операций по установленным правилам. Например:

```csharp
if (x || y && z && a || b)
{
}
```

Хотя этот код допустим, его трудно читать и сопровождать. Чтобы полностью понять его, разработчик должен знать и понимать основные правила приоритета операторов C#.

Это правило предназначено для повышения читаемости и удобства сопровождения такого кода, а также для снижения риска последующих ошибок. Оно требует от разработчика вставлять скобки, явно задающие приоритет операций. Например, разработчик может записать этот код так:

```csharp
if ((x || y) && z && (a || b))
{
}
```

или так:

```csharp
if (x || (y && z && a) || b)
{
}
```

Начиная с комбинаторов образцов, появившихся в C# 9, образцы `and` и `or` обрабатываются так же, как `&&` и `||`. Их смешение без скобок приводит к диагностике, например:

```csharp
if (value is > 0 and < 5 or 10)
{
}

if (value is (> 0 and < 5) or 10)
{
}
```

Скобки делают код более наглядным и понятным, избавляя читателя от необходимости делать предположения о нём.

## Как исправить нарушения

Добавьте скобки в условное выражение, явно задав приоритет операций.

## Как подавить нарушения

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1408:ConditionalExpressionsMustDeclarePrecedence", Justification = "Reviewed.")]
```

```csharp
#pragma warning restore SA1408 // ConditionalExpressionsMustDeclarePrecedence
```
