# SA1117: Parameters should be on same line or separate lines

## Příčina

Parametry při volání nebo deklaraci metody či indexeru C# nejsou všechny na stejném řádku ani každý na samostatném řádku.

## Popis pravidla

K porušení tohoto pravidla dochází, když parametry metody nebo indexeru nejsou všechny na stejném řádku ani každý na vlastním řádku. Například:

```csharp
public string JoinName(string first, string middle,
    string last)
{
}
```

Všechny parametry lze umístit na stejný řádek:

```csharp
public string JoinName(string first, string middle, string last)
{
}

public string JoinName(
    string first, string middle, string last)
{
}
```

Případně lze každý parametr umístit na vlastní řádek:

```csharp
public string JoinName(
    string first, 
    string middle, 
    string last)
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, umístěte všechny parametry na stejný řádek nebo každý parametr na vlastní řádek.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1117:ParametersMustBeOnSameLineOrSeparateLines", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1117 // ParametersMustBeOnSameLineOrSeparateLines
#pragma warning restore SA1117 // ParametersMustBeOnSameLineOrSeparateLines
```
