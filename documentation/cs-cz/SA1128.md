# SA1128: Put constructor initializers on their own line

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Inicializátor konstruktoru je v souboru s kódem C# na stejném řádku jako deklarace konstruktoru.

## Popis pravidla

K porušení tohoto pravidla dochází, když je inicializátor konstruktoru v kódu zčásti nebo zcela na stejném řádku jako deklarace konstruktoru.

Následující kód například porušuje toto pravidlo:

```csharp
public class TypeName
{
    public TypeName() : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

Znak `:` (dvojtečka) se považuje za součást inicializátoru a má být na stejném řádku jako klíčové slovo `base` nebo `this`.

Následující kód by také porušoval toto pravidlo:

```csharp
public class TypeName
{
	public TypeName() :
		base()
	{
	}
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
public class TypeName
{
    public TypeName()
        : this(0)
    {
    }

    public TypeName(int value)
    {
    }
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přesuňte inicializátor konstruktoru včetně znaku `:` na samostatný řádek.

## Jak potlačit porušení

```csharp
public class TypeName
{
#pragma warning disable SA1128 // Constructor initializers should be on their own line
    public TypeName() : this(0)
#pragma warning restore SA1128 // Constructor initializers should be on their own line
    {
    }

    public TypeName(int value)
    {
    }
}
```
