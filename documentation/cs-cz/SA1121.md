# SA1121: Use built-in type alias

## Příčina

Kód používá jeden ze základních typů C#, ale nepoužívá jeho předdefinovaný alias.

## Popis pravidla

K porušení tohoto pravidla dochází, když se v kódu použije některý z následujících typů: *Boolean, Byte, Char, Decimal, Double, Int16, Int32, Int64, Object, SByte, Single, String, UInt16, UInt32, UInt64*.

K porušení dochází také tehdy, když je některý z těchto typů v kódu uveden s úplným názvem oboru názvů: *System.Boolean, System.Byte, System.Char, System.Decimal, System.Double, System.Int16, System.Int32, System.Int64, System.Object, System.SByte, System.Single, System.String, System.UInt16, System.UInt32, System.UInt64*.

Namísto názvu typu nebo jeho plně kvalifikovaného názvu je třeba vždy použít předdefinovaný alias: *bool, byte, char, decimal, double, short, int, long, object, sbyte, float, string, ushort, uint, ulong*.

Pokud alias `using` odkazuje na jeden z těchto typů, diagnostika se hlásí u cílového typu aliasu, nikoli u každého použití aliasu. V C# 12 a novějších lze cíl nahradit předdefinovaným aliasem, například `using MyInt = System.Int32;` se má zapsat jako `using MyInt = int;`. Starší verze jazyka nepovolují předdefinovaný alias v cíli, takže diagnostiku lze potlačit u deklarace aliasu.

Následující tabulka uvádí každý z těchto typů ve všech třech formách:

| Type Alias | Type | Fully Qualified Type |
| --- | --- | --- |
| bool | Boolean | System.Boolean |
| byte | Byte | System.Byte |
| char | Char | System.Char |
| decimal | Decimal | System.Decimal |
| double | Double | System.Double |
| short | Int16 | System.Int16 |
| int | Int32 | System.Int32 |
| long | Int64 | System.Int64 |
| object | Object | System.Object |
| sbyte | SByte | System.SByte |
| float | Single | System.Single |
| string | String | System.String |
| ushort | UInt16 | System.UInt16 |
| uint | UInt32 | System.UInt32 |
| ulong | UInt64 | System.UInt64 |

### Celá čísla nativní velikosti (C# 11 a .NET 7 nebo novější)

Aliasy celých čísel nativní velikosti *nint* a *nuint* byly zavedeny v C# 9. SA1121 bere v úvahu typy `IntPtr`/`UIntPtr` a jejich aliasy od C# 11 při cílení na .NET 7 nebo novější (zjišťuje se pomocí `System.Runtime.CompilerServices.RuntimeFeature.NumericIntPtr`). Ve starších verzích jazyka nebo modulu runtime, včetně C# 9, tyto typy diagnostiku SA1121 nevyvolají.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, nahraďte typ jeho předdefinovaným aliasem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1121:UseBuiltInTypeAlias", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1121 // UseBuiltInTypeAlias
#pragma warning restore SA1121 // UseBuiltInTypeAlias
```
