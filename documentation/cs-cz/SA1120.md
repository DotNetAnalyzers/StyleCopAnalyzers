# SA1120: Comments should contain text

## Příčina

Komentář C# neobsahuje žádný text.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje komentář C#, který neobsahuje žádný text.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, doplňte do komentáře text nebo komentář odstraňte.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1120:CommentsMustContainText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1120 // CommentsMustContainText
#pragma warning restore SA1120 // CommentsMustContainText
```
