# SA1610: Property documentation should have value text

## Příčina

Záhlaví dokumentace XML vlastnosti C# obsahuje prázdnou značku `<value>`.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Dokumentace vlastností může zahrnovat značku `<value>`, která popisuje hodnotu uloženou ve vlastnosti.

Porušení tohoto pravidla nastává tehdy, když je značka `<value>` vlastnosti prázdná.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, vyplňte ve značce `<value>` popis hodnoty uložené ve vlastnosti.

Příklad:

Následující příklad ukazuje vlastnost obsahující v záhlaví dokumentace značku `<value>`.

```csharp
/// <summary>
/// Gets the name of the customer. 
/// </summary>
/// <value>The name of the customer.</value>
public bool Name
{
    get { return this.name; }
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1610:PropertyDocumentationMustHaveValueText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1610 // PropertyDocumentationMustHaveValueText
#pragma warning restore SA1610 // PropertyDocumentationMustHaveValueText
```
