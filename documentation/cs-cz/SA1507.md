## Příčina

Kód C# obsahuje několik po sobě jdoucích prázdných řádků.

## Popis pravidla

Pro zlepšení čitelnosti kódu StyleCop v některých případech vyžaduje prázdné řádky a v jiných je zakazuje. Díky tomu má kód jednotný vizuální vzhled, který může usnadnit rozpoznávání a čtení neznámého kódu.

Pravidlo se poruší, když kód obsahuje více než jeden prázdný řádek za sebou. Například:

```csharp
public bool Enabled
{
    get 
    { 
        Console.WriteLine("Getting the enabled flag.");


        return this.enabled; 
    }
}
```

Výše uvedený kód vede k výskytu tohoto porušení, protože obsahuje několik prázdných řádků za sebou.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odstraňte nadbytečné prázdné řádky.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1507:CodeMustNotContainMultipleBlankLinesInARow", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1507 // CodeMustNotContainMultipleBlankLinesInARow
#pragma warning restore SA1507 // CodeMustNotContainMultipleBlankLinesInARow
```
