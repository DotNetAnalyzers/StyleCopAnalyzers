# SA1015: Closing generic brackets should be spaced correctly

## Příčina

Uzavírací závorka obecného typu v prvku C# nemá správné mezery.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud mezery kolem uzavírací závorky obecného typu nejsou správné.

Uzavírací závorce obecného typu nesmí předcházet bílý znak, pokud závorka není prvním znakem na řádku.
Za uzavírací závorkou obecného typu musí následovat otevírací kulatá závorka, uzavírací kulatá závorka, uzavírací závorka obecného typu,
symbol označující možnou hodnotu null, konec řádku nebo jedna mezera (nikoli však mezera následovaná otevírací kulatou závorkou). V kontextech
podporujících hodnotu null se anotace odkazových typů s možnou hodnotou null (například `List<string?>?`) řídí stejnými pravidly jako hodnotové
typy s možnou hodnotou null.

Token `>`, který ukončuje seznam parametrů ukazatele na funkci v jazyce C# 9, se řídí stejnými pravidly pro mezery, například `delegate*<int, void>`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem uzavírací závorky obecného typu byly správné.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1015:ClosingGenericBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
#pragma warning restore SA1015 // ClosingGenericBracketsMustBeSpacedCorrectly
```
