# SA1625: Element documentation should not be copied and pasted

## Příčina

Dokumentace XML prvku C# obsahuje dvě nebo více shodných položek, což naznačuje, že dokumentace byla zkopírována a vložena. To může někdy znamenat neplatnou nebo nekvalitně napsanou dokumentaci.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud prvek obsahuje dva nebo více shodných textů dokumentace. Například:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">Part of the name.</param>
/// <param name="lastName">Part of the name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

V některých případech může metoda obsahovat jeden nebo více parametrů, které se v těle metody nepoužívají. Dokumentace takového parametru může mít text „The parameter is not used.“. StyleCop umožňuje, aby více parametrů mělo shodnou dokumentaci, pokud je jejím řetězcem „The parameter is not used.“.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, upravte dokumentaci prvku a zajistěte, aby byl každý jednotlivý text dokumentace jedinečný. Například:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1625:ElementDocumentationMustNotBeCopiedAndPasted", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1625 // ElementDocumentationMustNotBeCopiedAndPasted
#pragma warning restore SA1625 // ElementDocumentationMustNotBeCopiedAndPasted
```
