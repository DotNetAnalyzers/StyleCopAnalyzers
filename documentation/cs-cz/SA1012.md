# SA1012: Opening braces should be spaced correctly

## Příčina

Otevírací složená závorka v prvku C# nemá správné mezery.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud mezery kolem otevírací složené závorky nejsou správné.

Otevírací složené závorce musí vždy předcházet jedna mezera, pokud není prvním znakem na řádku nebo pokud jí nepředchází otevírací kulatá závorka; v takovém případě mezi kulatou a složenou závorkou mezera být nemá.

Za otevírací složenou závorkou musí vždy následovat jedna mezera, pokud není posledním znakem na řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem otevírací složené závorky odpovídaly výše uvedenému pravidlu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1012:OpeningBracesMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1012 // OpeningBracesMustBeSpacedCorrectly
#pragma warning restore SA1012 // OpeningBracesMustBeSpacedCorrectly
```
