# SA1403: File may only contain a single namespace

## Příčina

Zdrojový soubor C# obsahuje více než jeden obor názvů.

## Popis pravidla

K porušení tohoto pravidla dojde, když soubor C# obsahuje více než jeden obor názvů. Aby se zvýšila dlouhodobá udržovatelnost zdrojového kódu, měl by každý soubor obsahovat nejvýše jeden obor názvů.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby soubor obsahoval pouze jeden obor názvů.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1403:FileMayOnlyContainASingleNamespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1403 // FileMayOnlyContainASingleNamespace
#pragma warning restore SA1403 // FileMayOnlyContainASingleNamespace
```
