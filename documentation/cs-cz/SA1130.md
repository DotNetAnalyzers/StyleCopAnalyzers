# SA1130: Use lambda syntax

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Anonymní metoda byla deklarována ve tvaru `delegate (parameters) { }`, přestože by výraz lambda se syntaxí `(parameters) => { }` poskytl stejné chování.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje anonymní metodu používající „starý“ zápis `delegate (parameters) { }`.

Například každý z následujících zápisů by porušoval toto pravidlo:

```csharp
Action a = delegate { x = 0; };
Action b = delegate() { y = 0; };
Func<int, int, int> c = delegate(int m, int n) { return m + n; };
Action d = static delegate() { z = 0; };
```

Následující kód ukazuje odpovídající deklarace proměnných pomocí známější syntaxe lambda.

```csharp
Action a = () => { x = 0; };
Action b = () => { y = 0; };
Func<int, int, int> c = (m, n) => m + n;
Action d = static () => { z = 0; };
```

:memo: Anonymní metodu nelze vždy nahradit ekvivalentním výrazem lambda. Například následující kód toto pravidlo neporušuje, protože anonymní metoda a výraz lambda mají odlišnou sémantiku.

```csharp
var x = A(() => { });       // Expression
var y = A(delegate { });    // Action

private Expression<Action> A(Expression<Action> expression)
{
    return expression;
}

private Action A(Action action)
{
    return action;
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, nahraďte anonymní funkci ekvivalentním výrazem lambda.

Oprava kódu zachovává názvy parametrů anonymní metody. Zachovává také typy parametrů v případech, kdy je výraz lambda potřebuje: u parametrů `ref`, `out` a `in`, při odvozování argumentů typu obecnou metodou, když se anonymní metoda nepřevádí na typ delegáta a kdykoli by jejich odstranění způsobilo nejednoznačnost přetíženého volání.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1130 // Use lambda syntax
Action a = delegate { x = 0; };
#pragma warning restore SA1130 // Use lambda syntax
```
