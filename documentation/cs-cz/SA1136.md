# SA1136: Enum values should be on separate lines

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Multiple enum values are placed on the same line of code.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když two or more enum values are placed on the same line of code.

For example, the following code would produce a violation of this rule:

```csharp
public enum ExampleEnum
{
    FirstValue, SecondValue
}
```

The following code would not produce any violations:

```csharp
public enum ExampleEnum
{
    FirstValue,
    SecondValue
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, place each enum value on its own line.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1136 // Enum values should be on separate lines
public enum ExampleEnum
{
    FirstValue, SecondValue
}
#pragma warning restore SA1136 // Enum values should be on separate lines
```
