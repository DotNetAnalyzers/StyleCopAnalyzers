# SA1136: Enum values should be on separate lines

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Na stejném řádku kódu je umístěno více hodnot výčtu.

## Popis pravidla

K porušení tohoto pravidla dochází, když jsou na stejném řádku kódu umístěny dvě nebo více hodnot výčtu.

Následující kód například porušuje toto pravidlo:

```csharp
public enum ExampleEnum
{
    FirstValue, SecondValue
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
public enum ExampleEnum
{
    FirstValue,
    SecondValue
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, umístěte každou hodnotu výčtu na samostatný řádek.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1136 // Enum values should be on separate lines
public enum ExampleEnum
{
    FirstValue, SecondValue
}
#pragma warning restore SA1136 // Enum values should be on separate lines
```
