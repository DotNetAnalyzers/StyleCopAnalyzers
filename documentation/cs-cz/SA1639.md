:bulb: Toto pravidlo je ve výchozím nastavení zakázané.

## Příčina

Hlavička na začátku souboru se zdrojovým kódem C# neobsahuje vyplněnou značku summary.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud hlavička na začátku souboru C# neobsahuje platnou značku summary.

Například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Je-li toto pravidlo povoleno, hlavička souboru by měla obsahovat značku summary. Například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
// <summary>This is the Widget class.</summary>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte a vyplňte značku summary popisující obsah souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1639:FileHeaderMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1639 // FileHeaderMustHaveSummary
#pragma warning restore SA1639 // FileHeaderMustHaveSummary
```
