## Příčina

Soubor jazyka C# obsahuje nadbytečný kód, který lze odebrat bez změny celkové logiky kódu.

## Popis pravidla

K porušení tohoto pravidla dojde, když soubor obsahuje kód, který lze odebrat bez změny celkové logiky kódu.

Například následující příkaz try-catch lze zcela odebrat, protože bloky try i catch jsou prázdné.

```csharp
try
{
}
catch (Exception ex)
{
}
```

Následující příkaz try-finally sice obsahuje kód v bloku try, ale neobsahuje žádný blok catch a blok finally je prázdný. Příkaz try-finally proto neplní žádnou užitečnou funkci a lze jej odebrat.

```csharp
try
{
    this.Method();
}
finally
{
}
```

Posledním příkladem je následující prázdný příkaz unsafe, který tedy nepřináší žádnou hodnotu.

```csharp
unsafe
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odeberte nadbytečný kód nebo jej doplňte o další příkazy.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1409:RemoveUnnecessaryCode", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1409 // RemoveUnnecessaryCode
#pragma warning restore SA1409 // RemoveUnnecessaryCode
```
