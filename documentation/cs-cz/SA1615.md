# SA1615: Element return value should be documented

## Příčina

V dokumentaci prvku C# chybí popis jeho návratové hodnoty.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, pokud v dokumentaci prvku s návratovou hodnotou chybí značka `<returns>`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte do značky `<returns>` text dokumentace popisující hodnotu vrácenou prvkem nebo existující text doplňte.

Následující příklad ukazuje metodu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1615:ElementReturnValueMustBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1615 // ElementReturnValueMustBeDocumented
#pragma warning restore SA1615 // ElementReturnValueMustBeDocumented
```
