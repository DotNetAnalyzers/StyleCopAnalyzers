# SA1119: Statement should not use unnecessary parenthesis

## Příčina

Příkaz C# obsahuje závorky, které jsou nadbytečné a měly by být odstraněny.

## Popis pravidla

V jazyce C# lze závorky vložit téměř kolem libovolného výrazu, příkazu nebo klauzule a v mnoha případech mohou výrazně zlepšit čitelnost kódu. Nadměrné používání závorek však může mít opačný účinek a ztížit čtení i údržbu kódu.

K porušení tohoto pravidla dochází, když jsou závorky použity v situacích, kde nemají praktický přínos. Obvykle se tak děje, když závorky obklopují výraz, který je nutně nepotřebuje, a tento výraz je kořenem příkazu. Následující řádky kódu například obsahují nadbytečné závorky, a porušují tak toto pravidlo:

```csharp
int x = (5 + b);
string y = (this.Method()).ToString();
return (x.Value);
```

V každém z těchto příkazů lze nadbytečné závorky odstranit, aniž by se snížila čitelnost kódu:

```csharp
int x = 5 + b;
string y = this.Method().ToString();
return x.Value;
```

Od C# 8.0 mohou být závorky potřeba kolem výrazů `switch` nebo výrazů se vzorem, pokud jsou součástí jiných operací (například přetypování, `await`, podmíněného přístupu, přístupu k prvku či členu nebo logické negace). SA1119 nehlásí závorky nezbytné pro správnost kódu, ale stále označuje čistě nadbytečné závorky, například v `return (value switch { ... });` nebo `var flag = (input is { Length: 1 });`.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte nadbytečné závorky.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1119:StatementMustNotUseUnnecessaryParenthesis", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1119 // StatementMustNotUseUnnecessaryParenthesis
#pragma warning restore SA1119 // StatementMustNotUseUnnecessaryParenthesis
```
