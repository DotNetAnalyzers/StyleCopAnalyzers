# SA1112: Closing parenthesis should be on line of opening parenthesis

## Příčina

Uzavírací závorka nebo hranatá závorka při volání metody či indexeru C# nebo při jejich deklaraci není na stejném řádku jako otevírací závorka, pokud prvek nemá žádné parametry.

## Popis pravidla

K porušení tohoto pravidla dochází, když metoda nebo indexer nemá žádné parametry a uzavírací závorka jejich volání či deklarace není na stejném řádku jako otevírací závorka. Následující příklad ukazuje správné umístění uzavírací závorky:

Toto pravidlo se vztahuje také na volání konstruktorů a výrazy vytvářející objekty, včetně výrazů `new()` s cílovým typem v C# 9. Pokud nejsou zadány žádné argumenty, uzavírací závorka má zůstat na stejném řádku jako otevírací závorka následující po `new`.

```csharp
public string GetName()
{
    return this.name.Trim();
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby uzavírací závorka byla na stejném řádku jako otevírací závorka.
