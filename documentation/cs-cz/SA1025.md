## Příčina

Kód obsahuje několik po sobě jdoucích znaků bílého místa.

## Popis pravidla

K porušení tohoto pravidla dojde, když kód obsahuje několik po sobě jdoucích znaků bílého místa, pokud se
tyto znaky nenacházejí na začátku či konci řádku kódu ani bezprostředně za čárkou nebo středníkem.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odeberte nadbytečné znaky bílého místa a ponechte pouze jednu
mezeru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1025:CodeMustNotContainMultipleWhitespaceInARow", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1025 // CodeMustNotContainMultipleWhitespaceInARow
#pragma warning restore SA1025 // CodeMustNotContainMultipleWhitespaceInARow
```
