# SA1116: Split parameters should start on line after declaration

## Příčina

Parametry při volání nebo deklaraci metody či indexeru C# zasahují do více řádků, ale první parametr nezačíná na řádku následujícím po otevírací závorce.

## Popis pravidla

K porušení tohoto pravidla dochází, když parametry metody nebo indexeru zasahují do více řádků, ale první parametr nezačíná na řádku následujícím po otevírací závorce. Například:

```csharp
public string JoinName(string first, 
    string last)
{
}
```

Pokud parametry zabírají více řádků, mají začínat na řádku následujícím po deklaraci:

```csharp
public string JoinName(
    string first, 
    string last)
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby první parametr začínal na řádku následujícím po otevírací závorce, nebo umístěte všechny parametry na jeden řádek, pokud nejsou příliš dlouhé.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1116:SplitParametersMustStartOnLineAfterDeclaration", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1116 // SplitParametersMustStartOnLineAfterDeclaration
#pragma warning restore SA1116 // SplitParametersMustStartOnLineAfterDeclaration
```
