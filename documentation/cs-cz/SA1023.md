# SA1023: Dereference and access of symbols should be spaced correctly

## Příčina

Mezery kolem symbolu dereference nebo symbolu získání adresy v prvku jazyka C# nejsou správně umístěny.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud nejsou mezery kolem symbolu dereference nebo symbolu získání adresy správně umístěny.

Umístění mezer kolem tohoto symbolu závisí na tom, zda je použit v deklaraci typu. Je-li tomu tak, za symbolem má vždy následovat jediná mezera, s výjimkou případů, kdy je posledním znakem na řádku nebo po něm následuje otevírací hranatá či kulatá závorka. Symbolu navíc nesmí předcházet bílý znak a nesmí být prvním znakem na řádku. Příkladem správně odděleného symbolu dereference použitého v deklaraci typu je:

```csharp
object* x = null;
```

To platí také pro deklarace ukazatelů na funkce. V `delegate* unmanaged[Cdecl]<int*, void>` je `*` bezprostředně
následující po `delegate` považována za součást deklarace typu a řídí se stejnými pravidly pro mezery. Je-li
vynechána konvence volání, `*` se zapisuje přímo před seznam parametrů, například `delegate*<int*>` (bez
mezery před `<`).

Pokud se symbol dereference nebo symbol získání adresy použije mimo deklaraci typu, platí opačné pravidlo. V takovém případě mu má vždy předcházet jediná mezera, s výjimkou případů, kdy je prvním znakem na řádku nebo před ním je otevírací hranatá závorka, kulatá závorka nebo symbol stejného typu, tj. znaménko rovná se. Za symbolem nesmí následovat bílý znak a symbol nesmí být posledním znakem na řádku. Například:

```csharp
y = *x;
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem symbolu dereference nebo symbolu získání adresy splňovaly výše uvedené pravidlo.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1023:DereferenceAndAccessOfMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1023 // DereferenceAndAccessOfMustBeSpacedCorrectly
#pragma warning restore SA1023 // DereferenceAndAccessOfMustBeSpacedCorrectly
```
