# SA1654: Správně zapisujte závorky obecných typů

## Příčina

Atribut `cref` používá pro argumenty obecných typů escapované ostré závorky, například `GenericClass&lt;T&gt;`.

## Popis pravidla

V atributech `cref` v XML dokumentaci používejte pro argumenty obecných typů složené závorky.
Jde o čitelnější zápis než escapované ostré závorky a o doporučenou syntaxi odkazů v dokumentaci jazyka C#.

## Jak opravit porušení

Použijte automatickou opravu kódu nebo nahraďte escapované ostré závorky složenými:

```csharp
/// <summary>
/// Uses <see cref="GenericClass{T}"/>.
/// </summary>
public class GenericClass<T>
{
}
```

