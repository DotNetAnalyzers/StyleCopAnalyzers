# SA1106: Code should not contain empty statements

## Příčina

Kód C# obsahuje nadbytečný středník.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje nadbytečný středník. Z hlediska syntaxe tím v kódu vznikne prázdný příkaz navíc.

Deklarace `using` v C# 8 (například `using var stream = new MemoryStream();` nebo `await using`) končí povinným středníkem, který je součástí syntaxe deklarace. Tento středník se nepovažuje za prázdný příkaz a toto pravidlo kvůli němu diagnostiku nehlásí.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte nadbytečný středník.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1106:CodeMustNotContainEmptyStatements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1106 // CodeMustNotContainEmptyStatements
#pragma warning restore SA1106 // CodeMustNotContainEmptyStatements
```
