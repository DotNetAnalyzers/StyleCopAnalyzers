# SA1102: Query clause should follow previous clause

## Příčina

Klauzule dotazu C# nezačíná na stejném řádku jako předchozí klauzule ani na následujícím řádku.

## Popis pravidla

K porušení tohoto pravidla dochází, když klauzule ve výrazu dotazu nezačíná na stejném řádku jako předchozí klauzule ani na řádku následujícím po této klauzuli. Například:
```c#
    object x = from num in numbers

        select num;
```

Klauzuli dotazu lze správně zapsat takto:
```c#
    object x = from num in numbers select num;
```
or:
```c#
    object x =
        from num
        in numbers
        select num;
```
 
## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby každá klauzule výrazu dotazu začínala na stejném řádku jako předchozí klauzule nebo na následujícím řádku.

## Jak potlačit porušení

```c#
#pragma warning disable SA1102 // Query clause should follow previous clause
    object x = from num in numbers

        select num;
#pragma warning restore SA1102 // Query clause should follow previous clause
```
