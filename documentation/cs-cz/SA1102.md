## Příčina

A C# query clause does not begin on the same line as the previous clause, or on the next line.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když a clause within a query expression does not begin on the same line as the previous clause, or on the line after the query clause. For example:
```c#
    object x = from num in numbers

        select num;
```

The query clause can correctly be written as:
```c#
    object x = from num in numbers select num;
```
or:
```c#
    object x =
        from num
        in numbers
        select num;
```
 
## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, ensure that each clause in the query expression begins on the same line as the previous clause, or on the following line.

## Jak potlačit porušení

```c#
#pragma warning disable SA1102 // Query clause should follow previous clause
    object x = from num in numbers

        select num;
#pragma warning restore SA1102 // Query clause should follow previous clause
```
