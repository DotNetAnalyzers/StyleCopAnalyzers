# SA1006: Preprocessor keywords should not be preceded by space

## Příčina

Před klíčovým slovem direktivy preprocesoru C# je mezera.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud klíčovému slovu v direktivě preprocesoru předchází mezera. Například:

```csharp
# if Debug
```

Mezi úvodním znakem mřížky a klíčovým slovem direktivy preprocesoru nemá být žádný bílý znak:

```csharp
#if Debug
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezi úvodním znakem mřížky a klíčovým slovem direktivy
preprocesoru nebyl žádný bílý znak.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1006:PreprocessorKeywordsMustNotBePrecededBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1006 // PreprocessorKeywordsMustNotBePrecededBySpace
#pragma warning restore SA1006 // PreprocessorKeywordsMustNotBePrecededBySpace
```
