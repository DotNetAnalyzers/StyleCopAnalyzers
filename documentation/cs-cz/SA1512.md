## Příčina

Za jednořádkovým komentářem v kódu C# následuje prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

K porušení tohoto pravidla dochází, když za jednořádkovým komentářem následuje prázdný řádek. Například:

```csharp
public bool Enabled
{
    get 
    {
        // Return the value of the 'enabled' field.

        return this.enabled;
    }
}
```

Uvedený kód by vyvolal instanci tohoto porušení, protože za jednořádkovým komentářem následuje prázdný řádek.

Je povoleno vložit prázdný řádek mezi dva bloky jednořádkových komentářů. Například:

```csharp
public bool Enabled
{
    get 
    {
        // This is a sample comment which doesn't really say anything.
        // This is another part of the comment.

        // There is a blank line above this comment but that is ok.
        return this.enabled;  
    }
}
```

Pokud se komentář používá k zakomentování řádku kódu, umístěte na jeho začátek místo dvou čtyři lomítka. StyleCop
pak toto porušení ignoruje. Například:

```csharp
public bool Enabled
{
    get 
    {
        ////return false;

        return this.enabled;  
    }
}
```

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, odstraňte prázdný řádek následující za jednořádkovým komentářem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1512:SingleLineCommentsMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1512 // SingleLineCommentsMustNotBeFollowedByBlankLine
#pragma warning restore SA1512 // SingleLineCommentsMustNotBeFollowedByBlankLine
```
