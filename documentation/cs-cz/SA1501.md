## Příčina

Příkaz jazyka C# obsahující otevírací a uzavírací složené závorky je zapsán celý na jednom řádku.

## Popis pravidla

Pravidlo je porušeno, pokud je příkaz uzavřený mezi otevírací a uzavírací složené závorky zapsán na jediném řádku. Například:

```csharp
public object Method()
{
    lock (this) { return this.value; }
}
```

Pokud StyleCop tento kód analyzuje, pravidlo bude porušeno, protože celý příkaz lock je zapsán na jednom řádku. Příkaz má být rozložen do více řádků tak, aby otevírací i uzavírací složená závorka byly každá na vlastním řádku:

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value; 
    }
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přepište příkaz tak, aby byl rozložen do více řádků.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1501:StatementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1501 // StatementMustNotBeOnSingleLine
#pragma warning restore SA1501 // StatementMustNotBeOnSingleLine
```
