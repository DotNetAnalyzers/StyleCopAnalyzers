# SA1132: Do not combine fields

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Ve stejné syntaxi deklarace polí byla deklarována dvě nebo více polí.

## Popis pravidla

K porušení tohoto pravidla dochází, když jsou dvě pole deklarována v rámci stejné definice pole.

Následující kód například porušuje toto pravidlo:

```csharp
public class TypeName
{
    private int field1,
        field2; // SA1132
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
public class TypeName
{
    private int field1;
    private int field2;
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, deklarujte každé pole v samostatné definici pole.

## Jak potlačit porušení

```csharp
public class TypeName
{
    private int field1,
#pragma warning disable SA1132 // Do not combine fields
        field2;
#pragma warning restore SA1132 // Do not combine fields
}
```
