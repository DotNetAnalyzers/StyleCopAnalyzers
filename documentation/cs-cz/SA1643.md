## Příčina

Hlavička dokumentace XML pro finalizátor v jazyce C# neobsahuje vhodný souhrnný text.

## Popis pravidla

Syntaxe jazyka C# umožňuje vkládat dokumentaci ke třídám a prvkům přímo do kódu pomocí hlaviček dokumentace XML. Úvod k těmto hlavičkám a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, když značka `summary` v hlavičce dokumentace pro finalizátor nezačíná správným textem.

Účelem tohoto pravidla je sjednotit text souhrnu finalizátoru. Souhrn finalizátoru by měl začínat textem „Finalizes an instance of the {class name} class.“ Následující příklad ukazuje finalizátor třídy Customer.

```csharp
/// <summary>
/// Finalizes an instance of the Customer class.
/// </summary>
~Customer()
{
}
```

Do textu souhrnu je možné vložit další značky. Například:

```csharp
/// <summary>
/// Finalizes an instance of the <see cref="Customer"/> class.
/// </summary>
~Customer()
{
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, upravte text souhrnu finalizátoru podle výše uvedeného popisu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1643:DestructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1643 // DestructorSummaryDocumentationMustBeginWithStandardText
```
