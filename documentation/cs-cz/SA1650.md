## Příčina

Dokumentace prvku obsahuje jednu nebo více pravopisných chyb nebo nerozpoznaných slov.

## Popis pravidla

K porušení tohoto pravidla dochází, když dokumentace prvku obsahuje pravopisné chyby:

```csharp
/// <summary>
/// Joinsnames
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>Name</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

Pravopis se kontroluje s použitím jazykové verze zadané v souboru Settings.StyleCop (ve výchozím nastavení en-US).

V tomto příkladu je slovo Joinsnames v elementu `summary` napsáno chybně. Opravte pravopis, vložte případné názvy C# do elementů `<c> </c>`, potlačte porušení nebo přidejte Joinsnames do souboru CustomDictionary.xml.

Soubory CustomDictionary.xml mohou obsahovat slova, která kontrola pravopisu běžně nerozpozná.

Soubor CustomDictionary.xml by měl být umístěn ve stejné složce jako StyleCop.dll a Rules. Tato složka i všechny její podsložky se kontrolují na soubory slovníku.

StyleCop načítá soubory CustomDictionary.xml, CustomDictionary.en-GB.xml a poté CustomDictionary.en.xml (kde en-GB je jazyková verze zadaná v souboru Settings.StyleCop).

StyleCop také načítá soubory custom.dic, custom.en-GB.dic a poté custom.en.dic (kde en-GB je jazyková verze zadaná v souboru Settings.StyleCop).

Rozpoznaná slova lze do souboru Settings.StyleCop přidat také pomocí Editoru nastavení na kartě kontroly pravopisu.

Hodnoty atributů v dokumentaci XML prvku se nekontrolují na pravopis.

Veškerý text uvnitř elementů `<c> </c>` nebo `<code> </code>` se také ignoruje.

Ignoruje se také veškerý text, který začíná a končí znakem `$` nebo začíná a končí znaky `$$`, například $$(thtp kthpo kthpk)$$.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, opravte všechny pravopisné chyby v dokumentaci prvku.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1650:ElementDocumentationMustBeSpelledCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1650 // ElementDocumentationMustBeSpelledCorrectly
#pragma warning restore SA1650 // ElementDocumentationMustBeSpelledCorrectly
```
