# SA1013: Closing braces should be spaced correctly

## Příčina

Uzavírací složená závorka v prvku C# nemá správné mezery.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud mezery kolem uzavírací složené závorky nejsou správné.

Za uzavírací složenou závorkou musí vždy následovat jedna mezera, s výjimkou případů, kdy je posledním znakem na řádku nebo po ní následuje uzavírací kulatá závorka, čárka či středník. Operátor potlačení hodnoty null (`!`) může také bezprostředně následovat za uzavírací složenou závorkou bez mezery (například `new Foo { Value = null }!`).

Uzavírací složené závorce musí vždy předcházet jedna mezera, pokud není prvním znakem na řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem uzavírací složené závorky odpovídaly výše uvedenému pravidlu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1013:ClosingBracesMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1013 // ClosingBracesMustBeSpacedCorrectly
#pragma warning restore SA1013 // ClosingBracesMustBeSpacedCorrectly
```
