# SA1509: Opening braces should not be preceded by blank line

## Příčina

Otevírací složené závorce v prvku, příkazu nebo výrazu C# předchází prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

Obecně k porušení tohoto pravidla dochází, když otevírací složené závorce předchází prázdný řádek. Následující
příklad by například vyvolal dvě instance tohoto porušení, protože na dvou místech otevíracím složeným závorkám
předcházejí prázdné řádky.

```csharp
public bool Enabled

{
    get

    {
        return this.enabled;
    }
}
```

Výjimka z tohoto pravidla nastává, když otevírací složené závorce předchází uzavírací složená závorka. V takovém
případě vyžaduje [SA1513](SA1513.md) prázdný řádek. Následující příklad ukazuje správné použití prázdných řádků:

```csharp
public bool Enabled
{
    get
    {
        {
        }

        {
            return this.enabled;
        }
    }
}
```

Toto pravidlo se vztahuje také na otevírací složené závorky ve výrazech switch a vzorech vlastností zavedených v
C# 8.0. I v těchto konstrukcích nesmí být bezprostředně před otevírací složenou závorkou prázdný řádek.

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, odstraňte prázdný řádek před otevírací složenou závorkou.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1509:OpeningBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1509 // OpeningBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1509 // OpeningBracesMustNotBePrecededByBlankLine
```
