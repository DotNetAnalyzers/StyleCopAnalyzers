# SA1629: Documentation text should end with a period

## Příčina

Část záhlaví dokumentace XML prvku C# nekončí tečkou, vykřičníkem ani otazníkem.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud část dokumentace nekončí tečkou, vykřičníkem ani otazníkem. Například souhrnný text v následující dokumentaci nekončí platným interpunkčním znaménkem:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

Za tečkou, vykřičníkem nebo otazníkem mohou následovat uzavírací uvozovky (`"`, `'`, `”` nebo `’`) a poté uzavírací závorka; text končící na `."`, `!”` nebo `?)` proto tomuto pravidlu vyhovuje.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby všechny části dokumentace končily tečkou, vykřičníkem nebo otazníkem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1629:DocumentationTextMustEndWithAPeriod", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1629 // DocumentationTextMustEndWithAPeriod
#pragma warning restore SA1629 // DocumentationTextMustEndWithAPeriod
```
