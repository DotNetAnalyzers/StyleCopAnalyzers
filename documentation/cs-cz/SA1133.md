# SA1133: Do not combine attributes

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Ve stejné sadě hranatých závorek se nacházejí dva nebo více atributů.

## Popis pravidla

K porušení tohoto pravidla dochází, když jsou dva nebo více atributů umístěny ve stejné sadě hranatých závorek.

Následující kód například porušuje toto pravidlo:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider)), Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))]
[Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

### Výjimky

U atributů umístěných na parametrech nebo parametrech typu k porušení tohoto pravidla nedochází.

Následující kód například porušení nevyvolá:

```csharp
public class MyClass<[Foo, Bar] T>
{
	public T MyMethod([In, MarshalAs(UnmanagedType.LPWStr)] string value)
	{
	    ...
	}
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, umístěte každý atribut do vlastní sady hranatých závorek.

## Jak potlačit porušení

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider)),
#pragma warning disable SA1133 // Do not combine attributes
    Shared]
#pragma warning restore SA1133 // Do not combine attributes
public class MyCodeFixProvider : CodeFixProvider
{
}
```
