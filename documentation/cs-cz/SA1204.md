# SA1204: Static elements should appear before instance elements

## Příčina

Statický prvek je umístěn pod instančním prvkem stejného typu.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud je statický prvek umístěn pod instančním prvkem stejného typu. Všechny statické
prvky by měly být umístěny nad všemi instančními prvky stejného typu, aby bylo snazší rozpoznat rozhraní, které
zpřístupňuje instanční a statická verze třídy.

Toto pravidlo platí pro třídy, struktury a rozhraní. Statické členy rozhraní (zavedené v C# 8 společně s výchozími členy
rozhraní) musí být umístěny před instančními členy včetně členů, které poskytují výchozí implementace.

Například následující deklarace rozhraní toto pravidlo porušuje, protože se statický člen nachází za instančním členem s
výchozí implementací:

```csharp
public interface IExample
{
    void Instance() { }
    static void Helper() { } // SA1204
}
```

Vyhovující řazení umisťuje statické členy rozhraní před instanční členy:

```csharp
public interface IExample
{
    static void Helper() { }
    void Instance() { }
}
```

## Jak opravit porušení

Chcete-li tento případ porušení opravit, umístěte všechny statické prvky nad všechny instanční prvky stejného typu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1204:StaticElementsMustAppearBeforeInstanceElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1204 // StaticElementsMustAppearBeforeInstanceElements
#pragma warning restore SA1204 // StaticElementsMustAppearBeforeInstanceElements
```
