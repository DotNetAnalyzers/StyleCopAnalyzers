# SA1634: File header should show copyright

## Příčina

V hlavičce na začátku souboru se zdrojovým kódem C# chybí značka copyright.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud v hlavičce na začátku souboru C# chybí značka copyright. Například:

```csharp
//-----------------------------------------------------------------------
//<Tag>A fileheader which does not contain a copyright tag</Tag>
//-----------------------------------------------------------------------
```

Hlavička souboru by měla obsahovat značku copyright, například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte do hlavičky souboru standardní značku copyright.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1634:FileHeaderMustShowCopyright", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1634 // FileHeaderMustShowCopyright
#pragma warning restore SA1634 // FileHeaderMustShowCopyright
```
