# SA1145: Nepoužívejte přiřazení jako podmínku

## Příčina

Výraz přiřazení je použit jako podmínka nebo jako operand logického operátoru.
Toto pravidlo je ve výchozím nastavení povolené a hlásí upozornění na výrazu přiřazení.

## Popis pravidla

Použití `=` místo `==` v podmínce se v C# obvykle nepřeloží, ale přeloží se, pokud je přiřazená hodnota typu `bool`.
Toto pravidlo hlásí přiřazení (jednoduché, složené nebo `??=`), pokud je po přeskočení závorek jeho nadřazeným prvkem:

* operátor podmíněného AND (`&&`), podmíněného OR (`||`) nebo logické negace (`!`)
* podmínka podmíněného výrazu (`?:`)
* podmínka příkazu `if`, `while`, `do`...`while` nebo `for`
* filtr výjimky (klauzule `when`)

Následující kód porušuje pravidlo:

```csharp
bool flag = false;
if (flag = Compute())
{
}

while (!(done = Step()))
{
}
```

Přiřazení porovnávaná s další hodnotou se nehlásí:

```csharp
string line;
while ((line = reader.ReadLine()) != null)
{
}
```

## Jak opravit porušení

Nahraďte přiřazení porovnáním nebo přesuňte přiřazení do samostatného příkazu.

```csharp
bool flag = Compute();
if (flag)
{
}
```

## Jak potlačit porušení

```csharp
#pragma warning disable SA1145 // Do not use assignment as condition
// Code containing the violation.
#pragma warning restore SA1145 // Do not use assignment as condition
```
