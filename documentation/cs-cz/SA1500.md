# SA1500: Braces for multi-line statements should not share line

## Příčina

Otevírací nebo uzavírací složená závorka v příkazu, prvku nebo výrazu C# není umístěna na samostatném řádku.

> :memo: Chování tohoto pravidla se může změnit podle konfigurace vlastnosti `allowDoWhileOnClosingBrace` v souboru **stylecop.json**. Další informace najdete v souboru [Configuration.md](Configuration.md#layout-rules).

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když otevírací nebo uzavírací složená závorka v příkazu, prvku nebo výrazu není umístěna na samostatném řádku. Například:

```csharp
public object Method()
{
    lock (this) {
        return this.value;
    }
}
```

Když StyleCop tento kód kontroluje, dojde k porušení pravidla, protože otevírací složená závorka příkazu `lock` je umístěna na stejném řádku jako klíčové slovo `lock`, místo aby byla na vlastním řádku, jak ukazuje následující příklad:

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value;
    }
}
```

K porušení dojde také v případě, že uzavírací složená závorka sdílí řádek s jiným kódem. Například:

```csharp
public object Method()
{
    lock (this) 
    {
        return this.value; }
}
```

Od jazyka C# 8.0 se toto pravidlo vztahuje také na závorky zavedené výrazy `switch` a vzory vlastností. Pokud se
ramena nebo obsah vzoru rozkládají na více řádků, musí se `{` a `}` nacházet na samostatných řádcích.
Uzavírací závorka víceřádkového výrazu `switch` nesmí sdílet řádek s posledním ramenem, ale na stejném řádku
za ní může následovat kód pokračující ve výrazu, například operátor `??`.

Výrazy `switch` celé na jednom řádku jsou povoleny. Požadavky pravidel SA1012 a SA1013 na mezery nadále platí.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby otevírací i uzavírací složená závorka byly na vlastním řádku a nesdílely řádek s jiným kódem než s komentáři.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1500:BracesForMultiLineStatementsMustNotShareLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1500 // BracesForMultiLineStatementsMustNotShareLine
#pragma warning restore SA1500 // BracesForMultiLineStatementsMustNotShareLine
```
