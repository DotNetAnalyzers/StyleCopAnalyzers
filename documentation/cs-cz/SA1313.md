# SA1313: Parameter names should begin with lower-case letter

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Název parametru v jazyce C# nezačíná malým písmenem.

## Popis pravidla

K porušení tohoto pravidla dojde, když název parametru nezačíná malým písmenem.

### Zástupné znaky

Výjimka z tohoto pravidla platí pro parametry lambda s názvem `_` a `__`. Tyto parametry se často používají k označení
zástupného parametru, který se v těle výrazu lambda ve skutečnosti nepoužívá.

### Záznamy a primární konstruktory

Parametry pozičních záznamů se stanou veřejnými vlastnostmi, proto jsou pro tyto parametry přijatelné názvy PascalCase,
přestože se objevují v signatuře primárního konstruktoru.

### Kód pro interoperabilitu

Je-li název parametru určen k tomu, aby odpovídal názvu položky související s Win32 nebo COM, a musí proto začínat
velkým písmenem, umístěte parametr do zvláštní třídy `NativeMethods`. Třída `NativeMethods` je jakákoli třída, jejíž
název končí řetězcem `NativeMethods` a která slouží jako zástupný prostor pro obálky Win32 nebo COM. Pokud je položka
umístěna ve třídě `NativeMethods`, StyleCop toto porušení ignoruje.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, změňte název parametru tak, aby začínal malým písmenem, nebo položku podle
potřeby umístěte do třídy `NativeMethods`.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
void Method(int Parameter)
#pragma warning restore SA1313 // ParameterNamesMustBeginWithLowerCaseLetter
{
}
```
