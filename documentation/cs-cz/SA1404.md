## Příčina

Atribut Code Analysis `SuppressMessage` neobsahuje odůvodnění.

## Popis pravidla

K porušení tohoto pravidla dojde, když kód obsahuje atribut Code Analysis `SuppressMessage`, v němž ale není uvedeno odůvodnění potlačení. Při potlačení pravidla Code Analysis by mělo být vždy uvedeno odůvodnění. To může zvýšit dlouhodobou udržovatelnost kódu.

```csharp
[SuppressMessage("Microsoft.Performance", "CA1804:RemoveUnusedLocals", Justification = "Used during unit testing")]
public bool Enable()
{
}
```

## Jak opravit porušení

Chcete-li výskyt tohoto porušení opravit, přidejte do atributu `SuppressMessage` značku `Justification` a text odůvodnění popisující důvod potlačení.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1404:CodeAnalysisSuppressionMustHaveJustification", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1404 // CodeAnalysisSuppressionMustHaveJustification
#pragma warning restore SA1404 // CodeAnalysisSuppressionMustHaveJustification
```
