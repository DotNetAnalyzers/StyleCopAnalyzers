# SA1315: Názvy parametrů by měly odpovídat zděděným názvům

:memo: Toto pravidlo je nové pro StyleCop Analyzers a ve StyleCop Classic neexistovalo.

## Příčina

Název parametru v metodě, která přepisuje metodu základní třídy nebo implementuje člena rozhraní, neodpovídá názvu
zděděného parametru.

## Popis pravidla

Metoda, která přepisuje metodu základní třídy, by měla používat stejné názvy parametrů jako přepsaná metoda. Metoda,
která implementuje člena rozhraní, by měla používat názvy parametrů deklarované tímto členem rozhraní. Shodné názvy
parametrů zachovávají konzistenci pojmenovaných argumentů při volání metod podle jejich abstraktního kontraktu.

U přepsané metody určují očekávané názvy parametrů bezprostřední metoda základní třídy. U implementace rozhraní
analyzátor přijme název odpovídající kterémukoli implementovanému členu rozhraní se stejnou signaturou.

## Jak opravit porušení

Přejmenujte parametr tak, aby odpovídal názvu příslušného zděděného parametru. Pokud implementace odpovídá více než
jednomu zděděnému názvu, nabídne oprava kódu dostupné názvy.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1315 // ParametersShouldMatchInheritedNames
public override void Method(int differentName)
#pragma warning restore SA1315 // ParametersShouldMatchInheritedNames
{
}
```
