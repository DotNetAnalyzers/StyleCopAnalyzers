# SA1213: Event accessors should follow order

## Příčina

Přístupový objekt `add` je v události uveden za přístupovým objektem `remove`.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud je přístupový objekt `add` v události uveden za přístupovým objektem `remove`. Aby k porušení nedošlo, má být přístupový objekt `add` uveden před přístupovým objektem `remove`.

Například následující kód by vyvolal výskyt tohoto porušení:

```csharp
public event EventHandler NameChanged
{ 
    remove { this.nameChanged -= value; }
    add { this.nameChanged += value; }
}
```

Níže uvedený kód by toto porušení nevyvolal:

```csharp
public event EventHandler NameChanged
{ 
    add { this.nameChanged += value; }
    remove { this.nameChanged -= value; }
}
```

## Jak opravit porušení

Chcete-li toto porušení opravit, umístěte přístupový objekt `add` před přístupový objekt `remove`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1213:EventAccessorsMustFollowOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1213 // EventAccessorsMustFollowOrder
#pragma warning restore SA1213 // EventAccessorsMustFollowOrder
```
