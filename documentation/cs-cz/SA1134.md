## SA1134

<table>
<tr>
  <td>Název typu</td>
  <td>SA1134AttributesMustNotShareLine</td>
</tr>
<tr>
  <td>ID kontroly</td>
  <td>SA1134</td>
</tr>
<tr>
  <td>Kategorie</td>
  <td>Pravidla čitelnosti</td>
</tr>
</table>

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

An attribute is placed on the same line of code as another attribute or element.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když two more more attributes are placed on the same line of code, or an attribute is placed on the same line of code as another element.

For example, the following code would produce a violation of this rule:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

The following code would not produce any violations:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))]
[Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

### Výjimky

A violation of this rule will not occur for attributes placed on parameters, type parameters, or lambda expressions.

For example, the following code will not produce violations:

```csharp
public class MyClass<[Foo][Bar] T>
{
	public T MyMethod([In][MarshalAs(UnmanagedType.LPWStr)] string value)
	{
	    ...
	}
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, place each attribute on its own line.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1134 // Attributes should not share line
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
#pragma warning restore SA1134 // Attributes should not share line
public class MyCodeFixProvider : CodeFixProvider
{
}
```
