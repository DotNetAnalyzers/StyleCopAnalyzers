# SA1134: Attributes should not share line

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Atribut je umístěn na stejném řádku kódu jako jiný atribut nebo prvek.

## Popis pravidla

K porušení tohoto pravidla dochází, když jsou na stejném řádku kódu umístěny dva nebo více atributů nebo když je atribut na stejném řádku jako jiný prvek.

Následující kód například porušuje toto pravidlo:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))]
[Shared]
public class MyCodeFixProvider : CodeFixProvider
{
}
```

### Výjimky

U atributů umístěných na parametrech, parametrech typu nebo výrazech lambda k porušení tohoto pravidla nedochází.

Následující kód například porušení nevyvolá:

```csharp
public class MyClass<[Foo][Bar] T>
{
	public T MyMethod([In][MarshalAs(UnmanagedType.LPWStr)] string value)
	{
	    ...
	}
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, umístěte každý atribut na samostatný řádek.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1134 // Attributes should not share line
[ExportCodeFixProvider(LanguageNames.CSharp, Name = nameof(MyCodeFixProvider))][Shared]
#pragma warning restore SA1134 // Attributes should not share line
public class MyCodeFixProvider : CodeFixProvider
{
}
```
