# SA1649: File name should match first type name

## Příčina

Název souboru s kódem v jazyce C# neodpovídá prvnímu typu deklarovanému v souboru. Pro generické typy definované jako `Class1<T>` musí být název souboru `Class1{T}.cs` nebo ``Class1`1.cs`` podle nastavení `fileNamingConvention`. Další informace najdete v souboru [Configuration.md](Configuration.md).

Částečné třídy se ignorují.

## Popis pravidla

K porušení tohoto pravidla dochází, když název souboru C# neobsahuje název prvního typu v souboru. Zvažte například zdrojový soubor C# s názvem Class1.cs a následujícím kódem:

```csharp
public class Class2
{
}
```

K porušení tohoto pravidla by došlo, protože název souboru neobsahuje správný název prvního typu v souboru. Soubor by měl mít následující podobu:

```csharp
public class Class1
{
}
```

Modifikátor `readonly` na typu (například `readonly struct`) ani na členech uvnitř prvního typu (například na členech `readonly struct` v jazyce C# 8) nemění očekávaný název souboru. Analyzátor nadále používá identifikátor prvního nečástečného typu, takže typ deklarovaný jako `public readonly struct Point` stále patří do souboru `Point.cs`.

Při určování názvu souboru se vyhodnocují řídicí sekvence Unicode v identifikátoru. Například `class Name\u0065 { }` patří do souboru `Namee.cs`, nikoli do souboru, jehož název obsahuje řídicí sekvenci. Prefix `@` u doslovného identifikátoru rovněž není součástí očekávaného názvu souboru.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přejmenujte soubor tak, aby odpovídal názvu prvního typu v souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1649:FileNameMustMatchTypeName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1649 // SA1649FileNameMustMatchTypeName
#pragma warning restore SA1649 // SA1649FileNameMustMatchTypeName
```
