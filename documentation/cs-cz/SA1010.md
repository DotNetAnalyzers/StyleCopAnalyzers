# SA1010: Opening square brackets should be spaced correctly

## Příčina

Otevírací hranatá závorka v příkazu C# nemá správné mezery.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud otevírací hranaté závorce v příkazu předchází bílý znak nebo po ní bílý znak následuje.

Otevírací hranaté závorce nesmí nikdy předcházet bílý znak, pokud není prvním znakem na řádku, a za otevírací hranatou závorkou nesmí nikdy následovat bílý znak, pokud není posledním znakem na řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby na žádné straně otevírací hranaté závorky nebyl bílý znak.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1010:OpeningSquareBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1010 // OpeningSquareBracketsMustBeSpacedCorrectly
#pragma warning restore SA1010 // OpeningSquareBracketsMustBeSpacedCorrectly
```
