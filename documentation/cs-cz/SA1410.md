## Příčina

Volání anonymní metody jazyka C# neobsahuje žádné parametry metody, přesto příkaz obsahuje závorky.

## Popis pravidla

Pokud anonymní metoda neobsahuje žádné parametry, jsou závorky kolem parametrů nepovinné.

K porušení tohoto pravidla dojde, když volání anonymní metody bez parametrů obsahuje závorky. Například:

```csharp
this.Method(delegate() { return 2; });
this.Method(static delegate() { return 2; });
```

Závorky jsou nadbytečné a měly by být odebrány:

```csharp
this.Method(delegate { return 2; });
this.Method(static delegate { return 2; });
```

## Jak opravit porušení

Odeberte nadbytečné závorky za klíčovým slovem delegate.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1410:RemoveDelegateParenthesisWhenPossible", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1410 // RemoveDelegateParenthesisWhenPossible
#pragma warning restore SA1410 // RemoveDelegateParenthesisWhenPossible
```
