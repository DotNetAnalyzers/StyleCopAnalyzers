## Příčina

Zahrnutý soubor dokumentace XML neexistuje.

## Popis pravidla

Syntaxe jazyka C# umožňuje vkládat dokumentaci ke třídám a prvkům přímo do kódu pomocí hlaviček dokumentace XML. Úvod k těmto hlavičkám a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments.](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)

Jako alternativu k psaní dokumentace přímo do souboru s kódem lze dokumentaci pro více prvků umístit do samostatného souboru XML a poté na část tohoto souboru odkázat z hlavičky dokumentace prvku. Kompilátor pak dokumentaci daného prvku importuje ze zahrnutého dokumentu. Například:

```csharp
/// <include file="IncludedDocumentation.xml" path="root/EnabledMethodDocs" />
public bool Enabled(bool true)
{
}
```

K porušení tohoto pravidla dochází, když zahrnutý soubor v zadaném umístění neexistuje nebo jej nelze načíst.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, upravte cestu k zahrnutému souboru dokumentace tak, aby odkazovala na platné umístění souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1645:IncludedDocumentationFileDoesNotExist", Justification = "Reviewed.")]
```
