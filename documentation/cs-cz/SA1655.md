# SA1655: Značky prvků dokumentace musí být umístěny konzistentně

## Příčina

Úvodní značka prvku dokumentace XML je na samostatném řádku, ale koncová značka ne (nebo naopak).

## Popis pravidla

U každého prvku v komentáři dokumentace XML jsou buď obě značky (úvodní i koncová) na samostatných řádcích
(předchází jim pouze prefix komentáře `///` a nic za nimi nenásleduje), nebo ani jedna z nich.

Následující zápisy jsou povolené:

```csharp
/// <summary>Text souhrnu.</summary>
///
/// <summary>
/// Text souhrnu.
/// </summary>
///
/// <remarks>Text, který zabírá
/// více řádků.</remarks>
```

Značky prvku *mohou* být na různých řádcích, aniž by byly na samostatných řádcích:

```csharp
/// <para>Text odstavce
/// pokračuje.</para>
```

Následující kód pravidlo porušuje:

```csharp
/// <summary>
/// Text souhrnu.</summary>
///
/// <summary>Text souhrnu
/// </summary>
///
/// <para>
/// Text odstavce.</para>
```

Pravidlo se vztahuje na všechny prvky včetně `<para>` a na prvky vnořené do jiných prvků.

## Jak opravit porušení

Umístěte obě značky na samostatné řádky, nebo ponechte text na stejných řádcích jako obě značky:

```csharp
/// <summary>
/// Text souhrnu.
/// </summary>
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1655:DocumentationElementTagsMustBeConsistentlyPlaced", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1655 // Documentation element tags must be consistently placed
#pragma warning restore SA1655 // Documentation element tags must be consistently placed
```
