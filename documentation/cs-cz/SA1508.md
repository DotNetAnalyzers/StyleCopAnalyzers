# SA1508: Closing braces should not be preceded by blank line

## Příčina

Před uzavírací složenou závorkou v prvku, příkazu nebo výrazu C# se nachází prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu StyleCop v některých případech vyžaduje prázdné řádky a v jiných je zakazuje. Díky tomu má kód jednotný vizuální vzhled, který může usnadnit rozpoznávání a čtení neznámého kódu.

Pravidlo se poruší, když uzavírací složené závorce předchází prázdný řádek. Například:

```csharp
public bool Enabled
{
    get 
    { 
        return this.enabled; 

    }

}
```

Výše uvedený kód vede ke dvěma výskytům tohoto porušení, protože na dvou místech uzavírací složené závorce předchází prázdný řádek.

Počínaje C# 8.0 se pravidlo vztahuje také na uzavírací složené závorky ve výrazech switch a vzorech vlastností. Pokud
závorka patří k víceřádkovému seznamu větví výrazu switch nebo víceřádkovému vzoru vlastnosti, ani tehdy jí nesmí
předcházet prázdný řádek.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odstraňte prázdný řádek před uzavírací složenou závorkou.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1508:ClosingBracesMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1508 // ClosingBracesMustNotBePrecededByBlankLine
#pragma warning restore SA1508 // ClosingBracesMustNotBePrecededByBlankLine
```
