## Příčina

V záhlaví dokumentace XML prvku C# chybí značka `<summary>`.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Porušení tohoto pravidla nastává tehdy, když v dokumentaci prvku chybí značka `<summary>`.

Pro toto pravidlo se prvek se značkou `<exclude/>` na nejvyšší úrovni považuje za soukromý, i když je veřejně přístupný. Souhrn je stále vyžadován, pokud je zapnuto nastavení `documentPrivateElements` (u polí `documentPrivateFields`). Značka může být přímo v komentáři dokumentace nebo v zahrnuté dokumentaci. Nevypíná ostatní pravidla dokumentace.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte a vyplňte pro prvek značku `<summary>` obsahující jeho popis.

Následující příklad ukazuje třídu obsahující záhlaví dokumentace bez souhrnu.

```csharp
/// <remarks>A remark.</remarks>
public class Customer
{
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1604:ElementDocumentationMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1604 // ElementDocumentationMustHaveSummary
#pragma warning restore SA1604 // ElementDocumentationMustHaveSummary
```
