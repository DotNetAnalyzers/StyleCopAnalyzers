# SA1633: File should have header

## Příčina

V souboru se zdrojovým kódem C# chybí standardní hlavička souboru.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud v souboru zdrojového kódu C# chybí hlavička souboru.

Hlavička souboru musí začínat na jeho začátku a mohou jí předcházet pouze prázdné znaky.

Hlavička souboru by měla být formátována jako blok komentářů obsahující buď XML, nebo předem nakonfigurovaný text, například takto:

```csharp
//-----------------------------------------------------------------------
// <copyright file="NameOfFile.cs" company="CompanyName">
//     Company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

nebo

```csharp
// Copyright (c) Tunnel Vision Laboratories, LLC. All Rights Reserved.
// Licensed under the MIT License. See LICENSE in the project root for license information.
```

Typ použité hlavičky závisí na nastavení vlastnosti `xmlHeader`. Podrobnosti o jejím nastavení naleznete v části [konfigurace](Configuration.md).

### Příklady

Například soubor Widget.cs z fiktivní společnosti Sprocket Enterprises by měl obsahovat hlavičku podobnou této:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
//-----------------------------------------------------------------------
```

Přerušované čáry v horní a dolní části hlavičky nejsou nezbytně nutné, proto lze hlavičku zapsat také takto:

```csharp
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
```

Lze přidat další značky, ale StyleCop je nebude kontrolovat ani vynucovat:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
// <author>John Doe</author>
//-----------------------------------------------------------------------
```

Soubor zcela automaticky vygenerovaný nástrojem, který proto nemá být kontrolován ani vynucován nástrojem StyleCop, může namísto standardní hlavičky obsahovat hlavičku „auto-generated“. StyleCop pak tento soubor ignoruje. Tento druh hlavičky se nikdy nesmí umisťovat na začátek souboru s ručně psaným kódem.

```csharp
// <auto-generated />
namespace Sample.Something
{
    // The contents of this file are completely auto-generated by a tool.
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte na začátek souboru standardní hlavičku.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1633:FileMustHaveHeader", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1633 // FileMustHaveHeader
#pragma warning restore SA1633 // FileMustHaveHeader
```
