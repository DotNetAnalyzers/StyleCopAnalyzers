## Příčina

Část dokumentace v hlavičce XML prvku jazyka C# neobsahuje mezery mezi slovy.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí dokumentačních hlaviček XML. Úvod k těmto hlavičkám a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, pokud některá část dokumentace neobsahuje žádnou mezeru mezi slovy. To může naznačovat nekvalitně napsanou nebo formátovanou dokumentaci. Například:

```csharp
/// <summary>
/// Joinsnames
/// </summary>
/// <param name="firstName">First</param>
/// <param name="lastName">Last</param>
/// <returns>Name</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby všechny části dokumentace obsahovaly mezi slovy alespoň jednu mezeru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1630:DocumentationTextMustContainWhitespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1630 // DocumentationTextMustContainWhitespace
#pragma warning restore SA1630 // DocumentationTextMustContainWhitespace
```
