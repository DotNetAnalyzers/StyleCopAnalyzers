## Příčina

Mezery kolem dvojtečky v prvku C# nejsou správné.

## Popis pravidla

K porušení tohoto pravidla dojde, když nejsou správné mezery kolem dvojtečky.

Mezery kolem dvojtečky závisí na typu dvojtečky a jejím použití v kódu. Dvojtečka v deklaraci prvku má mít z obou stran jednu mezeru, pokud není prvním nebo posledním znakem na řádku. Tomuto pravidlu odpovídají všechny následující dvojtečky:

```csharp
public class Class2<T> : Class1 where T : MyType
{
    public Class2(int x) : base(x)
    {
    }
}
```


Když je dvojtečka na konci návěstí nebo příkazu `case`, má za ní vždy následovat prázdný znak nebo má být posledním znakem na řádku, ale nikdy jí nemá předcházet prázdný znak. Například:

```csharp
_label:
switch (x)
{
    case 2: 
        return x;
}
```


Před dvojtečkou, která je součástí komponenty formátování interpolace řetězce, nemají být prázdné znaky. Například:

```csharp
var s = $"{x:N}";
```


Pokud se dvojtečka objeví ve vzoru vlastnosti, včetně vnořených členů odkazovaných rozšířenou syntaxí vzoru vlastnosti, považuje se za oddělovač pojmenovaného prvku. Dvojtečce nemá předcházet prázdný znak a obvykle za ní má následovat jedna mezera.

```csharp
if (item is { Outer.Inner: value })
{
}
```


Nakonec, když se dvojtečka používá v podmíněném příkazu, má z obou stran vždy obsahovat jednu mezeru, pokud není prvním nebo posledním znakem na řádku. Například:

```csharp
int x = y ? 2 : 3;
```


## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem dvojtečky odpovídaly výše popsanému pravidlu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1024:ColonsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```


```csharp
#pragma warning disable SA1024 // ColonsMustBeSpacedCorrectly
#pragma warning restore SA1024 // ColonsMustBeSpacedCorrectly
```
