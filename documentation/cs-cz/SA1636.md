## Příčina

Hlavička na začátku souboru se zdrojovým kódem C# neobsahuje odpovídající text o autorských právech.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud hlavička na začátku souboru C# neobsahuje text o autorských právech, který byl pro projekt nastaven.

Aby bylo možné toto pravidlo povolit, musí být zadaná vlastnost `copyrightText`. Podrobnosti o jejím nastavení naleznete v části [konfigurace](Configuration.md).

Hodnota vlastnosti `xmlHeader` ovlivňuje chování tohoto pravidla. Když je `xmlHeader` **true** (výchozí nastavení), StyleCop Analyzers očekává, že hlavičky souborů budou odpovídat následujícímu standardnímu formátu StyleCop.

```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

Je-li vlastnost `xmlHeader` výslovně nastavena na **false**, StyleCop Analyzers očekává, že hlavičky souborů budou odpovídat následujícímu přizpůsobitelnému formátu.

```csharp
// {copyrightText}
```

Při tomto nastavení by každý soubor v projektu měl obsahovat požadovaný text o autorských právech ve formátu popsaném výše.

### Styly komentářů
Toto pravidlo přijímá několik stylů komentářů. Níže uvedené příklady poskytují přehled podporovaných stylů.

Příklady s vlastností `xmlHeader` nastavenou na **true**
```csharp
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
```

```csharp
// ----------------------------------------------------------------------
// <copyright file="{fileName}" company="{companyName}">
// {copyrightText}
// </copyright>
// ----------------------------------------------------------------------
```

```csharp
/* <copyright file="{fileName}" company="{companyName}">
 * {copyrightText}
 * </copyright>
 */
```

```csharp
/*
  <copyright file="{fileName}" company="{companyName}">
  {copyrightText}
  </copyright>
*/
```

Příklady s vlastností `xmlHeader` nastavenou na **false**

```csharp
// {copyrightText}
```

```csharp
/* {copyrightText} */
```

```csharp
/*
 * {copyrightText}
 */
```

```csharp
/*
  {copyrightText}
*/
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte standardní text o autorských právech své společnosti do značky copyright v hlavičce souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1636:FileHeaderCopyrightTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1636 // FileHeaderCopyrightTextMustMatch
#pragma warning restore SA1636 // FileHeaderCopyrightTextMustMatch
```
