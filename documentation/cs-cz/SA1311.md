# SA1311: Static readonly fields should begin with upper-case letter

## Příčina

Název statického pole `readonly` nezačíná velkým písmenem.

## Popis pravidla

K porušení tohoto pravidla dojde, když název statického pole `readonly` začíná malým písmenem.

C# 8 přidalo pro struktury členy označené `readonly`; toto pravidlo je však nadále zaměřeno pouze na statická `readonly` pole a ignoruje metody, vlastnosti, indexery a události s modifikátorem `readonly`. Přístupná statická `readonly` pole mohou rovněž aktivovat SA1307, zatímco SA1304 statická `readonly` pole nehlásí. Tím se zabrání tomu, aby se pro stejné pole vyvolala všechna tři pravidla pojmenování, a statická `readonly` pole přesto zůstávají pokryta.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, změňte název pole tak, aby začínal velkým písmenem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1311:StaticReadonlyFieldsMustBeginWithUpperCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1311 // StaticReadonlyFieldsMustBeginWithUpperCaseLetter
#pragma warning restore SA1311 // StaticReadonlyFieldsMustBeginWithUpperCaseLetter
```
