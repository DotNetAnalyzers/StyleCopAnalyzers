## Příčina

Přístupová metoda get se ve vlastnosti nebo indexeru nachází za přístupovou metodou set nebo init.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud je přístupová metoda get ve vlastnosti nebo indexeru umístěna za přístupovou
metodou set nebo init. Aby pravidlo bylo splněno, měla by být přístupová metoda get uvedena jako první.

Například následující kód by toto porušení vyvolal:

```csharp
public string Name
{ 
    set { this.name = value; }
    get { return this.name; }
}
```

Následující kód by toto porušení nevyvolal:

```csharp
public string Name
{ 
    get { return this.name; }
    set { this.name = value; }
}
```

### Přístupové metody readonly v C# 8

Členy readonly ve strukturách požadované řazení nemění. Getter `readonly` musí pro splnění tohoto pravidla stále
předcházet každé přístupové metodě `set` nebo `init`.

```csharp
public struct S
{
    public int Value
    {
        set => this.value = value;
        readonly get => this.value;
    }
}
```

Předchozí vlastnost porušuje SA1212, protože getter readonly následuje za setterem. Chcete-li upozornění odstranit,
přesuňte getter readonly před setter.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, umístěte přístupovou metodu get před přístupovou metodu set.
