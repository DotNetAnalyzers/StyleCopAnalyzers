# SA1019: Member access symbols should be spaced correctly

## Příčina

Mezery kolem symbolu přístupu k členu nejsou v souboru kódu C# správně umístěny.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud nejsou mezery kolem symbolu přístupu k členu správně umístěny. Symbol přístupu k členu nesmí mít bílý znak ani na jedné straně, ledaže je prvním znakem na řádku. Platí to i pro přístup k členu, který bezprostředně následuje po operátoru potlačení null (`!`) zavedeném spolu s referenčními typy s povolenou hodnotou null v C# 8, například `value!.Property` nebo `value!?.Method()`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby symbol přístupu k členu nebyl po žádné své straně obklopen bílým znakem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1019:MemberAccessSymbolsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1019 // MemberAccessSymbolsMustBeSpacedCorrectly
#pragma warning restore SA1019 // MemberAccessSymbolsMustBeSpacedCorrectly
```
