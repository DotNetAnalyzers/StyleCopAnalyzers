# SA1517: Code should not contain blank lines at start of file

## Příčina

Soubor kódu obsahuje na začátku prázdné řádky.

## Popis pravidla

Pro zlepšení rozložení kódu StyleCop vyžaduje, aby na začátku souborů nebyly žádné prázdné řádky.

Porušení tohoto pravidla nastává tehdy, když je na začátku souboru jeden nebo více prázdných řádků.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odeberte prázdné řádky ze začátku souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1517:CodeMustNotContainBlankLinesAtStartOfFile", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1517 // CodeMustNotContainBlankLinesAtStartOfFile
#pragma warning restore SA1517 // CodeMustNotContainBlankLinesAtStartOfFile
```
