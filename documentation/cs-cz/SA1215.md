# SA1215: Instance readonly elements should appear before instance non-readonly elements

:warning: Toto pravidlo bylo z analyzátorů StyleCop záměrně vynecháno. Další informace naleznete v souboru [KnownChanges.md](KnownChanges.md).

## Příčina

Prvek instance `readonly` je umístěn pod prvkem instance stejného typu, který není `readonly`.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud je prvek instance `readonly` umístěn pod prvkem instance stejného typu, který není `readonly`.

## Jak opravit porušení

Chcete-li toto porušení opravit, umístěte všechny prvky instance `readonly` nad všechny prvky instance stejného typu, které nejsou `readonly`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1215:InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1215 // InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements
#pragma warning restore SA1215 // InstanceReadonlyElementsMustAppearBeforeInstanceNonReadonlyElements
```
