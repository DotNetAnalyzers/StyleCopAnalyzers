# SA1653: Pouze jedna částečná deklarace má obsahovat souhrnnou dokumentaci

## Příčina

Více než jedna deklarace částečného typu obsahuje značku `<summary>` na nejvyšší úrovni.

## Popis pravidla

Dokumentace XML z deklarací částečného typu se slučuje do dokumentace jediného typu.
Uvedení dokumentace `<summary>` ve více deklaracích může vést k duplicitním nebo vzájemně si odporujícím souhrnům.

Oficiální dokumentaci typu, včetně značky `<summary>` a všech značek `<typeparam>`, ponechte v jedné deklaraci.
Ostatní části dokumentujte pro čtenáře zdrojového kódu pomocí značky `<content>` místo `<summary>`.
Tento postup je v souladu s pravidlem [SA1619](SA1619.md).

Pravidlo hlásí každou deklaraci obsahující konfliktní souhrn, místo aby vybralo deklaraci, která si jej má ponechat.
Vztahuje se na existující dokumentaci bez ohledu na to, zda je dokumentace pro danou úroveň přístupnosti typu vyžadována.
Ke konfliktům přispívají i souhrny v generovaných deklaracích, diagnostika se však hlásí pouze u deklarací, které nejsou generované.

Započítávají se pouze výslovně uvedené značky `<summary>` na nejvyšší úrovni.
Vnořené souhrny se nezapočítávají a dokumentace poskytovaná prostřednictvím `<include>` nebo `<inheritdoc>` se v tomto pravidle nerozbaluje.

## Jak opravit porušení

Použijte opravu kódu u deklarace, která si má ponechat značku `<summary>`. Oprava převede odlišné
souhrny v ostatních deklaracích na `<content>` a odstraní souhrny, jejichž text se mezi deklaracemi
opakuje. Zkontrolujte výsledek a ověřte, že ponechaný souhrn je oficiální dokumentací typu:

Oprava kódu se nenabídne, pokud by vyřešení konfliktu vyžadovalo změnu generované deklarace.

```csharp
/// <summary>
/// Represents a request processor.
/// </summary>
public partial class RequestProcessor
{
}

/// <content>
/// Contains request validation logic.
/// </content>
public partial class RequestProcessor
{
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1653:OnlyOnePartialDeclarationShouldContainSummaryDocumentation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1653 // Only one partial declaration should contain summary documentation
#pragma warning restore SA1653 // Only one partial declaration should contain summary documentation
```
