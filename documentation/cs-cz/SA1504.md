## Příčina

V rámci vlastnosti, indexeru nebo události jazyka C# je alespoň jedna z přístupových metod zapsána na jednom řádku a alespoň jedna na více řádcích.

## Popis pravidla

Pravidlo je porušeno, když implementované přístupové metody vlastnosti, indexeru nebo události nejsou důsledně zapisovány buď na jednom řádku, nebo na více řádcích. Kontrolují se přístupové metody s blokovým tělem i s tělem ve formě výrazu. Přístupové metody bez těla, například automatické přístupové metody vlastnosti, se nekontrolují. Účelem pravidla je zvýšit čitelnost kódu tím, že vyžaduje stejný formát všech implementovaných přístupových metod v rámci prvku.

Například následující vlastnost porušuje pravidlo, protože jedna přístupová metoda je zapsaná na jednom řádku, zatímco druhá je rozložena do více řádků.

```csharp
public bool Enabled
{
    get { return this.enabled; }

    set
    {
        this.enabled = value;
    }
}
```

Porušení lze předejít tím, že se obě přístupové metody zapíší na jeden řádek, nebo se obě rozloží do více řádků:

```csharp
public bool Enabled
{
    get { return this.enabled; }
    set { this.enabled = value; }
}


public bool Enabled
{
    get 
    { 
        return this.enabled; 
    }

    set 
    { 
        this.enabled = value;
    }
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zapište každou přístupovou metodu na jeden řádek, jsou-li přístupové metody krátké, nebo je všechny rozložte do více řádků, jsou-li delší.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1504:AllAccessorsMustBeSingleLineOrMultiLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
#pragma warning restore SA1504 // AllAccessorsMustBeSingleLineOrMultiLine
```
