# SA1616: Element return value documentation should have text

## Příčina

Značka `<returns>` v záhlaví dokumentace prvku C# je prázdná.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, pokud dokumentace prvku obsahuje prázdnou značku `<returns>`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, doplňte do značky `<returns>` text dokumentace popisující hodnotu vrácenou prvkem.

Následující příklad ukazuje metodu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1616:ElementReturnValueDocumentationMustHaveText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1616 // ElementReturnValueDocumentationMustHaveText
#pragma warning restore SA1616 // ElementReturnValueDocumentationMustHaveText
```
