# SA1021: Negative signs should be spaced correctly

## Příčina

Mezery kolem znaménka minus v prvku jazyka C# nejsou správně umístěny.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud nejsou mezery kolem znaménka minus správně umístěny.

Znaménku minus má vždy předcházet jediná mezera s výjimkou případů, kdy následuje po otevírací hranaté závorce, kulaté závorce nebo složené závorce interpolovaného řetězce, je prvním znakem na řádku nebo je součástí složky zarovnání interpolace řetězce.

Za znaménkem minus nikdy nesmí následovat bílý znak a znaménko nesmí být posledním znakem na řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem znaménka minus splňovaly výše uvedené pravidlo.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1021:NegativeSignsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1021 // NegativeSignsMustBeSpacedCorrectly
#pragma warning restore SA1021 // NegativeSignsMustBeSpacedCorrectly
```
