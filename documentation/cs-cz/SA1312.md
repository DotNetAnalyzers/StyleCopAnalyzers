# SA1312: Variable names should begin with lower-case letter

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Název proměnné v jazyce C# nezačíná malým písmenem.

## Popis pravidla

K porušení tohoto pravidla dojde, když název proměnné nezačíná malým písmenem.

Je-li název proměnné určen k tomu, aby odpovídal názvu položky související s Win32 nebo COM, a musí proto začínat
velkým písmenem, umístěte proměnnou do zvláštní třídy `NativeMethods`. Třída `NativeMethods` je jakákoli třída,
jejíž název končí řetězcem `NativeMethods` a která slouží jako zástupný prostor pro obálky Win32 nebo COM. Pokud je
položka umístěna ve třídě `NativeMethods`, StyleCop toto porušení ignoruje.

Názvy složené pouze z podtržítek (například `_` nebo `__`) jsou povoleny pro proměnné iterace `foreach` a deklarace
`using` z C# 8, protože na těchto místech nelze použít zástupný znak. Jinde by se místo proměnné nazvané `_` měl
použít zástupný znak. Pište například `_ = GetValue();` namísto `var _ = GetValue();`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, změňte název proměnné tak, aby začínal malým písmenem, nebo položku podle
potřeby umístěte do třídy `NativeMethods`.

Pokud proměnná s názvem složeným pouze z podtržítek není nikdy použita, může ji oprava kódu nahradit zástupným
znakem (C# 7 a novější). Například:

| Před | Poté |
| --- | --- |
| `var _ = GetValue();` | `_ = GetValue();` |
| `string __ = GetValue();` | `_ = GetValue();` |
| `int.TryParse(text, out var __);` | `int.TryParse(text, out _);` |
| `int.TryParse(text, out int __);` | `int.TryParse(text, out int _);` |
| `var (__, value) = GetPair();` | `var (_, value) = GetPair();` |
| `if (obj is int __)` | `if (obj is int _)` |

Tato oprava kódu se nenabízí, pokud se proměnná jinde čte nebo zapisuje, pokud deklarace deklaruje více než jednu
proměnnou nebo nemá inicializátor, pokud by její změna na zástupný znak změnila konverzi použitou na hodnotu
(například `long __ = 1;`, `string __ = null;` nebo uživatelem definovanou implicitní konverzi), nebo pokud je
v oboru jiný symbol s názvem `_` a zástupný znak by se navázal na tento symbol. Je-li v oboru jiný symbol `_`,
změní se `out var __` na `out var _` namísto `out _`.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1312 // VariableNamesMustBeginWithLowerCaseLetter
int Variable = 3;
#pragma warning restore SA1312 // VariableNamesMustBeginWithLowerCaseLetter
```
