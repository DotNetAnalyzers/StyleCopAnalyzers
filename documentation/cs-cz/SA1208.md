## Příčina

Direktiva using, která deklaruje člen oboru názvů *System*, se v souboru kódu C# nachází za direktivou using deklarující
člen jiného oboru názvů.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud je direktiva using pro obor názvů *System* umístěna za direktivou using jiného
než *System* oboru názvů. Umístění všech direktiv using pro *System* na začátek seznamu direktiv using může přispět k
čistšímu a čitelnějšímu kódu a usnadnit rozpoznání oborů názvů používaných v kódu.

Toto pravidlo platí pouze tehdy, když je `systemUsingDirectivesFirst` nastaveno na `true`, což je výchozí hodnota (viz
[Configuration.md](Configuration.md#using-directives)).

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, umístěte direktivu using pro *System* nad všechny direktivy using pro ostatní
obory názvů.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1208:SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
#pragma warning restore SA1208 // SystemUsingDirectivesMustBePlacedBeforeOtherUsingDirectives
```
