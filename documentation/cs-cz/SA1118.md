# SA1118: Parameter should not span multiple lines

## Příčina

Parametr metody nebo indexeru C# (s výjimkou prvního parametru) zasahuje do více řádků.

## Popis pravidla

Jednotlivé parametry a argumenty mají být na jednom řádku, aby volání metod nebyla příliš složitá a nečitelná. Pokud
parametry kromě prvního zasahují do více řádků, může být obtížné určit, kolik parametrů se metodě předává. Kód se
celkově hůře čte. Toto pravidlo hlásí porušení, když parametr nebo argument zasahuje do více řádků, s výjimkou
následujících případů:

* První parametr může zasahovat do více řádků.
* Anonymní metody (včetně výrazů lambda) mohou zasahovat do více řádků.
* Výrazy volání mohou zasahovat do více řádků.
* Výrazy vytvářející objekty a pole mohou zasahovat do více řádků.
* Výrazy tuple mohou zasahovat do více řádků.
* Výrazy `with` (C# 9) mohou zasahovat do více řádků.

Tyto výjimky se vztahují na argumenty atributů i na argumenty metod a indexerů.

Následující kód například porušuje toto pravidlo, protože druhý parametr zasahuje do více řádků:

```csharp
return JoinStrings(
    "John",
    "Smith" + 
    " Doe");
```

Chcete-li opravit výše uvedený příklad, zajistěte, aby parametry za prvním parametrem nezasahovaly do více řádků. Pokud
by tím některý parametr byl příliš dlouhý, uložte jeho hodnotu do dočasné proměnné. Například:

```csharp
string last = "Smith" + 
    " Doe";

return JoinStrings(
    "John",
    last);
```

V některých případech to umožní zapsat volání metody ještě stručněji, například takto:

```csharp
return JoinStrings("John", last);
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby parametry a argumenty nezasahovaly do více řádků, kromě výše uvedených konkrétních případů.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1118:ParameterMustNotSpanMultipleLines", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1118 // ParameterMustNotSpanMultipleLines
#pragma warning restore SA1118 // ParameterMustNotSpanMultipleLines
```
