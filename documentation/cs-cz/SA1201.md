# SA1201: Elements should appear in the correct order

## Příčina

Prvek v souboru kódu C# není ve správném pořadí vzhledem k ostatním prvkům kódu.

## Popis pravidla

K porušení tohoto pravidla dochází, když prvky kódu v souboru nedodržují standardní schéma uspořádání.

Chcete-li tomuto pravidlu vyhovět, prvky na kořenové úrovni souboru nebo v oboru názvů mají být v tomto pořadí:

* Direktivy aliasu extern
* Direktivy `using`
* Obory názvů
* Delegáti
* Výčty
* Rozhraní
* Struktury
* Třídy

V rámci třídy, struktury nebo rozhraní mají být prvky v tomto pořadí:

* Pole
* Konstruktory
* Finalizéry (destruktory)
* Delegáty
* Události
* Výčty
* Rozhraní
* Bloky rozšíření
* Vlastnosti
* Indexery
* Konverzní operátory
* Operátory
* Metody
* Struktury
* Třídy

> 📝 Pro účely uspořádání se záznamy C# 9 považují za třídy a struktury záznamů C# 10 za struktury.

> 📝 Bloky rozšíření C# 14 (`extension(...) { }`) se řadí jako vlastní typ prvku, za rozhraní a před vlastnosti.

Dodržování standardního schématu uspořádání podle typu prvku může zvýšit čitelnost a udržovatelnost souboru a podpořit opětovné použití kódu.

Při implementaci rozhraní je někdy vhodné seskupit všechny jeho členy vedle sebe. Pokud rozhraní obsahuje prvky různých typů, může to vyžadovat porušení tohoto pravidla. Problém lze vyřešit použitím částečných tříd.

1. Přidejte třídě atribut `partial`, pokud již částečná není.

2. Přidejte druhou částečnou třídu se stejným názvem. Lze ji umístit do stejného souboru pod původní třídu nebo do druhého souboru.

3. Přesuňte dědičnost rozhraní a všechny členy jeho implementace do druhé části třídy.

Například:

```csharp
/// <summary>
/// Represents a customer of the system.
/// </summary>
public partial class Customer
{
    // Contains the main functionality of the class.
}

/// <content>
/// Implements the ICollection class.
/// </content>
public partial class Customer : ICollection
{
    public int Count 
    { 
        get { return this.count; }
    }

    public bool IsSynchronized 
    { 
        get { return false; }
    }

    public object SyncRoot 
    { 
        get { return null; }
    }

    public void CopyTo(Array array, int index)
    {
        throw new NotImplementedException();
    }
}
```

## Jak opravit porušení

Chcete-li výskyt tohoto porušení opravit, seřaďte prvky v souboru podle výše popsaného pořadí.

Porušení pořadí se hlásí i přes direktivy preprocesoru. Oprava pořadí prvků nepřesouvá členy, pokud by přesun zahrnoval direktivy, protože by mohl změnit podmíněnou kompilaci nebo chování jiných direktiv. Tyto prvky seřaďte ručně při zachování hranic direktiv.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1201:ElementsMustAppearInTheCorrectOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1201 // ElementsMustAppearInTheCorrectOrder
#pragma warning restore SA1201 // ElementsMustAppearInTheCorrectOrder
```
