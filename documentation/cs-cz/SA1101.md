# SA1101: Prefix local calls with this

## Příčina

Volání člena instance místní třídy nebo základní třídy nemá v souboru s kódem C# předponu `this.`.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje volání člena instance místní třídy nebo základní třídy bez předpony `this.`. Výjimkou je případ, kdy existuje místní přepsání člena základní třídy a kód má v úmyslu volat přímo člena základní třídy, čímž místní přepsání obejde. V takovém případě lze místo `this.` použít předponu `base.`.

Ve výchozím nastavení StyleCop zakazuje označovat pole místní třídy podtržítkem nebo předponou *m_* a upřednostňuje předponu `this.`. Výhodou použití `this.` je, že se vztahuje stejně na všechny druhy prvků, včetně metod a vlastností, nejen na pole. Díky tomu lze všechna volání členů třídy snadno rozpoznat bez ohledu na použitý editor. Další výhodou je zřetelné odlišení členů instance od statických členů, které předponu nemají.

Poslední výhodou předpony `this.` je, že po napsání *this.* zobrazí Visual Studio okno IntelliSense, ve kterém může vývojář rychle a snadno vybrat volaný člen třídy.

Při použití vzorů vlastností, včetně rozšířené syntaxe vzorů vlastností zavedené v C# 10, pravidlo nevyžaduje ani nepovoluje kvalifikovat vlastnosti uvedené ve vzoru pomocí `this.`. Tyto výrazy odkazují na členy porovnávané hodnoty, nikoli na obsažený typ. Například pro následující kód se diagnostika SA1101 nehlásí:

```csharp
if (item is { Outer.Inner: value })
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, vložte před volání člena třídy předponu `this.`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1101:PrefixLocalCallsWithThis", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1101 // PrefixLocalCallsWithThis
#pragma warning restore SA1101 // PrefixLocalCallsWithThis
```
