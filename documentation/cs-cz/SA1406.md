# SA1406: Debug.Fail should provide message text

## Příčina

Volání `Debug.Fail` v kódu C# neobsahuje popisnou zprávu.

## Popis pravidla

K porušení tohoto pravidla dojde, když kód obsahuje volání `Debug.Fail`, které neposkytuje koncovému uživateli popis. Například následující volání obsahuje popisnou zprávu:

```csharp
Debug.Fail("The code should never reach this point.");
```

## Jak opravit porušení

Chcete-li výskyt tohoto porušení opravit, přidejte k volání `Debug.Fail` popisnou zprávu, která se koncovému uživateli zobrazí při vyvolání kontrolního tvrzení.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1406:DebugFailMustProvideMessageText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1406 // DebugFailMustProvideMessageText
#pragma warning restore SA1406 // DebugFailMustProvideMessageText
```
