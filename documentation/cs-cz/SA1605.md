# SA1605: Partial element documentation should have summary

## Příčina

Značka `<summary>` nebo `<content>` v hlavičce dokumentace prvku kódu C# chybí nebo je prázdná.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí hlaviček dokumentace XML.
Úvod k těmto hlavičkám a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, pokud v hlavičce dokumentace částečného prvku (prvku s modifikátorem `partial`) chybí značka `<summary>` nebo `<content>`, případně pokud obsahuje prázdnou značku `<summary>` nebo `<content>`, která nepopisuje daný prvek.
V jazyce C# mohou být modifikátorem `partial` označeny tyto typy prvků: třídy, metody, vlastnosti, indexery, konstruktory a události.

Je-li dokumentace uvedena ve více než jedné části částečné třídy, může se dokumentace obou částí sloučit do jediného zdroje dokumentace. Zvažte například následující dvě části částečné třídy:

```csharp
/// <summary>
/// Documentation for the first part of Class1.
/// </summary>
public partial class Class1
{
}

/// <summary>
/// Documentation for the second part of Class1.
/// </summary>
public partial class Class1
{
}
```

Tyto dvě odlišné části stejné částečné třídy poskytují pro třídu rozdílnou dokumentaci.
Při sestavování dokumentace této třídy do sady SDK nástroj pro sestavení dokumentace buď použije pouze jednu část dokumentace třídy a ostatní části ignoruje,
nebo v některých případech oba zdroje dokumentace sloučí do řetězce, jako je například: „Dokumentace první části Class1. Dokumentace druhé části Class1.“

Z těchto důvodů může být problematické poskytovat dokumentaci SDK ve více než jedné části částečné třídy.
Přesto je vhodné zdokumentovat každou část třídy, aby se zvýšila čitelnost a udržovatelnost kódu, a StyleCop bude vyžadovat, aby každá část třídy obsahovala hlavičku dokumentace.

Tento problém řeší značka `<content>`, která může u částečných tříd nahradit značku `<summary>`.
Doporučeným postupem dokumentování částečných tříd je uvést oficiální dokumentaci SDK pro třídu v hlavní části částečné třídy.
Tato dokumentace by měla používat standardní značku `<summary>`. Ve všech ostatních částech částečné třídy by se značka `<summary>` neměla uvádět vůbec a měla by být nahrazena značkou `<content>`.
Vývojář tak může zdokumentovat všechny části částečné třídy, a přitom soustředit veškerou oficiální dokumentaci SDK pro třídu do jedné její části.
Nástroje pro dokumentaci SDK budou značky `<content>` ignorovat.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte a vyplňte značku `<summary>` nebo `<content>` popisem prvku kódu.

Následující příklad ukazuje částečnou třídu s vyplněnou značkou `<summary>`.

```csharp
/// <summary>
/// Represents a customer in the database.
/// </summary>
public partial class Customer
{
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1605:PartialElementDocumentationMustHaveSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1605 // PartialElementDocumentationMustHaveSummary
#pragma warning restore SA1605 // PartialElementDocumentationMustHaveSummary
```
