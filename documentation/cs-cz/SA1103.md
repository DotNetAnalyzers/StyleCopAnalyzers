# SA1103: Query clauses should be on separate lines or all on one line

## Příčina

Klauzule výrazu dotazu C# nejsou všechny umístěny na stejném řádku a zároveň není každá klauzule na samostatném řádku.

## Popis pravidla

K porušení tohoto pravidla dochází, když klauzule dotazu nejsou buď všechny na stejném řádku, nebo každá na vlastním řádku. Například:
```c#
    object x = from num in numbers
        select num;
```

Klauzule dotazu lze správně zapsat takto:
```c#
    object x = from num in numbers select num;
```
or:
```c#
    object x =
        from num in numbers
        select num;
```
 
## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby všechny klauzule byly společně na jednom řádku, nebo aby každá klauzule začínala na samostatném řádku.

## Jak potlačit porušení

```c#
#pragma warning disable SA1103 // Query clauses should be on separate lines or all on one line
    object x = from num in numbers
        select num;
#pragma warning restore SA1103 // Query clauses should be on separate lines or all on one line
```
