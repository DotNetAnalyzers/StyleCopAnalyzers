## Příčina

V hlavičce na začátku souboru se zdrojovým kódem C# chybí název souboru.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud hlavička na začátku souboru C# neobsahuje platnou značku s názvem souboru. Například:

```csharp
//-----------------------------------------------------------------------
// <copyright company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

Hlavička souboru by měla obsahovat značku file s názvem souboru, například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte do hlavičky značku file obsahující název souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1637:FileHeaderMustContainFileName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1637 // FileHeaderMustContainFileName
#pragma warning restore SA1637 // FileHeaderMustContainFileName
```
