:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Název parametru typu C# nezačíná velkým písmenem T.

## Popis pravidla

K porušení tohoto pravidla dojde, když název parametru typu C# nezačíná velkým písmenem T. Názvy parametrů typu by měly vždy začínat písmenem T, například *T* nebo *TKey*.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte velké písmeno T na začátek názvu parametru typu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1314:TypeParameterNamesMustBeginWithT", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1314 // Type parameter names should begin with T
#pragma warning restore SA1314 // Type parameter names should begin with T
```
