# SA1016: Opening attribute brackets should be spaced correctly

## Příčina

Mezery kolem otevírací hranaté závorky atributu v prvku jazyka C# nejsou správně umístěny.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud nejsou mezery kolem otevírací hranaté závorky atributu správně umístěny.

Za otevírací hranatou závorkou atributu nikdy nemá následovat bílý znak, s výjimkou případu, kdy je tato závorka posledním znakem na řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby za otevírací hranatou závorkou atributu nebyl žádný bílý znak.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1016:OpeningAttributeBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1016 // OpeningAttributeBracketsMustBeSpacedCorrectly
#pragma warning restore SA1016 // OpeningAttributeBracketsMustBeSpacedCorrectly
```
