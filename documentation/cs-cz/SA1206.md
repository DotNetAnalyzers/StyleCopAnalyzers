# SA1206: Declaration keywords should follow order

## Příčina

Klíčová slova v deklaraci prvku nedodržují standardní schéma řazení.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud klíčová slova v deklaraci prvku nedodržují standardní schéma řazení.

V deklaraci prvku by se klíčová slova měla nacházet v následujícím pořadí:

*Modifikátory přístupu*

*static*

*Všechna ostatní klíčová slova*



Použití standardního schématu řazení klíčových slov v deklaracích prvků může zvýšit čitelnost kódu tím, že zvýrazní
úroveň přístupu jednotlivých prvků. Pomáhá také zabránit tomu, aby prvky dostaly vyšší úroveň přístupu, než potřebují.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, uspořádejte klíčová slova v deklaraci prvku podle výše popsaného pořadí.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1206:DeclarationKeywordsMustFollowOrder", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1206 // DeclarationKeywordsMustFollowOrder
#pragma warning restore SA1206 // DeclarationKeywordsMustFollowOrder
```
