# SA1305: Názvy by neměly používat maďarskou notaci

:bulb: Toto pravidlo je ve výchozím nastavení zakázané.

## Příčina

Název pole, proměnné nebo parametru v C# používá maďarskou notaci.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud se při pojmenování polí, proměnných nebo parametrů používá maďarská notace. Používání maďarské notace se rozšířilo v kódu C++, avšak v C# převládá používání delších a výstižnějších názvů, které nevycházejí z typu, ale popisují účel dané položky.

Moderní editory kódu, jako je Visual Studio, navíc usnadňují zjištění informací o typu proměnné, pole nebo parametru, obvykle najetím ukazatele myši na jeho název. Tím se potřeba maďarské notace snižuje.

StyleCop předpokládá, že každý název pole, proměnné nebo parametru začínající jedním nebo dvěma malými písmeny, po nichž následuje velké písmeno, používá maďarskou notaci, a v každém takovém případě nahlásí porušení tohoto pravidla. Parametry přepisujících metod a metod implementujících člena rozhraní se nekontrolují. Nekontrolují se ani názvy parametrů metod označených atributem `[DllImport]`, protože často odpovídají názvům parametrů nativního API. Určité předpony lze označit jako povolené, a pak budou ignorovány. Například proměnná s názvem *onExecute* se bude jevit nástroji StyleCop jako proměnná využívající maďarskou notaci, ačkoli tomu tak není. Předponu *on* proto označte jako povolenou.

Seznam povolených předpon nakonfigurujete v souboru **stylecop.json** například takto:

```json
{
  "settings": {
    "namingRules": {
      "allowedHungarianPrefixes": [ "aa", "bb" ],
    },
  }
}
```

Přidáním jedno- nebo dvoupísmenné předpony do tohoto seznamu způsobíte, že StyleCop bude ignorovat pole, proměnné a parametry začínající touto předponou.

Má-li název pole, proměnné nebo parametru odpovídat názvu položky související s Win32 nebo COM, a musí proto používat maďarskou notaci, umístěte položku do zvláštní třídy *NativeMethods*. Třída NativeMethods je každá třída s názvem končícím na NativeMethods a slouží jako zástupný symbol pro obálky Win32 nebo COM. Pokud je položka umístěna ve třídě NativeMethods, StyleCop toto porušení ignoruje.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odeberte z názvu pole, proměnné nebo parametru maďarskou notaci nebo případně umístěte položku do třídy NativeMethods.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1305:FieldNamesMustNotUseHungarianNotation", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1305 // FieldNamesMustNotUseHungarianNotation
#pragma warning restore SA1305 // FieldNamesMustNotUseHungarianNotation
```
