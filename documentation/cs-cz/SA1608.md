## Příčina

Značka `<summary>` v záhlaví dokumentace XML prvku obsahuje výchozí text, který při vytváření prvku vygenerovalo Visual Studio.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Visual Studio poskytuje pomocné funkce pro přidávání nových prvků, například tříd, do projektu. Visual Studio pro novou třídu vytvoří výchozí záhlaví dokumentace a vyplní je výchozím textem dokumentace.

Porušení tohoto pravidla nastává tehdy, když značka `<summary>` prvku kódu stále obsahuje výchozí text dokumentace vygenerovaný Visual Studiem.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, nahraďte výchozí text dokumentace novým textem popisujícím obsah prvku kódu.

Následující příklad ukazuje třídu obsahující výchozí text souhrnu vygenerovaný Visual Studiem.

```csharp
/// <summary>
/// Summary description for the Example class.
/// </summary>
public class Example
{
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1608:ElementDocumentationMustNotHaveDefaultSummary", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1608 // ElementDocumentationMustNotHaveDefaultSummary
#pragma warning restore SA1608 // ElementDocumentationMustNotHaveDefaultSummary
```
