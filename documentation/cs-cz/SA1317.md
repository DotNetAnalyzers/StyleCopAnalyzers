# SA1317: Názvy identifikátorů mají obsahovat pouze latinská písmena

## Příčina

Deklarovaný identifikátor obsahuje písmeno jiné než základní latinská písmena `A`–`Z` a `a`–`z`.

## Popis pravidla

Písmena z různých abeced mohou vypadat stejně, takže náhodnou záměnu lze snadno přehlédnout.
Pravidlo kontroluje části názvů oborů názvů, názvy typů a členů, parametry a parametry typů, místní proměnné, proměnné dotazů, návěští a explicitně zadané názvy prvků n-tic.
Kontrolují se deklarace, nikoli odkazy na identifikátory.

Omezení se týká pouze písmen: číslice, podtržítka a další nepísmenné znaky povolené jazykem C# zůstávají beze změny.
Latinská písmena s diakritikou, například `é`, nepatří mezi základní latinská písmena a jsou hlášena.
Před kontrolou názvu se odstraní předpona `@` a dekódují se řídicí sekvence Unicode.
Každé nepovolené písmeno vyvolá diagnostiku na identifikátoru; pozice ve zprávě je index od nuly v jednotkách UTF-16 v dekódovaném názvu bez předpony `@`.

Například název `ЕxаmplеClаss` obsahuje písmena cyrilice, a proto následující deklarace porušuje pravidlo:

```csharp
public class ЕxаmplеClаss {}
```

Následující deklarace pravidlo neporušuje:

```csharp
public class ExampleClass {}
```

## Oprava porušení

Nahraďte nepovolená písmena vhodnými základními latinskými písmeny.
Automatická oprava kódu není k dispozici, protože zamýšlenou náhradu nelze spolehlivě určit.

## Potlačení porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1317:IdentifierShouldBeNamedOnlyWithLatinLetters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1317 // Identifier should be named only with Latin letters
#pragma warning restore SA1317 // Identifier should be named only with Latin letters
```
