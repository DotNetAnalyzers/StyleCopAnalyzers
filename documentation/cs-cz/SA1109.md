# SA1109: Block statements should not contain embedded regions

:warning: Toto pravidlo bylo ve StyleCop Analyzers záměrně vynecháno. Další informace najdete v souboru [KnownChanges.md](KnownChanges.md).

## Příčina

Příkaz C# obsahuje značku oblasti mezi svou deklarací a otevírací složenou závorkou.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje značku oblasti mezi deklarací příkazu a otevírací složenou závorkou. Například:

```csharp
if (x != y)
#region
{
}
#endregion
```

Při sbalení oblasti se tím skryje tělo příkazu.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte oblast nebo ji přesuňte mimo příkaz.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1109:BlockStatementsMustNotContainEmbeddedRegions", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1109 // BlockStatementsMustNotContainEmbeddedRegions
#pragma warning restore SA1109 // BlockStatementsMustNotContainEmbeddedRegions
```
