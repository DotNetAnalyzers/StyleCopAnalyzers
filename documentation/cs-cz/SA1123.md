## Příčina

The C# code contains a region within the body of a code element.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, kdyžever a region is placed within the body of a code element. In many editors, including Visual Studio, the region will appear collapsed by default, hiding the code within the region. It is generally a bad practice to hide code within the body of an element, as this can lead to bad decisions as the code is maintained over time.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, remove the region from the code.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1123:DoNotPlaceRegionsWithinElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1123 // DoNotPlaceRegionsWithinElements
#pragma warning restore SA1123 // DoNotPlaceRegionsWithinElements
```
