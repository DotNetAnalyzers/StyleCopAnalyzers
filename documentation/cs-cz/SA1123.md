# SA1123: Do not place regions within elements

## Příčina

Kód C# obsahuje oblast uvnitř těla prvku kódu.

## Popis pravidla

K porušení tohoto pravidla dochází, když je oblast umístěna uvnitř těla prvku kódu. V mnoha editorech, včetně Visual Studia, bude oblast ve výchozím nastavení sbalená a její obsah skrytý. Skrývat kód uvnitř těla prvku je obecně nevhodné, protože to může při pozdější údržbě vést ke špatným rozhodnutím.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte oblast z kódu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1123:DoNotPlaceRegionsWithinElements", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1123 // DoNotPlaceRegionsWithinElements
#pragma warning restore SA1123 // DoNotPlaceRegionsWithinElements
```
