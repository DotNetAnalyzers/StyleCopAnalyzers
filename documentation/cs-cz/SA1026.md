# SA1026: Code should not contain space after new or stackalloc keyword in implicitly typed array allocation

## Příčina

Alokace implicitně typovaného pole v souboru s kódem jazyka C# není správně oddělena mezerami.

## Popis pravidla

K porušení tohoto pravidla dojde, když kód obsahuje alokaci implicitně typovaného pole s nesprávnými
mezerami. V alokaci implicitně typovaného pole nesmí být mezi klíčovým slovem `new` nebo `stackalloc`
a otevírací hranatou závorkou pole žádná mezera ani prázdný řádek. Například:

```csharp
var a = new[] { 1, 10, 100, 1000 };
Span<int> a = stackalloc[] { 1, 10, 100, 1000 };
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odeberte veškeré bílé místo mezi klíčovým slovem `new` nebo
`stackalloc` a otevírací hranatou závorkou pole.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1026 // Code should not contain space after new or stackalloc keyword in implicitly typed array allocation
var ints = new [] { 1, 2, 3 };
#pragma warning restore SA1026 // Code should not contain space after new or stackalloc keyword in implicitly typed array allocation
```
