# SA1110: Opening parenthesis or bracket should be on declaration line

## Příčina

Otevírací závorka nebo hranatá závorka při volání metody či indexeru C# nebo při jejich deklaraci není umístěna na stejném řádku jako název metody nebo indexeru.

## Popis pravidla

K porušení tohoto pravidla dochází, když otevírací závorka volání nebo deklarace metody či indexeru není na stejném řádku jako metoda nebo indexer. Následující příklady ukazují správné umístění otevírací závorky:

Toto pravidlo se vztahuje také na volání konstruktorů a výrazy vytvářející objekty, včetně výrazů `new` s cílovým typem zavedených v C# 9. Ve všech těchto případech má být `(` na stejném řádku jako klíčové slovo `new`.

```csharp
public string JoinName(string first, string last)
{
    return JoinStrings(
        first, last);
}

public int this[int x]
{
    get { return this.items[x]; }
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby otevírací závorka byla na stejném řádku jako název metody nebo indexeru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1110:OpeningParenthesisMustBeOnDeclarationLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1110 // OpeningParenthesisMustBeOnDeclarationLine
#pragma warning restore SA1110 // OpeningParenthesisMustBeOnDeclarationLine
```
