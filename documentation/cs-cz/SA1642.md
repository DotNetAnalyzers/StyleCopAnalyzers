## Příčina

Záhlaví dokumentace XML konstruktoru C# neobsahuje vhodný text souhrnu.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML.
Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Porušení tohoto pravidla nastává tehdy, když značka souhrnu v záhlaví dokumentace konstruktoru nezačíná vhodným
textem.

Účelem pravidla je standardizovat text souhrnu konstruktoru podle úrovně jeho přístupu. Souhrn konstruktoru instance má
začínat textem „Initializes a new instance of the {class name} class.“. Následující příklad ukazuje konstruktor třídy
`Customer`.

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </summary>
public Customer()
{
}
```

Při dokumentování struktury má souhrn obsahovat místo slova „class“ slovo „struct“. Následující příklad ukazuje konstruktor struktury `MyStruct`.

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="MyStruct"/> struct.
/// </summary>
public MyStruct()
{
}
```

U typů záznamů se konstruktory řídí stejným vzorem: třídy záznamů používají v textu souhrnu slovo „class“, zatímco struktury záznamů používají „struct“. Například:

```csharp
public record struct Customer
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Customer"/> struct.
    /// </summary>
    public Customer()
    {
    }
}
```

U sjednocených typů C# 15 má souhrn obsahovat slovo „union“. Následující příklad ukazuje konstruktor sjednoceného
typu `Result<T>`.

```csharp
public union Result<T>(T, string)
{
    /// <summary>
    /// Initializes a new instance of the <see cref="Result{T}"/> union.
    /// </summary>
    /// <param name="value">The value.</param>
    /// <param name="message">The message.</param>
    public Result(T value, string message)
    {
    }
}
```

Pokud třída obsahuje obecné parametry, lze je anotovat v odkazu `cref` pomocí některého z následujících dvou formátů:

```csharp
/// <summary>
/// Initializes a new instance of the <see cref="Customer`1"/> class.
/// </summary>
public Customer()
{
}

/// <summary>
/// Initializes a new instance of the <see cref="Customer{T}"/> class.
/// </summary>
public Customer()
{
}
```

Pokud je konstruktor statický, má text souhrnu začínat textem „Initializes static members of the {class name} class.“.
Například:

```csharp
/// <summary>
/// Initializes static members of the <see cref="Customer"/> class.
/// </summary>
public static Customer()
{
}
```

Kvůli kompatibilitě se StyleCop Classic smějí privátní konstruktory instancí používat text souhrnu „Prevents a default
instance of the {class name} class from being created.“. Pro nový kód se však doporučuje používat u všech konstruktorů
instancí výše uvedenou formulaci.

```csharp
/// <summary>
/// Prevents a default instance of the <see cref="Customer"/> class from being created.
/// </summary>
private Customer()
{
}
```

Značku `<para>` lze použít uvnitř značky `<summary>` k uspořádání textu. Například:

```csharp
/// <summary>
/// <para>
/// Initializes a new instance of the <see cref="Customer"/> class.
/// </para>
/// <para>
/// Additional information can be included in subsequent paragraphs.
/// </para>
/// </summary>
public Customer()
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, upravte text souhrnu konstruktoru podle výše uvedeného popisu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1642:ConstructorSummaryDocumentationMustBeginWithStandardText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
#pragma warning restore SA1642 // ConstructorSummaryDocumentationMustBeginWithStandardText
```
