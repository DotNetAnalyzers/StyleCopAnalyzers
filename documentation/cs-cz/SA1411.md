# SA1411: Attribute constructor should not use unnecessary parenthesis

## Příčina

Deklarace atributu neobsahuje žádné parametry, přesto obsahuje závorky.

## Popis pravidla

Pokud deklarace atributu neobsahuje žádné parametry, jsou závorky kolem parametrů nepovinné.

K porušení tohoto pravidla dojde, když jsou v konstruktoru atributu použity nadbytečné závorky. Například:

```csharp
[Serializable()]
```

Závorky jsou nadbytečné a měly by být odebrány:

```csharp
[Serializable]
```

## Jak opravit porušení

Odeberte nadbytečné závorky.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1411:AttributeConstructorMustNotUseUnnecessaryParenthesis", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1411 // AttributeConstructorMustNotUseUnnecessaryParenthesis
#pragma warning restore SA1411 // AttributeConstructorMustNotUseUnnecessaryParenthesis
```
