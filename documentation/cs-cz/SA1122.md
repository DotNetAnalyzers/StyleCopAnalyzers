# SA1122: Use string.Empty for empty strings

## Příčina

Kód C# obsahuje prázdný řetězec zapsaný jako `""`.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje prázdný řetězec. Například:

```csharp
string s = "";
```

Kompilátor tím vloží prázdný řetězec do zkompilovaného kódu. Namísto pevně zadaného prázdného řetězce použijte statickou vlastnost `string.Empty`:

```csharp
string s = string.Empty;
```

Hlásí se všechny podoby literálu prázdného řetězce, včetně doslovných, interpolovaných a surových řetězců:

```csharp
string s1 = @"";
string s2 = $"";
string s3 = @$"";
string s4 = """

    """;
string s5 = $"""

    """;
```

Interpolovaný řetězec se hlásí pouze tehdy, když vůbec neobsahuje žádný obsah; výrazy `$"{value}"` a `$"text"` se tedy nehlásí. Prázdný interpolovaný řetězec se nehlásí ani při převodu na `FormattableString`, `IFormattable` nebo typ obslužné rutiny interpolovaného řetězce, protože `string.Empty` nelze na tyto typy převést.

Literál řetězce UTF-8, například `""u8`, se nehlásí, protože jde o `ReadOnlySpan<byte>`, nikoli o řetězec.

K porušení nedochází v místech, kde jazyk vyžaduje konstantu, bez ohledu na její zápis, protože `string.Empty` je statické pole pouze pro čtení, nikoli konstanta, a nelze ji použít místo ní. To se týká argumentů atributů, popisků `case`, konstantních vzorů, výchozích hodnot parametrů a polí i místních proměnných `const`.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, nahraďte pevně zadaný prázdný řetězec výrazem `string.Empty`.

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1122:UseStringEmptyForEmptyStrings", Justification = "Reviewed.")]
```

```csharp
#pragma warning restore SA1122 // UseStringEmptyForEmptyStrings
```
