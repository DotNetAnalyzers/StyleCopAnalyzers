# SA1141: Use tuple syntax

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.
:memo: Toto pravidlo je aktivní pouze pro C# 7.0 a novější.

## Příčina

Místo upřednostňované jazykové konstrukce pro n-tice byla použita deklarace typu ValueTuple.

## Popis pravidla

Místo upřednostňované jazykové konstrukce pro n-tice byla použita deklarace typu ValueTuple. Informace o práci s n-ticemi v C# 7 najdete v dokumentaci k [typům n-tic](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Následující kód například porušuje toto pravidlo:

```csharp
ValueTuple<int, int> x; // SA1141
```

Následující kód žádné porušení nezpůsobí:

```csharp
(int, int) x;
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, použijte v kódu příslušný typ n-tice namísto typu ValueTuple.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1141:UseTupleSyntax", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1141 // Use tuple syntax
#pragma warning restore SA1141 // Use tuple syntax
```
