# SA1018: Nullable type symbols should be spaced correctly

## Příčina

Mezery kolem symbolu typu s povolenou hodnotou null v prvku jazyka C# nejsou správně umístěny.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud nejsou mezery kolem symbolu typu s povolenou hodnotou null správně umístěny.

Symbolu typu s povolenou hodnotou null nikdy nesmí předcházet bílý znak, s výjimkou případu, kdy je symbol prvním znakem na řádku.

Toto pravidlo platí pro hodnotové typy s povolenou hodnotou null i pro referenční typy s povolenou hodnotou null, které byly zavedeny v C# 8. V kontextu `#nullable enable` toto pravidlo vyvolá například kód `string ? value` nebo `System.Collections.Generic.List<string?> ? list`. Správný zápis nepoužívá mezeru před `?`, například `string? value` nebo `System.Collections.Generic.List<string?>? list`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby před symbolem typu s povolenou hodnotou null nebyl žádný bílý znak.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1018:NullableTypeSymbolsMustNotBePrecededBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
#pragma warning restore SA1018 // NullableTypeSymbolsMustNotBePrecededBySpace
```
