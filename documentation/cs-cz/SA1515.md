## Příčina

Jednořádkovému komentáři v kódu C# nepředchází prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

K porušení tohoto pravidla dochází, když jednořádkovému komentáři nepředchází prázdný řádek. Například:

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

Uvedený kód by vyvolal instanci tohoto porušení, protože jednořádkovému komentáři nepředchází prázdný řádek.

Výjimka z tohoto pravidla nastává, když je jednořádkový komentář první položkou ve svém oboru. V takovém případě
komentáři nemá předcházet prázdný řádek. Například:

```csharp
public bool Enabled
{
    get 
    {
        // Return the value of the 'enabled' field.
        return this.enabled;  
    }
}
```

V uvedeném kódu je komentář první položkou ve svém oboru, a proto mu nemá předcházet prázdný řádek.

Pokud se komentář používá k zakomentování řádku kódu, začněte jej místo dvou čtyřmi lomítky. StyleCop pak toto
porušení ignoruje. Například:

```csharp
public bool Enabled
{
    get 
    {
        Console.WriteLine("Getting the enabled flag.");
        ////return false;
        return this.enabled;  
    }
}
```

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, přidejte prázdný řádek před komentář.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1515:SingleLineCommentMustBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1515 // SingleLineCommentMustBePrecededByBlankLine
#pragma warning restore SA1515 // SingleLineCommentMustBePrecededByBlankLine
```
