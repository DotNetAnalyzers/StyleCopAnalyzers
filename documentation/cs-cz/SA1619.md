## Příčina

Obecnému částečnému prvku C# chybí dokumentace pro jeden nebo více jeho obecných parametrů typu a dokumentace prvku obsahuje značku `<summary>`.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud obecnému částečnému prvku chybí dokumentace pro jeden nebo více jeho obecných parametrů typu a dokumentace prvku obsahuje značku `<summary>` namísto značky `<content>`.

Pokud je dokumentace uvedena ve více než jedné části částečné třídy, dokumentace jednotlivých částí se může sloučit do jediného zdroje dokumentace. Zvažte například následující dvě části částečné třídy:

```csharp
/// <summary>
/// Documentation for the first part of Class1.
/// </summary>
public partial class Class1
{
}

/// <summary>
/// Documentation for the second part of Class1.
/// </summary>
public partial class Class1
{
}
```

Tyto dvě odlišné části téže částečné třídy poskytují pro třídu rozdílnou dokumentaci. Při vytváření dokumentace této třídy pro sadu SDK nástroj pro vytváření dokumentace buď použije jen jednu část dokumentace třídy a ostatní části ignoruje, nebo v některých případech sloučí oba zdroje dokumentace do řetězce, jako je: „Dokumentace první části Class1. Dokumentace druhé části Class1.“

Z těchto důvodů může být problematické uvádět dokumentaci sady SDK ve více než jedné části částečné třídy. Přesto je vhodné dokumentovat každou část třídy, aby se zvýšila čitelnost a udržovatelnost kódu, a StyleCop vyžaduje, aby každá část třídy obsahovala dokumentaci v záhlaví.

Tento problém řeší značka `<content>`, která může v částečných třídách nahradit značku `<summary>`. Doporučeným postupem pro dokumentování částečných tříd je uvést oficiální dokumentaci sady SDK pro třídu v hlavní části částečné třídy. Tato dokumentace má být zapsána pomocí standardní značky `<summary>`. Všechny ostatní části částečné třídy mají značku `<summary>` zcela vynechat a nahradit ji značkou `<content>`. Vývojář tak může dokumentovat všechny části částečné třídy a současně soustředit veškerou oficiální dokumentaci sady SDK pro třídu do jedné její části. Nástroje pro dokumentaci sady SDK budou značky `<content>` ignorovat.

Pokud obecný prvek obsahuje v záhlaví dokumentace značku `<summary>`, StyleCop předpokládá, že jde o hlavní část třídy, a vyžaduje, aby záhlaví obsahovalo značky `<typeparam>` pro každý obecný parametr typu třídy. Pokud však záhlaví dokumentace třídy obsahuje místo značky `<summary>` značku `<content>`, StyleCop předpokládá, že obecné parametry typu jsou definovány v jiné části třídy, a značky `<typeparam>` v této části třídy nevyžaduje.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte nebo doplňte text dokumentace do značky `<typeparam>` pro každý obecný parametr typu prvku, případně změňte značku `<summary>` na značku `<content>`, pokud nejde o hlavní část částečné třídy.

Následující příklad ukazuje třídu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1619:GenericTypeParametersMustBeDocumentedPartialClass", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1619 // GenericTypeParametersMustBeDocumentedPartialClass
#pragma warning restore SA1619 // GenericTypeParametersMustBeDocumentedPartialClass
```
