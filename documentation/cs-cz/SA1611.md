# SA1611: Element parameters should be documented

## Příčina

Metodě, konstruktoru, delegátu nebo indexeru C# chybí dokumentace jednoho nebo více parametrů.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Porušení tohoto pravidla nastává, pokud prvku s parametry chybí dokumentace jednoho nebo více jeho parametrů.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte nebo vyplňte text dokumentace ve značce `<param>` pro každý parametr prvku.

Následující příklad ukazuje metodu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1611:ElementParametersMustBeDocumented", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1611 // ElementParametersMustBeDocumented
#pragma warning restore SA1611 // ElementParametersMustBeDocumented
```
