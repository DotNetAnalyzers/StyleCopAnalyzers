# SA1131: Use readable conditions

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Bylo provedeno porovnání proměnné s literálem nebo konstantní hodnotou a proměnná se ve výrazu nacházela na pravé straně.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje porovnání literálu nebo konstantní hodnoty s hodnotou proměnné a proměnná se ve výrazu nachází na pravé straně.

Následující kód například ukazuje častý případ tohoto porušení:

```csharp
public void Method(string value)
{
    if (null == value) // SA1131
    {
        throw new ArgumentNullException(nameof(value));
    }
}
```

Pro účely tohoto pravidla je *literál nebo konstantní hodnota* kterákoli z následujících možností:

* Číselný literál, například `1`, `0.0f` nebo `5.0m`
* Řetězcový literál
* `null`
* `default(T)` (pro libovolný typ `T`)
* Libovolný výraz, jehož hodnotu lze určit jako konstantu při kompilaci
* Odkaz na pole `static readonly`, například `IntPtr.Zero`
* Vzor

*Hodnota proměnné* je libovolný výraz, který se nepovažuje za literál ani konstantní hodnotu.

*Porovnání* je binární výraz používající některý z následujících operátorů:

* `==`
* `!=`
* `<`
* `>`
* `<=`
* `>=`

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, obraťte pořadí operandů porovnání.

## Jak potlačit porušení

```csharp
public void Method(string value)
{
#pragma warning disable SA1131 // Use readable conditions
    if (null == value)
#pragma warning restore SA1131 // Use readable conditions
    {
        throw new ArgumentNullException(nameof(value));
    }
}
```
