# SA1402: File may only contain a single type

## Příčina

Zdrojový soubor C# obsahuje více než jeden jedinečný typ.

## Popis pravidla

K porušení tohoto pravidla dojde, když soubor C# obsahuje více než jeden typ. Aby se zvýšila dlouhodobá udržovatelnost zdrojového kódu, měl by být každý typ umístěn ve vlastním souboru a názvy souborů by měly odpovídat názvu typu v souboru.

Lze nakonfigurovat druhy typů, na které má toto pravidlo působit. Ve výchozím nastavení pravidlo umožňuje umístit delegáty, výčty, struktury a rozhraní společně s třídou.

Do stejného souboru lze také umístit více částí stejného částečného typu.

Typy s oborem platnosti souboru deklarované pomocí modifikátoru `file` jsou z tohoto pravidla vyňaty.

Soubory obsahující příkazy nejvyšší úrovně jsou z tohoto pravidla také vyňaty.

## Jak opravit porušení

Chcete-li výskyt tohoto porušení opravit, přesuňte každý typ do vlastního souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1402:FileMayOnlyContainASingleType", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1402 // FileMayOnlyContainASingleType
#pragma warning restore SA1402 // FileMayOnlyContainASingleType
```
