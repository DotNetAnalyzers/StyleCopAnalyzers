# SX1309S: Static field names should begin with underscore

## Alternativní pravidlo

Toto pravidlo je nestandardním rozšířením výchozího chování StyleCop a představuje alternativní styl používaný
některými projekty. Je známo, že alternativní pravidla jsou v přímém rozporu se standardními pravidly StyleCop.

## Příčina

Název statického pole nezačíná podtržítkem.

## Popis pravidla

K porušení tohoto pravidla dochází, když název statického pole nezačíná podtržítkem.

### Podrobné chování

Toto pravidlo kontroluje pouze názvy soukromých statických polí, která nejsou označena jako `const` ani `readonly`.
Statická pole `readonly` se považují za konstanty a ignorují se. Toto pravidlo neanalyzuje členy struktur `readonly`
v C# 8 (metody, vlastnosti a indexery).

## Jak opravit porušení

Chcete-li toto porušení opravit, přidejte na začátek názvu pole podtržítko (`_`).

## Jak potlačit porušení

```csharp
#pragma warning disable SX1309S // Static field names should begin with underscore
static int bar;
#pragma warning restore SX1309S // Static field names should begin with underscore
```
