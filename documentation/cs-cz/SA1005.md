## Příčina

Jednořádkový komentář v souboru kódu C# nezačíná jednou mezerou.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud jednořádkový komentář nezačíná jednou mezerou. Například:

```csharp
private void Method1()
{
    //A single-line comment.
    //   A single-line comment.
}
```

Komentáře mají začínat jednou mezerou za úvodními lomítky:

```csharp
private void Method1()
{
    // A single-line comment.
    // A single-line comment.
}
```

Výjimkou z tohoto pravidla je použití komentáře k zakomentování řádku kódu. V takovém případě lze mezeru vynechat,
pokud komentář začíná čtyřmi lomítky, která označují zakomentovaný kód. Například:

```csharp
private void Method1()
{
    ////int x = 2;
    ////return x;
}
```

Toto pravidlo také nehlásí komentáře začínající dvěma nebo více pomlčkami (`//--`), zpětným lomítkem (`//\`) ani
direktivou zpracování šablonovacího modulu .NET (`//-:cnd` nebo `//+:cnd`, například `//-:cnd:noEmit`).

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby komentář začínal jednou mezerou. Používá-li se komentář
k zakomentování řádku kódu, zajistěte, aby začínal čtyřmi lomítky; v takovém případě lze úvodní mezeru vynechat.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1005:SingleLineCommentsMustBeginWithSingleSpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1005 // SingleLineCommentsMustBeginWithSingleSpace
#pragma warning restore SA1005 // SingleLineCommentsMustBeginWithSingleSpace
```
