## Příčina

Modifikátor přístupu prvku C# nebyl explicitně definován.

## Popis pravidla

C# umožňuje definovat prvky bez modifikátoru přístupu. V takovém případě C# prvku automaticky přiřadí úroveň přístupu podle jeho typu.

Toto pravidlo vyžaduje explicitní definici modifikátoru přístupu pro každý prvek. Odstraňuje tím potřebu čtenáře odhadovat vlastnosti kódu a zlepšuje jeho čitelnost.

Členy deklarované v `interface` jsou implicitně `public` a explicitní modifikátor přístupu nepotřebují. Patří sem výchozí členy rozhraní zavedené v C# 8 (instanční členy s výchozími implementacemi, statické členy rozhraní a vnořené členy rozhraní, například delegáti). SA1400 pro tyto členy diagnostiku nehlásí.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte do deklarace prvku modifikátor přístupu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1400:AccessModifierMustBeDeclared", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1400 // AccessModifierMustBeDeclared
#pragma warning restore SA1400 // AccessModifierMustBeDeclared
```
