# SA1513: Closing brace should be followed by blank line

## Příčina

Za uzavírací složenou závorkou v prvku, příkazu nebo výrazu C# nenásleduje prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

K porušení tohoto pravidla dochází, když za uzavírací složenou závorkou nenásleduje prázdný řádek. Následující kód
by například vyvolal jednu instanci tohoto porušení, protože na jednom místě za uzavírací složenou závorkou
nenásleduje prázdný řádek.

```csharp
if (condition)
{
    DoSomething();
}
return value;
```

Složené závorky, které jsou součástí výrazu nebo vzoru (například výrazů switch nebo vzorů vlastností zavedených
v C# 8.0), nevyžadují prázdný řádek, pokud po závorce bezprostředně následuje token pokračování, například `=>`,
`,` nebo `;`. Totéž platí, pokud po závorce přímo následuje logický operátor (například `&&` nebo `||`) nebo označení
vzoru (např. `} patternVar`), které pokračuje ve stejném výrazu.

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, zajistěte, aby za uzavíracími složenými závorkami následoval prázdný řádek.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1513:ClosingBraceMustBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1513 // ClosingBraceMustBeFollowedByBlankLine
#pragma warning restore SA1513 // ClosingBraceMustBeFollowedByBlankLine
```
