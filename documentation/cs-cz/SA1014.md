# SA1014: Opening generic brackets should be spaced correctly

## Příčina

Otevírací závorka obecného typu v prvku C# nemá správné mezery.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud mezery kolem otevírací závorky obecného typu nejsou správné.

Otevírací závorce obecného typu nesmí předcházet ani po ní následovat bílý znak, pokud závorka není prvním nebo posledním znakem na řádku.

Stejná pravidla pro mezery platí i pro `<`, kterým začíná seznam parametrů ukazatele na funkci v jazyce C# 9, například `delegate*<int, void>`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby na žádné straně otevírací závorky obecného typu nebyl bílý znak.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1014:OpeningGenericBracketsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1014 // OpeningGenericBracketsMustBeSpacedCorrectly
#pragma warning restore SA1014 // OpeningGenericBracketsMustBeSpacedCorrectly
```
