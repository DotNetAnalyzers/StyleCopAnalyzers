# SA1632: Documentation text should meet minimum character length

:warning: Toto pravidlo bylo ze StyleCop Analyzers záměrně vynecháno. Další informace naleznete v souboru [KnownChanges.md](KnownChanges.md).

## Příčina

Od verze StyleCop 4.5 je toto pravidlo ve výchozím nastavení zakázané.

Část dokumentace v hlavičce XML prvku jazyka C# je příliš krátká.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí dokumentačních hlaviček XML. Úvod k těmto hlavičkám a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, pokud je část dokumentace příliš krátká. Často to značí, že dokumentace není dostatečně popisná. Například:

```csharp
/// <summary>
/// A name
/// </summary>
public class Name
{
    ...
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přepracujte text dokumentace do gramaticky správného a popisného jazyka. Ve většině případů se tím délka textu dokumentace zvětší nad minimální délku, při jejímž nedosažení se toto pravidlo aktivuje.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1632:DocumentationTextMustMeetMinimumCharacterLength", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1632 // DocumentationTextMustMeetMinimumCharacterLength
#pragma warning restore SA1632 // DocumentationTextMustMeetMinimumCharacterLength
```
