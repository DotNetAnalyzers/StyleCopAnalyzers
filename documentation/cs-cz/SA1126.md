# SA1126: Prefix calls correctly

:warning: Toto pravidlo bylo ve StyleCop Analyzers záměrně vynecháno. Další informace najdete v souboru [KnownChanges.md](KnownChanges.md).

## Příčina

Volání člena v souboru s kódem C# nemá předponu `this.`, `base.`, `object.` nebo `typename.`, která by určovala zamýšlené volání metody.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje volání člena bez správné předpony.

V některých případech nelze z analýzy zdrojového kódu určit, která předpona je potřebná. Může jít o `this`, `base`, `object`, název typu aktuální třídy nebo některé z jejích základních tříd.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, vložte před volání člena třídy správnou předponu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1126:PrefixCallsCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1126 // PrefixCallsCorrectly
#pragma warning restore SA1126 // PrefixCallsCorrectly
```
