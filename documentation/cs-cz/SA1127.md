# SA1127: Generic type constraints should be on their own line

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Obecné omezení v deklaraci typu nebo metody je v souboru s kódem C# na stejném řádku jako deklarace.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje jednu nebo více klauzulí `where` s omezeními obecných typů na stejném řádku jako samotná deklarace typu nebo metody.

Následující kód například porušuje toto pravidlo dvakrát:

```csharp
private void Method<T, R>() where T : class where R : class, new()
{
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
private void Method<T, R>()
    where T : class
    where R : class, new()
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přesuňte každou klauzuli `where` na samostatný řádek.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1127 // Generic type constraints should be on their own line
private void Method<T>() where T : class
#pragma warning restore SA1127 // Generic type constraints should be on their own line
{
    // method body...
}
```
