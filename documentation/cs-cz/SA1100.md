# SA1100: Do not prefix calls with base unless local implementation exists

## Příčina

Volání členu zděděné třídy začíná `base.`, ale místní třída neobsahuje přepsání ani implementaci tohoto členu.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud kód obsahuje volání členu základní třídy s předponou `base.` a neexistuje místní implementace tohoto členu. Příklad:

```csharp
string name = base.JoinName("John", "Doe");
```

Toto pravidlo zabraňuje možnému zdroji chyb. Zvažte základní třídu, která obsahuje následující virtuální metodu:

```csharp
public virtual string JoinName(string first, string last)
{
}
```

Jiná třída dědí z této základní třídy, ale neposkytuje místní přepsání této metody. Někde v této třídě je metoda základní třídy volána pomocí `base.JoinName(...)`. To funguje očekávaným způsobem. Později někdo do třídy přidá místní přepsání této metody:

```csharp
public override string JoinName(string first, string last)
{
    return "Bob";
}
```

V tomto okamžiku místní volání `base.JoinName(...)` s největší pravděpodobností vnáší do kódu chybu. Toto volání vždy zavolá metodu základní třídy a způsobí ignorování místního přepsání.

Z tohoto důvodu by volání členů základní třídy neměla začínat `base.`, pokud není implementováno místní přepsání a vývojář nechce výslovně volat člen základní třídy. Pokud místní přepsání členu základní třídy neexistuje, volání má mít předponu `this.` místo `base.`.

### Kovarientní návratové typy

Od C# 9 mohou přepsání vracet odvozenější typ než základní člen. Volání `base.` stále obchází nejvíce odvozené přepsání, i když mezilehlá třída poskytuje kovarientní implementaci. SA1100 nadále hlásí volání `base.` ze třídy, která nedefinuje vlastní přepsání, a doporučenou opravou zůstává volat člen pomocí `this.`.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, změňte předponu `base.` na `this.`.

Automatická oprava není nabízena pro přepsatelný člen v typu, ze kterého lze dědit. Změna `base.` na `this.` může zavolat přepsání v odvozené třídě, změnit chování nebo způsobit nekonečnou rekurzi. Diagnostika se nadále hlásí; před změnou volání nebo potlačením porušení ověřte, která implementace má být volána. Automatické opravy zůstávají dostupné pro nevirtuální členy, přepsání `sealed` a volání v typech `sealed`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1100:DoNotPrefixCallsWithBaseUnlessLocalImplementationExists", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1100 // DoNotPrefixCallsWithBaseUnlessLocalImplementationExists
#pragma warning restore SA1100 // DoNotPrefixCallsWithBaseUnlessLocalImplementationExists
```
