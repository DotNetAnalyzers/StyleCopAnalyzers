:memo: Toto pravidlo je ve StyleCop Analyzers nové a ve StyleCop Classic nebylo k dispozici.

## Příčina

Dokumentace prvku obsahuje jeden nebo více elementů `<placeholder>`.

## Popis pravidla

K porušení tohoto pravidla dochází, když dokumentace prvku obsahuje elementy `<placeholder>`:

```csharp
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
{
}
```

Zástupné elementy je nutné zkontrolovat a z dokumentace odstranit.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, ověřte správnost zástupné dokumentace a odeberte značky `<placeholder>`.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1651 // Do not use placeholder elements
/// <summary>
/// This method <placeholder>performs some operation</placeholder>.
/// </summary>
public void SomeOperation()
#pragma warning restore SA1651 // Do not use placeholder elements
{
}
```
