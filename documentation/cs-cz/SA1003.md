## Příčina

Mezery kolem symbolu operátoru v souboru kódu C# jsou nesprávné.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud jsou mezery kolem symbolu operátoru nesprávné.

Následující typy symbolů operátorů mají být z obou stran obklopeny jednou mezerou: dvojtečky, aritmetické operátory,
operátory přiřazení, podmíněné operátory, logické operátory, relační operátory, posunovací operátory a operátory
lambda. Například:

```csharp
int x = 4 + y;
```

Od C# 8.0 se operátor lambda `=>` objevuje také v ramenech výrazu switch. Platí stejná pravidla pro mezery:
na obou stranách každé šipky má být jedna mezera.

```csharp
var description = value switch { 0 => "zero", _ => "nonzero" };
```

Relační operátory uvnitř výrazů porovnávání vzorů se řídí stejnými pravidly, pokud se objeví za klíčovými slovy,
jako je `is`. Například v relačním vzoru musí být `>` v `value is > 5` obklopen mezerami: `value is > 5`. Pokud je
relační vzor uzavřen v závorkách, nemá bezprostředně za `(` ani před `)` být mezera, v souladu s pravidly pro
závorky popsanými v SA1008.

Naproti tomu před unárními operátory má být jedna mezera, ale nikdy za nimi nemá být mezera. Například:

```csharp
bool x = !value;
```

Výjimkou je případ, kdy symbolu předchází nebo po něm následuje závorka či hranatá závorka; mezi symbolem a závorkou
pak nemá být mezera. Například:

```csharp
if (!value)
{
}
```

Operátor C# 8 *indexování od konce* (`^`) dodržuje stejné požadavky na mezery jako unární operátory. Zapisuje se
bezprostředně u svého operandu bez mezery za sebou; pokud bezprostředně následuje za `[` nebo `(`, nevkládá se ani
za tyto tokeny žádná další mezera. Příklady:

```csharp
var last = values[^1];
Index start = ^5;
```

Operátor C# 8 *rozsahu* (`..`) se považuje za binární operátor, který nemá být z žádné strany obklopen mezerou.
V indexerech se toto pravidlo používá mezi operandy, přičemž za `[` ani před `]` stále není mezera. Například:

```csharp
Range middle = 1..4;
var slice = values[1..^2];
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby mezery kolem symbolu odpovídaly výše popsanému pravidlu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1003:SymbolsMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1003 // SymbolsMustBeSpacedCorrectly
#pragma warning restore SA1003 // SymbolsMustBeSpacedCorrectly
```
