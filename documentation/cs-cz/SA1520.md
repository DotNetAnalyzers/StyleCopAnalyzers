:memo: Toto pravidlo je nové ve StyleCop Analyzers a ve StyleCop Classic nebylo k dispozici.

## Příčina

Otevírací a uzavírací složené závorky řetězené konstrukce `if`/`else if`/`else` byly u některých klauzulí použity,
ale u jiných vynechány.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když byly otevírací a uzavírací složené závorky řetězeného příkazu použity
u některých klauzulí, ale u jiných vynechány. V C# mohou některé typy příkazů složené závorky obsahovat volitelně.
Příkaz `if` lze například zapsat s nekonzistentními složenými závorkami:

```csharp
if (true)
    return this.value;
else
{
    return that.value.
}
```

Přestože je to v C# platné, StyleCop vyžaduje složené závorky u všech klauzulí řetězené konstrukce `if`/`else if`/
`else`, pokud byly složené závorky použity u kterékoli klauzule, aby zvýšil čitelnost a udržovatelnost kódu.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, převeďte příkaz porušující pravidlo na blokový příkaz.

## Jak potlačit porušení

```csharp
if (true)
#pragma warning disable SA1520 // Use braces consistently
    return this.value;
#pragma warning restore SA1520 // Use braces consistently
else
{
    return that.value.
}
```
