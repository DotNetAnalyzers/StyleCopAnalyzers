# SA1113: Comma should be on the same line as previous parameter

## Příčina

Čárka mezi dvěma parametry při volání metody či indexeru C# nebo při jejich deklaraci není umístěna na stejném řádku jako předchozí parametr.

## Popis pravidla

K porušení tohoto pravidla dochází, když čárka mezi dvěma parametry metody nebo indexeru není na stejném řádku jako předchozí parametr. Následující příklady ukazují správné umístění čárky:

Stejné pravidlo platí pro volání konstruktorů a výrazy vytvářející objekty, včetně výrazu `new` s cílovým typem zavedeného v C# 9. Čárky oddělující argumenty ve výrazu `new(...)` musí být na stejném řádku jako předchozí argument.

```csharp
public string JoinName(string first, string last)
{
    string name = JoinStrings(
        first, 
        last);
}

public int this[int x, 
   int y]
{
    get { return this.items[x, y]; }
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby čárka byla na stejném řádku jako předchozí parametr.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1113:CommaMustBeOnSameLineAsPreviousParameter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1113 // CommaMustBeOnSameLineAsPreviousParameter
#pragma warning restore SA1113 // CommaMustBeOnSameLineAsPreviousParameter
```
