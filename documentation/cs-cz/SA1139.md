# SA1139: Use literal suffix notation instead of casting

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Místo číselného literálu se používá přetypování.

## Popis pravidla

Místo číselného literálu se používá přetypování. K vytvoření 32bitového nezáporného celého čísla použijte příponu `U`, pro 64bitové celé číslo `L`, pro 64bitové nezáporné celé číslo `UL`, pro 32bitové číslo s plovoucí desetinnou čárkou `F`, pro 64bitové číslo s plovoucí desetinnou čárkou `D` a pro desetinné číslo `M`. U přípon nezáleží na velikosti písmen.

Následující kód například porušuje toto pravidlo:

```csharp
var x = (long)1;
```

Následující kód žádné porušení nezpůsobí:

```csharp
var x = 1L;
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, použijte místo přetypování hodnoty v kódu příslušnou příponu literálu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1139:UseLiteralsSuffixNotationInsteadOfCasting", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1139 // Use literal suffix notation instead of casting
#pragma warning restore SA1139 // Use literal suffix notation instead of casting
```
