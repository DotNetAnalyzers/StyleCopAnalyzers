# SA1124: Do not use regions

## Příčina

Kód C# obsahuje oblast.

## Popis pravidla

K porušení tohoto pravidla dochází, když je oblast umístěna kdekoli v kódu. V mnoha editorech, včetně Visual Studia, bude oblast ve výchozím nastavení sbalená a její obsah skrytý. Skrývat kód je obecně nevhodné, protože to může při pozdější údržbě vést ke špatným rozhodnutím.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte oblast z kódu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1124:DoNotUseRegions", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1124 // DoNotUseRegions
#pragma warning restore SA1124 // DoNotUseRegions
```
