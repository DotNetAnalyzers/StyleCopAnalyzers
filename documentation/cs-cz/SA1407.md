# SA1407: Arithmetic expressions should declare precedence

## Příčina

Příkaz jazyka C# obsahuje složitý výraz s aritmetickými, bitovými nebo posuvnými operátory bez závorek, které by jednoznačně určovaly jejich prioritu.

## Popis pravidla

Jazyk C# používá hierarchii priorit aritmetických, bitových a posuvných operátorů. V jazyce C# lze v jediném příkazu zřetězit více operací bez uzavření kterékoliv z nich do závorek. Kompilátor pak podle předem stanovených pravidel automaticky určí pořadí a prioritu operací. Například:

```csharp
int x = 5 + y * b / 6 % z - 2;
```

Přestože je tento kód platný, není příliš čitelný ani udržovatelný. Aby mu vývojář plně porozuměl, musí znát základní pravidla priorit operátorů v jazyce C#.

Účelem tohoto pravidla je zvýšit čitelnost a udržovatelnost tohoto typu kódu a snížit riziko pozdějšího zavedení chyb tím, že vývojáře nutí vložit závorky a explicitně tak určit prioritu operátorů. Následující příklad ukazuje více aritmetických operací uzavřených v závorkách:

```csharp
int x = 5 + (y * ((b / 6) % z)) - 2;
```

Vložení závorek činí kód zřetelnějším a srozumitelnějším a čtenář díky němu nemusí předpokládat, jak se má kód vyhodnotit.
Pravidlo se vztahuje také na bitové operátory `&`, `|` a `^` a na posuvné operátory `<<`, `>>` a `>>>`.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, vložte do výrazu závorky, které určí priority operací.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainabilityRules", "SA1407:ArithmeticExpressionsMustDeclarePrecedence", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1407 // ArithmeticExpressionsMustDeclarePrecedence
#pragma warning restore SA1407 // ArithmeticExpressionsMustDeclarePrecedence
```
