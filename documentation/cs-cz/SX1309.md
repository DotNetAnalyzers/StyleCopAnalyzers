# SX1309: Field names should begin with underscore

## Alternativní pravidlo

Toto pravidlo je nestandardním rozšířením výchozího chování StyleCop a představuje alternativní styl používaný
některými projekty. Je známo, že alternativní pravidla jsou v přímém rozporu se standardními pravidly StyleCop.

## Příčina

Název pole nezačíná podtržítkem.

## Popis pravidla

K porušení tohoto pravidla dochází, když název pole nezačíná podtržítkem.

### Podrobné chování

Toto pravidlo kontroluje pouze názvy soukromých polí instancí. Ignoruje pole, která jsou `static` nebo `const` nebo
mají přístupnost `public`, `internal` či `protected`. V C# 8 a novějších toto pravidlo nebere v úvahu členy instancí
struktur označené `readonly` (například metody nebo přístupové členy `readonly`); předponu podtržítka potřebují pouze
soukromá pole, včetně soukromých polí `readonly`. Statická pole `readonly` toto pravidlo ignoruje (považuje je za
konstanty).

## Jak opravit porušení

Chcete-li toto porušení opravit, přidejte na začátek názvu pole podtržítko (`_`).

Označení zahozených hodnot zavedená porovnáváním se vzory (například `_` ve vzorech vlastností nebo pozičních vzorech v C# 8) se nepovažují za pole a toto pravidlo je ignoruje.

## Jak potlačit porušení

```csharp
#pragma warning disable SX1309 // Field names should begin with underscore
int bar;
#pragma warning restore SX1309 // Field names should begin with underscore
```
