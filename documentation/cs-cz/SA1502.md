## Příčina

Prvek jazyka C# obsahující otevírací a uzavírací složené závorky je zapsán celý na jednom řádku.

## Popis pravidla

Pravidlo je porušeno, pokud je prvek uzavřený mezi otevírací a uzavírací složené závorky zapsán na jediném řádku. Například:

```csharp
public object Method() { return null; }
```

Pokud StyleCop tento kód analyzuje, pravidlo bude porušeno, protože celá metoda je zapsána na jednom řádku. Metoda má být rozložena do více řádků tak, aby otevírací i uzavírací složená závorka byly každá na vlastním řádku:

```csharp
public object Method()
{
    return null; 
}
```

Výjimkou jsou přístupové metody ve vlastnostech, událostech nebo indexerech: pokud je přístupová metoda krátká, mohou být všechny zapsány na jednom řádku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přepište prvek tak, aby byl rozložen do více řádků.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1502:ElementMustNotBeOnSingleLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1502 // ElementMustNotBeOnSingleLine
#pragma warning restore SA1502 // ElementMustNotBeOnSingleLine
```
