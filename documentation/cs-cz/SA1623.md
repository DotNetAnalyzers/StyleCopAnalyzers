## Příčina

Text dokumentace ve značce `<summary>` vlastnosti C# neodpovídá přístupovým metodám vlastnosti.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

Porušení tohoto pravidla nastává, pokud souhrnná dokumentace vlastnosti neodpovídá přístupovým metodám vlastnosti.

Text souhrnu vlastnosti má začínat formulací popisující typy přístupových metod zpřístupněných vlastností. Pokud vlastnost obsahuje pouze přístupovou metodu `get`, má souhrn začínat slovem „Gets“. Pokud vlastnost obsahuje pouze přístupovou metodu `set`, má souhrn začínat slovem „Sets“. Pokud vlastnost zpřístupňuje metody `get` i `set`, má text souhrnu začínat slovy „Gets or sets“.

S přístupovými metodami `init` zavedenými v C# 9 se zachází pružněji než s metodami `set`. Vlastnost s metodami `get` a `init` smí použít buď „Gets“, nebo „Gets or initializes“.

Zvažte například následující vlastnost, která zpřístupňuje metody `get` i `set`. Text souhrnu začíná slovy „Gets or sets“.

```csharp
/// <summary>
/// Gets or sets the name of the customer. 
/// </summary>
public string Name
{
    get { return this.name; }
    set { this.name = value; }
}
```

Pokud vlastnost vrací logickou hodnotu, použije se další pravidlo. Text souhrnu logických vlastností má obsahovat slova „Gets a value indicating whether“, „Sets a value indicating whether“ nebo „Gets or sets a value indicating whether“. Zvažte například následující logickou vlastnost, která zpřístupňuje pouze metodu `get`:

```csharp
/// <summary>
/// Gets a value indicating whether the item is enabled.
/// </summary>
public bool Enabled
{
    get { return this.enabled; }
}
```

V některých situacích může mít přístupová metoda `set` vlastnosti omezenější přístup než metoda `get`. Například:

```csharp
/// <summary>
/// Gets the name of the customer. 
/// </summary>
public string Name
{
    get { return this.name; }
    private set { this.name = value; }
}
```

V tomto příkladu má přístupová metoda `set` přístup `private`, což znamená, že k ní mají přístup pouze místní členové třídy, která ji obsahuje. Metoda `get` však dědí přístup z nadřazené vlastnosti, a protože vlastnost má přístup `public`, může k ní přistupovat každý volající.

V tomto případě se text souhrnu dokumentace nemá odkazovat na přístupovou metodu `set`, protože není viditelná pro externí volající.

StyleCop používá řadu pravidel k určení, kdy má být přístupová metoda `set` uvedena v souhrnné dokumentaci vlastnosti. Tato pravidla obecně vyžadují uvedení metody `set`, kdykoli je viditelná pro stejnou sadu volajících jako metoda `get` nebo kdykoli je viditelná pro externí či odvozené třídy.

Konkrétní pravidla pro určení, zda přístupovou metodu `set` zahrnout do souhrnné dokumentace vlastnosti, jsou následující:

1. Přístupová metoda `set` má stejnou úroveň přístupu jako metoda `get`. Například:

    ```csharp
    /// <summary>
    /// Gets or sets the name of the customer. 
    /// </summary>
    protected string Name
    {
        get { return this.name; }
        set { this.name = value; }
    }
    ```

2. Vlastnost je interně přístupná pouze v rámci sestavení a přístupová metoda `set` má také přístup `internal`. Například:

    ```csharp
    internal class Class1
    {
        /// <summary>
        /// Gets or sets the name of the customer. 
        /// </summary>
        protected string Name
        {
            get { return this.name; }
            internal set { this.name = value; }
        }
    }

    internal class Class1
    {
        public class Class2
        {
            /// <summary>
            /// Gets or sets the name of the customer. 
            /// </summary>
            public string Name
            {
                get { return this.name; }
                internal set { this.name = value; }
            }
        }
    }
    ```

3. Vlastnost je `private` nebo je obsažena v privátní třídě a přístupová metoda `set` má jiný modifikátor přístupu než `private`. V následujícím příkladu nemá modifikátor přístupu deklarovaný pro metodu `set` žádný význam, protože je metoda `set` obsažena v privátní třídě, a proto ji nemohou vidět jiné třídy mimo `Class1`. Metoda `set` tak má stejnou úroveň přístupu jako metoda `get`.

    ```csharp
    public class Class1
    {
        private class Class2
        {
            public class Class3
            {
                /// <summary>
                /// Gets or sets the name of the customer. 
                /// </summary>
                public string Name
                {
                    get { return this.name; }
                    internal set { this.name = value; }
                }
            }
        }
    }
    ```

4. Kdykoli má přístupová metoda `set` přístup `protected` nebo `protected internal`, má být uvedena v dokumentaci. Přístupová metoda `set` s přístupem `protected` nebo `protected internal` je vždy viditelná pro třídu dědící z třídy obsahující vlastnost.

    ```csharp
    internal class Class1
    {
        public class Class2
        {
            /// <summary>
            /// Gets or sets the name of the customer. 
            /// </summary>
            internal string Name
            {
                get { return this.name; }
                protected set { this.name = value; }
            }
        }

        private class Class3 : Class2
        {
            public Class3(string name) { this.Name = name; }
        }
    }
    ```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, upravte text souhrnu vlastnosti tak, aby popis začínal správnou formulací podle typu vlastnosti a typů přístupových metod v této vlastnosti.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1623:PropertySummaryDocumentationMustMatchAccessors", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1623 // PropertySummaryDocumentationMustMatchAccessors
#pragma warning restore SA1623 // PropertySummaryDocumentationMustMatchAccessors
```
