# SA1622: Generic type parameter documentation should have text

## Příčina

Značka `<typeparam>` v záhlaví dokumentace XML obecného prvku C# je prázdná.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud prvek v záhlaví dokumentace XML obsahuje prázdnou značku `<typeparam>`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, vyplňte každou značku `<typeparam>` popisem obecného parametru typu.

Následující příklad ukazuje třídu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1622:GenericTypeParameterDocumentationMustHaveText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1622 // GenericTypeParameterDocumentationMustHaveText
#pragma warning restore SA1622 // GenericTypeParameterDocumentationMustHaveText
```
