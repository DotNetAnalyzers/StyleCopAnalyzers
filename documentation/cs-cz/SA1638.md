# SA1638: File header file name documentation should match file name

## Příčina

Značka file v hlavičce na začátku souboru se zdrojovým kódem C# neobsahuje název souboru.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud značka file v hlavičce na začátku souboru C# neobsahuje název souboru. Například zvažte soubor se zdrojovým kódem C# s názvem File1.cs a následující hlavičkou:

```csharp
//-----------------------------------------------------------------------
// <copyright file="File2.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

K porušení tohoto pravidla by došlo, protože značka file neobsahuje správný název souboru. Hlavička by měla být zapsána takto:

```csharp
//-----------------------------------------------------------------------
// <copyright file="File1.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte název souboru do značky file.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1638:FileHeaderFileNameDocumentationMustMatchFileName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1638 // FileHeaderFileNameDocumentationMustMatchFileName
#pragma warning restore SA1638 // FileHeaderFileNameDocumentationMustMatchFileName
```
