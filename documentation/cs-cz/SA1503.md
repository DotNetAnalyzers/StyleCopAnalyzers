# SA1503: Braces should not be omitted

## Příčina

U příkazu C# byly vynechány otevírací a uzavírací složené závorky.

## Popis pravidla

Pravidlo je porušeno, když jsou u příkazu vynechány otevírací a uzavírací složené závorky. V jazyce C# lze u některých typů příkazů závorky uvést volitelně. Patří mezi ně příkazy if, while a for. Například příkaz if lze zapsat bez závorek:

```csharp
if (true) 
    return this.value;
```

To je sice v C# platné, ale StyleCop vždy vyžaduje závorky, aby byl kód čitelnější a snáze udržovatelný.

Pokud závorky chybějí, lze vložením dalšího příkazu pod příkaz if snadno zanést chybu. Například:

```csharp
if (true) 
    this.value = 2;       
    return this.value;
```

Na první pohled tento kód vypadá, jako by příkaz přiřazení i příkaz return byly podřízené příkazu if. Ve skutečnosti tomu tak není. Podřízený příkazu if je pouze příkaz přiřazení a příkaz return se provede vždy, bez ohledu na výsledek příkazu if.

StyleCop proto vždy vyžaduje otevírací a uzavírací složené závorky, aby se těmto chybám předešlo:

```csharp
if (true) 
{
    this.value = 2;
    return this.value;
}
```

Deklarace using v C# 8 záměrně neobsahují blok ve složených závorkách. Příkazy jako `using var stream = new MemoryStream();` (nebo `await using` pro `IAsyncDisposable`) jsou platné a toto pravidlo je neoznačí, protože jejich uzavření do složených závorek by změnilo dobu života deklarovaného prostředku.

## Jak opravit porušení

The optional `layoutRules.allowBracelessIfStatements` setting defaults to `"off"`. With `"sameLine"`, a
standalone `if` may have a single-line jump statement without braces on the same line as its closing `)`.
With `"nextLine"`, the jump must be on the immediately following line. This does not apply to any branch
of an `if`/`else if`/`else` chain, or to other statement bodies. Existing braced statements are unaffected.
The entire `if` header must fit on one line for either option; `"sameLine"` requires the whole `if`
statement to fit on one line. Multiline conditions require braces.
See [Configuration.md](Configuration.md#braceless-if-statements) for supported jumps and examples.

Chcete-li porušení tohoto pravidla opravit, uzavřete tělo příkazu do složených závorek.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1503:BracesMustNotBeOmitted", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1503 // BracesMustNotBeOmitted
#pragma warning restore SA1503 // BracesMustNotBeOmitted
```
