# SA1514: Element documentation header should be preceded by blank line

## Příčina

Záhlaví dokumentace prvku nad prvkem C# nemá před sebou prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

K porušení tohoto pravidla dochází, když záhlaví dokumentace nad prvkem nemá před sebou prázdný řádek. Například:

```csharp
public bool Visible
{
    get { return this.visible; }
}
/// <summary>
/// Gets a value indicating whether the control is enabled.
/// </summary>
public bool Enabled
{
    get { return this.enabled; }
}
```

Uvedený kód by vyvolal instanci tohoto porušení, protože záhlaví dokumentace nemá před sebou prázdný řádek.

Výjimka z tohoto pravidla nastává, když je záhlaví dokumentace první položkou ve svém oboru. V takovém případě
záhlaví nemá předcházet prázdný řádek. Například:

```csharp
public class Class1
{
    /// <summary>
    /// Gets a value indicating whether the control is enabled.
    /// </summary>
    public bool Enabled
    {
        get { return this.enabled; }
    }
}
```

V uvedeném kódu je záhlaví první položkou ve svém oboru, a proto mu nemá předcházet prázdný řádek.

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, přidejte prázdný řádek před záhlaví dokumentace.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1514:ElementDocumentationHeaderMustBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1514 // ElementDocumentationHeaderMustBePrecededByBlankLine
#pragma warning restore SA1514 // ElementDocumentationHeaderMustBePrecededByBlankLine
```
