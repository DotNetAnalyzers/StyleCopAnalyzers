# SA1107: Code should not contain multiple statements on one line

## Příčina

The C# code contains more than one statement on a single line.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když the code contain more than one statement on the same line. Each statement should begin on a new line.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, move each statement to begin on its own line.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1107:CodeMustNotContainMultipleStatementsOnOneLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1107 // CodeMustNotContainMultipleStatementsOnOneLine
#pragma warning restore SA1107 // CodeMustNotContainMultipleStatementsOnOneLine
```
