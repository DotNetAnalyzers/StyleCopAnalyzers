# SA1607: Partial element documentation should have summary text

## Příčina

Značka `<summary>` nebo `<content>` v záhlaví dokumentace prvku kódu C# je prázdná.

## Popis pravidla

Syntaxe C# poskytuje mechanismus pro vkládání dokumentace tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod k těmto záhlavím a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dojde, když záhlaví dokumentace částečného prvku (prvku s modifikátorem `partial`) obsahuje prázdnou značku `<summary>` nebo `<content>`, která neobsahuje popis prvku.
V jazyce C# lze modifikátorem `partial` označit tyto typy prvků: třídy, metody, vlastnosti, indexery, konstruktory a události.

Je-li dokumentace uvedena ve více než jedné části částečné třídy, může být dokumentace obou částí sloučena do jednoho zdroje dokumentace. Zvažte například tyto dvě části částečné třídy:

```csharp
/// <summary>
/// Documentation for the first part of Class1.
/// </summary>
public partial class Class1
{
}

/// <summary>
/// Documentation for the second part of Class1.
/// </summary>
public partial class Class1
{
}
```

Tyto dvě odlišné části téže částečné třídy poskytují pro třídu rozdílnou dokumentaci. Při sestavování dokumentace pro tuto třídu do sady SDK nástroj sestavující dokumentaci buď použije pouze dokumentaci z jedné části a ostatní ignoruje, nebo oba zdroje dokumentace v některých případech sloučí do řetězce, například: „Dokumentace první části Class1. Dokumentace druhé části Class1.“

Z těchto důvodů může být problematické poskytovat dokumentaci SDK pro více než jednu část částečné třídy. Přesto je vhodné dokumentovat každou část třídy, aby se zvýšila čitelnost a udržovatelnost kódu, a StyleCop vyžaduje, aby každá část třídy obsahovala dokumentaci v záhlaví.

Tento problém řeší značka `<content>`, která může u částečných tříd nahradit značku `<summary>`. Doporučeným postupem pro dokumentování částečných tříd je uvést oficiální dokumentaci SDK pro třídu v hlavní části částečné třídy. Tato dokumentace by měla být zapsána pomocí standardní značky `<summary>`. Ve všech ostatních částech částečné třídy by měla být značka `<summary>` zcela vynechána a nahrazena značkou `<content>`. Vývojář tak může dokumentovat všechny části částečné třídy a současně soustředit veškerou oficiální dokumentaci SDK pro třídu do jedné její části. Značky `<content>` nástroje pro dokumentaci SDK ignorují.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, vyplňte obsah značky `<summary>` nebo `<content>` popisem prvku kódu.

Následující příklad ukazuje metodu obsahující prázdnou značku `<summary>`.

```csharp
/// <summary>  </summary>
/// <param name="customerId">The ID of the customer to find.</param>
/// <returns>The customer, or null if the customer could not be found.</returns>
public Customer FindCustomer(int customerId)
{
    // ... finds the customer ...
}
```

Chcete-li porušení opravit, přidejte platný text souhrnu. Například:

```csharp
/// <summary>Attempts to locate a record for the customer with the given ID.</summary>
/// <param name="customerId">The ID of the customer to find.</param>
/// <returns>The customer, or null if the customer could not be found.</returns>
public Customer FindCustomer(int customerId)
{
    // ... finds the customer ...
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1607:PartialElementDocumentationMustHaveSummaryText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1607 // PartialElementDocumentationMustHaveSummaryText
#pragma warning restore SA1607 // PartialElementDocumentationMustHaveSummaryText
```
