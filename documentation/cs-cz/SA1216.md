:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Direktiva `using static` je umístěna na nesprávném místě (před běžnou direktivou `using` nebo za direktivou `using` s aliasem).

## Popis pravidla

K porušení tohoto pravidla dojde, pokud je direktiva `using static` umístěna před běžnou direktivou `using` nebo za direktivou `using` s aliasem. Seskupení direktiv `using static` za běžnými direktivami `using` a před direktivami `using` s aliasem může zpřehlednit kód, usnadnit jeho čtení a usnadnit rozpoznání statických členů používaných v celém kódu.

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li toto porušení opravit, umístěte direktivu `using static` za běžné direktivy `using` a před direktivy `using` s aliasem.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1216 // Using static directives should be placed at the correct location
using static System.Math;
#pragma warning restore SA1216 // Using static directives should be placed at the correct location
```
