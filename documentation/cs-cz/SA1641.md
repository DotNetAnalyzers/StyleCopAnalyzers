# SA1641: File header company name text should match

## Příčina

Hlavička na začátku souboru se zdrojovým kódem C# neobsahuje správný text názvu společnosti.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud hlavička na začátku souboru C# neobsahuje text názvu společnosti, který byl nastaven pro projekt.

Aby bylo možné toto pravidlo povolit, musí být zadaná vlastnost `companyName`. Zároveň musí být vlastnost `xmlHeader` buď vynechána, nebo mít hodnotu **true**.
Podrobnosti o jejím nastavení naleznete v části [konfigurace](Configuration.md).

Při tomto nastavení by každý soubor v projektu měl ve značce copyright své hlavičky obsahovat požadovaný text názvu společnosti, jak ukazuje příklad níže:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="My Company">
//     Custom company copyright tag.
// </copyright>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte standardní text názvu své společnosti do značky copyright v hlavičce souboru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1641:FileHeaderCompanyNameTextMustMatch", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1641 // FileHeaderCompanyNameTextMustMatch
#pragma warning restore SA1641 // FileHeaderCompanyNameTextMustMatch
```
