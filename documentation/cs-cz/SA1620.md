# SA1620: Generic type parameter documentation should match type parameters

## Příčina

Značky `<typeparam>` v záhlaví dokumentace XML obecného prvku C# neodpovídají obecným parametrům typu prvku.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud značky `<typeparam>` v záhlaví dokumentace prvku neodpovídají obecným parametrům typu prvku nebo nejsou uvedeny ve stejném pořadí jako parametry typu prvku.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte a vyplňte jednu značku `<typeparam>` pro každý obecný parametr typu prvku a zajistěte, aby značky `<typeparam>` byly uvedeny ve stejném pořadí jako parametry typu prvku.

Následující příklad ukazuje třídu se správným záhlavím dokumentace:

```csharp
/// <summary>
/// A sample generic class.
/// </summary>
/// <typeparam name="S">The first generic type parameter.</typeparam>
/// <typeparam name="T">The second generic type parameter.</typeparam>
public class Class1<S, T>
{ 
}
```

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1620:GenericTypeParameterDocumentationMustMatchTypeParameters", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1620 // GenericTypeParameterDocumentationMustMatchTypeParameters
#pragma warning restore SA1620 // GenericTypeParameterDocumentationMustMatchTypeParameters
```
