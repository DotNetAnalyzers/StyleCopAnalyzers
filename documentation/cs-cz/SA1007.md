## Příčina

Za klíčovým slovem operator v metodě přetížení operátoru C# nenásleduje žádný bílý znak.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud za klíčovým slovem operator v metodě přetížení operátoru nenásleduje
žádný bílý znak. Za klíčovým slovem operator má vždy následovat jedna mezera. Například:

```csharp
public MyClass operator +(MyClass a, MyClass b)
{
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte za klíčové slovo operator jednu mezeru.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1007:OperatorKeywordMustBeFollowedBySpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1007 // OperatorKeywordMustBeFollowedBySpace
#pragma warning restore SA1007 // OperatorKeywordMustBeFollowedBySpace
```
