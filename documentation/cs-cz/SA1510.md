## Příčina

Řetězené příkazy C# jsou odděleny prázdným řádkem.

## Popis pravidla

Pro zlepšení čitelnosti kódu vyžaduje StyleCop v některých situacích prázdné řádky a v jiných je zakazuje. Tím
v celém kódu vzniká jednotný vizuální vzor, který může usnadnit rozpoznávání a čtení neznámého kódu.

Některé typy příkazů C# lze použít pouze tehdy, když navazují na jiný příkaz. Příkladem jsou příkazy catch a
finally, které musí vždy navazovat na příkaz try. Dalším příkladem je příkaz else, který musí vždy navazovat na
příkaz if nebo jiný příkaz else. Tyto typy řetězených příkazů by neměly být odděleny prázdným řádkem. Například:

```csharp
try
{
    this.SomeMethod();
}

catch (Exception ex)
{
    Console.WriteLine(ex.ToString());
}
```

## Jak opravit porušení

Chcete-li toto porušení pravidla opravit, odstraňte všechny prázdné řádky mezi řetězenými příkazy.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1510:ChainedStatementBlocksMustNotBePrecededByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
#pragma warning restore SA1510 // ChainedStatementBlocksMustNotBePrecededByBlankLine
```
