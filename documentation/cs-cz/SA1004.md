# SA1004: Documentation lines should begin with single space

## Příčina

Řádek v hlavičce dokumentace nad prvkem C# nezačíná jednou mezerou.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud řádek v hlavičce dokumentace nezačíná jednou mezerou. Například:

```csharp
///<summary>
///The summary text.
///</summary>
///   <param name="x">The document root.</param>
///    <param name="y">The Xml header token.</param>
private void Method1(int x, int y)
{
}
```

Řádky hlavičky mají začínat jednou mezerou za třemi úvodními lomítky:

```csharp
/// <summary>
/// The summary text.
/// </summary>
/// <param name="x">The document root.</param>
/// <param name="y">The Xml header token.</param>
private void Method1(int x, int y)
{
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby řádek hlavičky začínal jednou mezerou.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1004:DocumentationLinesMustBeginWithSingleSpace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1004 // DocumentationLinesMustBeginWithSingleSpace
#pragma warning restore SA1004 // DocumentationLinesMustBeginWithSingleSpace
```
