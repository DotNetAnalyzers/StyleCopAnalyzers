## Příčina

Za záhlavím dokumentace prvku nad prvkem C# následuje prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu StyleCop v některých případech vyžaduje prázdné řádky a v jiných je zakazuje. Díky tomu má kód jednotný vizuální vzhled, který může usnadnit rozpoznávání a čtení neznámého kódu.

Pravidlo se poruší, když po záhlaví dokumentace nad prvkem následuje prázdný řádek. Například:

```csharp
/// <summary>
/// Gets a value indicating whether the control is enabled.
/// </summary>

public bool Enabled
{
    get { return this.enabled; }
}
```

Výše uvedený kód vede k výskytu tohoto porušení, protože po záhlaví dokumentace následuje prázdný řádek.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odstraňte prázdný řádek následující po záhlaví dokumentace.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1506:ElementDocumentationHeadersMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1506 // ElementDocumentationHeadersMustNotBeFollowedByBlankLine
#pragma warning restore SA1506 // ElementDocumentationHeadersMustNotBeFollowedByBlankLine
```
