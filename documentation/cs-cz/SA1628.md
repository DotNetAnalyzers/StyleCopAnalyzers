# SA1628: Documentation text should begin with a capital letter

:warning: Toto pravidlo bylo ze StyleCop Analyzers záměrně vynecháno. Další informace najdete v souboru
[KnownChanges.md](KnownChanges.md).

## Příčina

Část záhlaví dokumentace XML prvku C# nezačíná velkým písmenem.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud část dokumentace nezačíná velkým písmenem. Například souhrnný text v následující dokumentaci začíná malým písmenem:

```csharp
/// <summary>
/// joins a first name and a last name together into a single string.
/// </summary>
/// <param name="firstName">The first name.</param>
/// <param name="lastName">The last name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zajistěte, aby všechny části dokumentace začínaly velkým písmenem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1628:DocumentationTextMustBeginWithACapitalLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1628 // DocumentationTextMustBeginWithACapitalLetter
#pragma warning restore SA1628 // DocumentationTextMustBeginWithACapitalLetter
```
