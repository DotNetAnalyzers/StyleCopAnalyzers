# SA1210: Using directives should be ordered alphabetically by namespace

## Příčina

Direktivy using v souboru kódu C# nejsou seřazeny abecedně podle oboru názvů.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud direktivy using nejsou seřazeny abecedně podle oboru názvů. Abecední řazení
direktiv using může přispět k čistšímu a čitelnějšímu kódu a usnadnit rozpoznání oborů názvů používaných v kódu. Obory
názvů System jsou ve výchozím nastavení výjimkou z tohoto pravidla a předcházejí všechny ostatní obory názvů. Další
podrobnosti najdete v SA1208. Tuto výjimku lze vypnout nastavením `systemUsingDirectivesFirst` na `false` (viz
[Configuration.md](Configuration.md#using-directives)); potom se obory názvů System řadí abecedně společně se všemi
ostatními obory názvů.

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, seřaďte direktivy using abecedně podle oboru názvů a položky oboru názvů System
umístěte jako první, pokud `systemUsingDirectivesFirst` není nastaveno na `false`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1210:UsingDirectivesMustBeOrderedAlphabeticallyByNamespace", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
#pragma warning restore SA1210 // UsingDirectivesMustBeOrderedAlphabeticallyByNamespace
```
