# SA1209: Using alias directives should be placed after other using directives

## Příčina

Direktiva using s aliasem je umístěna před běžnou direktivou using.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud je direktiva using s aliasem umístěna před běžnou direktivou using. Direktivy
using s aliasem mají zvláštní chování, které může změnit význam zbývajícího kódu v souboru nebo oboru názvů. Umístění
direktiv using s aliasem společně pod všechny ostatní direktivy using může přispět k čistšímu a čitelnějšímu kódu a
usnadnit rozpoznání typů používaných v celém kódu.

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, umístěte všechny direktivy using s aliasem pod všechny běžné direktivy using.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1209:UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1209 // UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives
#pragma warning restore SA1209 // UsingAliasDirectivesMustBePlacedAfterOtherUsingDirectives
```
