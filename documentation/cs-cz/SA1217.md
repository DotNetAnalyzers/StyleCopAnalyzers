# SA1217: Using static directives should be ordered alphabetically

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Direktivy `using static` v souboru kódu C# nejsou řazeny abecedně podle úplného názvu typu.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud direktivy `using static` nejsou řazeny abecedně podle úplného názvu typu. Abecední řazení direktiv `using static` činí kód přehlednějším a usnadňuje jeho čtení.

Ve výchozím nastavení direktivy `using static` pro typy v oboru názvů System předcházejí všem ostatním direktivám `using static`, stejně jako pravidlo SA1210 řadí obory názvů System na první místo. Například `using static System.Math;` má být uvedeno před `using static Absolutes.Constants;`. Chcete-li místo toho řadit všechny direktivy `using static` společně abecedně, nastavte `systemUsingDirectivesFirst` na `false` (viz [Configuration.md](Configuration.md#using-directives)).

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li toto porušení opravit, seřaďte direktivy `using static` abecedně podle úplného názvu typu.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1217 // Using static directives should be ordered alphabetically
using static System.Math;
#pragma warning restore SA1217 // Using static directives should be ordered alphabetically
```
