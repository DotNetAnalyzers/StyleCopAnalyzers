# SA1115: Parameter should follow comma

## Příčina

Parametr při volání nebo deklaraci metody či indexeru C# nezačíná na stejném řádku jako předchozí parametr ani na následujícím řádku.

## Popis pravidla

K porušení tohoto pravidla dochází, když je mezi parametrem a předchozím parametrem jeden nebo více prázdných řádků. Například:

```csharp
public string JoinName(
    string first, 

    string last)
{
}
```

Parametr má začínat na stejném řádku jako předchozí čárka nebo na následujícím řádku. Například:

```csharp
public string JoinName(string first, string last)
{
}

public string JoinName(
    string first, 
    string last)
{
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby parametr začínal na stejném řádku jako předchozí čárka nebo na následujícím řádku.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1115:ParameterMustFollowComma", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1115 // ParameterMustFollowComma
#pragma warning restore SA1115 // ParameterMustFollowComma
```
