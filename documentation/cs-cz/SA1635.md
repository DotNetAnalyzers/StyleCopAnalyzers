## Příčina

V hlavičce na začátku souboru se zdrojovým kódem C# chybí text o autorských právech.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud hlavička na začátku souboru C# neobsahuje text uvnitř značky copyright. Například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
// </copyright>
//-----------------------------------------------------------------------
```

Hlavička souboru by měla obsahovat text o autorských právech, například:

```csharp
//-----------------------------------------------------------------------
// <copyright file="Widget.cs" company="Sprocket Enterprises">
//     Copyright (c) Sprocket Enterprises. All rights reserved.
// </copyright>
//-----------------------------------------------------------------------
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte do značky copyright standardní text o autorských právech své společnosti.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1635:FileHeaderMustHaveCopyrightText", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1635 // FileHeaderMustHaveCopyrightText
#pragma warning restore SA1635 // FileHeaderMustHaveCopyrightText
```
