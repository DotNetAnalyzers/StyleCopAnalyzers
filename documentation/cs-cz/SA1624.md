# SA1624: Property summary documentation should omit accessor with restricted access

## Příčina

Text dokumentace ve značce `<summary>` vlastnosti C# zohledňuje všechny přístupové metody vlastnosti, ale jedna z nich má omezený přístup.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud má některá z přístupových metod vlastnosti omezený přístup (obvykle přístupová metoda `set`), ale souhrnný text dokumentace vlastnosti stále odkazuje na obě přístupové metody.

Souhrnný text vlastnosti má obvykle začínat formulací popisující přístupové metody, které vlastnost zpřístupňuje. Pokud vlastnost obsahuje pouze přístupovou metodu `get`, má souhrn začínat slovem „Gets“. Pokud vlastnost obsahuje pouze přístupovou metodu `set`, má souhrn začínat slovem „Sets“. Pokud vlastnost zpřístupňuje přístupovou metodu `get` i `set`, má souhrnný text začínat slovy „Gets or sets“.

Pokud má však přístupová metoda vlastnosti úroveň přístupu omezenější než samotná vlastnost, má být z dokumentace souhrnu vynechána. To platí i pro přístupové metody `init` s omezenou přístupností.

Někdy není zřejmé, zda je přístupová metoda `set` vlastnosti skutečně méně přístupná než přístupová metoda `get`. Zvažte například případ, kdy je veřejná vlastnost součástí interní třídy a přístupová metoda `set` má přístup `internal`. Obě přístupové metody `get` a `set` pak mají ve skutečnosti stejnou úroveň přístupu. Dokumentace souhrnu má v tomto případě uvádět obě přístupové metody, protože jejich úroveň přístupu je fakticky stejná.

V některých situacích může mít přístupová metoda `set` vlastnosti omezenější přístup než přístupová metoda `get`. Například:

```csharp
/// <summary>
/// Gets the name of the customer. 
/// </summary>
public string Name
{
    get { return this.name; }
    private set { this.name = value; }
}
```

V tomto příkladu má přístupová metoda `set` přístup `private`, takže k ní mohou přistupovat pouze členy třídy, ve které je obsažena. Přístupová metoda `get` naproti tomu dědí přístup z nadřazené vlastnosti, a protože vlastnost má přístup `public`, může k ní přistupovat kterýkoli volající.

V tomto případě by se souhrnný text dokumentace neměl o přístupové metodě `set` zmiňovat, protože není viditelná pro externí volající.

StyleCop používá sadu pravidel pro určení, kdy má být přístupová metoda `set` zmíněna v dokumentaci souhrnu vlastnosti. Obecně tato pravidla vyžadují zmínit přístupovou metodu `set`, pokud je viditelná pro stejnou skupinu volajících jako přístupová metoda `get` nebo pokud je viditelná pro externí či dědící třídy.

Konkrétní pravidla pro určení, zda do dokumentace souhrnu vlastnosti zahrnout přístupovou metodu `set`, jsou následující:

1. Přístupová metoda `set` má stejnou úroveň přístupu jako přístupová metoda `get`. Například:

    ```csharp
    /// <summary>
    /// Gets or sets the name of the customer. 
    /// </summary>
    protected string Name
    {
        get { return this.name; }
        set { this.name = value; }
    }
    ```

2. Vlastnost je přístupná pouze interně v rámci sestavení a přístupová metoda `set` má také přístup `internal`. Například:

    ```csharp
    internal class Class1
    {
        /// <summary>
        /// Gets or sets the name of the customer. 
        /// </summary>
        protected string Name
        {
            get { return this.name; }
            internal set { this.name = value; }
        }
    }

    internal class Class1
    {
        public class Class2
        {
            /// <summary>
            /// Gets or sets the name of the customer. 
            /// </summary>
            public string Name
            {
                get { return this.name; }
                internal set { this.name = value; }
            }
        }
    }
    ```

3. Vlastnost je `private` nebo je obsažena v soukromé třídě a přístupová metoda `set` má libovolný modifikátor přístupu kromě `private`. V následujícím příkladu nemá modifikátor přístupu deklarovaný pro přístupovou metodu `set` žádný význam, protože tato metoda je obsažena v soukromé třídě a jiné třídy mimo `Class1` ji proto nevidí. Přístupová metoda `set` tak má fakticky stejnou úroveň přístupu jako přístupová metoda `get`.

    ```csharp
    public class Class1
    {
        private class Class2
        {
            public class Class3
            {
                /// <summary>
                /// Gets or sets the name of the customer. 
                /// </summary>
                public string Name
                {
                    get { return this.name; }
                    internal set { this.name = value; }
                }
            }
        }
    }
    ```

4. Pokud má přístupová metoda `set` přístup `protected` nebo `protected internal`, má být v dokumentaci zmíněna. Přístupová metoda `set` s přístupem `protected` nebo `protected internal` je vždy viditelná pro třídu dědící z třídy obsahující vlastnost.

    ```csharp
    internal class Class1
    {
        public class Class2
        {
            /// <summary>
            /// Gets or sets the name of the customer. 
            /// </summary>
            internal string Name
            {
                get { return this.name; }
                protected set { this.name = value; }
            }
        }

        private class Class3 : Class2
        {
            public Class3(string name) { this.Name = name; }
        }
    }
    ```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, aktualizujte souhrnný text vlastnosti a odstraňte formulaci odkazující na přístupovou metodu s omezeným přístupem.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1624:PropertySummaryDocumentationMustOmitSetAccessorWithRestrictedAccess", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1624 // PropertySummaryDocumentationMustOmitSetAccessorWithRestrictedAccess
#pragma warning restore SA1624 // PropertySummaryDocumentationMustOmitSetAccessorWithRestrictedAccess
```
