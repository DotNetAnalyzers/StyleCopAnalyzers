:memo: Toto pravidlo je ve StyleCop Analyzers nové a ve StyleCop Classic nebylo k dispozici.

## Příčina

Řádek kódu končí mezerou, tabulátorem nebo jiným znakem bílého místa před znakem (nebo znaky) konce
řádku.

## Popis pravidla

K porušení tohoto pravidla dojde, když řádek kódu končí libovolnou formou bílého místa jinou než znaky
konce řádku. Nadbytečné bílé místo může být viditelné v editorech se zobrazením bílých znaků nebo
způsobovat zbytečné změny kódu při formátování dokumentu vývojáři, při kterém se koncové bílé místo později
odstraní. Některé nástroje pro porovnávání rozdílů dokonce koncové bílé místo zvýrazňují, aby vývojáře vedly
k jeho odstranění.

### Podrobné chování

Jazyk C# obsahuje několik konstrukcí, které zahrnují více řádků kódu. Následující tabulka popisuje chování
tohoto pravidla pro každou z těchto konstrukcí.

| Konstrukce | Analýza povolena |
| --- | --- |
| „Běžný“ kód | ✔ |
| Řádkové komentáře (začínající `// ...`) | ✔ |
| Uvnitř blokových komentářů (`/* ... */`) | ✔ |
| Jednořádkové dokumentační komentáře (`/// ...`) | ✔ |
| Víceřádkové dokumentační komentáře (`/** ... */`) | ✔ |
| Direktivy preprocesoru (`#if`, `#pragma`, `#region` atd.) | ✔ |
| Doslovné řetězcové literály (`@""`) | |
| Vypnutý kód (text nacházející se uvnitř neaktivního bloku `#if`, `#elif` nebo `#else`) | |

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte všechny nadbytečné znaky bílého místa na konci řádku.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1028 // Code should not contain trailing whitespace
SomeMethodWithSpaceAfterTheSemicolon();    
#pragma warning restore SA1028 // Code should not contain trailing whitespace
```
