# SA1142: Refer to tuple fields by name

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.
:memo: Toto pravidlo je aktivní pouze pro C# 7.0 a novější.

## Příčina

Na prvek n-tice se odkazuje jeho názvem metadat, přestože je k dispozici název prvku.

## Popis pravidla

Na prvek n-tice se odkazuje jeho názvem metadat, přestože je k dispozici název prvku. Informace o práci s n-ticemi v C# 7 najdete v dokumentaci k [typům n-tic](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Následující kód například porušuje toto pravidlo:

```csharp
(int valueA, int valueB) x;

var y = x.Item1; // SA1142
```

Následující kód žádné porušení nezpůsobí:

```csharp
(int valueA, int valueB) x;

var y = x.valueA;
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, použijte v kódu příslušný název prvku n-tice namísto názvu metadat.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1142:ReferToTupleElementsByName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1142 // Refer to tuple elements by name
#pragma warning restore SA1142 // Refer to tuple elements by name
```
