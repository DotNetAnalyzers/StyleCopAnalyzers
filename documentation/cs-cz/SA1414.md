:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.
:memo: Toto pravidlo je aktivní pouze pro C# 7.0 a novější.

## Příčina

V deklaraci člena je použit typ řazené kolekce bez názvů prvků.

## Popis pravidla

Typy řazených kolekcí použité v deklaracích členů mají mít explicitně pojmenované prvky. Informace o práci s řazenými kolekcemi v C# 7 najdete v dokumentaci [typů řazených kolekcí](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Například následující kód by porušil toto pravidlo:

```csharp
public class ExampleClass
{
  public (int, int) ExampleMethod() // SA1414
  {
  }
}
```

Následující kód by nevedl k žádnému porušení:

```csharp
public class ExampleClass
{
  public (int valueA, int valueB) ExampleMethod()
  {
  }
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, zadejte název každého prvku řazené kolekce.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.MaintainAbilityRules", "SA1414:TupleTypesInSignaturesShouldHaveElementNames", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1414 // Tuple types appearing in member declarations should have explicitly named tuple elements
#pragma warning restore SA1414 // Tuple types appearing in member declarations should have explicitly named tuple elements
```
