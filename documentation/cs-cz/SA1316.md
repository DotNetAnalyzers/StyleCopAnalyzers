:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.
:memo: Toto pravidlo je aktivní pouze pro C# 7.0 a novější.

## Příčina

Názvy prvků v typu n-tice by měly používat správné psaní velkých a malých písmen.

## Popis pravidla

Typy n-tic s pojmenovanými prvky by pro názvy prvků měly používat nakonfigurované psaní velkých a malých písmen (podrobnosti viz [Configuration.md](Configuration.md)). Informace o práci s n-ticemi v C# 7 naleznete v dokumentaci k [typům n-tic](https://docs.microsoft.com/en-us/dotnet/csharp/tuples).

Například následující kód by při výchozím nastavení vedl k porušení tohoto pravidla:

```csharp
public class ExampleClass
{
  public (int valueA, int valueB) ExampleMethod() // SA1316
  {
  }
}
```

Následující kód by nevedl k žádnému porušení:

```csharp
public class ExampleClass
{
  public (int ValueA, int ValueB) ExampleMethod()
  {
  }
}
```

Explicitní názvy prvků ve výrazech n-tic, například `(valueA: 1, valueB: 2)`, se kontrolují stejným způsobem. Názvy
prvků odvozené z výrazu, například `(valueA, valueB)`, se kontrolují pouze tehdy, když je povoleno
`includeInferredTupleElementNames` (viz [Configuration.md](Configuration.md)).

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, upravte psaní velkých a malých písmen v názvu prvku n-tice.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1316:TupleElementNamesShouldUseCorrectCasing", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1316 // Tuple element names should use correct casing
#pragma warning restore SA1316 // Tuple element names should use correct casing
```
