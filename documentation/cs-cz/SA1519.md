:memo: Toto pravidlo je nové ve StyleCop Analyzers a ve StyleCop Classic nebylo k dispozici.

## Příčina

Otevírací a uzavírací složená závorka víceřádkového příkazu C# byla vynechána.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když byla vynechána otevírací a uzavírací složená závorka víceřádkového příkazu.
V C# mohou některé typy příkazů složené závorky obsahovat volitelně. Patří sem například příkazy `if`, `while` a
`for`. Příkaz `if` lze například zapsat bez složených závorek:

```csharp
if (true)
    return
        this.value;
```

Přestože je to v C# platné, StyleCop vyžaduje složené závorky, pokud se příkaz rozkládá na více řádků, aby zvýšil
čitelnost a udržovatelnost kódu.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, převeďte příkaz porušující pravidlo na blokový příkaz.

## Jak potlačit porušení

```csharp
if (true)
#pragma warning disable SA1519 // Braces should not be omitted from multi-line child statement
    return
        this.value;
#pragma warning restore SA1519 // Braces should not be omitted from multi-line child statement
```
