## Příčina

Oddíl v hlavičce dokumentace XML pro prvek jazyka C# obsahuje prázdné řádky.

## Popis pravidla

Syntaxe jazyka C# umožňuje vkládat dokumentaci ke třídám a prvkům přímo do kódu pomocí hlaviček dokumentace XML. Úvod k těmto hlavičkám a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, když hlavička dokumentace obsahuje v rámci některého oddílu dokumentace jeden nebo více prázdných řádků. Například:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
///
/// Uses a simple form of string concatenation.
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

Místo vkládání prázdných řádků do dokumentace použijte značku `<para>` k označení odstavců. Například:

```csharp
/// <summary>
/// <para>
/// Joins a first name and a last name together into a single string.
/// </para><para>
/// Uses a simple form of string concatenation.
/// </para>
/// </summary>
/// <param name="firstName">The first name to join.</param>
/// <param name="lastName">The last name to join.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    return firstName + " " + lastName;
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odstraňte z hlavičky dokumentace prázdné řádky a případně je nahraďte značkami `<para/>`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1644:DocumentationHeadersMustNotContainBlankLines", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1644 // DocumentationHeadersMustNotContainBlankLines
#pragma warning restore SA1644 // DocumentationHeadersMustNotContainBlankLines
```
