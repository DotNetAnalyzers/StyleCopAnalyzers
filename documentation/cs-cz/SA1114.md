# SA1114: Parameter list should follow declaration

## Příčina

Seznam parametrů při volání nebo deklaraci metody či indexeru nezačíná na stejném řádku jako otevírací závorka ani na řádku bezprostředně následujícím.

## Popis pravidla

K porušení tohoto pravidla dochází, když je mezi otevírací závorkou a začátkem seznamu parametrů jeden nebo více prázdných řádků. Například:

```csharp
public string JoinName(

    string first, string last)
{
}
```

Seznam parametrů má začínat na stejném řádku jako otevírací závorka nebo na následujícím řádku. Například:

```csharp
public string JoinName(string first, string last)
{
}

public string JoinName(
    string first, string last)
{
}
```

## Jak opravit porušení

Řádky s komentáři mezi otevírací závorkou a prvním parametrem nebo argumentem jsou povoleny.
Prázdné řádky před těmito komentáři nebo za nimi nadále porušují toto pravidlo.

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby seznam parametrů začínal na stejném řádku jako otevírací závorka nebo na následujícím řádku.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1114:ParameterListMustFollowDeclaration", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1114 // ParameterListMustFollowDeclaration
#pragma warning restore SA1114 // ParameterListMustFollowDeclaration
```
