# SA1114: Parameter list should follow declaration

## Příčina

The start of the parameter list for a method or indexer call or declaration does not begin on the same line as the opening bracket, or on the line after the opening bracket.

## Popis pravidla

Porušení tohoto pravidla nastává tehdy, když there are one or more blank lines between the opening bracket and the start of the parameter list. For example:

```csharp
public string JoinName(

    string first, string last)
{
}
```

The parameter list should begin on the same line as the opening bracket, or on the next line. For example:

```csharp
public string JoinName(string first, string last)
{
}

public string JoinName(
    string first, string last)
{
}
```

## Jak opravit porušení

Řádky s komentáři mezi otevírací závorkou a prvním parametrem nebo argumentem jsou povoleny.
Prázdné řádky před těmito komentáři nebo za nimi nadále porušují toto pravidlo.

Chcete-li opravit porušení tohoto pravidla, ensure that the parameter list begins on the same line as the opening bracket, or on the next line.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1114:ParameterListMustFollowDeclaration", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1114 // ParameterListMustFollowDeclaration
#pragma warning restore SA1114 // ParameterListMustFollowDeclaration
```
