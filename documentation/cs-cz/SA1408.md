## Příčina

Příkaz jazyka C# obsahuje složitý podmíněný výraz bez závorek kolem operátorů.

## Popis pravidla

Jazyk C# používá hierarchii priorit podmíněných operátorů. V jazyce C# lze v jediném příkazu zřetězit více podmíněných operací bez uzavření kterékoliv z nich do závorek. Kompilátor pak podle předem stanovených pravidel automaticky určí pořadí a prioritu operací. Například:

```csharp
if (x || y && z && a || b)
{
}
```

Přestože je tento kód platný, není příliš čitelný ani udržovatelný. Aby mu vývojář plně porozuměl, musí znát základní pravidla priorit operátorů v jazyce C#.

Účelem tohoto pravidla je zvýšit čitelnost a udržovatelnost tohoto typu kódu a snížit riziko pozdějšího zavedení chyb tím, že vývojáře nutí vložit závorky a explicitně tak určit prioritu operátorů. Vývojář může například kód napsat takto:

```csharp
if ((x || y) && z && (a || b))
{
}
```

nebo

```csharp
if (x || (y && z && a) || b)
{
}
```

Od kombinátorů vzorů zavedených v C# 9 se se vzory `and` a `or` zachází stejně jako s `&&` a `||`. Jejich kombinace bez závorek vytvoří diagnostiku, například:

```csharp
if (value is > 0 and < 5 or 10)
{
}

if (value is (> 0 and < 5) or 10)
{
}
```

Vložení závorek činí kód zřetelnějším a srozumitelnějším a čtenář díky němu nemusí předpokládat, jak se má kód vyhodnotit.

## Jak opravit porušení

Vložte do podmíněného výrazu závorky, které určí priority operací.
