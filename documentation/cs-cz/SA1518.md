# SA1518: Use line endings correctly at end of file

## Příčina

Zakončení řádků na konci souboru neodpovídá nastavení projektu.

## Popis pravidla

Pro zlepšení rozložení kódu StyleCop vyžaduje jednotné zakončení řádků na konci souborů. Konkrétní požadavky projektu
lze nastavit v souboru **stylecop.json**. Další informace najdete v souboru [Configuration.md](Configuration.md).

Konkrétní nastavení je jedno z následujících:

* Povolit (výchozí): Soubory mohou končit jedním znakem nového řádku, ale není to vyžadováno.
* Vyžadovat: Soubory musí končit jedním znakem nového řádku.
* Vynechat: Soubory nesmějí končit znakem nového řádku.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, upravte zakončení řádků na konci souboru tak, aby odpovídalo nastavení
aktuálního projektu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1518:CodeMustNotContainBlankLinesAtEndOfFile", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
#pragma warning restore SA1518 // CodeMustNotContainBlankLinesAtEndOfFile
```
