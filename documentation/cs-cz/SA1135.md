# SA1135: Using directives should be qualified

:memo: Toto pravidlo je nové pro StyleCop Analyzers a v StyleCop Classic neexistovalo.

## Příčina

Direktiva `using` není plně kvalifikována.

## Popis pravidla

K porušení tohoto pravidla dochází, když se direktiva `using` nachází uvnitř oboru názvů a není plně kvalifikována.
Definice aliasů tříd ve stejném oboru názvů není nutné kvalifikovat.

Následující kód například porušuje toto pravidlo:

```csharp
namespace System.Threading
{
    using IO;
    using Tasks;
}
```

Následující kód žádné porušení nezpůsobí:

```csharp
namespace System.Threading
{
    using System.IO;
    using System.Threading.Tasks;

    using T = Thread;
}
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, použijte plně kvalifikovaný název oboru názvů.

## Jak potlačit porušení

```csharp
namespace N1.N2
{
#pragma warning disable SA1135 // Using directives must be qualified
    using N3;
#pragma warning restore SA1135 // Using directives must be qualified
}
```
