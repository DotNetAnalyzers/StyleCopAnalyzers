# SA1104: Query clause should begin on new line when previous clause spans multiple lines

## Příčina

Klauzule výrazu dotazu C# začíná na stejném řádku jako předchozí klauzule, přestože předchozí klauzule zasahuje do více řádků.

## Popis pravidla

K porušení tohoto pravidla dochází, když klauzule dotazu zasahuje do více řádků a následující klauzule začíná na stejném řádku, na kterém předchozí klauzule končí. Například:
```c#
    var elementNames =
        from element in GetElements
        (
            12,
			45
        ) select element.Name;
```

Klauzule dotazu lze správně zapsat takto:
```c#
    var elementNames =
        from element in GetElements
        (
            12,
			45
        )
		select element.Name;
```
 
## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přesuňte klauzuli na následující řádek.

## Jak potlačit porušení

```c#
#pragma warning disable SA1104 // Query clause should begin on new line when previous clause spans multiple lines
    var elementNames =
        from element in GetElements
        (
            12,
			45
        ) select element.Name;
#pragma warning restore SA1104 // Query clause should begin on new line when previous clause spans multiple lines
```
