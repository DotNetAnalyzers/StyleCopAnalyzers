# SX1101: Do not prefix local calls with 'this.'

## Příčina

Volání člena instance místní třídy nebo základní třídy má předponu `this.`.

## Popis pravidla

K porušení tohoto pravidla dochází, když kód obsahuje volání člena instance místní třídy nebo základní třídy s předponou `this.`. Výjimkou je případ, kdy název parametru metody koliduje s identifikátorem za předponou `this.`; v takovém případě se porušení nehlásí.
Toto pravidlo je ve výchozím nastavení zakázáno. Pokud jej povolíte, měli byste zakázat pravidlo [SA1101](SA1101.md).

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, odstraňte předponu `this.` před voláním člena třídy.

## Jak potlačit porušení

```csharp
#pragma warning disable SX1101 // DoNotPrefixLocalMembersWithThis
#pragma warning restore SX1101 // DoNotPrefixLocalMembersWithThis
```
