# SA1211: Using alias directives should be ordered alphabetically by alias name

## Příčina

Direktivy using s aliasem v souboru kódu C# nejsou seřazeny abecedně podle názvu aliasu.

## Popis pravidla

K porušení tohoto pravidla dochází, pokud direktivy using s aliasem nejsou seřazeny abecedně podle názvu aliasu.
Abecední řazení direktiv using s aliasem může přispět k čistšímu a čitelnějšímu kódu a usnadnit rozpoznání oborů názvů
používaných v kódu.

Globální direktivy `using` (C# 10) se analyzují nezávisle na místních direktivách `using`. Diagnostika a opravy porovnávají pouze direktivy, které obě používají nebo obě vynechávají modifikátor `global`.

## Jak opravit porušení

Chcete-li tento případ porušení opravit, seřaďte direktivy using s aliasem abecedně podle názvu aliasu.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.OrderingRules", "SA1211:UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1211 // UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName
#pragma warning restore SA1211 // UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasName
```
