# SA1143: Podmíněné výrazy musí být formátovány konzistentně

## Příčina

Podmíněný výraz (`?:`) zabírá více řádků, ale nepoužívá žádný z podporovaných způsobů formátování.
Toto pravidlo je ve výchozím nastavení povolené a hlásí upozornění na tokenu `?` nejvnějšího podmíněného výrazu.

## Popis pravidla

Použijte jeden z těchto tří způsobů formátování:

* Celý výraz na jednom řádku.
* Podmínka, která může zabírat více řádků, následovaná samostatnými, stejně odsazenými řádky začínajícími
  operátory `?` a `:`. Každá větev začíná na stejném řádku jako příslušný operátor a může pokračovat na dalších
  řádcích. Řádky s operátory musí být odsazeny více než poslední řádek podmínky.
* U řetězce podmíněných výrazů ve větvích pro nepravdivou podmínku obsahuje každý řádek jednu podmínku,
  operátor `?`, větev pro pravdivou podmínku a operátor `:`. Následující podmínky a poslední větev pro
  nepravdivou podmínku začínají na samostatných řádcích zarovnaných s první podmínkou.

Následující částečně zalomený výraz například porušuje toto pravidlo:

```csharp
var x = condition ? first :
    second;
```

Každý z následujících způsobů formátování je platný:

```csharp
var x = condition ? first : second;

var x = condition
    ? first
    : second;

var x = p == "Cat" ? "Animals" :
        p == "Bat" ? "Equipment" :
        p == "Fat" ? "Nutrition" :
        "None";
```

Rozvinutý formát také umožňuje pokračování větve na dalších řádcích. Každý takový řádek musí být odsazen
více než příslušný operátor `?` nebo `:`. Výjimkou jsou řádky začínající znaky `{` nebo `}`, které mohou být
zarovnány s operátorem:

```csharp
var x = condition &&
        otherCondition
            ? first * second +
                third * fourth +
                fifth * sixth
            : 0;
```

Rozvinutý formát také podporuje vnořené větve pro nepravdivou podmínku s dalším odsazením:

```csharp
var x = firstCondition
    ? first
    : secondCondition
        ? second
        : third;
```

Tabulátory se vyhodnocují podle nastavené šířky tabulátoru. Toto pravidlo neomezuje délku řádků.
Pravidlo nepřidává ani neodebírá závorky; výrazy v závorkách se kontrolují také.

## Jak opravit porušení

Oprava kódu nabízí jednořádkový a rozvinutý víceřádkový formát. Pro řetězce podmíněných výrazů ve větvích
pro nepravdivou podmínku nabízí také zarovnaný formát řetězce. Každá možnost podporuje hromadnou opravu (Fix All).

Tyto možnosti zachovávají blokové komentáře, které jsou vložené do řádku a nezabírají více řádků. Nenabízejí se,
pokud výraz obsahuje řádkové komentáře, víceřádkové komentáře, direktivy nebo víceřádkové tokeny literálů,
které nelze bezpečně převést na jeden řádek.

Samostatná oprava kódu zarovnává nedostatečně odsazené uzavírací závorky s odpovídajícími otevíracími závorkami
ve víceřádkových větvích. Podporuje výrazy kolekcí, inicializátory objektů a kolekcí, n-tice a výrazy
v závorkách. Například:

```csharp
static string[] Foo(bool condition) =>
    condition
        ? [
            "a",
            "b",
          ]
        : [];
```

Tato akce mění pouze bílé znaky před uzavíracími závorkami. Zachovává zalomení řádků, komentáře, prázdné řádky,
obsah literálů a ostatní formátování výrazů a používá nastavenou šířku tabulátoru a styl odsazení. Podporuje
hromadnou opravu (Fix All) a nabízí se pouze tehdy, když oprava odstraní porušení pravidla SA1143 v celém
podmíněném výrazu bez změny direktiv. Pokud není dostupná bezpečná oprava, upravte formát ručně, aniž byste
změnili obsah komentářů nebo literálů.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1143 // Podmíněné výrazy musí být formátovány konzistentně
// Kód obsahující porušení pravidla.
#pragma warning restore SA1143 // Podmíněné výrazy musí být formátovány konzistentně
```
