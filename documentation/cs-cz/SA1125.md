# SA1125: Use shorthand for nullable types

## Příčina

Typ Nullable byl definován bez použití zkráceného zápisu jazyka C#. Například místo upřednostňovaného `DateTime?` byl použit typ `Nullable<DateTime>`.

## Popis pravidla

K porušení tohoto pravidla dochází, když je typ Nullable definován bez použití zkráceného zápisu jazyka C#.

Toto pravidlo se vztahuje pouze na syntaxi nullable hodnotových typů. V kontextu `#nullable enable` se diagnostika SA1125 stále hlásí u dlouhých zápisů hodnotových typů, například `Nullable<int>` nebo `System.Nullable<DateTime>`, které se mají zapsat jako `int?` nebo `DateTime?`. Anotací nullable referenčních typů, jako jsou `string?` nebo `T?`, se toto pravidlo netýká.

V C# 12 a novějších se toto pravidlo vztahuje také na cíl direktivy aliasu `using`: `using MyNullableInt = System.Nullable<int>;` se má zapsat jako `using MyNullableInt = int?;`. Starší verze jazyka zde zkrácený zápis nepovolují, proto v těchto verzích pravidlo direktivy `using` nehlásí.

### Příklady

```csharp
#nullable enable

// The following fields will report SA1125 and should use the shorthand form
private Nullable<int> count;
private System.Nullable<DateTime> timestamp;

// These nullable reference type annotations are valid and do not require changes for SA1125
private string? name;
private T? value;
```

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, použijte zkrácený zápis nullable typu, například `int?`, `DateTime?` apod.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.ReadabilityRules", "SA1125:UseShorthandForNullableTypes", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1125 // UseShorthandForNullableTypes
#pragma warning restore SA1125 // UseShorthandForNullableTypes
```
