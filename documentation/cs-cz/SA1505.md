## Příčina

Za otevírací složenou závorkou v prvku, příkazu nebo výrazu C# následuje prázdný řádek.

## Popis pravidla

Pro zlepšení čitelnosti kódu StyleCop v některých případech vyžaduje prázdné řádky a v jiných je zakazuje. Díky tomu má kód jednotný vizuální vzhled, který může usnadnit rozpoznávání a čtení neznámého kódu.

Pravidlo se poruší, když za otevírací složenou závorkou následuje prázdný řádek. Například:

```csharp
public bool Enabled
{

    get 
    { 

        return this.enabled; 
    }
}
```

Výše uvedený kód vede ke dvěma výskytům tohoto porušení, protože na dvou místech následuje po otevírací složené závorce prázdný řádek.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, odstraňte prázdný řádek následující po otevírací složené závorce.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1505:OpeningBracesMustNotBeFollowedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
#pragma warning restore SA1505 // OpeningBracesMustNotBeFollowedByBlankLine
```
