# SA1001: Commas should be spaced correctly

## Příčina

Mezery kolem čárky v souboru kódu C# nejsou správné.

## Popis pravidla

K porušení tohoto pravidla dojde, když nejsou správné mezery kolem čárky.

Za čárkou má následovat jedna mezera, s výjimkou následujících případů.

* Čárka může být na konci řádku.
* Za čárkou nemá následovat mezera, pokud se používá v otevřeném obecném typu ve výrazu `typeof`.
* Čárka je součástí komponenty zarovnání interpolace řetězce. Například: `$"{x,3}"`
* Čárka následuje po podmíněné direktivě preprocesoru (#if, #elif, #else, #endif). Například:
  ```csharp
  partial struct Money : IFormattable
  #if !NETSTANDARD
      , ISpanFormattable
  #endif

Čárce nikdy nesmí předcházet mezera a nesmí se objevit jako první token na řádku.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, zajistěte, aby po čárce následovala právě jedna mezera a před čárkou nebyla žádná mezera.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.SpacingRules", "SA1001:CommasMustBeSpacedCorrectly", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1001 // CommasMustBeSpacedCorrectly
#pragma warning restore SA1001 // CommasMustBeSpacedCorrectly
```
