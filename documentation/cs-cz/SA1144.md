# SA1144: Znaky s nulovou šířkou v literálech musí být escapovány

## Příčina

Řetězcový nebo znakový literál obsahuje znak s nulovou šířkou zapsaný přímo ve zdrojovém textu.

## Popis pravidla

Znaky s nulovou šířkou jsou ve většině editorů neviditelné, takže je snadné je omylem vložit (například vložením textu z webové stránky) a později je obtížné je najít. Toto pravidlo hlásí řetězcové, znakové, UTF-8 řetězcové a interpolované řetězcové literály, které obsahují některý z těchto znaků:

* U+200B ZERO WIDTH SPACE
* U+2060 WORD JOINER
* U+FEFF ZERO WIDTH NO-BREAK SPACE

Pro každý token literálu se hlásí jedna diagnostika. Spojovač a nespojovač s nulovou šířkou (U+200D a U+200C) se nehlásí, protože jsou v některých písmech a v sekvencích emoji významné.

```csharp
string value = "a​b"; // contains an invisible U+200B between 'a' and 'b'
```

## Jak opravit porušení

Nahraďte každý znak s nulovou šířkou jeho escape sekvencí. Oprava kódu to provede u běžných řetězcových, znakových a (nedoslovných) interpolovaných řetězcových literálů:

```csharp
string value = "a\u200Bb";
```

Druhá oprava kódu místo toho znaky s nulovou šířkou odebere. Nenabízí se u znakových literálů, u raw řetězcových literálů (odebrání by mohlo změnit nebo narušit oddělovače) ani tehdy, když by odebrání znaku prodloužilo předchozí šestnáctkovou escape sekvenci `\x`. Doslovné řetězce a raw řetězcové literály escape sekvence nepodporují, proto se u doslovných řetězců nabízí pouze odebrání a u raw řetězců žádná oprava; chcete-li znak zachovat, sestavte řetězec pomocí escape sekvence, například zřetězením `"\u200B"`. Znaky s nulovou šířkou ve formátovacích klauzulích interpolace, například `$"{value:0\u200B}"`, se rovněž hlásí a opravují.

## Jak potlačit porušení

```csharp
#pragma warning disable SA1144 // Zero-width characters in literals must be escaped
// Code containing the violation.
#pragma warning restore SA1144 // Zero-width characters in literals must be escaped
```
