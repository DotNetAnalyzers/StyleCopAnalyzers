# SA1647: Include node does not contain valid file and path

:warning: Toto pravidlo bylo ze StyleCop Analyzers záměrně vynecháno. Další informace najdete v souboru [KnownChanges.md](KnownChanges.md).

## Příčina

Značka `include` v hlavičce dokumentace XML neobsahuje platné atributy `file` a `path`.

## Popis pravidla

Syntaxe jazyka C# umožňuje vkládat dokumentaci ke třídám a prvkům přímo do kódu pomocí hlaviček dokumentace XML. Úvod k těmto hlavičkám a popis jejich syntaxe najdete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments.](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments)

Jako alternativu k psaní dokumentace přímo do souboru s kódem lze dokumentaci pro více prvků umístit do samostatného souboru XML a poté na část tohoto souboru odkázat z hlavičky dokumentace prvku. Kompilátor pak dokumentaci daného prvku importuje ze zahrnutého dokumentu. Například:

```csharp
/// <include file="IncludedDocumentation.xml" path="root/EnabledMethodDocs" />
public bool Enabled(bool true)
{
}
```

K porušení tohoto pravidla dochází, když značce `include` chybí atribut `file` nebo `path` nebo když obsahuje nesprávně formátovaný atribut `file` či `path`.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte nebo opravte atributy `file` a `path`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1647:IncludeNodeDoesNotContainValidFileAndPath", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1647 // IncludeNodeDoesNotContainValidFileAndPath
#pragma warning restore SA1647 // IncludeNodeDoesNotContainValidFileAndPath
```
