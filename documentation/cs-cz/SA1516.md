# SA1516: Elements should be separated by blank line

## Příčina

Sousední prvky C# nejsou odděleny prázdným řádkem.

> :memo: Chování tohoto pravidla se může změnit podle konfigurace vlastnosti `blankLinesBetweenUsingGroups` v souboru **stylecop.json**. Další informace najdete v souboru [Configuration.md](Configuration.md).

> :memo: Globální direktivy using (C# 10) se považují za samostatnou sadu skupin direktiv using. Pokud `blankLinesBetweenUsingGroups` vyžaduje oddělení, pravidlo kromě obvyklého odsazení v každé sadě direktiv using vyžaduje prázdné řádky mezi blokem globálních direktiv using a následnými direktivami using na úrovni oboru názvů nebo příkazy nejvyšší úrovně.

## Popis pravidla

Pro zlepšení čitelnosti kódu StyleCop v některých situacích vyžaduje prázdné řádky a v jiných je zakazuje. Výsledkem je jednotný vizuální vzor v celém kódu, který může zlepšit rozpoznávání a čitelnost neznámého kódu.

Porušení tohoto pravidla nastává tehdy, když dva sousední prvky nejsou odděleny prázdným řádkem. Například:

```csharp
public void Method1()
{
}
public bool Property
{
    get { return true; }
}
```

Ve výše uvedeném příkladu nejsou metoda a vlastnost odděleny prázdným řádkem, proto by došlo k porušení tohoto pravidla.

```csharp
public event EventHandler SomeEvent
{
    add
    {
        // add event subscriber here
    }
    remove
    {
        // remove event subscriber here
    }
}
```

Ve výše uvedeném příkladu musí být metody `add` a `remove` události odděleny prázdným řádkem, protože `add` je víceřádková.

Při použití oborů názvů se souborem jako oborem z C# 10 má po deklaraci `namespace` následovat prázdný řádek před všemi deklaracemi `using`, `extern alias` nebo typů.

## Jak opravit porušení

Chcete-li opravit porušení tohoto pravidla, přidejte prázdný řádek mezi sousední prvky.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.LayoutRules", "SA1516:ElementsMustBeSeparatedByBlankLine", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1516 // ElementsMustBeSeparatedByBlankLine
#pragma warning restore SA1516 // ElementsMustBeSeparatedByBlankLine
```
