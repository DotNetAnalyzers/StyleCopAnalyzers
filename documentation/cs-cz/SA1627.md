# SA1627: Documentation text should not be empty

## Příčina

Záhlaví dokumentace XML prvku kódu C# obsahuje prázdnou značku.

## Popis pravidla

Syntaxe C# umožňuje vkládat dokumentaci tříd a prvků přímo do kódu pomocí záhlaví dokumentace XML. Úvod do těchto záhlaví a popis jejich syntaxe naleznete v následujícím článku: [https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/xmldoc/xml-documentation-comments).

K porušení tohoto pravidla dochází, pokud záhlaví dokumentace prvku obsahuje prázdnou značku. Například:

```csharp
/// <summary>
/// Joins a first name and a last name together into a single string.
/// </summary>
/// <remarks></remarks>
/// <param name="firstName">Other part of name.</param>
/// <param name="lastName">Part of the name.</param>
/// <returns>The joined names.</returns>
public string JoinNames(string firstName, string lastName)
{
    ...
}
```

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, přidejte do prázdné značky text dokumentace.



## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1627:DocumentationTextMustNotBeEmpty", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1627 // DocumentationTextMustNotBeEmpty
#pragma warning restore SA1627 // DocumentationTextMustNotBeEmpty
```
