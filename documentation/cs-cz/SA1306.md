# SA1306: Field names should begin with lower-case letter

## Příčina

Název pole v C# nezačíná malým písmenem.

## Popis pravidla

K porušení tohoto pravidla dojde, pokud název pole začíná velkým písmenem. Konstanty, pole `readonly`, která nejsou
`private`, a statická pole `readonly` mají vždy začínat velkým písmenem, zatímco pole `readonly` s přístupem `private`
mají začínat malým písmenem. Pole s přístupem `public` nebo `internal` mají také vždy začínat velkým písmenem.

Má-li název pole odpovídat názvu položky související s Win32 nebo COM, a musí proto začínat velkým písmenem, umístěte
pole do zvláštní třídy `NativeMethods`. Třída `NativeMethods` je každá třída s názvem končícím na `NativeMethods` a
slouží jako zástupný symbol pro obálky Win32 nebo COM. Pokud je položka umístěna ve třídě `NativeMethods`, StyleCop toto
porušení ignoruje.

> :warning: Toto pravidlo se od odpovídajícího pravidla v klasickém nástroji StyleCop liší následovně:
>
> Toto pravidlo kontroluje pouze názvy polí. SA1306 v klasickém nástroji StyleCop kontroluje pole, parametry a místní
> proměnné.

## Jak opravit porušení

Chcete-li porušení tohoto pravidla opravit, změňte název pole tak, aby začínal malým písmenem, nebo případně umístěte
položku do třídy `NativeMethods`.

## Jak potlačit porušení

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1306:FieldNamesMustBeginWithLowerCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1306 // FieldNamesMustBeginWithLowerCaseLetter
private int Field = 3;
#pragma warning restore SA1306 // FieldNamesMustBeginWithLowerCaseLetter
```
