# SA1315: Parameter names should match inherited names

:memo: This rule is new for StyleCop Analyzers, and was not present in StyleCop Classic.

## Cause

A parameter name in a method that overrides a base method or implements an interface member does not match an
inherited parameter name.

## Rule description

When a method overrides a base method, its parameter names should match the parameter names declared by the overridden
method. When a method implements an interface member, its parameter names should match the parameter names declared by
the interface member. Matching inherited parameter names keeps callers using named arguments consistent with the
abstract contract.

For an override, the immediate base method determines the expected parameter names. For an interface implementation,
the analyzer accepts a name that matches any implemented interface member with the same signature.

## How to fix violations

Rename the parameter to match the corresponding inherited parameter name. The code fix offers the available inherited
names when an implementation has more than one.

## How to suppress violations

```csharp
#pragma warning disable SA1315 // ParametersShouldMatchInheritedNames
public override void Method(int differentName)
#pragma warning restore SA1315 // ParametersShouldMatchInheritedNames
{
}
```
