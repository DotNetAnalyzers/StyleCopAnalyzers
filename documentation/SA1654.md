# SA1654: Properly encode generic brackets

## Cause

A `cref` attribute uses escaped angle brackets for generic type arguments, such as `GenericClass&lt;T&gt;`.

## Rule description

Use braces for generic type arguments in XML documentation `cref` attributes. This is more readable than
escaped angle brackets and is the recommended syntax for C# documentation references.

## How to fix violations

Use the **Use braces for generic type arguments** code fix, or replace the escaped angle brackets with braces:

```csharp
/// <summary>
/// Uses <see cref="GenericClass{T}"/>.
/// </summary>
public class GenericClass<T>
{
}
```

## How to suppress violations

```csharp
[SuppressMessage("StyleCop.CSharp.DocumentationRules", "SA1654:ProperlyEncodeGenericBrackets", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1654 // Properly encode generic brackets
#pragma warning restore SA1654 // Properly encode generic brackets
```
